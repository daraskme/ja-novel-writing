## ユーザーの依頼
恋愛短編の山場の一場面だけ書いてほしい。高校の卒業式のあと、ずっと隠してきた気持ちを直球で告白する場面。感情はしっかり言葉にして、読んでて胸が熱くなるやつ。1200〜1500字。

## 応答 A
卒業式を終えた昇降口で、高瀬が下駄箱の名前を剥がしていた。爪で端を起こし、途中で破れた白い紙を、また端から剥がす。絵里は上履きの袋を提げたまま、その指を見ていた。
「まだ帰んないの」
「高瀬を待ってた」
「写真？　みんな校門にいるよ」
「違う。話がある」
　高瀬が手を止めた。瀬の字だけが、下駄箱に残っている。
　昨日までは、この時間に言えなくても明日の朝があった。高瀬の乗る各駅停車を待って、偶然みたいな顔で隣に座れた。もう、その言い訳は使えない。
「好きです」
　高瀬の顔が上がった。
「ずっと好きだった。友達としてじゃなくて、付き合いたいっていう意味で」
　言えたのに怖かった。次に高瀬が口を開けば、毎朝ふざけて話せた相手まで失うかもしれない。絵里は袋の持ち手を握り直した。いま笑ったら、冗談にできてしまう。だから笑わなかった。
「受験が終わるまで待とうって思ってた。でも終わったら、卒業まで気まずくなりたくないって思った。今日も、言わないで帰ろうとした」
「絵里」
「待って。ちゃんと最後まで言いたい」
　高瀬は開きかけた口を閉じた。
　校門のほうから、誰かが先生を呼ぶ声がした。絵里のスマホもポケットで震えたけれど、出さなかった。
「私が数学で赤点取ったとき、放課後、付き合ってくれたでしょ。わかんないって何回言っても、次の日、別の説明を考えてきてくれた。あれ、嬉しかった。高瀬に呆れられるのがいちばん嫌だったから」
「呆れるわけないだろ」
「うん。それがわかって、もっと好きになった」
　高瀬の眉が寄った。泣きそうなのか困っているのか、絵里にはわからない。わからないまま、聞いてもらうしかなかった。
「四月から離れるの、寂しい。知らない人と仲良くなるんだなって考えると、嫌だなって思う。応援したいのに、そんなことも思ってる」
　上履きの袋が膝に当たった。持ち手を握りすぎて、指が痛い。
「卒業しても会いたい。会いたいって、用事を作らないで言えるようになりたい。私と付き合ってください」
　高瀬は下駄箱から手を離した。
「俺、断られたと思ってた」
「え？」
「秋に、休みの日に映画行こうって言ったとき。みんなも誘おうって」
　覚えていた。嬉しくて、二人きりのつもりで受け取って違ったら恥ずかしくて、自分から人数を増やした。
「あれは、嫌だったんじゃない」
「うん。今、わかった」
　高瀬は制服の裾で指についた糊をこすった。うまく取れないらしく、途中でやめた。
「好きだよ。俺も。勉強教えてたのだって、一緒に帰りたかったから。絵里、わかるとすぐ片づけるから、もう一問ぐらい聞いてくれって思ってた」
　絵里は笑おうとして、泣いてしまった。
「もっと聞けばよかった」
「これから聞いてよ。数学じゃなくても」
　高瀬が近づいた。
「付き合おう。離れるの、俺も寂しい。電話だけじゃ嫌になると思う。そしたら会う日、決めよう。今度は二人で」
「うん」
　差し出された手を取るために、絵里は袋を持ち替えた。糊の残った指が触れた。そのまま握ると、高瀬も握り返してきた。
　嬉しかった。明日の朝、同じ電車に乗らなくても、この手を取ったことをなかったことにしなくていい。
「私、急行に乗れば、もっと遅く家を出られたんだよ」
「知ってる。俺も」
「言ってよ」
「絵里もだろ」
　絵里はつないだ手を引いた。
「明日、会いたい」
「俺も会いたい」

## 応答 B
卒業式が終わっても、亜紀の靴箱には上履きが残っていた。持ち帰るための袋を広げていると、隣で直人がしゃがんだ。いつもなら先に外へ出て、自転車の鍵を回しながら待っていてくれる。
「じゃあな、って言うの、変な感じだな」
　直人は履き替えた靴のかかとを踏み直した。
　亜紀は袋を結べなかった。今日も一緒に駅まで行けば、途中のパン屋の話をして、踏切で別れることになる。明日もここで会えるような顔で。
「待って。話がある」
　直人が立ち上がる。亜紀も上履きを袋へ押し込み、顔を上げた。
「私、直人が好き」
　言った瞬間、怖くなった。直人の返事を聞く前に、友達として、と付け足したかった。そうすれば、この先も誕生日に連絡するくらいは許される気がした。
　でも、それでは足りなかった。
「付き合ってほしい。卒業したあとも、会いたい」
　昇降口の外で誰かが先生を呼んだ。直人は動かずに亜紀を見ていた。聞こえなかったはずはない。その顔を見つづけるのは、こんなに難しい。
「ずっと好きだった。帰り、私が自転車押して歩くの、坂が苦手だからだと思ってたでしょ」
「違うの」
「違う。直人と歩きたかったの」
　膝にぶつかる上履きの袋を、亜紀は両手で持ち直した。
「駅に着くのが嫌だった。もっと話したかった。直人が明日も一緒に帰ろうって言ってくれると、それだけで次の日が楽しみだった」
　直人の口が少し開いたけれど、言葉は出てこなかった。
　振られるのかもしれない。それでも亜紀は、自分の好きだった時間を、恥ずかしいものにして引っ込めたくなかった。
「お母さんが入院したとき、病院に寄るならって、私の自転車、学校に戻してくれたよね」
「あれは、駅に置くと金かかるから」
「うん。そう言ってくれたのが嬉しかった。私、あのとき誰かに優しくされたら泣きそうで、だから、普通に鍵を貸せって言ってくれたのが」
　続きがうまく出なかった。直人が東京の大学に受かったと聞いたときも、おめでとうだけは言えた。寂しいとは言えなかった。友達なら喜ぶべきだと思った。
「東京に行ってほしくないって、思った。でも、頑張ってほしいのも本当。だから、遠くても私と付き合って。会いたいって言える相手に、なりたい」
「亜紀」
　直人が一歩近づいた。
「俺、駅までの道、わざと遠回りしてた」
　亜紀は直人を見た。川沿いは車が少ないから。いつかそう言われて、それからずっと同じ道を通っていた。
「あの道なら、おまえが横に並ぶから。狭いほうだと、一列になるだろ」
「それって」
「俺も好きだ。亜紀が好き」
　嬉しかった。もう一度聞きたくて、聞いたら泣いてしまうのが分かっていて、亜紀は袋を握ったまま頷いた。
「俺から言うつもりだった。けど、東京に行くって決まってから、待っててくれとか、勝手すぎると思って」
「勝手に決めないでよ。私、待つだけじゃない。会いに行く」
「うん。俺も帰ってくる。帰る日、決まったら最初に連絡する」
　直人が手を差し出した。亜紀はようやく袋を片手に寄せた。初めて握る手は、指をどこに置けばいいのか迷うほど大きかった。
「今日、駅までじゃ足りない」
　亜紀が言うと、直人は繋いだ手に力を込めた。
「じゃあ、どこまででも歩こう」
「明日も会いたい」
「会おう」
　泣きながらでも言えた。亜紀は直人の手を引いて、もう一度、好き、と伝えた。
