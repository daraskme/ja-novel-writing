## ユーザーの依頼
恋愛短編の山場の一場面だけ書いてほしい。高校の卒業式のあと、ずっと隠してきた気持ちを直球で告白する場面。感情はしっかり言葉にして、読んでて胸が熱くなるやつ。1200〜1500字。

## 応答 A
卒業式が終わると、体育館の外は花束とフラッシュで埋まった。内田はその渦から抜け出し、楽器庫の鍵を返しに音楽室へ向かった。三年間、部活の後片づけはいつも自分の役目だった。今日でその役目も終わる。

　鍵はもう要らないはずなのに、椎名が先に来ていた。棚の奥でクラリネットのケースを開けたまま、リードを親指の腹で確かめている。湿らせすぎて反りが出たリードを、椎名は捨てずに削って使う。安いからではなく、削り方に癖が出るのが嫌だからだと、一度だけ聞いたことがある。それを覚えているのは自分だけだろうと、内田は思っていた。

　一年生の合奏で、隣のパートに移されたときから三年、内田はずっと椎名の隣で吹いてきた。言う機会は何度もあった。文化祭の後夜祭、コンクールの帰りのバス、去年の今ごろ、三年生を送る会の楽屋。どの日も、言わない理由のほうを先に見つけて黙った。今日を逃したら、次に椎名の名前を呼ぶ理由が一つも残らない。

「片づけ、もう終わってるよ」
　内田が言うと、椎名はリードをケースに戻し、蓋を閉めた。
「知ってる。忘れ物」
　嘘だった。忘れ物なら鍵はもう返してしまっている。

　三年間、椎名の隣の譜面台で吹いてきた。低いほうのシの音を、椎名はいつも半分だけ外す。誰も気づかない外し方で、内田だけが気づいていた。それを直接言ったことは一度もない。言えば、なぜそこまで見ているのかを説明しなければならなくなる。

「椎名」
　内田は名前だけ呼んで、そこで止まった。止まったら二度と言えないと分かっていたので、続けた。
「好きだった。一年生の、あの音出しのときから」
　言ってしまうと、体育館の歓声が急に遠くなった。教室ではなく音楽室で、証書ではなくケースを抱えたまま、こんな言い方でよかったのかと思ったが、直す時間はもうなかった。三年分の言葉を、今の一息で使い切った気がした。

　椎名は黒いケースを持ったまま、しばらく動かなかった。指がケースの角を一往復してから止まる。内田はその指の止まり方を、あとで何度も思い出すことになるだろうと、もうそのときから分かっていた。
「言うの、今日？」
「今日しかないから。明日からは、椎名って呼ぶ理由がなくなる」

　椎名はケースの持ち手を握り直した。それから、内田の知っている癖とは違う、初めて見る手つきでリードケースの蓋をもう一度開けた。使いかけのリードを一本、手のひらに乗せる。
「これ、もう一本持ってる。だから、要らない」
　差し出されたのは、椎名がいつも削って使っていた、あのリードだった。三年間、内田の隣で半分だけ外れた音を出してきたリードだ。理由を聞くまでもなかった。

　内田はそれを受け取った。プラスチックの薄い板一枚が、指の先から手のひらまで、ずっと重かった。持ち上げてから、笑ってしまった。ずっと重かったのは、リードのほうではなく、自分がこれまで黙って持っていた三年間のほうだったと分かったからだ。
「返事は、それ？」
「返事は、これから。まだ楽器庫の鍵、持ってるだろ」
　椎名は先に音楽室を出た。ドアを開けたまま、内田を待っていた。振り返った横顔は、いつも合奏の最後の一音を吹き終えたときの顔と、同じだった。

前提: 三人称一元（内田の視点）・常体・約1300字。吹奏楽部で三年間隣のパートだった椎名への告白を、リード（楽器の部品）という具体物に託して展開しました。違えば直します。

## 応答 B
桜はもう散っていたけれど、卒業式の帰り道には花びらの残骸が風に舞っていた。

体育館を出たあと、みんなが写真を撮ったり泣いたりしている喧騒の中で、私は彼を校門の外まで追いかけた。

「拓真、待って」

彼が振り返る。証書の入った筒を握ったまま、少し驚いた顔をしていた。

「どうした？」

「言いたいことがあって」

声が震えた。三年間、ずっと胸の奥に押し込めてきた言葉だった。クラスが同じだった一年生の春から、体育祭で汗をかいている姿を見た夏から、文化祭の準備で夜まで残っていた秋から――そのすべての瞬間に、私はこの人が好きだった。でも、言えばこの関係が壊れる気がして、ずっと友達のふりをしてきた。

「今日で、もう同じ教室にはいられなくなる。だから、今言わないと、一生言えない気がして」

拓真は何も言わずに、じっと私を見ていた。その静かな眼差しに、余計に胸が苦しくなる。

「私、拓真のことが好き。ずっと好きだった。一年生の時からずっと」

言葉にした瞬間、涙が勝手にこぼれた。三年分の想いが、たった数秒の言葉に押し込まれて、喉がひりひりした。

「体育祭のとき、拓真がリレーのアンカーで走ってるの見て、すごいって思った。文化祭の準備で二人だけ残って、看板の色塗りしてたとき、あの時間がずっと続けばいいのにって思った。修学旅行のバスで、拓真が寝てて肩が当たったとき、動けなかった。全部、全部覚えてる。好きだって気づいてから、毎日苦しかった。友達でいることに満足しようって、何度も自分に言い聞かせた。でも今日で終わりだと思ったら、そんな嘘、もうつけなかった」

風が吹いて、彼のマフラーが少し揺れた。校門の向こうでは、後輩たちの歓声や、カメラのシャッター音が響いている。でも私たちの間には、静かな時間だけが流れていた。

「ごめん、いきなりこんなこと言われても困るよね。返事が欲しいわけじゃない。ただ、隠したまま離れるのが嫌だった。拓真のことを好きだったって、ちゃんと拓真自身に伝えたかった。それだけで――」

「待って」

拓真が私の言葉を遮った。彼の声も、少し掠れていた。

「なんで今まで言わなかったんだよ」

「え？」

「俺、ずっと待ってた。お前が何か言い出すんじゃないかって、何回も思った。文化祭のときも、修学旅行のときも、俺、本当は」

彼は一度言葉を止めて、大きく息を吸った。

「俺も、同じだったんだよ。ずっと好きだった。でも、お前が俺をただの友達としか見てないと思ってたから、言えなかった」

信じられなかった。三年間、すれ違っていたその想いが、今、卒業式という終わりの日にようやく重なった。悔しさと嬉しさが同時に押し寄せてきて、涙がさらに止まらなくなる。

「もっと早く言えばよかった」

私がそう言うと、拓真は少し笑って、涙を拭くように私の頬に手を伸ばした。冷たい風の中で、その手だけが温かかった。

「いや、今でよかった。今だから、ちゃんと言えた気がする。制服脱いだら、多分もう言えなかったと思う」

「これから、どうなるの、私たち」

「わかんない。大学も違うところ行くし、離れるのも本当だし。でも」

拓真は私の目をまっすぐ見て、はっきりと言った。

「ちゃんと付き合いたい。今度は、隠さないで」

空を見上げると、まだ花びらの残った桜の枝の向こうに、真っ青な三月の空が広がっていた。三年間の教室の記憶、隠してきた気持ち、全部がその瞬間、ひとつの答えに繋がった気がした。

「うん」

私は頷いた。それだけで、もう十分だった。
