## ユーザーの依頼
恋愛短編の山場の一場面だけ書いてほしい。高校の卒業式のあと、ずっと隠してきた気持ちを直球で告白する場面。感情はしっかり言葉にして、読んでて胸が熱くなるやつ。1200〜1500字。

## 応答 A
卒業式が終わっても、駐輪場には人がまだ残っていた。花束を抱えた保護者の列が校門へ流れていくのを横目に、颯太は自分の自転車のスタンドを蹴って直しながら、咲のサドルにかけたビニールの雨よけを外した。雨の予報が出た朝はいつもこれをかけに来た。裾がほつれて、縫い直した跡が重なっている。三年間、一度も本人に気づかれなかった。咲の鍵は冷えた朝ほど渋くなる。今日も一度で回らないだろうと思いながら、颯太は自分の鍵を先に差した。式のあいだ、隣の列に咲がいたのに、話す機会は一度もなかった。今日を逃したら、次に会うのがいつになるか分からない。

　咲が来た。証書の筒を荷台に括りながら、こちらを見もせずに言う。
「それ、もう外していいよ。明日から乗らないし」

　颯太は雨よけを丸めて、鞄の底に押し込んだ。捨てるつもりはなかった。
「咲」
「なに」
「一年の入学式の朝、おまえの自転車、チェーンが外れてて。おれ、直すの下手で、えらい時間かかった」
「覚えてる。おかげで二人とも遅刻した」
「それから毎朝、先にここに来た。おまえより早く来て、鍵を開けとくくらいしか、できることなかったから」
「知ってたよ、それくらい」
「言わないから、おれも黙ってた。言ったら、これが終わる気がして」

　咲は証書の筒を握り直した。何か言おうとして、やめた。校門のほうから、担任の呼ぶ声がまだ続いている。

「東京、行くんだろ」
「うん。四月から」
「行く前に言っとく」

　颯太は一度、雨よけを押し込んだ鞄の底を握った。声を出す前に、喉のあたりで一拍つまった。
「好きだった。一年のときから、ずっと」

　言い終えると、耳の裏まで熱くなった。自分の声が、いつもより低く、他人のもののように聞こえている。取り消せる言葉ではなかったので、取り消さなかった。

　咲は少しの間、雨よけの入った鞄のあたりを見ていた。
「知ってた、と思う。二年の頃から」
「じゃあ、なんで黙ってた」
「颯太が言わないから。言ったら、あたしも同じことになる」
「同じ」
「毎朝ここで待たれなくなる。それが怖かった」

　颯太は自転車のハンドルを握った手を、少しだけ動かした。
「終わらせたくないから、言った」

「あたしも、好き」
　咲は筒の紐を結び直しながら、そう言った。目は合わせなかったが、声は震えていなかった。
「じゃあ、付き合ってくれ。東京と、こっちで」
「距離、あるよ」
「新幹線の時刻表、もう調べた。月に二回は行く。夏休みは、二週間そっちにいる。バイトも今日、探すつもりで来た」
　咲はやっと顔を上げた。
「気が早い」
「三年、遅かった分」
「うん。付き合う」

　咲は笑って、颯太の鞄から雨よけの端を少しだけ引き出した。
「これ、あたしが持ってる。忘れ物にしとくから」
「なくすなよ」
「なくさない。次に会うとき、返す」

　颯太はスタンドを起こした。咲もスタンドを起こしながら、鍵を差した。今日は一度で回った。
「ほら、直った」
「おれが直したわけじゃない」
「彼氏の力ってことにしとく」
　咲はサドルにまたがった。颯太も自分の鍵を回し、隣に並んだ。

## 応答 B
卒業証書の筒を握る手が、汗で滑った。

体育館を出た生徒たちが桜の残り葉の下でそれぞれの春に散っていく中、俺は誰もいない渡り廊下で彼女を待っていた。制服のボタンを外す最後の日。もう二度と、この場所で彼女の名前を呼べないかもしれない。それだけが怖かった。

「渡辺、こんなところにいたんだ」

声をかけられて顔を上げると、涼が卒業アルバムを抱えて立っていた。目の縁が少し赤い。泣いていたのだろう。

「話したいことがあって」

「私も。先生たちに挨拶回らないと――」

「待って」

彼女の腕を掴んだ。自分でも驚くくらい強く。涼が息を止めたのが分かった。

「三年間、ずっと言えなかったことがある」

風が渡り廊下を吹き抜けて、彼女の髪が揺れた。今まで何度も言葉にしようとして、その度に喉の奥に押し込んできた。体育祭で肩を組んで応援した時も、文化祭の準備で二人だけ教室に残った夜も、受験の相談で電話越しに彼女が泣いた時も。全部、言えなかった。

「俺、一年生の入学式の日からお前のことが好きだった」

言ってしまった。もう戻れない。

「席が近くて、消しゴム借りたのがきっかけで、それだけだったのに、なんでか目が離せなくなって。お前が誰かと笑ってるだけで胸が痛くなって、自分でも馬鹿みたいだと思ってた。友達でいる方が絶対安全だって分かってたから、ずっと隠してきた。告白して壊れるより、隣にいられる今のままがいいと思ってた」

涼は何も言わず、俺の目をじっと見ていた。逃げ場のない視線だった。

「でも今日で終わりなんだよな。今日で高校が終わって、俺たちはたぶん別々の場所に行く。このまま黙ってたら、一生後悔する。お前が誰かの隣で笑ってるのを、遠くから見て『言えばよかった』って思う自分が、今からもう見える。それが嫌なんだ」

指先が震えていた。それでも止まらなかった。

「好きだ。友達としてじゃない。お前が好きだ、涼。今さらこんなこと言われても迷惑かもしれないけど、言わずに卒業したら、俺は俺を一生許せない気がした。だから聞いてほしかった。返事はいらない。今日じゃなくてもいい。でも、伝えたかった。ずっと、隠しててごめん」

しばらく、渡り廊下には風の音だけが流れた。涼は卒業アルバムを胸に抱えたまま、唇を噛んで、それから小さく笑った。泣きそうな笑い方だった。

「遅いよ、馬鹿」

「え」

「三年間、気づかないわけないでしょ。私だってずっと待ってたのに。お前が言ってくれるの、ずっと待ってた」

そう言った瞬間、涼の目から涙がこぼれた。俺はその涙を見て、自分がどれだけ長く、どれだけ多くの言葉を飲み込んできたかを思い出して、胸の奥から何かが崩れるように熱くなった。

「じゃあ、返事は今もらってもいいか」

「うん」

たった一言だったのに、三年分の重さが全部そこに乗っているように聞こえた。桜の葉が一枚、二人の間に落ちて、渡り廊下の光の中で回った。俺たちはまだ何も始まっていないのに、もう何かが確かに変わったのが分かった。

「これから、ちゃんとやっていこうな」

「うん。ちゃんと」

涼が笑って、俺も笑った。卒業式の日に、俺たちはようやく本当のスタートラインに立った。
