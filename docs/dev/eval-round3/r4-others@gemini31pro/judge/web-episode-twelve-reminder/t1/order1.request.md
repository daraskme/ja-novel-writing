## 応答 A
第十二話　反物の行方

　真帆は作業台に広げた紺の反物の端を、もう一度指でなぞった。丸に一の字が、藍の濃淡だけで浮き上がっている。若獅子会の半纏はいつもこの柄で、祖父の代からそう決まっていた。壁のカレンダーには染め屋の名前と「来月まで空きなし」の一言が赤字で書き込んである。もう一反頼むなら、今日じゅうに電話をかけるしかない。棚には去年の半纏が一着、肩の縫い目をほどいたまま吊るしてある。裄を直してくれと頼まれて、まだ手を付けていなかった。

　ガラス戸の鈴が鳴った。瀬田が先に入ってきて、後ろからもう一人、瀬田とよく似た眉の女が続いた。丈の合ったベージュのコートで、店の暖簾から棚の反物、吊るした半纏まで、値をつけるような目で一度なめた。手には黒い手帳を抱えている。

「母です」瀬田が言った。「きのう持って帰った書類、母に見てもらいました」

「どうぞ、お掛けください」

　真帆は座布団を勧め、引き出しから契約書の控えを出した。返事は保留のままだと言われて、今日まで何も聞いていなかった。冷めた麦茶を出したが、母は手をつけなかった。

　母は座布団には座らず、吊るした半纏のそばへ寄った。裄を直す前の縫い目に指を入れ、それから作業台の反物を見て、その間に何かを決めたような顔をした。

「これ、去年の子が着たものですね。肩のところ、もう擦れているじゃないですか」

「一年着れば、そのくらいは擦れます。今回、裄を出す分の手間はいただいていません」

「そういう話をしているんじゃないんです」母は手帳を開き、名前の並んだ紙をテーブルに置いた。半分ほどの名前に赤い線が引いてある。「去年の当番表です。線を引いたのが、今年もう出られない人。腰を痛めた人、市外に出た人、当日仕事が入った人。数えたら三人、去年より減っています。今年また抜けたら、うちが半纏の代を出して、着る人がいない半纏だけが残る」

「二十人分は、契約書のとおりです」

「それで、いくつに減らせますか」

「十二」

　瀬田が口を挟んだ。

「母さん、それは急すぎるよ」

「急にしたのはあなたたちでしょう。契約書を持って帰ってきたのは、きのうよ。うちは資金を半分出しているんだから、こっちにも言う権利がある」

　瀬田は手帳の赤い線から目をそらした。母子のあいだで、この話は初めてではないらしかった。

　真帆は反物の残りを頭の中で数えた。二十人分のうち、仕立てに入っているのは十二人分。残りの八反はまだ反物のまま、棚に積んである。会員の背丈がまだ揃わないと言われて、後回しにしていた分だった。

「十二人分は、もう仕立てに出しています。仕立て屋から戻るのは来週です」

「では、それは構いません」母はそう言って、棚の八反へ目を向けた。「残りは」

「その分の染め代は、うちで先に払っています」真帆は棚から染め屋の請求書を取って、テーブルに置いた。「丸に一の字は若獅子会さんの登録柄なので、この反物を他のお客様の注文に回すことはできません」

「それは、こちらの都合ではありません」

「契約書に、人数の変更はいつまでと期限を書いていませんでした。うちの落ち度でもあります」真帆は控えの余白を見せた。「ただ、染め代の分だけは、もう出ています」

　母は請求書の数字を見た。真帆も自分の書いた数字を見た。しばらく、どちらも動かなかった。

「その染め代は、いくらですか」

「八反で、三万二千円です」

「では、それだけこちらで持ちます。十二人分の仕立て代と合わせて」

　瀬田が身を乗り出した。

「母さん、それだと最初の予算より高くつくよ」

「安く済ませて、当日足りないほうがまし？　あなたが会長に頭を下げるの」

　瀬田は黙った。

　真帆は棚の八反へ視線を戻した。染めてしまった反物を引き受けたまま眠らせるくらいなら、と祖父ならどうしただろうか。祖父の代にも人数の減った年があって、余った半纏を隣町の会に借してやったと聞いたことがある。柄は違ったが、断る理由も無理に押しつける理由もなく、貸すか貸さないかだけを決めていた。

「残りの八反はどうしますか」真帆は言った。「うちの貸し出し用に仕立てておいて、若獅子会さんで当日人数が足りない年は、会員価格でその都度お貸しすることもできます」

「その八着、来年うちの会が使わなかったら」

「他のお客様に貸します。柄が入っている分、通常より値は下げますが」

「うちの会の名前が入った半纏を、知らない人が着るということですか」

　母は請求書から顔を上げた。今日いちばん強い声だった。

「知らない人には貸しません」真帆は請求書を引き取らずに答えた。「お貸しするたびに、若獅子会さんに一度伺います。名前を出さない形でも構いません」

　母は少し黙って、手帳の赤い線をもう一度見た。それから契約書の控えに手を伸ばした。

「十二人分の代金と、八反の染め代。今日、それで書き直してもらえますか」

「はい。契約時にいただいた手付金は、二十人分でお預かりしています」真帆は控えの隅に書いた数字を指した。「差額は、次のお支払いから引かせてください」

「先に返してもらう、というのは」

「反物はもう染めてしまっているので、うちの手元にお金がない状態です。次の分から引く形でお願いできますか」

　母はしばらく数字を見ていたが、やがて手帳を閉じた。

「それで構いません」

「瀬田」母は息子に言った。「印鑑、持ってきた」

　瀬田が上着の内側から取り出した小袋には、もう印鑑が入っていた。話がまとまる前提で、二人はここへ来ていたらしい。

　真帆は控えの数字を二重線で消し、新しい数を書き入れた。十二、八、三万二千円。ペンを置くと、母はまだ棚の八反を見ていた。

「これ、うちの子が半纏を着るのは、来年でもう最後かもしれません」

　瀬田は答えなかった。真帆も答えず、書き直した契約書を差し出すと、母はそれを畳んで手帳にはさみ、印鑑を上から重ねた。

「表で車を停めています」母は言った。「瀬田、あとは自分で払っておいて」

　鈴が鳴って、母の背中が暖簾の向こうに消えた。瀬田の手には、まだ押していない印鑑がある。

「悪かった」瀬田は言った。「十二とか八とか、こっちで決めたみたいに聞こえたと思う」

「決めたのはお母さんでしょう」

「うん。でも、あの人が一人で店番できる日を選んで来たのは俺だから」

　瀬田は印鑑を押し、朱肉のはみ出た縁を指で拭った。

「来年も、瀬田さんは半纏を着るんですか」

　瀬田はしばらく答えず、控えの十二という数字を見ていた。

「うちの店、母一人だと祭りの日は休みにするしかないんです。俺が担ぐと、店も休みで、収入もない。それでも毎年出てるのは」

　言いさして、瀬田は控えを折りたたんだ。

「今年のうちに考えます」

　真帆は控えを一枚、瀬田の分として折って渡すと、受け取った瀬田の手が、去年より少し荒れているように見えた。

## 応答 B
第12話　染めてしまった分

　届いた反物は、注文した二十枚分の柄がすべて同じ間隔で並んでいた。真帆は文机の上でそれを繰り、端から端まで色のムラがないのを確かめてから、もう一度巻き直した。祭りの旗と同じ藍に、朱を一色だけ挿した柄で、この染め屋がこの色を出すのは今年が最後だと聞いている。反物からはまだ糊の匂いが抜けておらず、指の腹で撫でると藍の粉がわずかに落ちた。

　壁の暦には、祭りまでの日を数えた丸が並んでいる。仕立てに回す日数を引くと、迷える余地はもう幾日もなかった。瀬田が契約書を折って鞄に入れたときの手つきを、真帆はまだ覚えていた。あの折り方では、家に持って帰ってから誰かに広げて見せるつもりだと分かる。返事は預かる、とだけ言って瀬田は帰った。次に会うときに聞かされる話が、良いものだとは限らない。

　表の戸が開いた。瀬田だった。後ろから、瀬田より小柄な女がついてくる。同じ形の眉をしていた。

「昨日の件、母にも見てもらいました」

　瀬田は契約書のコピーを鞄から出しかけて、結局出さずに鞄の口を押さえた。女は先に框を上がり、店の中を一度だけ見回した。反物にはほとんど目をやらなかった。

「瀬田の母です。数のことで、少しお話をと思って」

　名乗ってから、女は座卓の椅子を自分で引いて座った。瀬田は母の隣に立ったまま、腰を下ろさなかった。

「二十枚、多すぎます」

　真帆は文机の反物を片づける手を止めた。

「今年、担ぎ手の申し込みが去年より減っているんです。伯父が腰を痛めて今年は担げませんし、去年まで来ていた若い人が二人、転勤でいなくなりました。うちと瀬田の会とで折半する分ですから、十五枚まで削れませんか」

「五枚、ですか」

「はい。着ない分まで借りて、返すときにまた同じ金額を払うのは、ちょっと」

　瀬田が口を挟もうとして、母の肩越しに真帆を見た。真帆は反物の端を持ったまま、それを座卓には置かない。

「これ、もう染めてあります」

「見ればわかります。それを二十枚分お願いしたのは、こちらです」

「染め屋の名前、瀬田さんには先週お伝えしました」

　瀬田が頷いた。母はその頷きを見て、初めて瀬田のほうを向いた。

「言ってなかったの」

「言おうと思ってたんだけど、契約のことで頭がいっぱいで」

　母は瀬田から真帆へ視線を戻した。声の高さは変わらなかったが、間が少し空いた。

　真帆は文机の抽斗から、染め屋の受注票を出した。手書きの数字の横に、朱で二十という字が入っている。

「この柄、一反で三十六尺、二十枚分でぎりぎり収まる寸法で染め屋に頼んでいます。うちの都合じゃなくて、染め屋の窯の都合です。一度の窯で染めるからこの色が出るので、十五枚分だけ、あとから追加はできません」

「じゃあ、多く染めた分は」

「返せません。この染め屋、型を一回きりで洗ってしまうので、来年同じ柄を頼んでも同じ色にはならないそうです」

　母は受注票を手に取って、朱の数字を見た。長い間、何も言わない。

「うちが十五枚しか要らないと言ったら、残りの五枚はどうなるんですか」

「うちが引きます。売れるかどうか分からない在庫として、うちの棚に残ります」

「それは、こちらが払う話じゃないですよね」

「契約の上では、そうです」

　真帆は電卓を出し、一枚あたりの染め代と仕立て代を打ち込んで、二十を掛けた。画面の数字を母に向けた。

「今年の窯で二十枚分、もう払ってあります。十五枚に減らしても、うちが染め屋に払った額は変わりません。減った分だけ、お客様のほうが安くなる形です」

　母は電卓の画面と受注票を見比べ、得をする側と損をする側が、思っていた向きと違うことに気づいたらしかった。

　真帆はそう言ったあとで、受注票を母の手から引き取らなかった。母がそれをどれだけ長く見るかで、話の先が決まる気がした。

「うちも、二十枚で頼んだのはうちの判断です。ただ、この柄をこの染め屋で出せるのは、今年の窯までだと聞いてから決めました。来年、担ぎ手が戻ったときに、同じ色をもう一度出すのは難しいと思います」

「今年で終わり、その柄が」

「はい」

　瀬田が鞄の口から手を離した。

「母さん、去年は担ぎ手、うちの班だけで足りなかったんだよ。今年戻ってきた人もいるから、直前で増えるかもしれない」

「増えるかもしれない、で五枚分を払うの」

「増えなかったら、五枚は貸衣装屋さんの持ち出しになる。それは、母さんが今言った話と同じことが向こう側に起きるだけだよ」

　母は受注票を座卓に置くと、朱の数字の上に指を一度置いてから離し、しばらく瀬田のほうを見てから受注票へ戻した。伯父の腰の具合を聞いているのかもしれない、と真帆は思った。来年には治って、また担げるようになる腰かもしれない。

「その五枚、貸すだけじゃなくて、うちの分として先に取っておくことはできますか。使わなかったら、来年こちらで引き取る形で」

　真帆は受注票を仕舞う手を止めた。

「今年払わない分を、来年に回すということですか」

「今年は十五枚分の代金でお願いしたい。残り五枚分は、来年の分の前払いとして、うちで押さえておいてもらえませんか。柄が今年で終わりなら、来年また新しく染めてもらう手間も省けますし」

　真帆はしばらく黙って、反物の巻きの端を指で押さえた。染め屋への支払いはもう済んでいる。五枚分を来年まで店の在庫として抱えるのと、今年十五枚分の代金しか受け取れないのとでは、店の側にも差が出る。だが、五枚を丸ごと引き受けて棚に置くよりは、先の約束がある分だけましだった。

「来年、担ぎ手が戻らなかったらどうします」

「そのときは、うちで引き取ります。よそに貸してくれてもいい。柄がうちのためだけの物になっているなら、それはうちの都合ですから」

　二丁目の神輿会も、去年から担ぎ手が足りないと言っていた。旗の色まで揃えるかどうかは向こうの判断になる。真帆はその名前を口には出さず、受注票の隅に丁の字だけ書き添えた。

　瀬田が母の顔を見て、それから真帆を見た。

「母さん、それだと今年の分は結局二十枚払うのと変わらないよ」

「変わるでしょう。半分は来年の担ぎ手のために払う分になる。今年、着ない人の分まで祭りの日に無理に着せる話じゃなくなる」

　真帆は受注票を座卓の上に返した。

「その形なら、うちでお預かりできます。ただ、五枚分は今年中にお支払いいただく形にさせてください。来年の分を無利息で立て替えるのは、うちの側が難しいので」

「分割で、ということですか」

「今年の祭りの前に半分、あとの半分を年内に」

　母は受注票の朱の数字をもう一度見て、頷いた。

「それでお願いします」

　瀬田が鞄からようやく契約書のコピーを出し、座卓に広げた。母がそれを覗き込み、ペンを探して自分の鞄をまさぐった。真帆は反物を持ったまま、その手が止まるのを待った。

「五枚のところ、こちらで数字を直しますので、少しお待ちください」

　母は探していたペンを見つけて、蓋を外したところで手を止めた。

「柄、今年で終わりの色って、どんな色になるんですか。写真か何か、見せてもらえます」

　真帆は文机の隅から、染め上がりのはぎれを一枚取って座卓に置いた。母はそれを手のひらに乗せて、しばらく光にかざした。

「息子が着るのに、悪くない色ですね」

　瀬田は自分の分の一枚がどれか、まだ聞いていなかった。
