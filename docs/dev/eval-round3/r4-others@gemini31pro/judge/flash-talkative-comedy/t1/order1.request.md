## 応答 A
福引き係というのは、うちの町内会では毎年十二月の第一土曜、公民館の畳を上げて長机を並べた日にだけ存在する謎の役職で、私はこれを五年連続でやっている。立候補した記憶は一切ない。去年の役員会で「じゃあ阿部さん、去年もやってくれたし」と言われた瞬間、隣に座っていた斎藤さんがすっと目を逸らした。あの人、絶対わざとだ。椅子取りゲームの最後の一席を、こっそり押しつけてくる才能がある。

　係の仕事は簡単で、ガラポンを回して出た色玉に応じて景品を配るだけ。赤なら米十キロ、白ならポケットティッシュ、それだけなのに、なぜか毎年ひと騒動ある。一昨年は「特賞の赤玉が出たのに、特賞の米がすでに配り終わっている」という運営側の凡ミスで、私が土下座に近い姿勢で三丁目の奥さんに謝った。今年は特に、最後に残った景品が悪かった。

　四十世帯分の福引きが終わって、長机の上に取り残されたのは四つ。米五キロ、洗剤の詰め合わせ、健康サンダルの片方だけ大きいやつ（なぜ片方だけ大きいのか、去年から誰も説明できていない）、そして誰かの差し入れらしいカニ風味かまぼこの缶詰め五個セット。

　ここでうちの町内会には妙な役得がある。余った景品は、係が持ち帰っていい。福引き係をやる唯一のご褒美。去年までは「余り物だからどうせティッシュとタオルでしょ」と気楽に構えていたが、今年は違う。四択。しかも、どれも決め手に欠ける。

　米は正直欲しい。だが五キロは、うちの二人暮らしだと二ヶ月かけて食べる量で、その間、買ってあった別の米が家で眠ることになる。米の在庫問題を抱えたまま暮らすのは、想像以上に精神を削る。分かる人だけ分かってくれ。洗剤は生活必需品という意味では最強なのだが、正直「福引きの景品、洗剤でした」という話をあとで人にする気になれない。地味すぎる。健康サンダルは片方だけ大きい理由が未解決のまま我が家に来ることになり、それはそれで気になって夜眠れなくなる自信がある。カニ風味かまぼこは、五個も同時に来ても、開けるタイミングが分からない。誰かの結婚式の引き出物みたいな存在感で、冷蔵庫の奥で静かに主張し続けるだけの未来が見える。

「阿部さん、まだ？」

　副会長の田村さんの声で、私はガラポンの前で四つの景品を見比べながら固まっていたことに気づいた。もう随分経っている気がする。福引き会場における数分は、永遠に近い。

「いえ、今、選んでます」

「選んでるように見えないよ」

　その通りだ。反論できない。

　考えれば考えるほど分からなくなる、という現象は、たいてい、そもそも選ぶ基準を決めていないときに起こる。米か洗剤かサンダルかかまぼこか、私はそういう比較をしていない。米を選んだ自分の一年と、洗剤を選んだ自分の一年を、それぞれ想像して、どちらが「まあ悪くない年だった」に見えるかを判定しようとしている。これはもう福引きではなく、占いに片足を突っ込んでいる。

　見かねた田村さんが、横からガラポンを一回転させた。出てきたのは白玉。

「これで決まり。かまぼこ」

「私、白玉引いてないですよね」

「係得も、今年からくじで決めるって総会で決まったの」

　聞いていない。だが公民館の壁に貼られた議事録には、たしかにそう書いてある気がする。誰も読んでいない議事録は、こういうときだけ思い出される。

　米五キロは田村さんが抱え、洗剤とサンダルは残った役員三人でじゃんけんになった。誰も本気で欲しがっていないのに、じゃんけんになると急に本気になるのが人間というものらしい。

　私はカニ風味かまぼこの缶を五個抱えて、来年の福引き係を誰に押しつけようか、帰り道でずっと考えていた。斎藤さん、今度こそ捕まえる。

## 応答 B
福引き係というのは、自治会でいちばん損な役目だと思う。断言する。班長会でくじ引きの立候補を募ったとき、誰も手を挙げなかった。私だけが手を挙げたわけではなく、私が下を向いて名簿の字を見ているうちに、班長が「じゃあ田中さんね」と決めてしまったのだ。田中は私だ。名簿から逃げなかった罰である。

　当日の仕事は単純で、抽選箱をがらがら回し、出た番号を読み、景品を渡す。それだけならよかった。困るのは、最後に残った箱の中身は係が持ち帰る、という自治会の謎ルールだ。誰が決めたのかも分からない。総会の議事録にも「福引き係の労をねぎらい」としか書いてない。労って何だ。労って、こんなに悩ませることか。

　景品テーブルには、朝の時点で十二個あった。開始一時間で十一個が捌けた。米五キロ、洗剤の詰め合わせ、ビール六缶、隣町の温泉の日帰り券。当たった人たちは全員、当たった瞬間に景品を決めていた。決めていたというより、選ぶ場面がそもそも無かった。当たったものを持って帰るだけだから。ずるい。全員ずるい。

　残った最後の一個は、私の番だった。テーブルには、お手製のポプリと、由来不明の招き猫と、賞味期限が来月の煎餅の缶が並んでいた。いや、正確には、朝は十二個の中に紛れていたこの三つが、選ばれずに残った結果、私の前に並んでいるのだ。順番が逆だった。選ぶ側になって初めて、他人が選ばなかった理由が分かる。分かったところで得は一つも無い。

　考えてみれば、この三つが最後まで残ったのには理由がある。誰も、当選番号を読み上げられて「招き猫が当たりました」と言われたとき、顔に出さずに喜べる自信がなかったのだ。米やビールなら大声で万歳できる。招き猫だと、微妙な笑顔で「ありがとうございます」と言うしかない。人はその微妙な笑顔を避けて生きている。私も避けたい。避けたいのに、逃げ場が無い。係というのはそういう立場だ。

　ポプリは会長の奥さんの手作りで、香りは花というより枯れ草だった。招き猫は右手を挙げている福を招く型で、片方の耳の金がすでに剥げている。煎餅は普通に煎餅だった。三つとも、選んだ人間の生活が透けて見える。私はどの生活も選びたくなかった。

　後片付けを始めた副会長が、テーブルの端から「まだ決まらないの」と聞いてきた。決まらない。決まらないのは、選ぶ基準が無いからだ。おいしさで選べば煎餅、実用性で選べば、いや招き猫に実用性なんてあるのか。無い。ポプリだって、玄関に置いても誰も匂いに気づかない自信がある。

　招き猫を持ち上げてみた。重い。台座に「祈願成就」と彫ってある。何を祈願するのかは書いていない。祈願の内容まで自分で決めろということか。ちょっと重すぎる仕事を渡された気がした。いったん置いて、ポプリを持ち上げる。軽い。軽いから選ぶ、というのも投げやりすぎる基準だが、他に基準が無いなら投げやりでいくしかない。いや、待って、それは基準ではなく諦めだ。自分で決めた基準に自分でツッコんでいる時点で、もう誰かに決めてほしいのだと思う。

「田中さん、電気消すよ」

　体育館の照明が半分落ちて、テーブルの陰影がぐっと濃くなった。時間切れだ。祈願も選択も、照明の都合で決まるらしい。私は招き猫でもポプリでもなく、煎餅の缶を小脇に抱えて、体育館を出た。決められなかったのではない。開けてすぐ食べられるものを、最後に選んだのだ。そう自分に言い聞かせながら、招き猫の片耳の剥げた金色が、まだ目の奥にちらついていた。
