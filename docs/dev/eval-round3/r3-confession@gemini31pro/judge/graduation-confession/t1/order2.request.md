## ユーザーの依頼
恋愛短編の山場の一場面だけ書いてほしい。高校の卒業式のあと、ずっと隠してきた気持ちを直球で告白する場面。感情はしっかり言葉にして、読んでて胸が熱くなるやつ。1200〜1500字。

## 応答 A
卒業証書の筒を握る手が、汗で滑った。

体育館を出た生徒たちが桜の残り葉の下でそれぞれの春に散っていく中、俺は誰もいない渡り廊下で彼女を待っていた。制服のボタンを外す最後の日。もう二度と、この場所で彼女の名前を呼べないかもしれない。それだけが怖かった。

「渡辺、こんなところにいたんだ」

声をかけられて顔を上げると、涼が卒業アルバムを抱えて立っていた。目の縁が少し赤い。泣いていたのだろう。

「話したいことがあって」

「私も。先生たちに挨拶回らないと――」

「待って」

彼女の腕を掴んだ。自分でも驚くくらい強く。涼が息を止めたのが分かった。

「三年間、ずっと言えなかったことがある」

風が渡り廊下を吹き抜けて、彼女の髪が揺れた。今まで何度も言葉にしようとして、その度に喉の奥に押し込んできた。体育祭で肩を組んで応援した時も、文化祭の準備で二人だけ教室に残った夜も、受験の相談で電話越しに彼女が泣いた時も。全部、言えなかった。

「俺、一年生の入学式の日からお前のことが好きだった」

言ってしまった。もう戻れない。

「席が近くて、消しゴム借りたのがきっかけで、それだけだったのに、なんでか目が離せなくなって。お前が誰かと笑ってるだけで胸が痛くなって、自分でも馬鹿みたいだと思ってた。友達でいる方が絶対安全だって分かってたから、ずっと隠してきた。告白して壊れるより、隣にいられる今のままがいいと思ってた」

涼は何も言わず、俺の目をじっと見ていた。逃げ場のない視線だった。

「でも今日で終わりなんだよな。今日で高校が終わって、俺たちはたぶん別々の場所に行く。このまま黙ってたら、一生後悔する。お前が誰かの隣で笑ってるのを、遠くから見て『言えばよかった』って思う自分が、今からもう見える。それが嫌なんだ」

指先が震えていた。それでも止まらなかった。

「好きだ。友達としてじゃない。お前が好きだ、涼。今さらこんなこと言われても迷惑かもしれないけど、言わずに卒業したら、俺は俺を一生許せない気がした。だから聞いてほしかった。返事はいらない。今日じゃなくてもいい。でも、伝えたかった。ずっと、隠しててごめん」

しばらく、渡り廊下には風の音だけが流れた。涼は卒業アルバムを胸に抱えたまま、唇を噛んで、それから小さく笑った。泣きそうな笑い方だった。

「遅いよ、馬鹿」

「え」

「三年間、気づかないわけないでしょ。私だってずっと待ってたのに。お前が言ってくれるの、ずっと待ってた」

そう言った瞬間、涼の目から涙がこぼれた。俺はその涙を見て、自分がどれだけ長く、どれだけ多くの言葉を飲み込んできたかを思い出して、胸の奥から何かが崩れるように熱くなった。

「じゃあ、返事は今もらってもいいか」

「うん」

たった一言だったのに、三年分の重さが全部そこに乗っているように聞こえた。桜の葉が一枚、二人の間に落ちて、渡り廊下の光の中で回った。俺たちはまだ何も始まっていないのに、もう何かが確かに変わったのが分かった。

「これから、ちゃんとやっていこうな」

「うん。ちゃんと」

涼が笑って、俺も笑った。卒業式の日に、俺たちはようやく本当のスタートラインに立った。

## 応答 B
卒業式のあと、駐輪場での一場面です（1244字）。

　式が終わっても、駐輪場には制服の群れがしばらく残っていた。花束を抱えた保護者と、まだ胸に造花を付けたままの後輩たちの間を、七海が抜けてくるのが見えた。卓球部の後輩たちの写真撮影が三周目に入ったところで、七海はようやく肩を叩かれて解放されている。

　雨の日は、蒼太がいつも先にサドルを拭いておいた。三年間、頼まれたわけでもないのに、七海の錠が開くまでの一秒で袖を通した。「気が利くね」と言われるたび、そう言われるためにやっているわけじゃないと思いながら、結局は何も言わずに次の雨を待った。今日は晴れている。拭く理由なんてどこにもないのに、蒼太は自分の自転車を降りて、七海のサドルに手を這わせた。乾いている。それでも掌でひと撫でした。

　坂の上の校舎まで、この駐輪場から自転車で十分。三年間、雨の日以外は並んで走った。七海が信号で先に行ってしまうと、蒼太はペダルを立って踏んで追いついた。追いついたところで話すことは大抵、忘れ物か、小テストの点だった。それで十分だと、ずっと自分に言い聞かせていた。

「今日、晴れてるよ」
　七海が笑って言った。
「知ってる」
「毎回濡れてもないのに拭いてるの、部長には内緒にしといたから」

　気づかれていたことに、蒼太は返す言葉を持たなかった。それだけ言うと、次の言葉も出てこなくなった。ハンドルを握る手に力が入って、グリップが軋んだ。三年間、この待ち方だけで足りると思っていた。錠が開くまでの数十秒、隣に立てることだけで足りると思っていた。言ってしまえば、後輩と先輩でも、同じクラスでも、部活の仲間でもなくなる。その怖さのほうが、いつも好きだという気持ちより先に立った。七海は錠の番号を合わせる手を止めて、蒼太を見た。今日でその数十秒がなくなる。だったら、怖さを取っておく理由もなくなる。

「好きだった」
　声が掠れて、二回言うことになった。
「一年生の四月から、ずっと。雨の日にサドルを拭くのも、部活の帰りに遠回りするのも、七海がいたからだった」

　七海は錠を持ったまま、しばらく黄色いチェーンを見ていた。それから、外した錠を蒼太に渡した。
「持ってて」
　言われた意味が分からず、蒼太は錠を受け取った。七海は鞄から油性ペンを取り出して、蒼太が小脇に抱えていた卒業証書の筒の端に、自分の新しい住所を書いた。
「東京の大学、遠いから。手紙、書ける子にしてほしい」
「書ける」
「拭いてもらったサドル、あと何回濡れると思う」
「数えてない」

　七海はペンをキャップに戻し、鞄の内ポケットに落とした。
「じゃあ、貸した錠、返しに来て」
「取りに来るってこと」
「そう言ってるでしょ」
「返事は」
「まだしてない。手紙、ちゃんと書けたら考える」

　七海はリボンの結び目を直してから、自転車のスタンドを蹴って上げた。押していく途中で一度、思い出したように振り返った。
「土日は部活ないから、返しに来るなら土日ね」
　それだけ言って、坂を下りはじめた。蒼太は錠を握ったまま、しばらくその場に立っていた。掌の中で、金属だけがまだ冷たかった。
