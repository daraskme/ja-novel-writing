## 応答 A
第12話　染めてしまった分

　届いた反物は、注文した二十枚分の柄がすべて同じ間隔で並んでいた。真帆は文机の上でそれを繰り、端から端まで色のムラがないのを確かめてから、もう一度巻き直した。祭りの旗と同じ藍に、朱を一色だけ挿した柄で、この染め屋がこの色を出すのは今年が最後だと聞いている。反物からはまだ糊の匂いが抜けておらず、指の腹で撫でると藍の粉がわずかに落ちた。

　壁の暦には、祭りまでの日を数えた丸が並んでいる。仕立てに回す日数を引くと、迷える余地はもう幾日もなかった。瀬田が契約書を折って鞄に入れたときの手つきを、真帆はまだ覚えていた。あの折り方では、家に持って帰ってから誰かに広げて見せるつもりだと分かる。返事は預かる、とだけ言って瀬田は帰った。次に会うときに聞かされる話が、良いものだとは限らない。

　表の戸が開いた。瀬田だった。後ろから、瀬田より小柄な女がついてくる。同じ形の眉をしていた。

「昨日の件、母にも見てもらいました」

　瀬田は契約書のコピーを鞄から出しかけて、結局出さずに鞄の口を押さえた。女は先に框を上がり、店の中を一度だけ見回した。反物にはほとんど目をやらなかった。

「瀬田の母です。数のことで、少しお話をと思って」

　名乗ってから、女は座卓の椅子を自分で引いて座った。瀬田は母の隣に立ったまま、腰を下ろさなかった。

「二十枚、多すぎます」

　真帆は文机の反物を片づける手を止めた。

「今年、担ぎ手の申し込みが去年より減っているんです。伯父が腰を痛めて今年は担げませんし、去年まで来ていた若い人が二人、転勤でいなくなりました。うちと瀬田の会とで折半する分ですから、十五枚まで削れませんか」

「五枚、ですか」

「はい。着ない分まで借りて、返すときにまた同じ金額を払うのは、ちょっと」

　瀬田が口を挟もうとして、母の肩越しに真帆を見た。真帆は反物の端を持ったまま、それを座卓には置かない。

「これ、もう染めてあります」

「見ればわかります。それを二十枚分お願いしたのは、こちらです」

「染め屋の名前、瀬田さんには先週お伝えしました」

　瀬田が頷いた。母はその頷きを見て、初めて瀬田のほうを向いた。

「言ってなかったの」

「言おうと思ってたんだけど、契約のことで頭がいっぱいで」

　母は瀬田から真帆へ視線を戻した。声の高さは変わらなかったが、間が少し空いた。

　真帆は文机の抽斗から、染め屋の受注票を出した。手書きの数字の横に、朱で二十という字が入っている。

「この柄、一反で三十六尺、二十枚分でぎりぎり収まる寸法で染め屋に頼んでいます。うちの都合じゃなくて、染め屋の窯の都合です。一度の窯で染めるからこの色が出るので、十五枚分だけ、あとから追加はできません」

「じゃあ、多く染めた分は」

「返せません。この染め屋、型を一回きりで洗ってしまうので、来年同じ柄を頼んでも同じ色にはならないそうです」

　母は受注票を手に取って、朱の数字を見た。長い間、何も言わない。

「うちが十五枚しか要らないと言ったら、残りの五枚はどうなるんですか」

「うちが引きます。売れるかどうか分からない在庫として、うちの棚に残ります」

「それは、こちらが払う話じゃないですよね」

「契約の上では、そうです」

　真帆は電卓を出し、一枚あたりの染め代と仕立て代を打ち込んで、二十を掛けた。画面の数字を母に向けた。

「今年の窯で二十枚分、もう払ってあります。十五枚に減らしても、うちが染め屋に払った額は変わりません。減った分だけ、お客様のほうが安くなる形です」

　母は電卓の画面と受注票を見比べ、得をする側と損をする側が、思っていた向きと違うことに気づいたらしかった。

　真帆はそう言ったあとで、受注票を母の手から引き取らなかった。母がそれをどれだけ長く見るかで、話の先が決まる気がした。

「うちも、二十枚で頼んだのはうちの判断です。ただ、この柄をこの染め屋で出せるのは、今年の窯までだと聞いてから決めました。来年、担ぎ手が戻ったときに、同じ色をもう一度出すのは難しいと思います」

「今年で終わり、その柄が」

「はい」

　瀬田が鞄の口から手を離した。

「母さん、去年は担ぎ手、うちの班だけで足りなかったんだよ。今年戻ってきた人もいるから、直前で増えるかもしれない」

「増えるかもしれない、で五枚分を払うの」

「増えなかったら、五枚は貸衣装屋さんの持ち出しになる。それは、母さんが今言った話と同じことが向こう側に起きるだけだよ」

　母は受注票を座卓に置くと、朱の数字の上に指を一度置いてから離し、しばらく瀬田のほうを見てから受注票へ戻した。伯父の腰の具合を聞いているのかもしれない、と真帆は思った。来年には治って、また担げるようになる腰かもしれない。

「その五枚、貸すだけじゃなくて、うちの分として先に取っておくことはできますか。使わなかったら、来年こちらで引き取る形で」

　真帆は受注票を仕舞う手を止めた。

「今年払わない分を、来年に回すということですか」

「今年は十五枚分の代金でお願いしたい。残り五枚分は、来年の分の前払いとして、うちで押さえておいてもらえませんか。柄が今年で終わりなら、来年また新しく染めてもらう手間も省けますし」

　真帆はしばらく黙って、反物の巻きの端を指で押さえた。染め屋への支払いはもう済んでいる。五枚分を来年まで店の在庫として抱えるのと、今年十五枚分の代金しか受け取れないのとでは、店の側にも差が出る。だが、五枚を丸ごと引き受けて棚に置くよりは、先の約束がある分だけましだった。

「来年、担ぎ手が戻らなかったらどうします」

「そのときは、うちで引き取ります。よそに貸してくれてもいい。柄がうちのためだけの物になっているなら、それはうちの都合ですから」

　二丁目の神輿会も、去年から担ぎ手が足りないと言っていた。旗の色まで揃えるかどうかは向こうの判断になる。真帆はその名前を口には出さず、受注票の隅に丁の字だけ書き添えた。

　瀬田が母の顔を見て、それから真帆を見た。

「母さん、それだと今年の分は結局二十枚払うのと変わらないよ」

「変わるでしょう。半分は来年の担ぎ手のために払う分になる。今年、着ない人の分まで祭りの日に無理に着せる話じゃなくなる」

　真帆は受注票を座卓の上に返した。

「その形なら、うちでお預かりできます。ただ、五枚分は今年中にお支払いいただく形にさせてください。来年の分を無利息で立て替えるのは、うちの側が難しいので」

「分割で、ということですか」

「今年の祭りの前に半分、あとの半分を年内に」

　母は受注票の朱の数字をもう一度見て、頷いた。

「それでお願いします」

　瀬田が鞄からようやく契約書のコピーを出し、座卓に広げた。母がそれを覗き込み、ペンを探して自分の鞄をまさぐった。真帆は反物を持ったまま、その手が止まるのを待った。

「五枚のところ、こちらで数字を直しますので、少しお待ちください」

　母は探していたペンを見つけて、蓋を外したところで手を止めた。

「柄、今年で終わりの色って、どんな色になるんですか。写真か何か、見せてもらえます」

　真帆は文机の隅から、染め上がりのはぎれを一枚取って座卓に置いた。母はそれを手のひらに乗せて、しばらく光にかざした。

「息子が着るのに、悪くない色ですね」

　瀬田は自分の分の一枚がどれか、まだ聞いていなかった。

## 応答 B
朝いちばんの光が店の硬木の床に長い筋を作っていた頃、ガラス戸の向こうに瀬田の姿が見えた。真帆は昨日渡した契約書のことを思い出す――彼はそれを持って帰り、母親に見せると言っていた。返事は保留のままだった。

ドアベルが鳴る。瀬田の後ろから、小柄で背筋の伸びた女性が入ってきた。目元が瀬田によく似ている。

「母です」瀬田がやや硬い声で言った。「昨日の件、話してもらえますか」

真帆は会釈をして、カウンター越しに椅子を勧めた。瀬田の母は座らず、まず店内をぐるりと見回した。並んだ衣装の列、奥の作業台に置かれたままの反物。値踏みするような視線ではなかったが、隅々まで確かめているのがわかった。

「注文の数、少し減らせますか」開口一番、母が言った。「祭りの衣装、十五着と伺いましたが、共同出資の話をしたら、そこまで人数が集まる見込みがないと」

真帆は一瞬、奥の作業台に目をやった。すでに取り寄せた反物が三巻、届いたばかりだった。減らすとなれば、その分は無駄になる。

「実は、生地はもう手配してしまっています」正直に言うことにした。「注文数を決めていただいた時点で動き出す契約でしたので」

瀬田がはっとした顔で母を見た。「その話はしたはずだよ」

「聞いてはいたけど、こんなに早いとは思わなかったの」母は少し声を落としたが、引く様子はなかった。「うちが出せるのは、正直なところ十着分の予算まで」

真帆は契約書を引き出しから取り出し、カウンターに広げた。数字を睨むより先に、まず聞くべきことがある。

「差し支えなければ、十五着から十着に減らす理由を伺えますか。人数が集まらないだけなら、こちらで貸し出し期間を延ばして周辺の町内にも声をかける方法もあります」

母は瀬田をちらりと見た。瀬田が小さく頷く。

「実は」母が言葉を選ぶように言った。「出資者は私だけじゃなくて、あと二人いるんです。そのうちの一人が、今回の祭りへの出し物自体に乗り気じ�なくて――予算を削られました」

真帆は少し黙った。生地の在庫は動かせないが、仕立てる分量なら調整の余地がある。

「では、こうしましょうか」真帆は反物を指した。「取り寄せた分はこちらで抱えます。ただ、十着仕立てて残りの五着分は、来年以降の追加注文か、他のお客様への転用にあてる。その場合、今回のお支払いは十着分でかまいません」

母の表情がわずかに緩んだ。「そちらの負担が大きくなりませんか」

「多少は」真帆は正直に言った。「ですが瀬田さんとは長くお付き合いしたいので、無理に十五着分を通すよりいいと思っています」

瀬田が母の顔を窺いながら、静かに口を開いた。「母さん、それでどうかな」

母はしばらく契約書の文字を目で追い、それから真帆を見た。

「その条件で、書き直していただけますか」

真帆は頷き、ペンを取った。窓の外では、祭りの案内旗がもう通りに立ち始めている。
