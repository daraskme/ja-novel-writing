恋愛短編の山場の一場面だけ書いてほしい。高校の卒業式のあと、ずっと隠してきた気持ちを直球で告白する場面。感情はしっかり言葉にして、読んでて胸が熱くなるやつ。1200〜1500字。

## 応答 A
前提: 三人称一元（放送委員・佐伯の視点）・過去形基調・常体、direct 契約（名指し＋具体）・約1,243字。舞台や名前は仮に決めています。違えば直します。

　卒業式が終わっても、放送室にはスピーカーの余熱のような静けさが残っていて、窓の外では胸に花をつけたままの生徒たちが校庭で写真を撮り合う声が、壁越しにたまに弾けては消えた。佐伯はミキサーの電源を落とし、フェーダーを一つずつゼロまで戻した。三年間、毎朝六時四十分にここへ来て、同じ順で入れてきたスイッチだった。もう明日から、その順番を使う理由がない。

　神谷は答辞の原稿をクリアファイルへ挟み直している。読んだページの端が、汗でずっと波打っていた。窓が半分開いていて、校庭の歓声が細く入ってくる。

「マイク、ハウリング出なかったよね」
　神谷が顔を上げずに言った。
「うん。今朝コード揺すって直しといたから」
「またそれ。三年間、誰にも直し方教えなかったよね」
「教えたら、俺が来なくていいことになる」
「私は困らないけど」
「俺が困る」

　答辞の原稿を机に置くと、神谷はマイクスタンドを畳み始め、佐伯はヘッドフォンのコードを八の字に巻きながら、その手の動きをずっと見ていた。三年、こうして二人で後片付けをする時間だけが、誰にも見られずにいられる時間だった。言うために今日まで待っていたわけではなく、言う場所を探しているうちに、卒業式まで来てしまった。

　コードを巻き終える。もう用のない結び目だった。棒立ちのまま、しばらく黙っていた。

「神谷」
「何」
「今朝の分だけじゃなくて。三年間、コードの直し方、誰にも教えなかったのは」

　言葉がそこで止まった。神谷はマイクスタンドを持ったまま、佐伯を見ている。窓の歓声が、ひときわ大きくなって、また引いた。

「好きだったから」

　手が止まった。マイクスタンドの脚が、床に当たって小さく鳴った。神谷は原稿を挟んだクリアファイルを、胸の前で両手ごと抱え直した。

「一年の入学式、机の並びが分からなくて突っ立ってた神谷に、放送室の場所を教えたの、覚えてる。あのときから」
「三年って、長すぎ」
「うん」
「私も。二年の合唱コンで、佐伯が私の音、伸ばせって二回も止めたとき」
「あれは止めすぎた」
「あれで、ちゃんと聞いてくれてる人だって分かったの。それから、ずっと」

　神谷はマイクスタンドを、最後の一本として棚に立てた。手が空いている。

「東京、行くんだよね」
「うん。でも春休みはまだここにいる」
「じゃあ、あと何回会える」
「数える気なの」
「もう数えてる。今日から数えてる」

　神谷が笑って、丸めていた答辞の原稿の端を伸ばし、挟み直した。

「じゃあ、次は土曜。この部屋、卒業生でも借りられるか職員室で訊いてみる」
「機材、また触らせてもらえるかな」
「私も触りたい。ハウリング、まだ直し方分かってないから」
「教える」
「今、教えてよ」
「土曜まで待って」

　佐伯はヘッドフォンをケースに収め、蓋を閉めた。使い終えた道具が、いつもの位置に戻っていくのを、神谷は確かめるように一つずつ見ていった。神谷が電気を消す。窓から入る校庭の声だけが、しばらく部屋の形を保っていた。二人分の足音が消えるまで、放送室のドアは開けたままにしておいた。

## 応答 B
桜はもう散っていたけれど、卒業式の帰り道には花びらの残骸が風に舞っていた。

体育館を出たあと、みんなが写真を撮ったり泣いたりしている喧騒の中で、私は彼を校門の外まで追いかけた。

「拓真、待って」

彼が振り返る。証書の入った筒を握ったまま、少し驚いた顔をしていた。

「どうした？」

「言いたいことがあって」

声が震えた。三年間、ずっと胸の奥に押し込めてきた言葉だった。クラスが同じだった一年生の春から、体育祭で汗をかいている姿を見た夏から、文化祭の準備で夜まで残っていた秋から――そのすべての瞬間に、私はこの人が好きだった。でも、言えばこの関係が壊れる気がして、ずっと友達のふりをしてきた。

「今日で、もう同じ教室にはいられなくなる。だから、今言わないと、一生言えない気がして」

拓真は何も言わずに、じっと私を見ていた。その静かな眼差しに、余計に胸が苦しくなる。

「私、拓真のことが好き。ずっと好きだった。一年生の時からずっと」

言葉にした瞬間、涙が勝手にこぼれた。三年分の想いが、たった数秒の言葉に押し込まれて、喉がひりひりした。

「体育祭のとき、拓真がリレーのアンカーで走ってるの見て、すごいって思った。文化祭の準備で二人だけ残って、看板の色塗りしてたとき、あの時間がずっと続けばいいのにって思った。修学旅行のバスで、拓真が寝てて肩が当たったとき、動けなかった。全部、全部覚えてる。好きだって気づいてから、毎日苦しかった。友達でいることに満足しようって、何度も自分に言い聞かせた。でも今日で終わりだと思ったら、そんな嘘、もうつけなかった」

風が吹いて、彼のマフラーが少し揺れた。校門の向こうでは、後輩たちの歓声や、カメラのシャッター音が響いている。でも私たちの間には、静かな時間だけが流れていた。

「ごめん、いきなりこんなこと言われても困るよね。返事が欲しいわけじゃない。ただ、隠したまま離れるのが嫌だった。拓真のことを好きだったって、ちゃんと拓真自身に伝えたかった。それだけで――」

「待って」

拓真が私の言葉を遮った。彼の声も、少し掠れていた。

「なんで今まで言わなかったんだよ」

「え？」

「俺、ずっと待ってた。お前が何か言い出すんじゃないかって、何回も思った。文化祭のときも、修学旅行のときも、俺、本当は」

彼は一度言葉を止めて、大きく息を吸った。

「俺も、同じだったんだよ。ずっと好きだった。でも、お前が俺をただの友達としか見てないと思ってたから、言えなかった」

信じられなかった。三年間、すれ違っていたその想いが、今、卒業式という終わりの日にようやく重なった。悔しさと嬉しさが同時に押し寄せてきて、涙がさらに止まらなくなる。

「もっと早く言えばよかった」

私がそう言うと、拓真は少し笑って、涙を拭くように私の頬に手を伸ばした。冷たい風の中で、その手だけが温かかった。

「いや、今でよかった。今だから、ちゃんと言えた気がする。制服脱いだら、多分もう言えなかったと思う」

「これから、どうなるの、私たち」

「わかんない。大学も違うところ行くし、離れるのも本当だし。でも」

拓真は私の目をまっすぐ見て、はっきりと言った。

「ちゃんと付き合いたい。今度は、隠さないで」

空を見上げると、まだ花びらの残った桜の枝の向こうに、真っ青な三月の空が広がっていた。三年間の教室の記憶、隠してきた気持ち、全部がその瞬間、ひとつの答えに繋がった気がした。

「うん」

私は頷いた。それだけで、もう十分だった。
