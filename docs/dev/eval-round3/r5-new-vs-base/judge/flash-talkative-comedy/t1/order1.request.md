## ユーザーの依頼
よく喋る一人称のコメディ掌編を書いて。自治会の福引きで、くじを引く係が自分の景品だけ決められない話。語り手は脱線したり、自分で自分にツッコんだりする人にして。真顔で淡々と語る感じにはしないで。長さは1500字くらい、本文から始めて。

## 応答 A
自治会の福引き係を任されたのは、単純に「あんた声大きいから」という理由だった。声の大きさと公正さって何の関係もないと思うんだけど、町内会というのは謎の人選ロジックで動いている組織なので、もう慣れた。

で、当日。ガラガラ回して、番号読んで、「はい一等!炊飯器!」「はい五等!ティッシュ十箱!」とテンポよくやってたんだけど、問題が発生した。景品係(私)自身の分の抽選券が、最後に一枚だけ残った。景品も、最後に一つだけ残っていた。つまり選ぶ余地がない。ないはずなのに、なぜか私は五分間そこで固まった。

残っていたのは「洗剤セット」。普通に良い景品。文句なし。なのに私の脳が急に会議を開き始めた。「洗剤って、もう家に三個あるよね」「でも消耗品だから困らない」「いや待って、隣の田中さんが欲しそうな顔してたの見た」「見てないよ、そんなの見てない、なんで見てもいない顔を思い出してるんだ」——完全に一人芝居。周りは「早く早く」って空気になってるのに、私だけ人生の岐路みたいな顔で洗剤の箱を見つめている。

会長が「どうしたの」って聞くから「いや、選べなくて」って言ったら、「選ぶもの一つしかないでしょ」って正論をくれた。そう、それはわかってる。わかってるんだけど、選択肢がゼロだと逆に緊張するタイプの人間っているんですよ、私みたいに。レストランで「本日のおすすめ一品のみです」って言われると、逆に「そのおすすめ、本当に自分に合ってるのか」と謎の吟味を始めてしまう、あのめんどくさい心理。

しかもここで余計なことを考え始めた。「これ、本当にランダムに残ったのか?誰かが気を遣って最後まで残してくれたんじゃ?」——いや違う、単純に数字の並びの結果です。私はただの確率の産物に運命を見出そうとしていた。福引き係のくせに福引きの原理を疑うという、職業倫理的にアウトな行為。

とはいえ箱を持った瞬間、変な満足感があった。「これ以上でもこれ以下でもない、ちょうどいい景品」感。炊飯器みたいに気合を入れて使う必要もなく、ティッシュみたいに地味すぎず、洗剤はちょうど中間の安心感がある。景品のヒエラルキーの中では中間管理職みたいな存在で、なんか勝手に親近感を持ってしまった。

最終的に、私は洗剤セットを両手で受け取り、周りに向かって「これ、私にぴったりです!」と謎に力強く宣言した。誰も聞いてなかった。会長はもう次の番号を読んでいた。

家に帰って洗剤を四個並べて、「これは選んだ景品だから特別」と自分に言い聞かせながらお皿を洗った。特別な洗剤で洗った茶碗の味は、特に変わらなかった。当たり前だ。

来年また係をやらされるらしいので、今度は迷わず即答するつもりだ——たぶん。

## 応答 B
福引き係というのは、うちの町内会では毎年十二月の第一土曜、公民館の畳を上げて長机を並べた日にだけ存在する謎の役職で、私はこれを五年連続でやっている。立候補した記憶は一切ない。去年の役員会で「じゃあ阿部さん、去年もやってくれたし」と言われた瞬間、隣に座っていた斎藤さんがすっと目を逸らした。あの人、絶対わざとだ。椅子取りゲームの最後の一席を、こっそり押しつけてくる才能がある。

　係の仕事は簡単で、ガラポンを回して出た色玉に応じて景品を配るだけ。赤なら米十キロ、白ならポケットティッシュ、それだけなのに、なぜか毎年ひと騒動ある。一昨年は「特賞の赤玉が出たのに、特賞の米がすでに配り終わっている」という運営側の凡ミスで、私が土下座に近い姿勢で三丁目の奥さんに謝った。今年は特に、最後に残った景品が悪かった。

　四十世帯分の福引きが終わって、長机の上に取り残されたのは四つ。米五キロ、洗剤の詰め合わせ、健康サンダルの片方だけ大きいやつ（なぜ片方だけ大きいのか、去年から誰も説明できていない）、そして誰かの差し入れらしいカニ風味かまぼこの缶詰め五個セット。

　ここでうちの町内会には妙な役得がある。余った景品は、係が持ち帰っていい。福引き係をやる唯一のご褒美。去年までは「余り物だからどうせティッシュとタオルでしょ」と気楽に構えていたが、今年は違う。四択。しかも、どれも決め手に欠ける。

　米は正直欲しい。だが五キロは、うちの二人暮らしだと二ヶ月かけて食べる量で、その間、買ってあった別の米が家で眠ることになる。米の在庫問題を抱えたまま暮らすのは、想像以上に精神を削る。分かる人だけ分かってくれ。洗剤は生活必需品という意味では最強なのだが、正直「福引きの景品、洗剤でした」という話をあとで人にする気になれない。地味すぎる。健康サンダルは片方だけ大きい理由が未解決のまま我が家に来ることになり、それはそれで気になって夜眠れなくなる自信がある。カニ風味かまぼこは、五個も同時に来ても、開けるタイミングが分からない。誰かの結婚式の引き出物みたいな存在感で、冷蔵庫の奥で静かに主張し続けるだけの未来が見える。

「阿部さん、まだ？」

　副会長の田村さんの声で、私はガラポンの前で四つの景品を見比べながら固まっていたことに気づいた。もう随分経っている気がする。福引き会場における数分は、永遠に近い。

「いえ、今、選んでます」

「選んでるように見えないよ」

　その通りだ。反論できない。

　考えれば考えるほど分からなくなる、という現象は、たいてい、そもそも選ぶ基準を決めていないときに起こる。米か洗剤かサンダルかかまぼこか、私はそういう比較をしていない。米を選んだ自分の一年と、洗剤を選んだ自分の一年を、それぞれ想像して、どちらが「まあ悪くない年だった」に見えるかを判定しようとしている。これはもう福引きではなく、占いに片足を突っ込んでいる。

　見かねた田村さんが、横からガラポンを一回転させた。出てきたのは白玉。

「これで決まり。かまぼこ」

「私、白玉引いてないですよね」

「係得も、今年からくじで決めるって総会で決まったの」

　聞いていない。だが公民館の壁に貼られた議事録には、たしかにそう書いてある気がする。誰も読んでいない議事録は、こういうときだけ思い出される。

　米五キロは田村さんが抱え、洗剤とサンダルは残った役員三人でじゃんけんになった。誰も本気で欲しがっていないのに、じゃんけんになると急に本気になるのが人間というものらしい。

　私はカニ風味かまぼこの缶を五個抱えて、来年の福引き係を誰に押しつけようか、帰り道でずっと考えていた。斎藤さん、今度こそ捕まえる。
