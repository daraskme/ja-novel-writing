　三月最後の水曜、始発から二本目の電車を待つ上川原駅の改札は、まだ半分眠っている。

　知夏はキャリーケースの持ち手を両手で握り直し、券売機の横を通り抜けようとしていた。コートのボタンを上まで留めているのは、大阪の三月がどれくらい寒いか、まだ知らないからだ。

「知夏」

　航は改札の手前で呼んだ。走ってきたぶん、声がひとつ裏返る。

　知夏が振り返ると、キャリーケースの車輪が石畳の段差に引っかかって、小さく跳ねた。

「見送りは、もう昨日済ませたじゃない」

「昨日は言えなかったから」

　航は一度、喉のあたりで言葉を落としかけたが、ここで拾わなければ、知夏は改札を抜け、次に会うのは大阪の会社の名刺を持った知夏になる。それだけは決まっている。

「知夏が好きです。付き合ってください」

　言い切った直後、耳のあたりが熱かった。声はまだ、改札の天井のあたりに残っている。

　知夏はキャリーケースの持ち手から手を離さないまま、しばらく航の顔だけを見ている。答えるまでの間に、駅員が発車ベルの試験放送を一度鳴らして、すぐに止めた。

「うれしい」

　知夏はそう言って、持ち手をようやく離す。

「好き。ずっと好きだった。航が飲み会で先に帰るとき、いつも私の分のタクシー代まで払おうとするのが、面倒だったし、うれしかった」

　その一つだけを持ち出されて、航は笑ってしまう。あれは大学一年、サークルの新入生歓迎会の帰りで、財布に千円しか入っていなかったのに、なぜあれを持ち出すのか分からない。分からないまま、うれしさのほうが先に来た。

「言えばよかった」

「言えばよかったね、私も」

　知夏は笑って、それから少し眉を寄せる。

「でも私、大阪行くよ」

「知ってる」

「毎週は帰ってこられない」

「知ってる。それでも、好きです」

　二度目の名指しに、知夏は今度はすぐに頷いた。上りの電車が減速する音が、改札の向こうから近づいてくる。

「じゃあ、電話して。今夜」

「する」

　知夏はキャリーケースを引いて、改札のICタッチ部にカードを当てる。ゲートが開く直前、知夏は空いている手を航に差し出した。航がその手を握ると、知夏は握り返してから、すぐに離す。それだけの長さで、次に会う日まで足りるとは、二人ともまだ思っていない。

「行ってきます」

　知夏は改札を抜け、ホームへの階段を上っていった。航はICカードを持たないまま、改札の手前に立って、電車が入ってくる音を聞いている。
