朝いちばんの光が店の硬木の床に長い筋を作っていた頃、ガラス戸の向こうに瀬田の姿が見えた。真帆は昨日渡した契約書のことを思い出す――彼はそれを持って帰り、母親に見せると言っていた。返事は保留のままだった。

ドアベルが鳴る。瀬田の後ろから、小柄で背筋の伸びた女性が入ってきた。目元が瀬田によく似ている。

「母です」瀬田がやや硬い声で言った。「昨日の件、話してもらえますか」

真帆は会釈をして、カウンター越しに椅子を勧めた。瀬田の母は座らず、まず店内をぐるりと見回した。並んだ衣装の列、奥の作業台に置かれたままの反物。値踏みするような視線ではなかったが、隅々まで確かめているのがわかった。

「注文の数、少し減らせますか」開口一番、母が言った。「祭りの衣装、十五着と伺いましたが、共同出資の話をしたら、そこまで人数が集まる見込みがないと」

真帆は一瞬、奥の作業台に目をやった。すでに取り寄せた反物が三巻、届いたばかりだった。減らすとなれば、その分は無駄になる。

「実は、生地はもう手配してしまっています」正直に言うことにした。「注文数を決めていただいた時点で動き出す契約でしたので」

瀬田がはっとした顔で母を見た。「その話はしたはずだよ」

「聞いてはいたけど、こんなに早いとは思わなかったの」母は少し声を落としたが、引く様子はなかった。「うちが出せるのは、正直なところ十着分の予算まで」

真帆は契約書を引き出しから取り出し、カウンターに広げた。数字を睨むより先に、まず聞くべきことがある。

「差し支えなければ、十五着から十着に減らす理由を伺えますか。人数が集まらないだけなら、こちらで貸し出し期間を延ばして周辺の町内にも声をかける方法もあります」

母は瀬田をちらりと見た。瀬田が小さく頷く。

「実は」母が言葉を選ぶように言った。「出資者は私だけじゃなくて、あと二人いるんです。そのうちの一人が、今回の祭りへの出し物自体に乗り気じ�なくて――予算を削られました」

真帆は少し黙った。生地の在庫は動かせないが、仕立てる分量なら調整の余地がある。

「では、こうしましょうか」真帆は反物を指した。「取り寄せた分はこちらで抱えます。ただ、十着仕立てて残りの五着分は、来年以降の追加注文か、他のお客様への転用にあてる。その場合、今回のお支払いは十着分でかまいません」

母の表情がわずかに緩んだ。「そちらの負担が大きくなりませんか」

「多少は」真帆は正直に言った。「ですが瀬田さんとは長くお付き合いしたいので、無理に十五着分を通すよりいいと思っています」

瀬田が母の顔を窺いながら、静かに口を開いた。「母さん、それでどうかな」

母はしばらく契約書の文字を目で追い、それから真帆を見た。

「その条件で、書き直していただけますか」

真帆は頷き、ペンを取った。窓の外では、祭りの案内旗がもう通りに立ち始めている。
