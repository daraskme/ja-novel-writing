桜はもう散っていたけれど、卒業式の帰り道には花びらの残骸が風に舞っていた。

体育館を出たあと、みんなが写真を撮ったり泣いたりしている喧騒の中で、私は彼を校門の外まで追いかけた。

「拓真、待って」

彼が振り返る。証書の入った筒を握ったまま、少し驚いた顔をしていた。

「どうした？」

「言いたいことがあって」

声が震えた。三年間、ずっと胸の奥に押し込めてきた言葉だった。クラスが同じだった一年生の春から、体育祭で汗をかいている姿を見た夏から、文化祭の準備で夜まで残っていた秋から――そのすべての瞬間に、私はこの人が好きだった。でも、言えばこの関係が壊れる気がして、ずっと友達のふりをしてきた。

「今日で、もう同じ教室にはいられなくなる。だから、今言わないと、一生言えない気がして」

拓真は何も言わずに、じっと私を見ていた。その静かな眼差しに、余計に胸が苦しくなる。

「私、拓真のことが好き。ずっと好きだった。一年生の時からずっと」

言葉にした瞬間、涙が勝手にこぼれた。三年分の想いが、たった数秒の言葉に押し込まれて、喉がひりひりした。

「体育祭のとき、拓真がリレーのアンカーで走ってるの見て、すごいって思った。文化祭の準備で二人だけ残って、看板の色塗りしてたとき、あの時間がずっと続けばいいのにって思った。修学旅行のバスで、拓真が寝てて肩が当たったとき、動けなかった。全部、全部覚えてる。好きだって気づいてから、毎日苦しかった。友達でいることに満足しようって、何度も自分に言い聞かせた。でも今日で終わりだと思ったら、そんな嘘、もうつけなかった」

風が吹いて、彼のマフラーが少し揺れた。校門の向こうでは、後輩たちの歓声や、カメラのシャッター音が響いている。でも私たちの間には、静かな時間だけが流れていた。

「ごめん、いきなりこんなこと言われても困るよね。返事が欲しいわけじゃない。ただ、隠したまま離れるのが嫌だった。拓真のことを好きだったって、ちゃんと拓真自身に伝えたかった。それだけで――」

「待って」

拓真が私の言葉を遮った。彼の声も、少し掠れていた。

「なんで今まで言わなかったんだよ」

「え？」

「俺、ずっと待ってた。お前が何か言い出すんじゃないかって、何回も思った。文化祭のときも、修学旅行のときも、俺、本当は」

彼は一度言葉を止めて、大きく息を吸った。

「俺も、同じだったんだよ。ずっと好きだった。でも、お前が俺をただの友達としか見てないと思ってたから、言えなかった」

信じられなかった。三年間、すれ違っていたその想いが、今、卒業式という終わりの日にようやく重なった。悔しさと嬉しさが同時に押し寄せてきて、涙がさらに止まらなくなる。

「もっと早く言えばよかった」

私がそう言うと、拓真は少し笑って、涙を拭くように私の頬に手を伸ばした。冷たい風の中で、その手だけが温かかった。

「いや、今でよかった。今だから、ちゃんと言えた気がする。制服脱いだら、多分もう言えなかったと思う」

「これから、どうなるの、私たち」

「わかんない。大学も違うところ行くし、離れるのも本当だし。でも」

拓真は私の目をまっすぐ見て、はっきりと言った。

「ちゃんと付き合いたい。今度は、隠さないで」

空を見上げると、まだ花びらの残った桜の枝の向こうに、真っ青な三月の空が広がっていた。三年間の教室の記憶、隠してきた気持ち、全部がその瞬間、ひとつの答えに繋がった気がした。

「うん」

私は頷いた。それだけで、もう十分だった。
