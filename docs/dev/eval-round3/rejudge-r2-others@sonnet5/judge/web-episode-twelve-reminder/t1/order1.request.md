## 応答 A
昨日、瀬田が持ち帰った契約書には、今朝もまだ署名がなかった。

「母です。出資の件で、一緒に話を聞いてもらおうと思って」

　店の戸口で瀬田が半歩よけると、後ろの女性が会釈した。真帆も頭を下げ、裁断台に広げていた生地を巻き戻した。

　祭りで使う、藍色の生地だった。窓から光が入ると、織り込まれた細い銀糸が浮かぶ。

「どうぞ。そちらへ」

　祖父から受け継いだ丸椅子は三脚とも高さが違う。真帆はいちばん安定したものを女性の前に置き、自分は座面の低い椅子に腰を下ろした。

　瀬田の母は契約書を台に置いた。折り目のついた二枚目に、小さな付箋が三つ貼ってあった。

「衣装を、二十四着から十六着に減らせませんか」

　真帆は、台の端に置いた鉛筆を取った。

「参加される方が減ったんでしょうか」

「人数は変わりません。八人は、前に使った衣装で出てもらえればと思っています」

　瀬田が膝の上で手を組み直した。

「昨日、家で予算を見直して。ほかにも増えた費用があって」

「そうでしたか」

　真帆は二十四という数字に線を引かず、その横に十六と書いた。

「ただ、生地は二十四着分、すでに取り寄せています」

　瀬田の母の目が、巻きかけの藍色へ動いた。

「契約は、まだしていませんよね」

「はい」

　返事が、自分で思ったより小さく出た。

「昨日、持ち帰って相談するとお伝えしたはずですが」

「伺っています」

　瀬田が口を開きかけたが、真帆は先に続けた。

「この生地は残りが少なくて、返事を待つと揃わない可能性がありました。それで、私の判断で取り寄せました。発注前に、費用の扱いまで確認するべきでした」

　壁時計の秒針が鳴った。祖父がいた頃は気にならなかった音だった。

　瀬田の母は付箋の一つを指で押さえた。

「では、十六着のお値段に直していただけますか」

「見積もりは直せます。ただ、総額をそのまま三分の二にはできません。型紙や見本の製作費は、着数にかかわらず必要なので」

　真帆は引き出しから計算用紙を出した。

　祖父なら、端数を丸めて笑ったかもしれない。けれど真帆は、祖父が客の帰ったあとにどんな帳面をつけていたのか、店を継ぐまで知らなかった。

「少しお時間をいただいてもいいですか。金額を分けてお見せします」

　返事を待ち、電卓を手元へ寄せた。

　型紙と見本。十六着分の仕立て。貸出後の手入れ。運搬。

　数字を書き出すあいだ、瀬田は生地を見ていた。

「これ、もう切ってありますか」

「まだです。今日、裁断に入るつもりでした」

「よかった」

　小さく言ってから、瀬田は真帆を見た。

「あ、すみません。よかったっていうのも」

「切る前でよかったです」

　真帆がそう答えると、彼の肩が少し下がった。

　計算用紙を二人のほうへ向ける。瀬田の母は鞄から眼鏡を出した。

「余った生地の代金は、ここには？」

「入れていません。店に残して、別の衣装に使います」

「使えるんですか」

「使い道はこれから考えます。でも、そこは今回お願いできる費用ではありませんから」

　口にすると、腹の底にあった迷いがようやく形をなくした。損が消えたわけではない。何を話し合うべきかが、はっきりしただけだった。

　瀬田の母は用紙の合計を見て、すぐには何も言わなかった。

「こちらの運搬を、私たちでやったらどうでしょう」

「受け取りと返却、両方ですか」

「車は出せます」

「それなら、この分は外せます。ただ、雨でも衣装が濡れないように運んでいただく必要があります。箱はこちらで用意します」

　真帆が数字を直すと、女性は初めて鞄から小さな手帳を出した。ページの隅に書かれた金額と見比べ、指で二度たどる。

「ここまでなら、出せます」

　示された予算には、まだ少し届かなかった。

　瀬田が身を乗り出した。

「飾りを減らすのはどうですか。袖の、あの結ぶやつとか」

「それは踊っているときに動きが出るので、できれば残したいです」

　真帆は衣装の見本を棚から下ろした。藍色の袖口から白い飾り紐が垂れ、低い椅子の座面に触れた。

「背中の紋を刺繍ではなく、縫いつける別布にするなら、作業を減らせます。遠くからの見え方は変わりますが、大きさは同じにできます」

　瀬田の母は見本を持ち上げ、背中を確かめた。

「洗ったときに外れたりは」

「祭りのあとはこちらで手入れします。そこも含めた貸出料です」

「そうでしたね」

　女性は契約書の一枚目に戻った。

　真帆は変更点を余白に書き留めた。十六着。背の紋は別布。店頭で受け取り、店頭へ返却。

「この条件で、作り直した契約書を確認していただけますか。お支払いは、契約時に三割、受け取りのときに残りをお願いします」

「それは大丈夫です」

「それと、着数は今日決めていただきたいです。裁断を始めてから減らす場合には、進んだ作業と材料の費用がかかります。その計算方法も書き加えます」

　瀬田の母は息子を見た。

「十六で、間違いないのね」

　瀬田はうなずきかけ、止まった。

「その前に、一つだけ」

　真帆の鉛筆も止まる。

「古い衣装の八人、同じ列で踊るんです。そんなに、ちぐはぐになりますか」

「現物はありますか」

「車に。母が、念のため持っていこうって」

　瀬田の母は眼鏡を外した。

「使えるつもりで話して、使えなかったら困りますから」

　瀬田が車へ戻ったあと、真帆は見本を台の上に広げた。女性も立ち上がり、袖が落ちないよう、そっと内側へ折った。

「息子は、全員揃えてやりたかったんです」

「はい」

「私も、できるならそうしてやりたいんですけど」

　真帆は、計算用紙を見た。消して書き直した運搬費の跡が、紙に残っている。

「古い衣装を見てから、並べ方も考えてみましょう」

　戸が開き、瀬田が大きな紙袋を抱えて戻ってきた。

　中から出てきた衣装は、日に褪せた山吹色だった。肩には保管中についた折り癖があり、襟の内側に、白い布が縫いつけてある。

　真帆はその布を指で返した。

　屋号の下に、祖父の字で番号が書かれていた。

「これ、うちの衣装です」

「え？」

「ずいぶん前のものだと思います。貸し出し用じゃなくて、注文で作った……」

　縫い目をたどる。脇には広い縫い代が残してあった。体格の違う人へ渡っても、直して着られるように。

　真帆は山吹色の衣装の隣に、藍色の見本を置いた。少し離れて見てから、巻いてあった生地を細く引き出し、古い衣装の腰に渡す。

　瀬田が、台の向こうからのぞき込んだ。

「帯ですか」

「はい。八人分、同じ藍色を入れたら、揃って見えるかもしれません」

　真帆は手を離した。山吹色の上に、銀糸が細く光った。

「こちらも見積もりを出します。まず、残りの七着を見せてもらえますか」

　瀬田の母が紙袋を引き寄せた。

「全部、持ってきています」

　真帆は裁断台の契約書を、棚の上へ移した。八着を広げるには、台いっぱいの場所が必要だった。

## 応答 B
昨日、瀬田が持ち帰った契約書は、母親の鞄から出てきた。祭りの衣装、三十着。署名欄は空いたままで、数量の横に鉛筆で小さく「二十」とある。

「お返事の前に、相談させてください」

　母親は契約書を真帆のほうへ向けた。昨日、瀬田が返事を保留したのは、共同出資者である母の意見を聞くためだった。

　真帆は作業台の下へ足を引いた。今朝届いた生地の包みが、踵に触れた。

「二十着に、ということでしょうか」
「ええ。人数を確かめたら、それで足りますので」

　瀬田は入口の脇に立ったままだった。真帆が椅子を勧めると、母親の隣へ腰を下ろしたが、契約書には手を伸ばさなかった。

「まだ返事をくれてない人もいるんです。出られるなら出たい、とは」
「出たいと、出るは違うでしょう」

　母親の返事は瀬田に向いていた。真帆は見積書の控えを出し、契約書の隣に置いた。

「今、参加が決まっているのは二十人ですか」
「はい。それは、俺が一人ずつ確認しました」
「でしたら、まず二十着の場合で計算させてください」

　そう言ってから、台の下の包みを持ち上げた。茶色の包装紙の継ぎ目に、卸先のテープが何重にも貼ってある。隠したまま金額の話をするほうが、後で言いにくくなる。

「生地は、三十着分を取り寄せています」

　母親は包みを見たあと、署名欄を指で押さえた。

「まだ、お願いするとは申し上げていませんよね」
「はい。生地がなくなると間に合わないので、私の判断で先に手配しました」
「その分も、こちらが払うというお話ですか」
「いいえ。使わない分の生地代を、そのまま請求するつもりはありません」

　言いながら、真帆は包装紙の端を折り直した。仕入れの支払いは月末だ。請求しないと言えば消える数字ではない。けれど昨日、返事は持ち帰ると聞いて、自分はそれを受けた。

「ただ、総額を三分の二にすることもできません。計算し直した額を見ていただいて、それから決めていただけますか」

　母親は署名欄から指を離した。

　真帆は電卓を引き寄せた。祖父から継いだ貸衣装店で、衣装の寸法よりもよく測り直すようになったのが、この数字だった。祖父の頃の値札を付けたまま貸して、洗いと直しの代金を引いたらほとんど残らなかったことがある。今日は、最後の合計から先に値引きをしない。

「昨日の見積もりは、一着八千円でしたよね」

　母親が言った。

「三十着で二十四万円です。今回はうちで新しく仕立てて、祭りのあとに返していただく。その条件は変わりません」
「二十着なら十六万円だと思って来ました」
「型紙を作ることと、見本を一着仕立てて動きを確かめることは、数が減っても必要です。その費用を、昨日は三十着に分けて入れています」

　真帆は控えの裏に線を引き、共通してかかる費用と、一着ずつかかる費用を分けて書いた。六万円と、一着六千円。電卓の表示を確かめて、合計を母親へ向ける。

「二十着で、十八万円です。洗い代も含みます。破れなどの扱いは、契約書のこちらに」
「二万円、違うのね」

　母親は損傷時の欄へ移らず、見積もりの数字を見ていた。真帆は返事を待った。二万円ぐらい、と言ってしまえば、この人が人数を確かめて来た手間まで小さくしてしまう。

　瀬田が椅子を台へ寄せた。

「差の二万は、俺が出すから」
「どこから？」
「それは、今月の」
「立て替える話なら、帰ってからにして」

　真帆は電卓を自分のほうへ戻した。二人の間で決まることなら待てばいい。だが瀬田は真帆を見て、すみません、と言いかけていた。

「お支払いの分担は、お二人で決めていただいて大丈夫です。お店からは、十八万円でお受けできるかというお話をしています」

　瀬田は口を閉じた。母親が初めて、鞄を膝から隣の空いた椅子へ移した。

「飾りを減らせば、もう少し下がりますか」
「どの飾りでしょう」
「袖の、白いところ。絵で見たとき、別の布を足しているように見えたので」

　真帆は図案を出した。袖口の白い部分を母親が指す。これは飾り布ではなく、腕を上げたときに裏側が見えるよう、袖を折り返す指定だった。

　包みを開き、生地の端を台に広げる。表の藍色を見せてから折り返すと、母親は図案と布を見比べた。

「ここは布を増やしていません。縫い方を変えても、今回、金額を大きく下げられるところではなくて」
「ああ、裏なの」
「はい。袖が揃って上がると、白が出ます」

　瀬田が布に手を置きかけ、止めた。

「これがいいと思ったんです。遠くからでも、動いたのがわかるから」

　母親は図案を裏返した。裏には何もなかった。もう一度表へ戻し、今度は襟の辺りを見たが、削れそうなものを口にはしなかった。

「十八万円なら、私が出す分は増やさずに済む？」
「ほかの予算を見直す。今度は、決まってる金だけで」
「見直してから言って」

　瀬田は携帯を出した。画面を何度か切り替え、母親へ見せる。真帆は布を畳み直しながら待った。机の向こうで、印刷する枚数と運搬の車について短い話が続いた。自分で運ぶ、と瀬田が言うと、母親は帰りの分も、と念を押した。

「衣装は十八万円でお願いします」

　母親が顔を上げた。

　真帆はすぐに契約書を取らず、瀬田を見た。

「瀬田さんも、二十着でよろしいですか」

　瀬田は鉛筆で書かれた数量を見ていた。

「あとから出たいと言われたら、増やせますか。布は、あるんですよね」
「布はあります。でも、縫う時間を空けて待つことはできません」
「一着か二着でも？」
「いつお返事をいただけるかで変わります。今日決めていただく二十着と、同じ納期でお約束することはできないです」

　ここで曖昧に頷けば、三十着分の仕事を待ちながら、二十着分の代金を受け取ることになる。真帆は図案の上に置いた定規をどけ、瀬田の前を空けた。

「追加を受けられるかと、その金額は、ご相談をいただいた時点でお答えします。今回の契約には、追加分の納期は含めません。それでもよければ」
「……わかりました。二十着で」

　瀬田は母親より先に言った。

　真帆は新しい契約書を印刷した。台の上で紙が温かいうちに、数量と金額を順に指し、納品日、返却日、申込金と残金の支払日を確認した。母親は途中で眼鏡を出し、損傷時の欄まで戻って読んだ。瀬田も同じページを開く。

　署名が終わると、昨日の契約書は不要になった。真帆が引き取ろうとすると、瀬田は一度だけその端を押さえた。

「これ、持って帰ってもいいですか」
「旧案だとわかるように、書いておきますね」

　斜線を入れた紙を瀬田へ渡す。その下にあった新しい契約書には、二十着と印刷されている。瀬田は古いほうを折り、新しいほうは折らずに鞄へ入れた。

　母親が椅子を戻す際、台に残った生地へ目をやった。

「残りは、返品できるんですか」
「この生地は、できません」
「そう」

　母親は包装紙に触れかけた手を引っ込めた。気遣われているのか、先走りを呆れられているのか、真帆にはわからなかった。ほかに使えるから平気です、という言葉だけは出さなかった。まだ使い道は決めていない。

　入口で、瀬田が振り返った。

「明日、寸法の表を持ってきます」
「お願いします。それと、見本ができたら、実際の振りで動いていただきたいんです。腕を上げるところだけでも」
「俺でよければ」
「では、瀬田さんに」

　母親が先に扉を開けた。瀬田は続きかけて、足を止める。

「袖の白いところは、そのままでお願いします」
「はい。そこは、そのままです」

　二人が出ていってから、真帆は生地の包みを作業台の中央へ置いた。二十着分を仕立てても、残りはここにある。棚をひと区画空けなければならない。

　まず、申込金の入金を確かめてから裁つ、と作業票に書いた。その下へ、瀬田の試着、と足す。

　台に残した図案を引き寄せ、袖の脇に鉛筆を入れた。腕を高く上げる。襟が引かれないか。白い裏が、客席から見えるか。

　瀬田に着てもらう一着目のために、真帆は作業台を端まで空けた。
