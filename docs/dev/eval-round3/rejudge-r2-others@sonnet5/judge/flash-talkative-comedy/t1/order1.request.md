## 応答 A
よその家には米だの洗剤だの景気よく引き当てておいて、自分の番になったら箱に手も入れられない。私である。さっきまで「無欲が大事ですよ！」とマイクで言っていた私である。返してほしい、さっきまでの信用。

　自治会の福引きは、係が番号札を引き、参加者に景品を渡す方式だ。今年は私が引く係になった。理由は声が通るから。声が通るだけで任される仕事には注意したほうがいい。去年は餅つきの掛け声を頼まれ、最終的に臼を洗った。声で洗えればよかったのに。

　さて、全世帯に配り終えて、係の私の分だけが残った。
　箱には札がまだある。景品は欠席世帯の分を含めて余っていて、特賞の布団乾燥機も残っていた。

　欲しい。

　うちの布団はベランダの手すりから取り込むと、必ず焼き魚の匂いがする。階下の夕飯が早いのだ。日当たり良好、塩サバつき。いや物件紹介はいい。

「早く引いて。机しまうから」

「でも私が特賞を引いたら、仕込んだと思われません？」

「そう言っていただけるのはありがたいんですが、皆さんの帰宅後ですよ。あの人、最後にちゃっかりって」

　公民館には私と蓮見さんしかいなかった。片づけまで逃げ切った皆さんに、私はずいぶん律儀である。
　しかし気になるものは気になる。私自身、去年の係が電気ケトルを当てたとき、「へえ」と言った。あの「へえ」はよくなかった。今なら謝れる。ケトルを持っている家を一軒ずつ回ろうか。範囲が広いな。

「じゃ、私が引く」
　蓮見さんが箱を寄せた。助かった。第三者による抽選なら公平だ。

「待ってください。私が今、布団乾燥機を見たの、気づきました？」
「見てたね」
「それで気を遣われると」

　そうだった。何を期待しているんだ私は、会計の特殊能力に。

「引きます！」

## 応答 B
私が自治会の福引きでくじを引く係になったのは、手が乾いているからだ。

「去年、山田さんが汗で三枚くっつけちゃってね」

　会長はそう言った。人事の理由って、もっと志とか適性とかじゃないのか。まあ乾いてますけど。冬場なんかスーパーの袋が開かず、買った豆腐と見つめ合っていますけど。

　福引きの仕組みは簡単。名前を呼ばれた人の代わりに私が箱からくじを引き、書かれた景品を渡す。なぜ本人に引かせないのか。

「進行が早いから」

　会長、その説明をする間に三人は引けます。

　ともかく私は働いた。

「三等、洗剤セット！　おめでとうございます！　汚れには厳しく、ご近所には優しく！」

　余計なことまで言った。黙って手だけ動かせばいいのに、口が勤務時間を守らない。

「五等、ラップ！　包んでください、いろいろ！　言いたいこととか！」

　前列で副会長が腕を組んだので、以後は商品の効能だけ紹介した。ラップは食品を包めます。急に説明が薄い。

　やがて全世帯に景品が行き渡り、箱には一枚だけ残った。

「最後は、係をやってくれたあなたの分ね」

　会長に促され、私は手を入れた。すると会計の田辺さんが「あっ」と叫んだ。

　やめて。その「あっ」、歯医者で聞いても嫌なやつ。

「本人が自分のくじを引くのは、公平性の点でどうでしょう」

「今まで全員、私が引きましたけど」

「だからこそです」

　だからこそ、という接着剤で、つながらない話をつなぐな。

　私は手を抜いた。

「じゃあ会長、お願いします」

　会長が袖をまくる。そこへ副会長。

「会長は景品を選定した立場ですから」

「じゃあ副会長」

「私は会長を補佐する立場ですから」

　補佐、便利だな。責任まで半歩後ろにいられる。

　田辺さんは会計上の中立性を理由に断り、受付の佐藤さんは私と同じ班だから断った。裏の鈴木さんも候補に挙がったが、私が先月、脚立を借りていた。

「利害関係がありますね」

　あるか？　返したぞ？　脚立に上って得た利益は、電球が替わったことだけだぞ？

　誰かが「子どもに引いてもらえば」と言った。

　いい。子どもはいい。七歳のケンタ君が呼ばれた。彼は箱をのぞき、鼻をすすって言った。

「やったら百円くれる？」

　いちばん露骨な利害関係が来た。

　しかも私が「いいよ」と即答したせいで、田辺さんのメモが一行増えた。何を書いた。自治会に私の調書を残すな。

「そもそも、残り一枚なんですよね？」

　私は箱を振った。かさっ。ほら、この音。選択肢のない音。

「景品も、あれしか残ってませんよね？」

　長机の上には、特賞の高級炊飯器が鎮座していた。

　そうなのだ。私は全員のラップだの洗剤だのを引き当て、最後に炊飯器を残してしまったのである。言っておくが偶然だ。うちの炊飯器は蓋を押さえないと炊けないが、それは別件だ。最近は炊飯中ずっと辞書を載せている。米が多少、賢くなっている可能性はある。

「ここであなたに渡すと、最初から決まっていたように見えます」

「今、決まらなくて困ってるんですが！」

　とうとう会長が、箱を逆さにしてくじを落とした。

「誰も引いていない。これならどうです」

　全員がうなずいた。私は拍手した。長かった。米より先に私が炊き上がるところだった。

　床に落ちたくじを開く。

『特賞　高級炊飯器』

「では、贈呈を」

　私は両手を伸ばした。

　田辺さんが「あっ」と言った。

　もうその音を自治会で禁止してくれ。

「景品の受領確認は、係の方が署名する決まりです。ご自身への贈呈をご自身で確認するのは……」

　私は今、公民館でこれを書いている。炊飯器は目の前にある。会議も続いている。さっき妻から「ご飯どうする？」と連絡が来た。

　私は「辞書、載せといて」と返した。
