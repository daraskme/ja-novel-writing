2. 問いへの答え（引用つき）
Aは、景品が一つしか残っていないのに「選択肢がゼロだと逆に緊張する」と迷い始める不条理さが笑いを生んでいる。「なんで見てもいない顔を思い出して」というセルフツッコミが、思考が暴走する語り手の面倒な人物像を見事に表現し、出来事（ただ景品を受け取るだけ）を無駄に壮大な葛藤へ仕立て上げている点が良い。一方で、「特別な洗剤で洗った茶碗の味は」とまとめる結末の描写はやや唐突である。

Bは、「無難を選ぶ人間だと思われるのが嫌」といった自意識過剰な脱線や、「重さの確認であって、うっかり踏んだ」といったツッコミが、見栄っ張りで小賢しい人物像を描き出していて面白い。ただ、「四つのうちどれか一つに勝手に決まる呪」付近の会話は、誰の発言か一瞬迷う作りになっており、コメディとしてのテンポを落としているのが悪い点である。
