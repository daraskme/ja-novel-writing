1. 条件の充足

A：母の来店、注文数の削減、手配済みの生地をめぐる交渉を描いています。「きのう持って帰った書類」で前話を短く思い出させ、そのまま今回へ進む入り方も適切です。ただし、返事が保留だった設定と「契約時にいただいた手付金」が食い違います。

B：今回の出来事は満たしています。「昨日の件」で時間もつながります。ただ、前話では母に見せると明言していたのに、「誰かに広げて見せるつもり」と推測し直す回想は、既知の関係をぼかしています。また、祖父から継いだ店という設定は本文に表れていません。

両方とも、感情を会話や仕草で示す小説形式です。長さや語り口に具体的な指定はなく、その点で違反はありません。章題は本文の一部とみなせます。

2. 問いへの答え（引用つき）

受け取りたいのはAです。契約設定の矛盾は修正が必要ですが、今回の交渉から人物の事情が見え、次話への関心につながっています。

Aは「うちは資金を半分出している」で母の立場を示し、終盤の「母一人だと祭りの日は」によって、衣装代の交渉が瀬田の家業と祭りへの参加の問題へ広がります。「それでも毎年出てるのは」という言いさしから、瀬田が参加を続ける理由と来年の選択を知りたくなりました。一方、「決めたのはお母さんでしょう」は、交渉してきた真帆の応答としてやや突き放しており、二人の距離の変化を読み取りにくくしています。

Bは、冒頭の「反物にはほとんど目をやらなかった」母が、最後には「しばらく光にかざした」と変わる点が良いです。費用だけを見ていた母が衣装そのものへ関心を向ける変化を、動作で追えます。ただ、支払い条件が揺れるため、何に納得して態度が変わったのかが曖昧です。末尾の「まだ聞いていなかった」も余韻はありますが、瀬田の一枚がどれかという疑問が、次話で確かめたい問題としては弱く感じました。これは条件違反ではなく、連載の引きについての好みです。

3. 誤り

A：
- 未契約で返事が保留という前提に対し、「契約時にいただいた手付金」は明確な不整合です。
- 「最初の予算より高くつく」は、提示された費用だけでは説明できません。八着分の仕立てを減らしたのに総額が増える根拠がありません。
- 母が契約書を手帳にしまった後、瀬田が「印鑑を押し」となるため、押印する書類の所在がつながっていません。

B：
- 「一反で三十六尺」に衣装二十枚分が収まるという説明は、通常の半纏用の反物として寸法に無理があります。
- 残り五枚は二十枚の四分の一であり、「半分は来年の担ぎ手のため」は数量と合いません。
- 「今年は十五枚分」の支払いと、残りを「来年の分の前払い」とする説明がかみ合っていません。その後の分割払いも、五枚分だけか総額か不明瞭です。
- 型を洗うことを、翌年に同じ色が出せない理由とする説明には技術的な飛躍があります。
