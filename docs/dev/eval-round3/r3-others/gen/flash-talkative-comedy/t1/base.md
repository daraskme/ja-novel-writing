自治会の福引き係を任されたのは、単純に「あんた声大きいから」という理由だった。声の大きさと公正さって何の関係もないと思うんだけど、町内会というのは謎の人選ロジックで動いている組織なので、もう慣れた。

で、当日。ガラガラ回して、番号読んで、「はい一等!炊飯器!」「はい五等!ティッシュ十箱!」とテンポよくやってたんだけど、問題が発生した。景品係(私)自身の分の抽選券が、最後に一枚だけ残った。景品も、最後に一つだけ残っていた。つまり選ぶ余地がない。ないはずなのに、なぜか私は五分間そこで固まった。

残っていたのは「洗剤セット」。普通に良い景品。文句なし。なのに私の脳が急に会議を開き始めた。「洗剤って、もう家に三個あるよね」「でも消耗品だから困らない」「いや待って、隣の田中さんが欲しそうな顔してたの見た」「見てないよ、そんなの見てない、なんで見てもいない顔を思い出してるんだ」——完全に一人芝居。周りは「早く早く」って空気になってるのに、私だけ人生の岐路みたいな顔で洗剤の箱を見つめている。

会長が「どうしたの」って聞くから「いや、選べなくて」って言ったら、「選ぶもの一つしかないでしょ」って正論をくれた。そう、それはわかってる。わかってるんだけど、選択肢がゼロだと逆に緊張するタイプの人間っているんですよ、私みたいに。レストランで「本日のおすすめ一品のみです」って言われると、逆に「そのおすすめ、本当に自分に合ってるのか」と謎の吟味を始めてしまう、あのめんどくさい心理。

しかもここで余計なことを考え始めた。「これ、本当にランダムに残ったのか?誰かが気を遣って最後まで残してくれたんじゃ?」——いや違う、単純に数字の並びの結果です。私はただの確率の産物に運命を見出そうとしていた。福引き係のくせに福引きの原理を疑うという、職業倫理的にアウトな行為。

とはいえ箱を持った瞬間、変な満足感があった。「これ以上でもこれ以下でもない、ちょうどいい景品」感。炊飯器みたいに気合を入れて使う必要もなく、ティッシュみたいに地味すぎず、洗剤はちょうど中間の安心感がある。景品のヒエラルキーの中では中間管理職みたいな存在で、なんか勝手に親近感を持ってしまった。

最終的に、私は洗剤セットを両手で受け取り、周りに向かって「これ、私にぴったりです!」と謎に力強く宣言した。誰も聞いてなかった。会長はもう次の番号を読んでいた。

家に帰って洗剤を四個並べて、「これは選んだ景品だから特別」と自分に言い聞かせながらお皿を洗った。特別な洗剤で洗った茶碗の味は、特に変わらなかった。当たり前だ。

来年また係をやらされるらしいので、今度は迷わず即答するつもりだ——たぶん。
