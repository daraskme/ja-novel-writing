　真帆は作業台に反物を広げ、注文書と見比べていた。藍地に唐子文様、二十着分。糊気の残る布はまだ硬く、指先で撫でると藍の匂いが立った。染め屋から届いたのは三日前で、注文書の隅には自分の字で「瀬田様　二十　浴衣地　唐子文様　仕立て希望日　祭り前日」と書いてある。この柄はよその客には出せない特色で、染め代の半分はすでに前払いしてある。反物の端を折り返し、寸法札を留めていくと、これで契約書の分だけ揃った。あとは瀬田の返事を待つだけだった。

　入り口の鈴が鳴った。

「真帆さん、すみません、急に」

　瀬田が先に入ってきて、後ろから年配の女が続いた。日傘の柄をきつく握っている。目は店の中をひとわたり見て、帳場の上に掛けた古い写真の前で一度止まり、また台の上の反物に戻った。瀬田は昨日、契約書を持って帰った。母に見せると言って、返事はまだ聞いていない。

「母です。話が長引いて、電話より直接のほうがいいと思って連れてきました」

「瀬田の母です。息子がお世話になっているそうで」

　頭を下げる仕草は丁寧だが、目は台の上の反物を先に見ていた。真帆は寸法札を留める手を止め、二人分の椅子を出し、湯呑みに麦茶を注いだ。

「お店を継いで、まだどれくらい」

「三年になります」

「三年で、こんな数の契約は初めてでしょう」

「初めてです。だからこそ、無駄を出さないやり方を先に決めておきたいと思っています」

「二十着分、もう染めていただいたんですか」

「三日前に届きました。仕立てに入れる前に、寸法を確認していたところです」

　瀬田の母は椅子に浅く腰かけ、日傘を膝に立てたまま話し始めた。

「単刀直入に言います。二十は多すぎます。十二にしてもらえませんか」

　八人分の仕立て代が消える。染め代の前払いはもう戻らない。今月の家賃も、その八人分を当て込んでいた。

「母さん、それは昨日話した額とだいぶ違う」

「出資者は私よ。息子が決めていい額じゃない」

　瀬田が言葉を挟もうとして、止めた。真帆は反物の端に手を置いたまま、二人の間に置かれた沈黙を数えた。

「去年の祭りは雨で客足が落ちたでしょう。今年も台風の当たり年だって、天気予報の人が言ってた。二十揃えて八人分が残ったら、それはうちが被る損」

「祭りの出し物には、揃いの数がそのまま見栄えになります。十二では列の後ろが薄く見えます。委員会にはもう二十で伝えてあるし、若い衆に声をかけたのも、二十人分揃うからって口説いたんだ」

「見栄えより先に、うちの持ち出しの話をしています。去年も、宵宮の櫓の借り賃が予算より三万かさんで、埋めたのはうちのお金でした」

「櫓の話と、着物の話は別です」

「別じゃない。祭りにお金を出すたび、こっちが埋める側になる。今年は先に数を決めておきたいんです」

　真帆は反物を一枚めくった。裏に染めた日付と、染め屋の判が押してある。

「この柄は、この契約のためだけに染めてもらいました。反物の反数も、二十着分でちょうど揃うように頼んでいます。十二に減らしても、布は二十着分そのまま残ります」

「それはこちらの都合ではなく、お店の仕入れの都合でしょう」

「はい。ただ、残る八人分の布を私がどうにかするしかない、という話にはなります」

　瀬田の母は日傘の柄から手を離し、初めて反物に触れた。糊の硬さを確かめるように、指先で表を押している。

「その八人分、うちで引き受けろと言いたいの」

「そうは言っていません。三つ、考えられます。一つは二十着のまま進めて、代金は十二分の相談に乗ること。一つは十二着で契約して、残る八人分の布は私のほうで別の形にすること。もう一つは、間を取って十六で組むことです」

「別の形って」

「巾着や帯締めにして、祭りの当日に露店で売ります。仕立てより手間は少ないので、その分は値引きに回せます」

　瀬田の母は反物の端をつまみ、裏の判をもう一度確かめた。

「売れ残ったら」

「そこは私の在庫になります。そちらのお金は動きません。去年、はんてんの余り布で巾着を作ったときは、宵宮の店先に並べて三十分もしないうちに売れました」

「去年もこんなことをしていたの」

「去年は残り布が二人分でした。今年は八人分あるので、同じようにとは言い切れません。売れ残った分は、来年の別の柄に仕立て直せます」

　瀬田の母は反物から手を引き、日傘の先で畳の縁を二度なぞった。それきり黙っている。

「十六なら、うちの持ち出しはどれくらい減るの」

「二十のときの契約額から、四人分を引いた額になります。細かい数字は、いま出します」

　真帆は台帳を開き、鉛筆で足し始めた。反物の隅に留めた寸法札が目に入り、二十のうち十六だけに丸をつけてから数字に戻る。瀬田はその手元を見ていたが、母は台帳ではなく、真帆の顔を見ていた。

「仕立ての日数は、十六でも二十のときと同じで間に合うの」

「同じ職人が縫うので、間に合います。むしろ十六のほうが、当日の直しに手が回ります」

「仕立てが上がるのは、いつになるの」

「祭りの三日前です。前日に最終の直しをします」

「間に合わなかったら」

「揃いの色だけでも合わせた別布を、うちの在庫から回します。当日の朝までに」

　瀬田がようやく口を開いた。

「母さん、十六なら委員会にも説明できる。後ろの列は、去年と同じ人数だから薄くはならない」

「あなたはさっき二十を前提にしてると言ったばかりよ」

「前提は変えられる。数字を見てからでいい」

「口説いた若い衆には、何と言うつもり」

「四人には、はんてんじゃなくて別の役をお願いする。旗持ちでも、太鼓を運ぶ役でも、人手は要る」

「今からそんな話ができるの」

「今日中にする」

　瀬田の母は日傘を握り直し、台帳を覗き込んだ。真帆は算盤を使わず、鉛筆の下に数字を並べていく。二十分の代金から四人分の仕立て代と生地代を引き、残る布を巾着に回した分の見込みを足した。出てきた額を、指で示す。

「十六着、この額でどうでしょう。巾着と帯締めは、うちの店先でも祭りの日まで並べておきます。売れた分の一部は、次の契約の頭金に回せます」

「次の契約なんて、まだ決めていません」

「決めていません。ただ、置いておく理由にはなります」

「ただ、うちからもひとつだけ。染め代は先に半分払っています。仕立てに入る前に、残りの半分をいただけますか」

「それは今日でなくても」

「今日でなくて構いません。仕立てに取りかかる日までで結構です。反物を切ってしまうと、後戻りができないので」

　瀬田の母は少し考え、頷いた。

「わかりました。仕立てに入る日に合わせます」

　瀬田の母は台帳の数字をもう一度見て、日傘を畳んだ。

「隼人が去年、この店の話をしたとき、あなたのお祖父さんの名前を出したの。覚えてる」

　鉛筆が止まった。祖父の名を、この人の口から聞くのは初めてだった。

「祖父を、ご存じでしたか」

　瀬田の母の目が、また帳場の写真へ動いた。

「知っているというほどじゃない。昔、この店で借りた着物があるだけ。それより先に、この十六の額で判を押してくれる」

　真帆は台帳を差し出した。瀬田の母は日傘を椅子の背に掛け、印鑑を取り出した。判を押す前に、もう一度反物の唐子文様に指を這わせている。

「これ、うちの祖母の帯にあった柄と似てる」

　真帆は何も答えず、朱肉の乾き方だけを見ていた。
