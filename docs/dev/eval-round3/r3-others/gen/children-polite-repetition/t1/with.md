# 赤い長ぐつ、どこですか

　夏休みがはじまって、まだ三日目の、あついひるすぎのことです。ひまりは、庭のすみにある小さな池で、カエルのげんたと水遊びをしていました。げんたは、ひまりの家の池に、ずっと前から住んでいる大きなカエルです。

　二人は長ぐつをぬいで岸に並べ、はだしで水に入ると、つめたい水が足のあいだをすべっていきました。「わっ、つめたい」ひまりが声をあげると、げんたが「ぴょん」とはねて、水しぶきが顔にかかりました。ひまりは声を出して笑いました。

　おひさまが少しかたむいて、家に帰る時間になりました。ひまりが岸に上がって長ぐつをはこうとすると、右の、赤い長ぐつが見あたりません。左の長ぐつだけが、ぽつんと草の上に立っています。

「げんたくん、げんたくん、赤い長ぐつ、どこですか」

　ひまりが聞くと、げんたは首をかしげて、池のまわりをぐるりと見ました。

「見ていないなあ。でも、いっしょに探そう」

　二人は、池のそばの草むらへ向かいました。細い葉の上に、とんぼが一ぴき止まっています。

「とんぼさん、とんぼさん、赤い長ぐつ、見ませんでしたか」

　とんぼは、羽をすっと広げました。

「見たよ。風にのって、水の上をひらひら流れていったよ。あっちの、小川のほうだ」

　ひまりとげんたは、とんぼが向いたほうへ歩きました。花壇のはしに、かたつむりが一ぴき、ゆっくりと葉っぱの上をすすんでいます。

「かたつむりさん、かたつむりさん、赤い長ぐつ、見ませんでしたか」

　かたつむりは、つのをゆらして、ずいぶん長いあいだ考えました。

「見てはいないけど……この先の草の間、赤いものが、ちらちら光っていたような気がするよ」

　ひまりは、かたつむりにお礼を言って、げんたと川べりまで走りました。着くと、たしかに草の間に、赤いものがちらりと見えます。近づくと、それは長ぐつでした。流れてきて、太い草の根にひっかかって、止まっていたのです。

　ひまりが長ぐつを持ち上げようとすると、げんたが「待って」と言いました。

「中に、なにか入っている」

　長ぐつの中をのぞくと、小さなアマガエルが三びき、丸くなって涼んでいました。げんたよりずっと小さくて、色もまだうすい緑です。

「げんたくんの、子どもたち」

「うん。暑い日は、涼しいところを探して歩くんだ。長ぐつの中は、ちょうどいい日陰だったんだろう」

　ひまりはしゃがんで、そっと長ぐつを横にしました。子ガエルたちは、ぴょん、ぴょん、ぴょんと、順番に草の上へ跳んでいき、池のほうへ帰っていきました。げんたは、その後ろ姿を、しばらく見送っていました。

　ひまりは長ぐつを川の水でゆすいで、砂をはらいました。日にあたって、赤い色がもとのとおりに光っています。

　両方の長ぐつをはいて、ひまりとげんたは、来た道をゆっくり帰りました。

「げんたくん、げんたくん、また明日も、池で遊べますか」

「うん。また明日」

　夕方の風が、二人のうしろから吹いてきました。ひまりは長ぐつをぱたぱた鳴らしながら、家の灯りへ向かって歩いていきました。
