# あかい ながぐつ、どこですか?

小さな女の子、ゆうちゃんは、あかい長ぐつが大すきでした。雨の日も晴れの日も、いつもはいて歩いていました。

でも、ある朝、げんかんを見ると、あかい長ぐつが一本しかありません。

「あれ? 長ぐつ、どこですか? 長ぐつ、どこですか?」

ゆうちゃんは、庭に出て、池のそばに住んでいる仲よしのカエル、ぴょんたに聞きました。

「ぴょんた、ぴょんた、わたしの長ぐつ、見なかった?」

ぴょんたは、大きな目をぱちぱちさせて言いました。

「見なかったよ。でも、いっしょに探そう! 長ぐつ、どこですか? 長ぐつ、どこですか?」

二人は、まず花だんを見に行きました。チューリップの後ろにも、ひまわりの下にも、長ぐつはありません。

「長ぐつ、どこですか? 長ぐつ、どこですか?」

つぎに、木のうろを見てみました。どんぐりや、まつぼっくりはありましたが、長ぐつはありません。

「長ぐつ、どこですか? 長ぐつ、どこですか?」

そのとき、池の方から、パシャン、パシャン、という音がしました。

「あ! あの音、なんだろう?」

二人が池をのぞくと、あかい長ぐつが、ぷかぷかと水にういていました。中には、小さなおたまじゃくしが三びき、ちゃぷちゃぷと泳いでいます。

「わあ、こんなところにいたのね!」

ゆうちゃんは、そっと長ぐつを持ち上げようとしましたが、おたまじゃくしたちが、きゅう屋さんになってしまったみたいで、なかなか出てきません。

ぴょんたが、にっこりして言いました。

「ゆうちゃん、この長ぐつ、おたまじゃくしのおうちになっちゃったみたいだね。もう少し、貸してあげようよ」

「うん、そうだね! じゃあ、こっちの長ぐつは、あしたも、はけるように、ここにおいておこう」

ゆうちゃんは、片方だけの長ぐつをはいて、もう片方は、ぴょんたと一緒に、そっと池のはたにおきました。おたまじゃくしたちは、うれしそうに、くるくる回っていました。

その日から、毎朝ゆうちゃんとぴょんたは、池をのぞきに行きました。おたまじゃくしたちが、だんだん大きくなって、小さな手や足が出てくるのを、二人で楽しみに見ていました。

そして、おたまじゃくしたちが、みんな元気なカエルになって、長ぐつからぴょんと飛び出していった日、あかい長ぐつは、ちゃんとゆうちゃんの元にかえってきました。

ゆうちゃんは、また両方の長ぐつをはいて、ぴょんたと一緒に、池のまわりをぐるぐる歩きました。

「長ぐつ、見つかりました! 長ぐつ、見つかりました!」

二人は、うれしくて、なんどもそう言いながら、笑い合いました。

おしまい
