## ユーザーの依頼
よく喋る一人称のコメディ掌編を書いて。自治会の福引きで、くじを引く係が自分の景品だけ決められない話。語り手は脱線したり、自分で自分にツッコんだりする人にして。真顔で淡々と語る感じにはしないで。長さは1500字くらい、本文から始めて。

## 応答 A
福引き係というのは、くじを引かせる側であって、引く側ではない。当日までそう思っていた。

　餅つき大会の後片付けが終わって、抽選箱の中身がとうとう空になったとき、テーブルの上には景品が四つだけ残っていた。型落ちの炊飯器、米五キロの袋、よくわからないウサギの顔がプリントされた子供用タオル三枚セット、それから商店会の商品券三千円分。誰が見ても順位のつけようがない組み合わせで、これを「余り物は係が持って帰る」という去年からの謎ルールのせいで、わたしが選ぶことになっていた。去年この係をやった田中さんは炊飯器を持って帰って、それはそれで幸せそうだったからルールとして定着したらしいんだけど、田中さんは一人暮らしで、うちは四人家族なので条件がそもそも違う。前例というのは大体こういう形で参考にならない。

　いや、選ぶだけならいいんですよ。好きなものを取ればいい話でしょう。でも炊飯器って、うちもう炊飯器あるし、二台目の炊飯器を持つ人生というのがそもそも想像できない。米五キロは重い。重いのは嫌だという話ではなく、これから自転車で帰る人間に五キロの米を持たせるという発想そのものに文句がある。タオルは、まあ子供がいれば喜ぶのかもしれないけど、うちの子はもう中学生で、ウサギの絵のタオルで顔を拭く年齢はとうに過ぎている。商品券は無難。無難すぎて、無難を選んだという事実だけが残る。無難を選ぶ人間だと思われるのが嫌で無難を選べないという、これはもう完全にわたし個人の問題だった。

「まだ決まんないんですか」

　班長の山口さんが、テーブルの上を片づけながら聞いてくる。決まんないですね、と答えながら、わたしは炊飯器を持ち上げてみたり、米袋を軽く踏んでみたり（重さの確認であって、うっかり踏んだわけではない）、意味のない動作で時間を稼いでいた。人間、決められないときにやることが増えるのは、決めるための情報収集ではなく、決めなくていい時間を延ばすための儀式にすぎないんだと、こういうときによく分かる。

「じゃあじゃんけんで」

「わたし一人でじゃんけんはできないですよ」

「そういう意味じゃなくて、四つのうちどれか一つに勝手に決まる呪文みたいなの、ないんですかって話です」

「気持ちで決めればいいと思いますよ」と山口さんが言うので、気持ちで決めようとしてみた。これが失敗だった。気持ちで炊飯器を見ると、二台目を持つ人生への抵抗が強くなる。気持ちで米袋を見ると、重さへの抵抗が強くなる。気持ちで選ぶというのは選択肢を減らす方向にしか働かないもので、最後まで気持ちで選び続けたら、たぶん何も持って帰れない。

　一度は商品券に決めて、それでいこうと思った。でも決めた瞬間、ウサギのタオルが目に入って、あれ子供が中学生になったからもう要らないって決めたけど、来年また誰か子供が生まれるかもしれないし、というどうでもいい未来のことを考え始めて、決めたはずの商品券が急にまた候補に戻ってしまった。

　山口さんの日本語がだんだん怪しくなってきたところで、公民館の時計が鳴った。五時。もう鍵を閉める時間だった。締め切りという概念が現れると、人間の選択能力は急に正常に戻る……はずだったんだけど、わたしの手はそのとき、自分の意志とは関係なく商品券をつまみ上げていた。

「あ」

「決まりましたね」

　決まったというより、わたしの手が勝手に、いちばん軽くて、いちばん持って帰るのが楽な方を選んでいたらしい。悩んでいた三十分は、性格でも欲でもなく、たぶん体力の計算だけでできていたんだと思う。

## 応答 B
自治会の福引き係を任されたのは、単純に「あんた声大きいから」という理由だった。声の大きさと公正さって何の関係もないと思うんだけど、町内会というのは謎の人選ロジックで動いている組織なので、もう慣れた。

で、当日。ガラガラ回して、番号読んで、「はい一等!炊飯器!」「はい五等!ティッシュ十箱!」とテンポよくやってたんだけど、問題が発生した。景品係(私)自身の分の抽選券が、最後に一枚だけ残った。景品も、最後に一つだけ残っていた。つまり選ぶ余地がない。ないはずなのに、なぜか私は五分間そこで固まった。

残っていたのは「洗剤セット」。普通に良い景品。文句なし。なのに私の脳が急に会議を開き始めた。「洗剤って、もう家に三個あるよね」「でも消耗品だから困らない」「いや待って、隣の田中さんが欲しそうな顔してたの見た」「見てないよ、そんなの見てない、なんで見てもいない顔を思い出してるんだ」——完全に一人芝居。周りは「早く早く」って空気になってるのに、私だけ人生の岐路みたいな顔で洗剤の箱を見つめている。

会長が「どうしたの」って聞くから「いや、選べなくて」って言ったら、「選ぶもの一つしかないでしょ」って正論をくれた。そう、それはわかってる。わかってるんだけど、選択肢がゼロだと逆に緊張するタイプの人間っているんですよ、私みたいに。レストランで「本日のおすすめ一品のみです」って言われると、逆に「そのおすすめ、本当に自分に合ってるのか」と謎の吟味を始めてしまう、あのめんどくさい心理。

しかもここで余計なことを考え始めた。「これ、本当にランダムに残ったのか?誰かが気を遣って最後まで残してくれたんじゃ?」——いや違う、単純に数字の並びの結果です。私はただの確率の産物に運命を見出そうとしていた。福引き係のくせに福引きの原理を疑うという、職業倫理的にアウトな行為。

とはいえ箱を持った瞬間、変な満足感があった。「これ以上でもこれ以下でもない、ちょうどいい景品」感。炊飯器みたいに気合を入れて使う必要もなく、ティッシュみたいに地味すぎず、洗剤はちょうど中間の安心感がある。景品のヒエラルキーの中では中間管理職みたいな存在で、なんか勝手に親近感を持ってしまった。

最終的に、私は洗剤セットを両手で受け取り、周りに向かって「これ、私にぴったりです!」と謎に力強く宣言した。誰も聞いてなかった。会長はもう次の番号を読んでいた。

家に帰って洗剤を四個並べて、「これは選んだ景品だから特別」と自分に言い聞かせながらお皿を洗った。特別な洗剤で洗った茶碗の味は、特に変わらなかった。当たり前だ。

来年また係をやらされるらしいので、今度は迷わず即答するつもりだ——たぶん。
