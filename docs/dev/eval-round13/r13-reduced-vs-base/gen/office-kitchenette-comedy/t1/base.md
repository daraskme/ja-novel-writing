# 給湯室の革命

新入社員・田中が入社して三週間。給湯室のコーヒーメーカーには、茶色い水垢の地層が形成されていた。

「これ、誰の当番なんですか?」

先輩に聞くと、みんな目を逸らした。

「昔は当番表あったんだけどね」
「いつの間にか消えたんだよ」
「触ると負けみたいな空気があってさ」

田中は闘志を燃やした。(よし、僕が変えてやる。)

まず「コーヒーメーカー清掃当番表」を作成。名前を五十音順に並べ、ラミネート加工までして壁に貼った。我ながら完璧な仕組みだと思った。

翌週、当番の鈴木さんが担当日だったが、出張で不在。誰も代わらなかった。

「まあ、来週鈴木さんがやればいいか」

田中は表に「※不在の場合は次の人へ」と注釈を追加した。

さらに翌週、次の当番の佐藤さんが「自分は出張の穴埋めじゃなくて元々の当番だから、鈴木さんの分は別枠」と主張し、押し問答の末、結局誰もやらなかった。

田中は今度はLINEグループを作った。「給湯室美化委員会」。リマインダーを毎朝8時に自動送信する設定にした。

一週間後、グループの通知はミュートされ、既読すらつかなくなっていた。

田中は諦めなかった。次は「見える化」だ。清掃した人がシールを貼る台紙を用意し、「みんなで貯めよう!ピカピカポイント」と手書きのポップまで添えた。

課長が通りがかりに言った。
「田中くん、それ、小学校の給食当番みたいだね」
「効果あると思うんです!」
「まあ、頑張って」

そのポップの下で、コーヒーメーカーは相変わらず茶色かった。

ついに田中は最終手段に出た。清掃当番をやった人には、部長公認で「早退10分券」を発行するという、独自の経済圏を構築したのだ。総務に内緒で作った手作りの券には、田中自身のハンコまで押してあった。

これが効いた。翌日から当番表は埋まり始めた。みんな喜々としてスポンジを握り、コーヒーメーカーは見違えるほど白くなった。

一週間後、部長が給湯室に立ち寄り、ピカピカのコーヒーメーカーに目を細めた。

「おお、綺麗になったな。誰の発案だ?」
「田中です!」と誰かが答えた。

部長は田中を呼び出し、こう言った。

「早退10分券、うちの会社にそんな制度ないんだが」

田中は青ざめた。すでに配布した券は十七枚。回収は不可能だった。

結局、田中の始末書一枚と引き換えに、「早退10分券」は正式に労務規定に組み込まれることになった。総務部長いわく、

「まあ、コーヒーメーカーがずっと綺麗になるならタダみたいなもんだ」

こうして給湯室には、いまも当番表の隣に「田中発行・早期承認済み」のスタンプ入り券が誇らしげに置かれている。革命は、思わぬ形で成し遂げられたのだった。
