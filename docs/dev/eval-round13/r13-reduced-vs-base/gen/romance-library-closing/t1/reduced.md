閉館十分前を告げるチャイムが鳴ったとき、書架の間に残っていたのは佐伯と松倉だけだった。

ゼミの発表資料はとっくに刷り終えている。それでも佐伯は返却カートの前でぐずぐずと本の背を並べ直し、松倉は自分の席で消しゴムのかすを掌に集めては机の端に落としていた。どちらも、帰る理由を探しているのではなく、帰らない理由を探しているのだと、佐伯は自分の手つきを見て気づいた。

言うなら今日だ、と決めてきたはずだった。松倉の家が今日は寄り道せずに帰れる日だと、前のゼミの雑談でうっかり聞いてしまったからだ。なのに閉館十五分前のアナウンスが流れても、佐伯は返した本の順番を並べ替えるふりを続けていた。あと一冊、あと一冊、と自分に言い聞かせるうちに、カートの本はとうに片づいていた。

「閉館時間になりました。お忘れ物のないよう」

天井のスピーカーから司書の声がして、奥の書架から順に照明が落ちていく。暗くなった通路が、二人のいる机のほうへじりじりと近づいてくるみたいだった。

「松倉さん」

呼んでから、続きを用意していないことに気づいた。それでも止まらなかった。

「おれ、松倉さんのこと好きです。ゼミが始まった頃からずっと」

言い終えると同時に、頭の中が真っ白になった。取り消すことも、笑ってごまかすこともできる間があったのに、佐伯はそのどちらもしなかった。

松倉は手の中の消しゴムのかすを、ゆっくりと机の端に落とした。それから顔を上げた。目が合った瞬間、佐伯は自分の心臓の音が松倉に聞こえているんじゃないかと思った。

「知ってる」

え、と佐伯が言うより先に、松倉は続けた。

「気づかないふりするの、そろそろ疲れてた」

「じゃあ」

「うん。わたしも、同じ」

言ってしまってから、松倉のほうが先に赤くなった。佐伯は何か言おうとして、結局「マジで」としか言えなかった。松倉が小さく噴き出した。

最後の一列の照明が落ち、非常灯だけが二人を照らした。カウンターのほうで司書が鍵を鳴らしている。それでも二人はしばらく席を立たなかった。立ってしまえば、この十分間が終わってしまう気がした。

「連絡先、交換しよう」

佐伯が言うと、松倉はスマホを取り出しながら、まだ赤い顔で笑った。

「一つ言っとくけど」

「なに」

「わたしのほうが先に気づいてたからね、佐伯くんの気持ち」

「それ、今言う必要あった？」

「ある。忘れないでほしいから」

図書館を出ると、外はもうすっかり暗くなっていた。並んで歩く歩幅が、いつもよりずっと近い。松倉のスマホにはまだ、佐伯の名前が「さえきくん」とひらがなのまま登録されている。それを見せられて、佐伯は思わず笑ってしまった。

「なにその登録の仕方」

「変える暇なかったの。……あとで直す」

直さなくていい、と言おうとしてやめた。今のままでいいと思う理由を、うまく言葉にできなかったからだ。ただ、鞄の持ち手を握る手に力がこもるのを感じながら、佐伯は今日という日を、これからきっと何度も思い出すだろうと思った。

（約1220字）
