閉館十分前を告げるチャイムが鳴って、図書館の照明が半分落ちた。

「そろそろ出ないと閉め出されるよ」

そう言いながら、遠野は参考書をまとめる手を止めない。私は向かいの席で、さっきからずっと同じページを開いたままだった。頭に入ってくるのはゼミの資料の文字じゃなくて、机の下でずっと落ち着かない自分の足先のことばかりだった。

「あの、遠野くん」

声が思ったより大きく響いて、隣の書架からカタン、と小さな音がした。遠野が顔を上げる。蛍光灯が半分消えた薄暗さのせいで、彼の表情がいつもよりやわらかく見えた。

「今日でいいや、って決めてきたから言うね」

一気に言ってしまわないと、また来週に持ち越して、また来週に持ち越して、結局卒業まで言えない気がした。だから息を吸って、続けた。

「ゼミ、遠野くんと同じ班になってから、レジュメ作るの楽しみになってた。それ、多分、勉強のせいじゃない」

言い終わった瞬間、心臓が耳のあたりまで移動した気がした。遠野は数秒、ペン立てのペンを意味もなく直していた。それから、ふ、と笑って、こっちを見た。

「先に言われた」

「え」

「今日、閉館の音楽鳴ったら言おうと思ってた。もうちょっとで鳴るところだった」

館内放送のチャイムが、まるで合わせたみたいに鳴り出した。『まもなく閉館時間です』という機械的な声が響いて、遠野が肩をすくめる。

「タイミング、悪いんだか良いんだか」

「良い方だと思う」

気づいたら、二人とも笑っていた。声を出して笑うわけにはいかない場所だから、肩を震わせるだけの、変な笑い方で。参考書の山を挟んで、お互い顔を見合わせているだけなのに、世界がさっきまでと少し違って見えた。

「じゃあ、正式に。付き合ってください」

遠野が急に姿勢を正して言うものだから、今度は私が笑ってしまう番だった。

「そんな畏まらなくても」

「いや、ここ図書館だから。声抑えるとこうなる」

真面目な顔で言うのが余計におかしくて、また肩が震えた。カウンターの司書さんがこっちをちらっと見た気がしたけど、もう気にならなかった。

荷物をまとめて、二人並んでエントランスに向かう。自動ドアが開いた瞬間、夜の空気がひんやりと頬に触れた。キャンパスの街灯がぽつぽつと並んでいて、さっきまでいた蛍光灯の白い光より、ずっとあたたかい色に見えた。

「これから、レジュメ作るの前より楽しみになりそうだね」

遠野が隣で言うから、私は「うん」とだけ返した。それだけで十分だった。

閉館間際の図書館で、告白なんて柄じゃないと思っていたのに、いざ言ってみたら、拍子抜けするくらいあっさりと、両想いだった。歩き出した二人分の足音が、静かなキャンパスに小さく響いていく。

来週のゼミが、今からもう待ち遠しい。
