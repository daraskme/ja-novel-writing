宿「灯火亭」の厨房からは、湯気とともに香ばしい匂いが漏れていた。

「おお、いい匂いだ」

先に食堂に降りてきたのは、大剣を背負ったままの青年剣士だった。主人のガロンは鍋をかき混ぜながら、振り返りもせずに答える。

「剣は部屋に置いてこいと言っただろう。飯を食う場に鉄の匂いを持ち込むもんじゃない」

「これは癖でして……。それより今夜は何が出るんです?」

「山鳥のシチューだ。裏の森で獲れたやつを、丸一日煮込んだ。あとはパンと、川で採れた野草のサラダ。それに、お前さんたちが持ってきた塩漬け肉も少し使わせてもらったよ」

「あ、それ、隣町で買ったやつです。高かったんですよ」

「だから旨いんだろうが。文句あるか」

ガロンがニヤリと笑うと、青年も苦笑して席についた。続いて、杖を持った小柄な魔法使いの少女が、眠そうな目をこすりながら降りてくる。

「おはようございます……もう夜ですけど」

「昼過ぎまで寝てたお前が言うことか。ほら、席に着く前に手を洗ってこい」

「はーい」

少女がのそのそと井戸の方へ向かうのを見送りながら、青年が尋ねた。

「主人さん、このシチュー、いつも同じ味付けなんですか? 前に来たときと少し違う気がする」

「よく気づいたな。今回は森ニンニクの代わりに、南の商人から仕入れた黄色いスパイスを使ってる。名前は忘れたが、辛みより甘みが立つやつだ。子供でも食えるようにって女房が調合を変えた」

「へえ……」

「あんたら、いつも命懸けの旅をしてるんだ。飯くらいは、変わり映えのしない安心できる味であってほしいのか、それとも旅先ならではの新しい味を楽しみたいのか、いつも迷うんだがね」

「両方欲しいです、贅沢言えば」

「贅沢言うな」

そう言いつつも、ガロンは大きめの器にシチューをよそい、パンを厚めに切って添えた。湯気の向こうで、僧衣を着た年配の男が静かに席についている。

「今日も見事な香りですな」

「神官様は薄味がお好みでしたな。取り分けて別に用意してあります」

「痛み入る。……この宿の飯を食うと、旅の疲れが半分になる気がします」

「半分は言い過ぎだが、腹が減ってちゃ剣も魔法も振るえんからな。しっかり食え」

戻ってきた魔法使いの少女が席に着き、シチューを一口すすると、目を丸くした。

「甘い……でも後からちゃんと来ますね、この辛さ」

「わかるか。それが黄色いスパイスの仕事だ」

「主人さんも料理人だったんですか?」

「昔はな。今は宿のおやじだが、腕は鈍っちゃいない」

四人が食卓を囲み、湯気の向こうで笑い合う声が、静かな夜の宿に満ちていった。ガロンは厨房の入り口に立ったまま、しばらくその様子を眺め、また鍋の前へと戻っていった。
