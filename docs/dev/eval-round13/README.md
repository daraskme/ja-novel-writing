## 言えること・言えないこと

- 言える: 娯楽の依頼では、初稿の前に読む参照が `flash-experience.md` だけになった（Codex と Claude Code の両方で確認）。静かな失恋の依頼は、文芸の道に振り分けられた。二人の読者で不足の指摘が重なったのは 3 組（給湯室の reduced の読後感、宿屋の勇者一行らしさ、夏祭りの base の台詞の多さ。原因の診断まで一致したわけではない）。
- 言えない: 変更後の本文が、変更前やスキルなし版より読まれること（娯楽の 3 依頼の「読みたい」は、所有者が「同じくらい」2・base 1、回答 2 が reduced 1・「同じくらい」2。依頼と生成が回ごとに違い、読者は 2 人）。二人の読みから一般の読者の好みを推すこと。所要時間が縮んだこと（同じ日の prev2 と変わらない）。
- 未解決: 守る条件の字数で、初稿が下限の近くに出ること。軽量確認が 1 回で終わらないこと。創作の出来を指示で制御しきれるのか、という問い自体（読み直し 2 回で、文言の追加は選好を動かさなかった）。
