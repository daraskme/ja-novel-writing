# 評価ラウンド 13（2026-09-19）: 初稿の前に読む規則を減らす

読み直しの第 2 回（`../eval-round11/README.md`）で、文言を足した版が 3 依頼とも選ばれなかった。Codex（gpt-6-astra）に相談し（`../consult-3-reduce-rules-before-draft.md`）、文言をさらに足すのをやめて、**初稿の前に読む規則を減らす**構造の変更を入れた。このラウンドは、その変更が手順として働くか（どの参照を読むか、時間と費用）を確かめたもの。**出来ばえは、どの判定役にも読ませていない。** 人間の読み比べに回した（下の「読み比べ」）。

## 入れた変更（相談 3 から）

相談の診断: 選ばれなかった版に欠けていたのは感情の語の数ではなく、**人物が出来事を受け取る過程**（告白へ踏み切るまでの時間、返事を受け止める反応、空回りする本人の張り切り方、相手への関心で進む会話）。抑制を禁じる例外は増やしてあったが、実行しやすい既定と例文は抑制の側に残っていて、どの作品でも初稿の前に読ませていた。

- `SKILL.md` の「書くときの操作」を、**どの作品でも守ること**（場面カード、視点と声、依頼の売りを中心に置く、依頼文の条件の照合、継ぎ足し後の通読、字数の扱い）と、**作風で分かれる操作**に分けた。
- 作風の道を二つにした。**娯楽の道**（恋愛、コメディ、ほのぼのした日常など）の掌編は `references/flash-experience.md` だけを読み、素直に書いて、限定した直しだけをする。`prose-core.md` は初稿の前に読まない。**文芸の道**は従来どおり `prose-core.md`。
- `references/flash-experience.md` を新設（出来事を要約で通り過ぎない、人物がどう受け取ったかを書く、踏み切る前の時間、相手への関心で進む会話、約束した気分を結びまで保つ、可笑しさは人物の張り切り方から。書いたあとは、依頼と本文の照合・軽量確認 1 回・支障のある箇所だけ）。毎回一定量を入れる規則にはしていない。
- 参照に残っていた抑制寄りの強制を選択肢に弱めた（`scene-cards.md` の会話カードは「隠す理由がある場面の型」、`short-pipeline.md` の結びの長さは作品の約束で決める、最終段落削除テストの繰り返しは余白で終える作品だけ）。
- 約束 5 に「依頼が求めた出来事と反応が本文のどこにあるかを指して確かめるのは編集上の確認で、採点ではない」を足した。

## 読み比べ（人間。実施中）

ここまでの読み直しは読者が 1 人で、Codex も「局所的な不具合の発見には十分だが、一般読者の好みの推定には足りない」と指摘した。複数の人に読んでもらうための共有シートを作った。

- 6 組。このラウンドの reduced 対 base が 3 組（図書館の告白、給湯室のコメディ、宿屋の夕食）、ラウンド 11 の new 対 base から、第 1 回でスキルあり版が選ばれた 3 組（夏祭りの帰り道、卒業旅行の最終日、十年ぶりの喫茶店）。後者は、1 人の選好がほかの読者でも再現するかを見るため。
- 由来は x / y の記号にして埋め、どちらがスキルあり版かの対応表はリポジトリの外に置いた。左右（A / B）の並びは読む人ごとに変わる。字下げ・空行・見出し記号・本文の外の注記（「前提」、末尾の字数）は揃えて外し、本文の字は変えていない。本文がすべて AI の生成であることは、シートの冒頭に書いた。
- ログイン不要。答えはその人の端末の中だけに保存され、最後に文章にまとめてコピーし、シートを渡した人へ送ってもらう（ページからの送信はしない）。
- 問いは第 2 回と同じ 3 つ（条件、読後感、読みたい）と任意のメモ。メモでは、わくわくした／笑えた行、冷めた／急がれた行、選ばなかった版から残したい所を尋ねている。
- 集めるのは選好の合算ではなく、**不足を感じた箇所が読者のあいだで一致するか**。結果はここへ追記する。

読み取れること:

- **娯楽の 3 依頼**: 第 1・2 回で base が選ばれていた宿屋は「同じくらい」になった。告白は、依頼を替えて「同じくらい」。コメディは 3 回続けて base。ただし依頼（告白）、生成、回がそれぞれ違い、1 試行・1 読者なので、構造の変更の効果とは言えない。
- **コメディは 3 回とも、Claude Code のスキルあり版が同じ骨組みに収束した**（当番表を貼る → 次の対策（シールとくじ／判子と写真）も空振り → 毎朝七時半ごろに出社して自分で洗うようになる → 当番表に戻って終わる。`../eval-round11/r11-new-vs-base/`・`../eval-round11/r12-after-reading/`・`r13-reduced-vs-base/` の各 `office-kitchenette-comedy`）。どの版も対策を一文ずつの要約で進め、皮肉な反転で静かに閉じる。同じ reduced でも、Codex が書いた予備確認の版（`r13-codex-precheck/`）は、台詞の応酬でポイント制度を先輩に使い倒される筋で、骨組みが違う。base は、対策ごとに周りの反応を場面で書き、ばかばかしい最終手段（「早退 10 分券」）と、はっきりした反転（そんな制度は無い → 正式に規定入り）で閉じる。`flash-experience.md` の「出来事を要約で通り過ぎない」「可笑しさは人物の張り切り方から」は、この本文では働いていない。
- **字数の範囲**: コメディの依頼は 800〜1,000 字。reduced は 810 字で下限の近く、base は 1,078 字で上限を 8% 超えていた（シートにも字数を出していた）。この読者は、条件を満たすのは「base だけ」とした。範囲の超過より、空回りとオチが無いことを条件違反と見ている（1 読者・1 組）。
- **同じ本文の読み直し**（夏祭り、卒業旅行、喫茶店）: 2 組は第 1 回と同じ選好で、卒業旅行は new から base に変わった。new を A に出したのは第 1 回と同じなので、並びのせいではない。第 1 回は new の「告白のあと言葉数が減り、地の文が増える」を評価し、今回は「あっさりしすぎ」とした。**同じ読者が同じ本文を読んでも、1 回の読みの選好は動く。** 間の議論が告白の溜めに集中していたので、読む基準が移った可能性がある。
- **3 回を通して、この読者で安定していること**: 告白と返事のような大きな場面の前に、地の文で時間を取ってほしい。台詞の多さや、なろう的な軽さは「素人感」として減点。あっさりしたもの、短すぎるものも減点。コメディは、空回りが見えて、オチがはっきりしていること。まとめると、娯楽の約束（出来事と感情の高まり）を、台詞の応酬ではなく地の文の厚みで運んでほしい、ということになる。これは、娯楽の道（素直に書く）と文芸の道（削る）の、どちらの既定とも合わない。
- **盲検の限界**: 回答者はシートを作らせた側で、s4〜s6 は第 1 回の結果（どちらがスキルあり版か）を知らされていた本文。s1〜s3 も、reduced 対 base の組であることは知っていた（どちらの側かは伏せてあった）。なお対応表では、6 組とも x がスキルなし版になった（組ごとの無作為で、偶然そうなった。確率は 1/64）。読む人に記号の意味は見えないが、結果を伝えるときに記号の意味を明かさないこと。

## 言えること・言えないこと

- 言える: 娯楽の依頼では、初稿の前に読む参照が `flash-experience.md` だけになった（Codex と Claude Code の両方で確認）。静かな失恋の依頼は、文芸の道に振り分けられた。
- 言えない: 変更後の本文が、変更前やスキルなし版より読まれること（所有者 1 人の読みでは、娯楽の 3 依頼が「同じくらい」2・base 1。依頼と生成が回ごとに違い、盲検も不完全）。所要時間が縮んだこと（同じ日の prev2 と変わらない）。
- 未解決: 守る条件の字数で、初稿が下限の近くに出ること。軽量確認が 1 回で終わらないこと。創作の出来を指示で制御しきれるのか、という問い自体（読み直し 2 回で、文言の追加は選好を動かさなかった）。
