閉館十五分前を告げる館内放送が流れて、返却台に本を積んでいた瀬名は、ちらりと壁の時計を見た。

「もう閉まっちゃうね」

向かいの席で参考文献リストをまとめていた小野寺が、ペンを置いて伸びをする。ゼミの共同発表資料は八割方できていた。あとは明日の朝でもいい範囲だ。

「小野寺さん」

呼びかけると、彼女はノートパソコンの画面から顔を上げた。蛍光灯の光が反射する眼鏡の奥で、目がまっすぐこちらを向いている。瀬名は昼間から何度も練習した言葉を、結局そのまま口にすることができなくて、代わりに全然違う質問をした。

「発表終わったら、二人で何かご飯行きません?」

「いいですよ、打ち上げみたいな感じで」

小野寺はあっさりと頷いた。想定していた返事と違って、瀬名は少し焦る。打ち上げ、みんなで、という意味だろうか。今この瞬間に言わなければ、たぶんこの先ずっと言えない気がした。

「あの、二人でって言ったの、その、ゼミのメンバー全員でって意味じゃなくて」

声が思ったより大きく響いて、隣の閲覧席にいた学生がちらりとこちらを見た。瀬名は慌てて声を落とす。

「ちゃんと言うと、小野寺さんのことが好きです。ゼミが始まった頃からずっと」

言い切ってしまうと、耳の先まで熱くなるのがわかった。小野寺は一瞬だけ目を丸くして、それから視線を机の上のノートパソコンに落とした。返事がない数秒間が、やけに長く感じられる。返却カートを押す司書の車輪の音が、やたらと大きく聞こえた。

「実は、来月あたりに私から言おうと思ってたんですけど」

顔を上げた小野寺は、困ったような、それでいて隠しきれない笑みを浮かべていた。

「先に言われちゃいましたね」

「え」

「同じです。私も、瀬名くんのこと」

その言葉が耳に届くまでに、少し時間がかかった。理解した瞬間、体の奥からじわっと何かが広がっていくのがわかる。嬉しいというより、安心に近い感覚だった。ずっと重たく抱えていたものが、急に軽くなった。

「マジで?」

つい素の言葉が出て、小野寺が小さく吹き出す。

「マジです」

館内放送がもう一度流れて、閉館五分前を告げた。二人は慌てて荷物をまとめ始めたけれど、手元はどこか上の空で、瀬名は資料をカバンに突っ込みながら、隣で同じように片付けをしている小野寺の横顔を何度も盗み見てしまう。目が合うたび、お互い意味もなく笑ってしまって、片付けが全然進まない。

「電気消しますよー」

館内アナウンスの声に急かされて、二人は最後に館内を出た学生になった。夜の空気はまだ夏の名残で少し蒸していたけれど、隣を歩く小野寺の肩がさっきより近い気がして、瀬名はそれだけで満ち足りた気持ちになった。

「さっきのご飯、打ち上げじゃなくて、普通に二人で行きましょうね」

念を押すように言うと、小野寺は前を向いたまま、耳を赤くして頷いた。

「わかってますよ」

自転車置き場までの短い道のりが、その日いちばん幸せな時間になった。
