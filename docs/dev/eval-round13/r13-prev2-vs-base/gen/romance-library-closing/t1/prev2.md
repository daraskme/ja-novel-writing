大学図書館の閉館まぎわ、ゼミの共同作業を続けていた二人が、告白と同時に「実は自分も先に言おうとしていた」と分かる場面を書きました。

---

　閉館十分前を告げる放送が、書架の上のスピーカーから流れた。四階の閲覧室にはもう二人しかいない。田村瑞穂は広げていたコピー用紙を重ね、ホチキスの位置を確かめてから、向かいの小野寺涼を見た。小野寺は返却期限のシールが貼られた本を三冊、背表紙の順に揃え直している。

　来週のゼミ発表のレジュメは、もう九割方できている。残りは瑞穂が担当した統計の章だけで、それも図表の位置を決めれば終わりだった。あと少し、あと少しと思いながら、瑞穂はさっきから同じグラフを見つめている。数字は頭に入ってこない。

「田村さん、あとどれくらいかかりそう」

「あ、ごめん、すぐ終わる」

　嘘だった。終わらせたくないだけだ。この本を返しに一階へ下りたら、小野寺は先に自転車置き場へ行ってしまう。そうしたら今日も言えない。

　瑞穂はシャープペンを置いた。

「小野寺くん、レジュメと関係ない話、していい」

「うん」

　本を揃える手が止まった。窓の外はもう真っ暗で、蛍光灯だけが二人の机を照らしている。天井の半分がふっと暗くなった。閉館五分前の合図で、照明を落とす手順のひとつだと、瑞穂は前にここでバイトしている先輩から聞いていた。

「わたし、小野寺くんのこと、好きです」

　言ってしまうと、思ったより声が大きく響いた。カウンターの方で司書が本を積む音がする。小野寺は本を揃える手つきのまま、しばらく動かなかった。

「……いつから」

「二年のとき、輪読の担当を代わってくれたときから」

「あれ、単に俺が暇だっただけだよ」

「知ってる。でも、そのとき」

　小野寺は本を三冊、机の端に寄せた。それから、返す言葉を探すみたいに、揃えたはずの角をもう一度指で撫でた。

「先に言われた」

「え」

「今日、田村さんが先に本を返しに行ったら、下の自販機の前で言おうと思ってた。二週間くらい、そのタイミングだけ探してた」

　瑞穂は自分の耳を疑った。疑ってから、じわじわと顔が熱くなるのが分かった。隠す場所がどこにもない。

「……先に言われたのは初めてで、悔しい」

「悔しいの」

「うん。俺の方が先に決めてたのに」

　その言い方があまりに小野寺らしくて、瑞穂は笑ってしまった。笑ったら涙が出そうになって、それも変だと思ってまた笑った。

　カウンターの司書がこちらを見て、それから壁の時計を見て、また本の山に視線を戻した。閉館の放送が二度目に流れる。

「片づけよう。怒られる」

「うん」

　小野寺が返却用の本を重ねて立ち上がる。瑞穂はコピー用紙を鞄にしまいながら、さっきまで頭に入らなかった数字の並びを、今度はちゃんと読めることに気づいた。

　エレベーターホールへ向かう途中、小野寺が三冊の本の一番上を差し出した。

「これ、代わりに返してきて。自販機の前で待ってる」

「一人で行かせる気」

「今日はもう、先に着いた方が勝ちにする」

　瑞穂は本を受け取って、返却口に向かって歩きだした。廊下の照明が、二人分の足音の後ろでひとつずつ落ちていった。

（1198字）
