　卒業旅行の最終日、菜穂は宿の玄関で、高瀬とみんなの荷物を見ていた。ほかの三人は、向かいのパン屋に朝食を買いに行っている。大学の友人五人で来た旅行は、昼のバスに乗れば終わる。
　高瀬はベンチの端に腰を下ろし、昨夜濡れた折り畳み傘を巻き直していた。
「高瀬、話してもいい」
「うん」
　傘を巻く手が止まった。菜穂は、その先を言う前に一度、パン屋を見た。店の前にはまだ列がある。
「好きなんだ。友達としてじゃなくて。卒業しても、付き合えたらって思ってる」
　高瀬の手元で、留め損ねた傘の帯が垂れた。
　旅行が終わるまで黙っているつもりだった。写真を送り合うやりとりが途切れたら、それで済むはずだった。でも今朝、みんなの靴が並ぶ玄関で高瀬が菜穂の分の荷物まで数えたとき、済ませたくないと思った。
「ありがとう。言ってくれて」
　高瀬は傘を膝に置いた。
「でも、ごめん。菜穂とは付き合えない。俺は、そういう気持ちではないんだ」
　菜穂は頷いた。頷くのは簡単で、次の言葉が見つからなかった。
　靴の先に、昨夜みんなで持ち帰った砂がついていた。帰ったら玄関で払わないと、と思い、それから、いま考えることではないと思った。
「そっか」
　ようやく声が出た。
「うん」
　高瀬は待っていた。菜穂がいつもの調子で何か言えば、この話を終わりにできる。冗談にして、肩を叩いて、パンが遅いとでも言えば。
「ちょっと、困った。ちゃんと振られると、こんななんだね」
　高瀬が口を開きかけたので、菜穂は首を振った。
「謝らなくていい。もう言ってくれたし」
「うん」
「帰ってから、しばらく連絡しないかも。写真も、すぐには見られないと思う」
「わかった」
　それだけの返事で、助かった。すぐ友達に戻る約束までしていたら、菜穂はきっと帰りのバスで後悔した。
　玄関の時計が進む音がした。高瀬は傘の帯を留め、足元の袋にしまった。
「先に向こう、行っててくれる。荷物は見てるから」
「わかった。何か買ってこようか」
　いつもなら高瀬と同じもの、と答えていた。頼み方まで知られているのが嬉しかったからだ。
「自分で選ぶ。あとで行くね」
　高瀬が出ていくと、菜穂はベンチに座り直した。目の下を指で押さえると濡れていた。鞄からハンカチを出して、しばらく顔に当てた。
　店の窓越しに、友人の真紀がこちらへ手を振った。菜穂も小さく振り返す。真紀は手にしたパンを掲げ、何か口を動かした。読めなかったけれど、丸くて大きなパンだった。
　菜穂は携帯を出した。
『私も選びたい。誰か荷物番かわって』
　送るとすぐ、真紀が袋を抱えて店から出てきた。小走りの足元で紙袋が跳ねる。菜穂はハンカチを畳み、ベンチに空きを作った。
「何がおいしそうだった？」
　声はまだ少し詰まった。それでも、店に入るころには決められるように、並んでいたパンの話を聞いた。
