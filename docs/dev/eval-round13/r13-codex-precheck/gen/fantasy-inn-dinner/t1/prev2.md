　宿の主人のベルタが玉葱を炒めていると、泊まったばかりの勇者が厨房の戸口から顔を出した。
「夕食、まだでしょうか」
「まだだよ。さっき部屋の鍵を渡したばかりだろう」
「はい。いい匂いがしたので」
　追い返すには正直すぎた。ベルタは粉を入れた鉢を顎で示した。
「手を洗っておいで。腹を空かせて見てるだけの人がいると、こっちまで急ぎたくなる」
　勇者はすぐに袖をまくった。

　今夜は青麦の団子を焼く。海沿いのこの町では、秋になると粉屋の軒先まで青い殻が吹き寄せる。白い小麦より粘りが強く、茹でてから焼くと、端がかりりとする。
　ベルタは炒めた玉葱を火から下ろし、勇者の鉢にぬるい湯を注いだ。
「耳たぶぐらいの硬さに練って」
　勇者は片手で自分の耳を触った。
「手、洗い直し」
「すみません」
　戸口で笑い声がした。杖を抱えた魔法使いだった。
「この人、言われたことを全部やるから」
「じゃあ、あんたには皿を並べてもらおうか。棚の茶色いの」
「全部？」
「泊まる人数ぶん」
　魔法使いは笑うのをやめて杖を壁に立てかけた。

　練り上がった生地を細く伸ばして切り、親指で浅くくぼませる。勇者の作る団子は大きかった。ベルタがひとつを切り分けると、次からは小さくなりすぎた。
「その間」
「難しいですね」
「売り物にするわけじゃない。火の通りが揃えばいいよ」
　ベルタは見本を手元に残してやった。勇者はそれを横に置き、ときどき自分の団子を並べて比べた。
　鍋へ落とすと、団子は底に沈んだ。ベルタは鍋底を匙でそっとさらい、脇の浅鍋へ燻製肉を入れた。脂が透き通ったところへ玉葱を戻し、羊乳を注ぐ。鍋肌の焦げをこそげるたびに、乳が薄い茶色を帯びた。
「それ、焦げてません？」
　皿を抱えた魔法使いが覗き込む。
「この色まではおいしい。ここから先は私の失敗」
「境目は？」
「今、話しかけないこと」
　魔法使いは皿を置きにいった。

　浮き上がった団子をもう少し茹で、湯を切って乳の鍋へ移す。くぼみに玉葱が入り、勇者が匙を持つベルタの手を目で追った。
「もう食べられますか」
「食べられるけど、まだ出さない」
　浅い焼き皿に移して、山羊の硬いチーズを削りかける。その上に、乾いたパンを揉み崩して散らした。
　勇者が身を乗り出した。
「そこ、厚くしてもらえますか」
「パン屑を？」
「焼けたところが好きなんです」
「だったら、広げないと。厚くすると下が湿る」
　ベルタが端まで薄くならすと、勇者はひどく真剣な顔で頷いた。

　焼き皿を竈へ入れる頃、僧侶が食堂から呼んだ。
「手伝いは足りていますか」
「足りてるよ。酢漬けの蕪を出しとくれ」
「味見をしたら、ずいぶん酸っぱかったのですが」
「だから肉と食べるんだよ」
「なるほど。パンを食べてしまいました」
　ベルタはパン籠を覗いた。端の硬いところだけが残っている。
「あんたたち、昼は？」
「干し林檎を」と勇者が答えた。
「分けました」と魔法使いが付け足した。
　それなら、と思ってベルタは残ったパンも砕いた。小さな鉄皿にバターを塗り、パン屑とチーズを広げて、焼き皿の隣へ押し込む。

　食堂へ運んだ団子は、縁のところでまだ乳をふつふつと煮立たせていた。匙を入れると焼けた表面が割れ、下から玉葱の甘い湯気が上がった。
　勇者は最初のひと口を飲み込んでから、自分の皿を見直した。
「あ、これ。僕が小さくしすぎたやつだ」
「火は通ってるだろ」
「はい。これもおいしい」
　魔法使いが酢漬けの蕪を噛み、すぐに団子へ匙を戻した。僧侶はパン籠へ伸ばしかけた手で、代わりに蕪の鉢を引き寄せる。
　ベルタは鍋敷きを足し、鉄皿のチーズ焼きを卓の真ん中に置いた。
「焼けたところの追加。ただし熱いからね」
　勇者が匙で端を剥がそうとしている間に、魔法使いが厨房から小刀を持ってきた。
「切り分けましょう。公平に」
「私のぶんも残しといておくれ」
　ベルタが言うと、勇者は隣の椅子に置いていた上着を取り、膝の上へ丸めた。
