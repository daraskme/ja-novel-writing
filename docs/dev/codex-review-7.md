**出荷を止める問題と修正案**

1. **C01・C03：同格形の後ろは、まだ「閉じた形」になっていません。**

   ```text
   「ありがとう」の四文字を否定した。
   「きゃく」の三拍を撤回した。
   「ありがとう」という四文字の言葉は存在しない。
   ```

   順に **C01 FAIL、C03 FAIL、C01 FAIL**。数の主張を否定・撤回している文章まで、数え間違いとして修正させます。

   [ASSERTIVE_TAIL](scripts/novel_lint.py:962) が格助詞以降の任意の述語を受け入れています。主題形は狭まりましたが、同格形には同じ問題が残っています。

   **修正案：** 同格形でも任意の述語をFAILの根拠にせず、数の断定を確認できた形だけに限定してください。「否定」「撤回」を追加するだけでは、疑念・不存在など別の述語で再発します。判別できない述語はWARNにします。

2. **C01・C03：訂正を読む前に文脈を切り捨てています。**

   ```text
   「ありがとう」の四文字。いや、五文字だった。
   ```

   **C01 FAIL＋C07 INFO**。

   ```text
   「きゃく」の三拍。
   　いや、二拍だった。
   ```

   **C03 FAIL＋C07 INFO**。どちらも本文自身が訂正しています。

   また、新規69では同じ文の後半に「数え直した」があるのにC01 FAILになります。[claim_context](scripts/novel_lint.py:995) は句点・改行で切り、さらに48文字までしか見ません。[呼び出し側](scripts/novel_lint.py:1098) にも60文字の制限があります。

   **修正案：** 長さ制限で文を読み切れていない場合は断定せずWARNにしてください。直後の文・段落が明示的な訂正である場合も、訂正前の数をFAILにしない処理が必要です。

3. **N01〜N04：非発話を台詞にする経路が残っています。**

   ```text
   本の題名は「終わり。」と言われている。
   ```

   **N04 FAIL**。引用の前に「本の題名は」があっても、[SPOKEN_AFTERの分岐](scripts/novel_lint.py:476) が文頭条件より先に成立します。説明された「引用が文の頭にある」という条件は、この分岐では適用されていません。

   ```text
   　画面には次の検索語が表示された。
   「...」
   　私は検索ボタンを押した。
   ```

   **N01 FAIL**。別行の題名・札でもN02〜N04が再現します。

   ```text
   「危険！入るな」 の札を外した。
   ```

   **N03 FAIL**。引用直後の空白で助詞判定が外れます。

   **修正案：** 明示された題名・文字列・札の文脈を発話動詞の推定より優先し、前後の段落も参照してください。後続判定の前には空白を除きます。「助詞でも『と』でもない」だけで台詞とする条件も、分類不能ならN09 WARNに倒す必要があります。

4. **N05：作中文書の本文は、句読点が付くだけで再び地の文になります。**

   ```text
   　母からのチャットを開いた。
   もう着きました。
   駅前で待っています。
   　私は走りだした。
   ```

   **N05 FAIL**。手紙、貼り紙、メニューの見出し、歌詞、漢数字の箇条書きでも再現しました。

   [narr_starts](scripts/novel_lint.py:561) の変更は項目行を除外できていますが、作中文書の範囲を認識していません。

   **修正案：** 作中文書の範囲を認識・指定できるようにし、その範囲を通常の地の文の字下げ集計から外してください。範囲が不確かな場合は混在をWARNにし、通常の地の文同士の明確な混在ではFAILを維持します。
