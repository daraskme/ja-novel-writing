## 応答 A
校了印を押したのは、日付が変わって一時を回った頃だった。瀬名は伸びをする代わりに非常口の重い扉を押し、先に屋上へ出る。ついて来い、とは言わず、扉を肩で押さえたまま待っていた。

　環と瀬名は、同じ春に編集部へ配属された同期だ。研修が終わってからずっと机は隣同士で、締めの遅い号のときは大抵この二人だけが最後まで残った。今夜も、創刊十年の特別号の色校を、瀬名はインクの匂いの残る刷り出しと見比べながら、環の隣で朱を入れていた。定規を滑らせる音だけが、電話も止んだ編集部に響いていた。

　風は排気口の匂いを含んで生ぬるく、フェンスの向こうでは高架を走る最終電車の灯りが一つ、線路のカーブに沿ってゆっくり遠ざかっていく。瀬名は上着のポケットから缶コーヒーを二本出し、片方を寄越した。無糖のブラックしか飲まない男で、いつもプルタブを引いてから、蓋を開けるまでに一拍置く。今夜もそうだった。

　環は缶を持ったまま、口をつけずにいる。ここまで来たら言うと決めていたのに、喉のところで言葉が固まった。缶を足元に置き、両手をフェンスにかけて、指の冷たさで踏み出す。半年前から用意していた言葉のはずが、いま並べてみると急に頼りない。それでも、今夜言わなければ次の号が始まってしまう。

「瀬名くん、私、瀬名くんのことが好きです。ずっと」

　プルタブに掛かっていた瀬名の指が止まる。環を見て、それから缶のふちを見て、もう一度環を見た。数秒の間があって、彼は缶を足元に置く。

「先を越された」

「え」

「言おうと思って、コーヒー買ってきた」

　瀬名は笑わずに言った。入社した年の夏、環が徹夜明けで色校の間違いを見つけたときから好きだった、と続ける。誰も気づかなかった小さな刷りずれを、環だけが指で示してみせた夜のことだ。忘れているだろうと思っていたので、環は少し泣きそうになった。

「私も。あのとき瀬名くんだけ、ちゃんと確認しに来た」

「それだけ？」

「それだけじゃない。でも、あれが最初」

　瀬名は環の足元から缶を拾い上げ、埃を払って返す。「乾杯にはまだ早いけど」と言って、自分の缶を軽く合わせた。

　環はようやく蓋を開けた。ブラックは苦く、それでも今夜だけは飲めそうな気がする。

「航一」

　名前で呼んでみると、思ったより自然に声が出た。瀬名は――航一は――少し驚いた顔をして、それから初めて笑う。

「次は、朝までやってる店に付き合ってもらう」

「いいよ」

　二人分の缶が、屋上のコンクリートに小さな音を立てて置かれた。始発が動くまで、まだ時間はある。

## 応答 B
提案書のプリントが終わったのは、日付が変わって一時間ほどしてからだった。谷口はホチキスの位置を確かめて三十部を揃え、クリップの向きをいつも同じ側にしてから箱にしまった。望は自分の分の校正紙をシュレッダーにかけ、最後の一枚が刃に巻き取られる音を聞いてから、伸びをした。

「屋上、開いてるらしいですよ。さっき田村さんが煙草吸いに行ってた」

　谷口が非常口の扉を肩で押すと、生ぬるい風が入ってきた。屋上には、去年の禁煙化で撤去された灰皿の跡が、コンクリートの色の違いとして四角く残っている。二人は室外機の並びを避けて、その四角の手前で足を止めた。自販機の灯りだけが、階段の入り口から漏れている。

「根岸さんの直し、ぜんぶ反映できました？」

「うん。あと、谷口くんが直した見積もりのケタ、助かった」

「あれ、去年もやったから。覚えてました」

　去年、望が競合コンペで負けた夜、谷口はこの階段のところで缶コーヒーを二本持って立っていた。何も言わず、片方を渡しただけだった。あのときのことを、望はいまだにうまく人に説明できない。

　谷口がクリアファイルの端を折り、また戻した。癖だ。緊張すると、いつも何かの角を触る。

　同じチームのまま気まずくなったら、来年の異動希望にも響く。そう思って、望はここまで自分から言わずにきた。

「望さん」

「はい」

「今日で言っておかないと、多分ずっと言わない気がして」

　風が室外機の音を運んできて、少しのあいだそれだけが聞こえた。

「好きです。同期とか、そういうのじゃなく」

　望は自分の声が思ったより落ち着いていることに、自分で驚いた。

「私も。谷口くんが去年、あそこでコーヒー渡してくれたときから、たぶんそうだった」

「それ、去年から黙ってたってことですか」

「谷口くんも今日まで黙ってたでしょ」

　谷口が笑って、それから笑うのをやめて、望の顔を見た。

「付き合ってください」

「うん」

　言葉はそれだけで済んだ。二人のあいだにあった距離が、その一往復でなくなった。

「呼び方、変えてもいいですか」

「変えて」

「望」

「うん」

　名前だけで呼ばれたのは初めてで、それだけのことに、望は自分の頬が熱くなるのが分かった。

「土曜、空いてますか」

「空いてる。空けます」

「じゃあ、駅前のあのラーメン屋。今度こそ、コンペ関係なく行きましょう」

「うん。行こう」

　谷口が伸びをして、灰皿の跡の四角を一度、靴の先で軽く踏んだ。望はその音を聞きながら、階下に戻ればまだ月曜の続きがあることを思い、それでも今夜だけは、この四角い跡の上に立っていたかった。
