ラウンド 6〜9（`../eval-round6/`）で残った 2 点、(1) 字数の指定がある依頼での継ぎ足しの周回、(2) 直球の告白で判定役の結果が割れること、について、Codex（gpt-6-astra）に相談し（`../consult-2-loop-and-confession.md`）、Grok 4.6 に検索つきで調べてもらった（`../research-grok/`）。ユーザーが別に Grok から得た回答（長編を安定させる型と、速く生成する方法）も参照した。その結論をスキルに入れたうえでの比較が、このラウンドである。

## 相談と調査から入れた変更

字数（工程で止める）:

- lint は数を報告するだけにする。字数の過不足への対処を lint が命じない（`novel_lint.py` の「次にやること」から「書き足す」「削る」を外した）。
- 字数の指定を種類で分ける。指定なし: 既定値への到達を確かめない。「約」「くらい」: 目安。実測を添えてそのまま出してよい。範囲・上限・最低字数・応募規定: 守る条件。満たせなければ未達と告げる。
- 足りないときは継ぎ足さない。構成（場面とやり取りの数）から 1 回書き直すか、要約になっている区間を、入口と出口の状態を保ったまま丸ごと書き換える。測り直しはそのあと 1 度だけ。
- 見積もりは字数でなく、場面の数とやり取りの往復の数で。守る条件の字数があるとき、2,000 字を超えるときは、二段以上に分けて書く（問いが立つところまで → 測る → 残り）。連載の章も、1 回に書くのは 1 場面。
- 掌編の検査は軽量確認を既定にする（`--only NCM`: 表記・数え上げ・混入と、1 行目の字数）。総合の検査は、推敲を頼まれたとき、気になる癖があるときだけ。

直球の恋愛（削除の基準を置き換える）:

- 「削って筋が通じれば終わり」を、「人物の関係、感情の変化、約束した読後感まで保たれていれば終わり」に置き換えた（prose-core の 9・10 節、short-pipeline の結末と最終段落削除テスト）。
- 積もっていた気持ち・受け止め・決断は別々の変化で、同じ感情の言い換えではない、と明記。
- direct の「名指しの直後に具体を接ぐ」を、毎回の必須から、抽象的な説明が続くときの手に弱めた。
- 恋愛の場面カードは、最初に「探り合いの途中」と「告白が実る山場」を分ける。山場では、告白と返事のあとに、二人が何を受け取ったかまで書く（行為を一つ置けば済む、とはしない）。
- 掌編でも感情の名指しの契約を検査に渡せるようにした（`novel_lint.py --emotion-naming direct`）。

## 依頼（6 件。どれもスキルの修正に使っていない）

字数の指定の種類と、恋愛の着地を振り分けた: 屋上の告白（直球の成就、1,000〜1,300 字）、夏祭りの帰り道（甘々の成就、1,500 字くらい）、十年ぶりの喫茶店（抑えた成就、指定なし）、卒業旅行の最終日（誠実な失恋、1,200 字前後）、給湯室のコメディ（800〜1,000 字）、宿屋の夕食（日常回、指定なし）。

生成役は Claude Code（Sonnet 5、ゲートウェイ経由）。系統は new（今回の変更を入れた版）、prev（入れる前の版。コミット b0f89b4）、base（スキルなし）。new 対 prev は、別々に作った応答を作り直さずにまとめた（`run.json` の `assembled`）。判定役は gpt-6-astra と Gemini 3.1 Pro。A/B を入れ替えて 2 回。

- **2 つの判定役が、new 対 base で正反対に出た。** gpt-6-astra は 4 件でスキルなし版、Gemini は 4 件でスキルあり版。提示順によらず同じ結果になった対の中で、両者が一致した対は無い。
- new 対 prev は割れていて、今回の変更で選好が良くなったとは言えない。
- gpt-6-astra の判定理由（スキルあり版への指摘）は 3 種類に分かれる。
  1. 返事のあとに温度を下げる台詞が入る（「乾杯にはまだ早いけど」「毎日は仕事にならない」「彼女でいい」）。依頼は「幸せな気分になれる」「甘々」だった。
  2. 細部の食い違い（缶コーヒーの開け方、当番表の記入の有無）。
  3. 末尾の「前提:」を、本文以外の混入として毎回挙げる（Gemini もほぼ毎回挙げている）。これは、依頼に無い仮置きを利用者に告げるための、スキルの意図した出力である。
- どちらの読みが利用者の実感に近いかは、判定役どうしでは決められない。→ ユーザーによる読み直し（由来を伏せた 7 組。体裁と「前提」を揃えて外したシート）で確かめる。

## 言えること・言えないこと

- 言える: 目安の字数と指定なしの依頼では、字数の測り直しが 2〜3 回に収まった。判定役の gpt-6-astra と Gemini は、この 6 依頼で正反対の選好を示した。
- 言えない: 今回の変更で読み比べの選好が良くなったこと。スキルあり版がスキルなし版より良いこと（判定役で逆になる）。所要時間が縮んだこと。
- 未解決: 守る条件の字数での周回。甘い場面に水を差す台詞。細部の食い違い。「前提」を既定で付けるかどうか（利用者の判断が要る）。
