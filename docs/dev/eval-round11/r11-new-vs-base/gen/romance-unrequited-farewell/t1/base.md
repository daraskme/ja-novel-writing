最終日の朝、僕らは高台の展望台に立っていた。眼下に広がる海は、四年間の何もかもを映すように静かに光っていた。

「見て、あの船」

美咲が指す先に、小さな漁船が一艘、白い航跡を引いていた。僕はその横顔を見ながら、この旅で何度も繰り返した言葉を、今日こそ言おうと決めていた。

「美咲、卒業したら会う機会も減ると思うから、今言っておきたいことがある」

彼女はこちらを向いた。風が彼女の前髪を揺らして、少しの間、二人とも黙っていた。

「ずっと好きだった。友達としてじゃなくて」

言い終えると、思ったより身体が軽くなった気がした。四年分の言葉を、ようやく手放せたからかもしれない。

美咲はすぐには答えず、海のほうへ視線を戻した。それから、ゆっくりと僕のほうを見た。

「ありがとう。ちゃんと言ってくれて」

そう前置きしてから、彼女は続けた。

「でも、ごめん。同じようには思えない。誠人のことは、この四年で一番信頼できる友達だと思ってる。だからこそ、はぐらかしたくなかった」

僕はうなずいた。悲しさはあったけれど、不思議と、それは想像していたような痛みではなかった。むしろ、真正面から向き合ってくれたことに、静かな安堵があった。

「正直、断られるだろうなとは思ってた。でも、ちゃんと聞いてもらえてよかった」

「聞かせてくれて、私もよかった。曖昧なまま卒業するより、ずっといい」

彼女はそう言って、少し笑った。気を遣った笑顔ではなく、ほっとしたような、自然な表情だった。

しばらく二人で海を眺めていた。気まずさはあったが、それは長くは続かなかった。四年間積み重ねてきた時間が、その気まずさをゆっくりと押し流していくのがわかった。

「これからも、たまに連絡してもいい?」と僕は聞いた。

「もちろん。誠人が就職したら、どんな社会人になるか楽しみにしてる」

「美咲こそ、あの夢、絶対叶えてよ」

「うん。見てて」

彼女はそう言って、遠くの水平線を指した。まるでそこに、これから始まる何かがあるかのように。

展望台を降りるとき、僕は自分の中で何かが静かに区切りをついたのを感じた。恋心がすぐに消えるわけではない。けれど、それを抱えたまま前に進む準備はできている気がした。振られたことは事実だけれど、失ったものより、確かめられたもののほうが大きかった。

バスに乗り込むとき、美咲が隣の席に座った。当たり前のように、これまでと同じ距離感で。

「次はどこ行く? 卒業したら、みんなでまた集まろう」

「いいね。今度は美咲が計画立ててよ」

「え、誠人がいつも適当に決めるから、私がしっかりしなきゃって思ってたのに」

笑いながら、バスは動き出した。窓の外には、来たときと同じ海が広がっていたけれど、僕の見え方は少し変わっていた。手にしていたものを一つ差し出して、代わりに、この四年間そのものの確かさを受け取ったような、そんな気持ちだった。

告白は届かなかった。けれど、その言葉を交わした場所に立っていたのは、これからも隣を歩いていける二人だった。
