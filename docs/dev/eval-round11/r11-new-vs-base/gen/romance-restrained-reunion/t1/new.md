　披露宴のあとの二次会まで、まだ四十分ほど間がある。「少し」と言い出したのがどちらだったか、尚子はもう思い出せない。式場の裏道にある喫茶店の扉は、十年前と同じ重さで開いた。

　田村は鞄を椅子の背もたれに掛け、コートを膝の上で畳んだ。順番まで、昔のままだ。

　尚子はブレンドを、田村はアイスコーヒーを頼んだ。十二月に、と思ったが口には出さなかった。二人きりで喫茶店の椅子に並ぶのは、記憶をたどっても十年ぶりだった。

　鞄の持ち手に、尚子は目を止めた。革の色は変わっているが、縫い目はそのままだ。一箇所だけ、太い麻糸で粗く縫われている。工房に入って一年目、まだ真っ直ぐに縫えなかった頃の、尚子の縫い目だった。

「まだそれ、使ってるの」

　田村はコーヒーに口をつけてから、鞄を一度見た。

「新しいの、何度も勧められたけど。持ち手だけ替えればいけるって言われて」

「誰に」

「あんたに」

　左手でグラスを持ち上げるとき、指に指輪の跡はない。それだけを確かめて、尚子はカップに視線を戻した。

「今、どこにいるの」

「工房、変わった。前のところは畳んだから」

「畳んだ」

「親方が体を悪くして。今は自分でやってる」

　田村は驚いた様子を見せなかった。驚かなかったことのほうが、尚子には応えた。

「新郎、うちの店の常連なんだって」

「知らなかった」

「向こうは知ってたみたい。あんたが来るって聞いて、来る気になったって」

　尚子は答えなかった。答える代わりに、鞄の持ち手を指で示した。

「これ、糸がもう擦れてきてる。切れる前に、今度見せて」

「今度って」

「今度」

　田村は少しの間、その言葉を確かめるように黙っていた。それから鞄を椅子の背もたれから外し、自分の膝の上に乗せ直した。

「持ち手だけじゃ、もう保たないかもしれない」

「保たなくても、直すよ」

　二次会の開始を告げる声が、扉の外で聞こえた。田村は席を立たず、鞄を膝に置いたまま、伝票をこちらへ押し出した。

「じゃあ、頼む」

　尚子は伝票の下に、名刺を一枚滑らせた。店の名前と電話番号だけが刷られた、いつもの名刺だった。それを財布ではなく、鞄の内側の小さなポケットへ入れたのを、尚子は見た。
