# 「当番表」

給湯室のコーヒーメーカーは、もう三週間掃除されていなかった。フィルターの縁には茶色い結晶がこびりつき、誰かが「これ、育ててる？」とつぶやくレベルに達していた。

新入社員の田中は、この状況を「改善できる問題」だと信じていた。彼はA4用紙に丁寧な当番表を作り、各人の名前を曜日ごとに割り振り、コーヒーメーカーの真上にテープで貼った。

「これで解決です」

翌朝、月曜担当の先輩は「今日出張だから」とスルー。火曜担当は「昨日使ってないから僕の責任じゃない」と言い張った。水曜担当は表の存在に気づいていなかった。田中は健気に、当番が飛ばされるたびに自分で掃除をした。

一週間後、田中は当番表をバージョンアップした。今度はチェックボックス付き、さらに「掃除したら判子を押す」という仕組みまで導入した。判子には自分のポケットマネーで買った、コーヒー豆のイラスト入りの可愛いものを用意した。

「押したくなる判子にすれば、みんなやってくれるはずです」

結果、判子を押すためだけに掃除もせずチェックを入れる者が現れ、田中はさらに疲弊した。彼は課長に相談した。課長は「うちの部署、昔から誰もやらないんだよ。歴代の新入社員が同じ表を作って、同じように諦めていった」と笑った。田中は自分の当番表が何代目かのリメイクだったことを初めて知った。

三週目、田中はついに「当番制」をやめることにした。代わりに導入したのは「掃除しない人が奢る制度」だった。コーヒーメーカーの横に募金箱を置き、「汚れてるのを見つけたら、直前に使った人が缶コーヒーを箱に入れる」というルールにした。誰が使ったかは、マグカップの位置と部屋の空気で「だいたいわかる」という牽制だけで機能させる、性善説と同調圧力のハイブリッド作戦である。

驚くことに、これは機能した。誰も奢りたくないので、使った後にさっと拭くようになったのだ。一ヶ月後、コーヒーメーカーはかつてないほど清潔になり、募金箱には誰も缶コーヒーを入れなくなった。

田中は密かに達成感を覚えていた。ある日、課長が給湯室でコーヒーを注ぎながら言った。

「田中くん、すごいな。これ、社内で表彰されるレベルだよ」

田中が謙遜しかけたその時、課長はマグカップを持ったまま、コーヒーの染みをテーブルにこぼし、何事もなくそのまま歩いて行った。

田中はしばらくその染みを見つめ、静かに募金箱を課長の机に移動させた。
