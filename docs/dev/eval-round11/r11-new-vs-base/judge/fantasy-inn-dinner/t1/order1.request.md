## ユーザーの依頼
異世界の宿屋の主人が、泊まりに来た勇者一行の夕食を用意する一場面を書いて。戦いの話じゃなくて、料理と会話で読ませる日常回にしてほしい。

## 応答 A
その日の客は四人組で、荷は軽く、靴は重かった。編み上げの底が片方だけ潰れているのを見て、峠の下り側から来たのだとオーレンは踏んだ。先触れの回状には、勇者の一行が越えてくるとだけ書いてあった。誰が勇者かまでは書いていない。宿帳には「四名、山越え」とだけ書いた。

　厨房では、朝のうちに猪の背を炙っておいた。脂だけ薄く残して切り身を鍋の縁に並べ、戻し汁ごと山茸を落とす。茸は今朝、猟師の孫が売りに来た分で、傘の裏がまだ湿っていた。湿っているうちに使わないと、明日には粥にするしかなくなる。塩は山塩を一つまみ、あとは客の匙に任せる。四人分なら鍋一つで足りるが、峠越えの直後は一人二杯を見込んで、多めに火を入れた。

　膳を運ぶと、四人のうち一人、数珠を膝に置いた男だけが匙を持ったまま鍋に手をつけなかった。オーレンは膳を置く手を止めた。
「うちのは山茸と猪です。肉が駄目なら、粥に変えます」
「……分かりますか」
「匙を鍋から遠ざけたまま止めてる客は、そう多くないので」

　粥を出すと、男は礼を言ってから、ようやく匙を動かした。

　剣を背負った女は鍋を一口食べて、それきり喋らなくなった。喋らないまま二杯目を頼んだ。
「靴、峠の下りで駄目にしましたね」
「石が滑るとは思わなかった」
「裏に修理屋がいます。安くはないですが、この先で修理屋はもう出てきません」

　フードを外した娘が、茸を匙で持ち上げて言った。
「この茸、うちの村にもありました。名前が違うだけで」
「名前は」
「あぶらしめじ、と呼んでました」
「こっちじゃ山茸で通ってます。同じかどうか、味比べてみますか」

　オーレンは厨房から、塩だけで炒った同じ茸を小皿に取って出した。娘は鍋の茸と小皿の茸を交互に口へ運び、しばらく黙って比べていた。
「同じです。うちのより、こっちのほうが水気が多い」
「山向きが違うので」

　残る一人、名を名乗らなかった男は、鍋を半分ほど食べたところで匙を置いていた。剣士がその皿を見て、
「団長、もう腹一杯ですか」
「……いや」

　男は少しの間、鍋の底に残った猪の脂を匙で追っていた。
「峠の向こうは、もう茸が出ないと聞いた」
「出ません。雪が早いので」

　男はそれで得心したように頷き、匙を鍋に戻した。
「もう少し、もらえるか」

　オーレンは鍋を運びながら、団長と呼ばれた男の膝の傷にちらりと目をやった。晴れているのに、右膝だけ包帯が巻かれている。訊かなかった。訊けば答えるだろうが、聞いたところで、こちらにできることは鍋を空にすることくらいしかない。

## 応答 B
宿「灯火亭」の厨房から、ぐつぐつという音と香草の匂いが漏れていた。

「今日は森トカゲの尾肉が安く手に入ったんでね」宿の主人ゴルドは、大鍋をかき混ぜながら言った。「臭みが強いから、赤ワインと酸味の強い山ベリーでじっくり煮込む。あんたら、辛いのは平気かい?」

「得意です」と剣士のレンが答えた。テーブルの隅で剣を布で磨いている。「戦うより先に、腹が空いて死にそうですけど」

「戦いより飯が本題の宿だからね、ここは」ゴルドは笑って、パンの塊をナイフで切り分けた。「表は硬いが中はもっちりしてる。バターの代わりにヤギの乳で作った塩気の強いクリームを付けるといい」

魔法使いのミレイユが本を閉じて鼻を鳴らした。「その匂い、知ってます。南の谷でしか採れない黒ベリーですよね。酸味が強すぎて、生じゃ誰も食べない」

「お嬢さん、詳しいね」ゴルドは目を丸くした。「昔、行商をしてた時分に谷まで買い出しに行ったことがあってさ。あの村の連中は、酸っぱいベリーを煮詰めて甘くする知恵を持ってた。教わったのをそのまま使ってるだけだよ」

「主人さんも旅をしてたんですね」

「若い頃の話さ。今はこうして鍋を振る方が性に合ってる」

僧侶のオーウェンが厨房の入り口からひょいと顔を出した。「手伝えることはありますか。祈るくらいしか能がありませんが」

「祈るより、そこの根菜の皮を剥いてくれるとありがたいね」ゴルドは笊を渡した。「薄く剥くんだよ、皮の下に旨味があるからね」

オーウェンは慣れない手つきでナイフを握り、根菜と格闘し始めた。ミレイユがそれを見て小さく笑う。

「戦うときはあんなに落ち着いてるのに」

「戦いは経典どおりに動けばいい。料理は経典に書いてないので」オーウェンは苦笑いした。

鍋の中身がとろりと煮詰まったころ、ゴルドは深皿に肉と野菜を盛りつけ、酸味の効いたソースをたっぷりかけた。「森トカゲの尾肉煮込み、山ベリー風味だ。冷めないうちに食いな」

レンが一口食べて目を見開いた。「うまい……酸っぱいのに、後から甘みが来る」

「それが煮詰めの妙よ。酸っぱいものを見捨てずに、じっくり付き合ってやると、こういう甘さが出てくる」ゴルドはパンを頬張りながら続けた。「あんたらも、これから先いろんな酸っぱい目に遭うだろうけど、じっくり付き合えば案外悪くないもんが出てくるかもしれないよ」

「主人さんの説教は、料理と一緒に出てくるんですね」ミレイユが笑いながらパンをちぎった。

「説教のつもりはないさ。ただの世間話だよ」

外では夜風が宿の看板を静かに揺らし、厨房の湯気だけが暖かく満ちていた。
