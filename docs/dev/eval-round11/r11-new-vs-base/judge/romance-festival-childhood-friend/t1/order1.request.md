## ユーザーの依頼
幼なじみもののラブコメで、夏祭りの帰り道に主人公が告白して、幼なじみも「ずっと好きだった」と返す山場を書いて。甘々で、二人の気持ちは全部セリフで言わせてほしい。1500字くらい。

## 応答 A
提灯の明かりが遠ざかる帰り道、浴衣姿の二人だけが取り残されたような静けさの中を歩いていた。

「なあ、陽菜」

「なに?」

「今日、屋台のとこでお前が笑ってるの見て、急に……なんか、もう限界だと思った」

「限界?」

「好きだ。ずっと前から。多分、小学校の時から」

陽菜の足が止まる。祭りの喧騒はもうほとんど聞こえなくて、代わりに虫の声だけが二人を包んでいた。

「……今の、もう一回言って」

「好きだ。幼なじみとしてじゃなくて、ちゃんと、一人の女の子として」

「ずるいよ、そんなの」

「ずるい?」

「うん。私の方がずっと先に好きだったのに」

「え」

「ずっと好きだった。多分あんたより先に。小学校の時、あんたが転んで泣いてるの隠そうとしてたとき、変なところ好きになっちゃったんだから」

「……それ、いつから黙ってたんだよ」

「言えるわけないでしょ。幼なじみが崩れたら怖かったし。あんたが他の女の子見てるとき、いつも心の中で『私を見て』って思ってた。言葉にしたら壊れそうで、ずっと黙ってた」

「じゃあ、なんで今」

「あんたが先に言ったから。ずっと待ってたの、あんたがそっち側に来てくれるの」

風が少し強くなって、浴衣の裾が揺れる。彼女は顔を上げて、まっすぐこちらを見た。

「返事、まだ聞いてないんだけど」

「言っただろ、好きだって」

「ちゃんと言って。今日から、ただの幼なじみじゃないって」

「陽菜のこと好きだ。彼女になってほしい」

「うん」

「うんって、それだけ?」

「足りない? じゃあもう一回言う。私も好き。ずっと好きだった。これからも、隣にいたい」

「……よかった」

「なにそれ、それだけ?」

「いや、心臓もつかと思った。ずっと片思いのつもりで祭り歩いてたから」

「バカ。私も同じ気持ちで歩いてたのに」

二人はしばらく黙って、でも自然に手を伸ばして、指をつないだ。

「これから、彼女って呼んでいい?」

「呼んで。何回でも」

「陽菜」

「うん」

「好きだ」

「知ってる。私も好き」

夜道に、二人分の足音がやっと同じ速さで重なっていく。祭りの終わりが、二人にとっての始まりになった夜だった。

## 応答 B
前提: 三人称一元視点（拓海）・過去形基調・常体・約1194字（依頼の「1500字くらい」よりやや短めですが、場面が書き切れた長さで出しています）。

　屋台の鉄板を洗い終えたころには、花火はとうに終わっていた。更紗の家が出していた焼きそばのソースの匂いが、拓海の腕にまだ残っている。片づけを手伝うのは、二人が小学生のころから続けてきた恒例で、今年も客が引くまで鉄板の前に立った。提灯の列を離れ、堤防沿いの道を並んで歩く。祭りの太鼓はもう遠く、川面に反射する明かりだけが揺れている。土手には夜露の匂いが立ちはじめていて、更紗の下駄の音が、その匂いのなかに一つだけ響いていた。

　途中から、その音が左右で違う音になった。
「鼻緒、擦れてる」
「うん。片づけのときにずれたみたい」
　更紗は片足を上げて、赤くなった指の跡を見せた。
「ここで少し休も」

　拓海は、二人が小さい頃から座ってきた石段に更紗を促した。となりに立つと、虫の声が土手いっぱいに広がっている。更紗は膝の上で金魚の袋を軽く振り、金魚がゆっくり向きを変えた。この石段は、毎年祭りの帰りに二人だけで少し話してから帰る場所で、去年もその前の年も、同じ順番でここに座っている。

「来年、東京だっけ」
「うん」
「そっか」
　金魚の袋がまた揺れて止まる。拓海はしばらく黙って川を見ていたが、来年もこの石段に座れるとは限らないと思うと、黙っていることのほうが怖くなった。

「更紗」
「なに」
「今年で最後かもしれないから、言っとく」
　更紗はこちらを見た。拓海は石段の縁を一度つかみ直してから続けた。
「好きだ。ずっと前から、ただの幼なじみでいいなんて思ったこと一度もない」

　更紗は金魚の袋を石段に置いた。
「知ってる」
「知ってたの」
「知ってた。たっくんが、絶対自分から言わない人だってことも知ってた」
　更紗は膝を抱えて、拓海の顔を覗きこんだ。
「じゃあ」
「私も好き。多分、たっくんより先から」
「いつから」
「小学校のプールでたっくんが溺れかけて、私が引き上げた日から」
「それ、たっくんが溺れかけたんじゃなくて、更紗がふざけて沈めたんだよ」
「細かいことはいいから」

　拓海は笑って、それから笑いきれなくなった。膝の上で拳を一度握って、開く。
「東京行っても、好きでいてくれる」
「行っても好き。会えないのがいちばん困る」
「月に一回は帰る」
「二週に一回にして」
「そんな頻繁には帰れないよ」
　更紗は金魚の袋を持ち上げて、拓海の膝にくっつけた。
「じゃあ毎日電話」
「毎日は仕事にならない」
「五分でいいから」

　拓海はしゃがんで、更紗の下駄の鼻緒に指をかけた。緩めて、結び目を作り直す。
「これで、朝まで保つ」
「ありがとう」
　顔を上げて、拓海は言った。
「彼女でいい」
　更紗は少し黙って、それから頷いた。
「うん。彼女でいい」

　更紗は立ち上がって、擦れていたはずの下駄の感触を確かめるように、その場で足踏みをした。もう痛くないという顔をしている。拓海は金魚の袋を代わりに持ち、もう片方の手を更紗に差し出した。
　二人はまた並んで、堤防の道を歩き出す。下駄の音は、もう揺れていない。
