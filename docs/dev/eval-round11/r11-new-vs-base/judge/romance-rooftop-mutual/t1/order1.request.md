## ユーザーの依頼
社会人の恋愛短編の山場を書いて。残業明けの会社の屋上で、同期に想いを告げて、相手も同じ気持ちだったと分かる場面。二人とも言葉でちゃんと伝え合って、読んだあと幸せな気分になれるやつがいい。1000〜1300字で。

## 応答 A
屋上に出た瞬間、夜風がやけに冷たく感じた。

「お疲れ、佳奈」

「お疲れさま、翔太」

自動販売機で買った缶コーヒーを二本、翔太が差し出す。佳奈はそのうちの一本を受け取って、まだ温かい缶を両手で包んだ。終電間近の空はビルの灯りで薄く白んでいて、星なんてほとんど見えない。それでも今夜はやたらと綺麗に思えた。

「あのプレゼン、佳奈のフォローがなかったら詰んでたわ。ほんと助かった」

「そんな大したことしてないよ。翔太が資料作り込んでたから、私は横で頷いてただけ」

「いや、あの土壇場でデータの矛盾見つけたのは佳奈だし。……昔からそうだよな。俺が焦ってる時に、佳奈がいると落ち着く」

佳奈は少し笑って、缶のプルタブをいじった。同期に入って四年、隣の部署に異動になってからも、こうして残業明けに屋上でだべるのが二人の習慣になっていた。それが特別なことだと、佳奈は最近ずっと気づいていた。気づかないふりをしていた、というのが正しいかもしれない。

「翔太」

「ん?」

言葉が喉のところで一度つかえて、佳奈は缶をベンチの縁に置いた。手が震えているのを見られたくなくて、ポケットに突っ込む。

「今日で決めてきたんだけど。ちゃんと言葉にする。……私、翔太のことが好き。同期としてじゃなくて、ずっと前から」

言い切った瞬間、体中の力が抜けるような感覚があった。もう戻れない。そう思ったら、逆に肩の荷が下りた気がした。

翔太は一瞬、缶を持つ手を止めた。驚いたような顔をして、それからゆっくり、佳奈の方に向き直る。

「……先に言われた。悔しいな」

「え?」

「俺もずっと考えてた。今日こそ言おうって、実は朝からタイミング探してた。プレゼンの後、佳奈が屋上来るか聞いてくれた時、正直めちゃくちゃ緊張してた」

佳奈は目を丸くした。心臓が跳ねる。聞き間違いじゃないかと、思わず一歩詰め寄ってしまう。

「翔太も、私のこと……」

「好きだよ。同期としてじゃなくて。佳奈がいてくれるから頑張れてたし、隣の部署に異動になった時、正直寂しかった。でも屋上でこうして話す時間だけは変わらなくて、それが俺にとってすごく大事なものになってた」

言葉を選びながら、それでも一つひとつはっきりと、翔太は伝えてきた。誤解のしようがないくらい、まっすぐに。

風が吹いて、佳奈の前髪が少し乱れる。それを見て翔太が小さく笑った。

「ちゃんと言葉にしてくれてありがとう。俺、たぶん今日言われなかったら、まだ数ヶ月ぐずぐずしてたと思う」

「私も、今日言えなかったらこのままずっと同期のふりして、いつか翔太が誰かと付き合うの見て後悔する未来しか見えなかったから」

「それは俺が全力で回避したい未来だな」

二人で笑い合う。さっきまでの緊張が溶けて、代わりに柔らかい温度が胸の奥に広がっていくのを佳奈は感じた。缶コーヒーはもうすっかり冷めていたけれど、それでもいいと思えた。

「じゃあ、今日から」

「うん。今日から」

言葉にした分だけ、確かなものになる。屋上の夜景を背にして、二人はしばらく、何も言わずにただ隣に立っていた。それだけで十分だった。

## 応答 B
校了印を押したのは、日付が変わって一時を回った頃だった。瀬名は伸びをする代わりに非常口の重い扉を押し、先に屋上へ出る。ついて来い、とは言わず、扉を肩で押さえたまま待っていた。

　環と瀬名は、同じ春に編集部へ配属された同期だ。研修が終わってからずっと机は隣同士で、締めの遅い号のときは大抵この二人だけが最後まで残った。今夜も、創刊十年の特別号の色校を、瀬名はインクの匂いの残る刷り出しと見比べながら、環の隣で朱を入れていた。定規を滑らせる音だけが、電話も止んだ編集部に響いていた。

　風は排気口の匂いを含んで生ぬるく、フェンスの向こうでは高架を走る最終電車の灯りが一つ、線路のカーブに沿ってゆっくり遠ざかっていく。瀬名は上着のポケットから缶コーヒーを二本出し、片方を寄越した。無糖のブラックしか飲まない男で、いつもプルタブを引いてから、蓋を開けるまでに一拍置く。今夜もそうだった。

　環は缶を持ったまま、口をつけずにいる。ここまで来たら言うと決めていたのに、喉のところで言葉が固まった。缶を足元に置き、両手をフェンスにかけて、指の冷たさで踏み出す。半年前から用意していた言葉のはずが、いま並べてみると急に頼りない。それでも、今夜言わなければ次の号が始まってしまう。

「瀬名くん、私、瀬名くんのことが好きです。ずっと」

　プルタブに掛かっていた瀬名の指が止まる。環を見て、それから缶のふちを見て、もう一度環を見た。数秒の間があって、彼は缶を足元に置く。

「先を越された」

「え」

「言おうと思って、コーヒー買ってきた」

　瀬名は笑わずに言った。入社した年の夏、環が徹夜明けで色校の間違いを見つけたときから好きだった、と続ける。誰も気づかなかった小さな刷りずれを、環だけが指で示してみせた夜のことだ。忘れているだろうと思っていたので、環は少し泣きそうになった。

「私も。あのとき瀬名くんだけ、ちゃんと確認しに来た」

「それだけ？」

「それだけじゃない。でも、あれが最初」

　瀬名は環の足元から缶を拾い上げ、埃を払って返す。「乾杯にはまだ早いけど」と言って、自分の缶を軽く合わせた。

　環はようやく蓋を開けた。ブラックは苦く、それでも今夜だけは飲めそうな気がする。

「航一」

　名前で呼んでみると、思ったより自然に声が出た。瀬名は――航一は――少し驚いた顔をして、それから初めて笑う。

「次は、朝までやってる店に付き合ってもらう」

「いいよ」

　二人分の缶が、屋上のコンクリートに小さな音を立てて置かれた。始発が動くまで、まだ時間はある。
