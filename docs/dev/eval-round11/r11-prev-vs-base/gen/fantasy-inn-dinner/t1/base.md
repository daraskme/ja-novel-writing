宿屋「灯火亭」の厨房から、鍋の煮える音と香草の匂いが立ち上る。

「おかみさん、今日の夕飯は何ですか」

台所の奥から顔を出したのは、旅装を解いたばかりの少女だった。腰には使い込まれた剣を提げているが、その目は子供のように厨房を覗き込んでいる。

「今日はね、川向こうの猟師が持ってきてくれた岩鹿の肉があるのよ。少し臭みがあるから、香り高いレンボの葉と赤ワインでよく煮込んでね」

宿の主人――名をミラという初老の女は、鍋の蓋を少し開けて中を見せた。とろりとした茶色の煮汁に、肉と根菜がくつくつと沈んでいる。

「臭みのある肉を美味しく食べる知恵ですね」

「そう。この世界に来て長いんでしょう、あなたたち。故郷ではこういう料理、しなかった?」

少女は少し考えてから答えた。

「うちの実家は牛や豚ばかりで……野生の獣の肉は、そのまま焼くくらいしか知りませんでした」

「あら、それじゃ勿体無い。獣の肉は下ごしらえが命よ。血抜きと、香草での下味。手間をかけた分だけ、優しい味になる」

そこへ、大柄な戦士の男が籠を抱えてやってきた。裏の畑からパンの下ごしらえに使う小麦粉と、頼まれていた根菜を採ってきたらしい。

「おかみさん、これで足りるか?」

「十分よ、ありがとう。あなた、力があるから助かるわ。今度は石臼を回すのも手伝ってちょうだいね」

「俺は剣より石臼の方が得意かもしれん」

男が真顔でそう言うので、少女がくすくすと笑った。厨房の隅では、ローブ姿の魔法使いの青年が暖炉の火加減を静かに見ている。焚き木の位置を少しずらすだけで、火の勢いが均等になった。

「あなた、火の扱いが上手ね。もしかして、魔法で?」

「いえ、ただの経験です。旅の途中で野営することが多いので……焚き火の癖はよく分かるようになりました」

「それは魔法よりも役に立つ技術ね。今度、パン窯の火加減も見てもらえる? いつも強すぎて焦がしてしまうの」

「喜んで」

やがて長い木のテーブルに、煮込みの鍋と焼きたてのパン、それに山盛りの塩茹で根菜が並んだ。パンの皮はかりっと香ばしく、割ると中からほのかに湯気が上がる。

「いただきます」

四人がそれぞれ器を手に取り、静かに、そしてどこか安らいだ様子で夕食を始めた。煮込みを一口食べた少女が、ふうっと息をつく。

「……おいしい。旅の途中でこんなにちゃんとした食事ができるなんて、思ってませんでした」

「あなたたちみたいな旅人がいっぱい来るから、この宿は繁盛してるのよ。でも、みんな慌てて次の町に向かっちゃうから、ゆっくり味わってくれる人は少なくて」

「僕らは……今夜は急ぎません。次の町までまだ時間はありますから」

魔法使いの青年がそう言うと、ミラは満足そうに頷いた。

「それなら明日の朝は、この土地でしか採れない蜂蜜を使った焼き菓子を出してあげる。楽しみにしてて」

窓の外では、異世界の二つの月が静かに光を落としている。厨房の暖かさと、煮込みの匂いと、四人の低い笑い声だけが、その夜の宿屋を満たしていた。
