　提案書のプリントが終わったのは、日付が変わって一時間ほどしてからだった。谷口はホチキスの位置を確かめて三十部を揃え、クリップの向きをいつも同じ側にしてから箱にしまった。望は自分の分の校正紙をシュレッダーにかけ、最後の一枚が刃に巻き取られる音を聞いてから、伸びをした。

「屋上、開いてるらしいですよ。さっき田村さんが煙草吸いに行ってた」

　谷口が非常口の扉を肩で押すと、生ぬるい風が入ってきた。屋上には、去年の禁煙化で撤去された灰皿の跡が、コンクリートの色の違いとして四角く残っている。二人は室外機の並びを避けて、その四角の手前で足を止めた。自販機の灯りだけが、階段の入り口から漏れている。

「根岸さんの直し、ぜんぶ反映できました？」

「うん。あと、谷口くんが直した見積もりのケタ、助かった」

「あれ、去年もやったから。覚えてました」

　去年、望が競合コンペで負けた夜、谷口はこの階段のところで缶コーヒーを二本持って立っていた。何も言わず、片方を渡しただけだった。あのときのことを、望はいまだにうまく人に説明できない。

　谷口がクリアファイルの端を折り、また戻した。癖だ。緊張すると、いつも何かの角を触る。

　同じチームのまま気まずくなったら、来年の異動希望にも響く。そう思って、望はここまで自分から言わずにきた。

「望さん」

「はい」

「今日で言っておかないと、多分ずっと言わない気がして」

　風が室外機の音を運んできて、少しのあいだそれだけが聞こえた。

「好きです。同期とか、そういうのじゃなく」

　望は自分の声が思ったより落ち着いていることに、自分で驚いた。

「私も。谷口くんが去年、あそこでコーヒー渡してくれたときから、たぶんそうだった」

「それ、去年から黙ってたってことですか」

「谷口くんも今日まで黙ってたでしょ」

　谷口が笑って、それから笑うのをやめて、望の顔を見た。

「付き合ってください」

「うん」

　言葉はそれだけで済んだ。二人のあいだにあった距離が、その一往復でなくなった。

「呼び方、変えてもいいですか」

「変えて」

「望」

「うん」

　名前だけで呼ばれたのは初めてで、それだけのことに、望は自分の頬が熱くなるのが分かった。

「土曜、空いてますか」

「空いてる。空けます」

「じゃあ、駅前のあのラーメン屋。今度こそ、コンペ関係なく行きましょう」

「うん。行こう」

　谷口が伸びをして、灰皿の跡の四角を一度、靴の先で軽く踏んだ。望はその音を聞きながら、階下に戻ればまだ月曜の続きがあることを思い、それでも今夜だけは、この四角い跡の上に立っていたかった。
