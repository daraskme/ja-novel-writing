屋上に出ると、九月の夜風がまだ湿った熱を残していた。

「お疲れ、望月さん」

声をかけると、彼女は缶コーヒーを両手で包んだまま、少し驚いた顔でこちらを見た。

「片瀬くんも残業? もう日付変わりそうだね」

自動販売機の光だけが白く灯る屋上で、二人の間に他には誰もいなかった。今日この四か月、ずっと言おうと思って言えなかった言葉が、喉の奥で詰まっている。

「あの、さ」

「うん?」

「入社してから、望月さんにずっと助けてもらってきた。同期で、一番信頼できる相手だと思ってる。……けど、それだけじゃなくて」

彼女はコーヒーの蓋を見つめたまま、動きを止めた。

「好きなんだ。同期としてじゃなくて、ちゃんと、一人の人として」

言い切った瞬間、心臓が痛いくらいに跳ねた。返事が来るまでの数秒が、やけに長く感じられる。

望月は顔を上げた。街の灯りを映した目が、少し潤んでいるように見えた。

「……ずるいよ、片瀬くん」

「え?」

「先に言われたら、私、意地張れなくなるじゃん」

彼女は缶コーヒーをベンチの縁に置くと、まっすぐにこちらを見た。

「私もずっと好きだった。同期だから、仕事の相棒だからって思うようにしてたけど、無理だった。片瀬くんが他の子と話してるだけで、勝手に苦しくなってた自分がいて。それが恋だってこと、ずっと前から気づいてたのに、言えなかった」

「なんで言えなかったの」

「怖かったから。今の関係が壊れるのが、一番怖かった」

「俺も同じだよ。同期っていう距離感が、ちょうどいい言い訳になってた気がする。踏み出したら、隣で笑い合える時間がなくなるかもしれないって思って」

望月は小さく笑って、目尻を指で拭った。

「じゃあ、二人とも同じくらい怖がってたってことだね」

「そうみたいだ」

風が一段と強く吹いて、彼女の前髪が揺れた。それでも彼女は目をそらさなかった。

「片瀬くん、はっきり言うね。私も、ちゃんと言葉にする。好きです。これからは、同期じゃなくて、ちゃんとあなたの彼女になりたい」

「望月さん」

「名前で呼んでよ、もう」

「……美咲」

呼び慣れない響きが、思ったより自然に口から出た。彼女は照れたように笑って、それから小さく頷いた。

「うん。これから、よろしくね」

「うん、よろしく」

握った手は、残業明けの疲れも忘れさせるくらい温かかった。屋上の向こうに広がる夜景は、いつもと同じはずなのに、今日だけは特別に輝いて見えた。

明日も同じ職場で、同じように顔を合わせる。けれど、もう「同期」という言葉だけでは足りない関係が、今、この場所で静かに始まったのだった。

二人はしばらく無言のまま、並んで夜景を見ていた。言葉はもう十分に交わした。あとは、この温度を確かめるように、ただ隣にいるだけでよかった。
