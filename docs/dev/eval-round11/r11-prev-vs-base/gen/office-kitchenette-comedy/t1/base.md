# 給湯室のセイギ

給湯室のコーヒーメーカーは、もう三週間掃除されていなかった。フィルターの縁には茶色い結晶が城壁のように積もり、誰かがマグカップを近づけるたびに、機械が咳き込むような音を立てた。

新入社員の田中は、入社二ヶ月目にしてこの惨状に気づいてしまった。彼は「見て見ぬふりをする組織文化」というものにまだ免疫がなく、正義感がやけに元気だった。

「よし、当番表を作ろう」

田中は模造紙に丁寧な表を書き、給湯室の壁に貼った。〈コーヒーメーカー清掃当番〉。曜日ごとに名前を書く欄まで用意した、完璧な表だった。

翌朝、表には誰の名前も書かれていなかった。

田中は諦めず、次に「清掃したらシールを貼るポイント制」を導入した。10ポイント貯まったら、なんと「田中が奢るコンビニスイーツ」と交換できる、という謎の景品まで自腹で用意した。

一週間後、シールが貼られていたのは1枚だけ。しかも田中自身が貼ったものだった。

三度目の正直で、田中はラミネート加工した「掃除しないと不幸になる」という怪しい張り紙を貼った。効果があったのは初日だけで、二日目には誰かがその張り紙の上に「Wi-Fiパスワード変わりました」という嘘の貼り紙を重ねて貼っていった。

とうとう田中は実力行使に出た。毎朝七時半に出社し、こっそり自分でコーヒーメーカーを掃除する日々。誰にも気づかれないまま、給湯室はいつの間にか清潔になっていた。田中は密かに満足していた。「正義は誰にも見られなくても果たされるものだ」と、心の中でひとりごとを言いながら。

そんなある日、部長が給湯室に入ってきて、ピカピカのコーヒーメーカーを見て感心した。

「おお、最近ここ綺麗だな。誰の当番だ?」

田中は「はい、実は私が…」と口を開こうとした瞬間、隣にいた先輩がすかさず答えた。

「あ、それ自動で綺麗になる新型なんですよ。総務が去年入れ替えたって噂で」

「へえ、いい時代になったなあ」

部長は満足げに頷き、給湯室を出て行った。

田中は、七時半に出社してひたすらブラシを動かしていた自分の腕を見つめ、そして壁に貼られたままの、誰も書き込まなかった当番表を見た。

――結局、この会社で一番働いていたのは、田中の腕とコーヒーメーカーだけだった。
