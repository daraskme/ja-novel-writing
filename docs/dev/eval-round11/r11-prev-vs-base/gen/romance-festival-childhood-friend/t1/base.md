祭りの帰り道、提灯の明かりが遠ざかって、あたりはもう虫の声しかしなかった。

「なあ、ちょっと待って」

歩き出した莱の背中に、俺は思わず声をかけた。振り返った莱の浴衣の袖が、風でひらりと揺れる。

「どうしたの、そんな真剣な顔して」

「……ずっと言えなかったことがあるんだ」

俺は下を向きそうになる自分を無理やり奮い立たせて、莱の顔をちゃんと見た。

「俺、莱のことが好きだ。幼なじみとかそういうのじゃなくて、ちゃんと――好きなんだ」

言ってしまった。心臓がバカみたいに鳴っている。莱は一瞬、目を丸くして、それから何も言わずに固まってしまった。

「あ、ごめん、いきなりこんな……返事とか、今じゃなくていいから」

焦って早口になる俺を、莱が遮った。

「待って、待ってよ。そんなに焦らないで」

莱は少し笑って、でもその目にはうっすら涙が浮かんでいた。

「あたし、ずっと好きだったよ」

「……え?」

「ずっとだよ。小学生の時からずっと、あんたのことばっかり考えてた。でも幼なじみっていう関係が壊れるのが怖くて、絶対に言えないと思ってた」

莱は一歩、俺に近づいた。

「今日だって、浴衣を選ぶときあんたに見てほしくて、柄まで真剣に選んだの。気づいてなかったでしょ」

「全然気づいてなかった……」

「知ってた。あんたそういうところ、昔から鈍いから」

莱は少し呆れたように笑ってから、真っ直ぐに続けた。

「でも、今日は言ってくれて嬉しい。あたしからは絶対言えなかったから」

「じゃあ……本当に、俺で いいの?」

「いいに決まってるでしょ。何年待たせるつもりだったの」

莱はそう言って、ちょっと拗ねたように頬を膨らませた。それがあまりに可愛くて、俺はつい笑ってしまう。

「ごめん、鈍くて。これから、ちゃんと取り戻すから」

「うん。約束ね」

「約束する。莱のこと、幼なじみじゃなくて、彼女として大事にする」

「その言葉、忘れないでよ」

「忘れない」

しばらく二人で黒い夜道を見つめたまま、どちらも動けなかった。やがて莱が、俺の浴衣の袖をちょんと掴んだ。

「帰ろ。……手、繋いでもいい?」

「もちろん」

俺が手を伸ばすと、莱の手はいつもよりずっと熱かった。指を絡めて歩き出すと、遠くでまだ祭りの太鼓の音が響いている。

「ねえ、これからは毎年一緒に祭りに来られるんだね」

「うん。来年も、その先も、ずっと一緒だ」

「ふふ、気が早いなあ」

そう言いながらも、莱は繋いだ手をきゅっと強く握り返してきた。夏の夜風が二人の間を通り抜けて、それでも繋いだ手だけは、離れることがなかった。
