窓際の席、注文したコーヒーはもう半分ほど冷めていた。

「変わらないね」と彼女が言った。「その、カップの持ち方」

「十年だぞ」

「うん。十年」

彼女はカップの縁を指でなぞりながら、店の外を見た。信号が変わって、誰も渡らない横断歩道を眺めているだけだった。

「結婚しなかったんだ」と彼が言った。質問のつもりはなかったのに、疑問形になってしまった。

「うん」

「俺も」

それだけで、テーブルの上の空気が少し重くなった気がした。彼はスプーンを持ち上げて、何も入っていないカップの中でくるくる回した。音だけが鳴った。

「なんで今日、誘ってくれたの」と彼女が聞いた。

「近くまで来たから」

「噓」

「噓だな」

彼女が笑った。十年前と同じ笑い方だった。少し困ったような、それでいて隠しきれない笑い方。彼はそれを見ないようにして、窓の外の信号がまた変わるのを待った。

「明日、また来てもいい?」と彼は言った。まったく違う話をするように、さらりと。

「この店に?」

「うん。この店に」

彼女は少し黙って、それからカップを両手で包むように持った。冷めたコーヒーを一口飲んで、「明日は、何時が空いてるの」と聞いた。それは、来るなという言葉ではなかった。

「三時」

「三時ね」彼女はうなずいた。「じゃあ、三時に」

「三時に」

彼が席を立つとき、彼女はまだ座っていた。でも、彼が店を出る前、彼女は小さく手を挙げた。それは、じゃあね、の合図ではなく、また明日ね、の合図だった。二人ともそれを分かっていた。

外に出た彼は、しばらく歩いてから、ポケットに入れていたはずの手が、なぜか少し温かいことに気づいた。何も持っていないのに。
