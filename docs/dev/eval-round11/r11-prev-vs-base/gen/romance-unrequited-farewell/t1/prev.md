前提: 三人称一元(颯太視点)・過去形基調・常体・1171字。しまなみ海道サイクリングの卒業旅行という設定にしました。違えば直します。

　瀬戸田港でレンタル自転車を返したのは、颯太と葵の二人だけだった。ほかの三人は先に売店へ走って、レモンジェラートの列に並んでいる。四日間、しまなみ海道を渡ってきた自転車は、どれもチェーンに潮風の砂を吸っていた。三月の瀬戸内は、まだ手袋を外すと指がかじかむ月だった。

　颯太は軍手でチェーンを拭ってから、鍵を受付の箱に落とした。葵はサドルの高さを元に戻している。初日、颯太が調整してやったときのまま、四日間ずっとこの高さだった。多々羅大橋の上り坂で葵が遅れたとき、颯太はスピードを落として並んだ。あの一往復ぶんの距離を、四日かけて詰めてきたつもりだった。

　フェリーは十五分後に出て、尾道に渡ればそこで解散になる。

　颯太は箱の蓋を閉めるふりをして、もう一度閉めた。今日を逃したら、次はもう合宿もない。四月からは、就職先も住む場所も、それぞれ別の方を向く。

「葵」

　呼んだだけで、葵はハンドルから手を離さなかった。

「好きだった。二年生の合宿からずっと」

　言ってしまえば軽くなるはずのものが、思ったより重かった。

　葵は顔を上げ、颯太を見た。逃げなかった。

「聞いてくれて。ちゃんと考えてから答えたいから、少し待って」

　売店のほうから、仲間の笑い声が届いた。葵はそちらを見ずに、颯太を見たまま続けた。

「颯太のことは、大事な友達だと思ってる。旅の間、一番助けてもらったのも颯太だし」

「わかってる」

「でも、応えられない。ずっと好きな人がいて、まだ言えてないだけなんだ」

　理由を並べる代わりに、葵はそれだけを置いた。言い訳のための一言は付け足さなかった。颯太は、葵が三日目の夜、みんなより先に寝たがった理由に、いまになって気づいた。あのとき電話でもしていたのかもしれない。訊かなかった。

　颯太が港の時計を見ると、長い針はまだそれほど進んでいない。

「その人に、言うの」

「たぶん、今度こそ言う。颯太のおかげで、先延ばしにしちゃいけないってわかったから」

「振られた側が背中押すの、変な話だな」

「変だね」

　葵は少し笑った。颯太も、思ったより早く笑えた。

「じゃあ、うまくいったら教えて」

「教えない。恥ずかしいから」

「教えてよ」

「颯太も、次の相手ができたら黒歴史にするくせに」

「するかもしれない」

　フェリーの汽笛が鳴った。売店から三人が走ってくる。手にはレモンジェラートのカップが五つ、颯太と葵のぶんまである。

「颯太、溶けるよ」

　颯太はジェラートを受け取ると、乗船口へ歩きだした。葵も自転車を押して並ぶ。四日間、ずっとこの並びで走ってきた。乗船券を切る係員の前で、葵が一歩前に出る。颯太は半歩遅れて続いた。並ぶ位置まで急に変わるわけではない。

　甲板に出ると、生口島がゆっくり遠くなった。ほかの三人は船室で早くもトランプを広げている。颯太はジェラートを一口食べた。レモンの酸味が、思ったよりまっすぐ効いた。
