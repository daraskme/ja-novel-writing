最終日の朝、空港行きのバスを待つあいだ、俺たちは荷物を挟んで並んで立っていた。四年間、同じゼミで、同じ居酒屋で、同じくだらない話で笑ってきた相手だった。

「ちょっと歩かない? 時間あるし」

彼女はそう言って、バス停から少し離れた堤防のほうへ歩き出した。海はまだ朝の色をしていて、波の音だけが間を埋めていた。

「言いたいことがあるんだけど」

俺がそう切り出すと、彼女は少し驚いた顔をしたけれど、遮らずに待ってくれた。それだけで、彼女がどういう人か、あらためて分かった気がした。

「ずっと好きだった。就活の相談も、朝までの電話も、ただの友達としてじゃなかった。今日で会う理由がなくなる前に、ちゃんと言っておきたかった」

言い終えると、思っていたより風が冷たく感じた。彼女は少し目を伏せて、それから海のほうを見た。長い沈黙ではなかった。ちゃんと考えてくれているのが分かる、短い沈黙だった。

「ありがとう。すごく、ちゃんと聞いた」

彼女はそう言ってから、ゆっくり続けた。

「でも、ごめん。同じ気持ちには、なれない。あなたと過ごした時間は本当に楽しかったし、大事だった。でもそれは、友達としての大事さで、恋愛の気持ちとは違う気がする。ここで違うって言うのも、なんか変な気がするけど」

はっきりとした言葉だった。曖昧にされるより、ずっと救われる断り方だった。

「そっか」

俺はそれだけ言った。悔しさより先に、変な安堵があった。ずっと胸の中で迷子になっていた感情に、ようやく行き先の看板が立った、という感じだった。

「気持ち悪くなかった?」

「全然。むしろ、最後にちゃんと言ってくれてよかったって思ってる。もし黙ってたら、あなたはずっと『言えばよかった』って思ってたでしょ」

「たぶん、一生言ってた」

彼女は笑った。俺も笑った。笑えたことに、自分でも少し驚いた。

「これから就職先も離れるけど、たまに連絡してもいい? 今日のこと抜きで、普通に」

「もちろん。今日のことは、今日でちゃんと終わったから」

その言葉は、突き放すためのものじゃなくて、ちゃんと区切りをつけてくれるための言葉だった。だから寂しさはあっても、みっともなくは感じなかった。

バスが来る時間になって、二人で堤防を戻った。荷物を持ち上げるとき、彼女が「大学生活、ありがとう」と言った。俺も「ありがとう」と返した。恋愛としては終わった関係だけれど、四年間そのものへの感謝は、ちゃんと別の場所にしまえる気がした。

バスの中で、俺は窓の外を見ながら、思ったより静かな気持ちでいることに気づいた。振られたのに、何かを失くしたというより、長く抱えていたものを、ちゃんとした形で下ろせた感覚だった。

好きだった気持ちは本当だったし、断られた事実も変わらない。でも、その両方を、恥ずかしいものとしてではなく、大学四年間の終わりにちゃんとあった出来事として、これから思い出せる気がした。

飛行機に乗る前、彼女が「次はいつ集合する?」と聞いてきた。俺は「決まってないけど、絶対集まろう」と答えた。それは、今日の答えとは別に、これからも続いていく関係の話だった。

卒業旅行の最終日に、俺は一つの気持ちに、静かに終止符を打った。そしてその隣に、次の日常への小さな一歩も、たしかに残っていた。
