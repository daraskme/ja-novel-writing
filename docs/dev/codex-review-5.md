**出荷を止める問題と修正案**

1. **C01・C03：断定形の認定範囲が広く、伝聞・虚偽の説明を断定にする。**  
   新規表1〜5が再現です。[claim_context](scripts/novel_lint.py:934) は数の後ろを中心に判定し、引用前の「弟によれば」を見ません。また [ASSERTIVE_TAIL](scripts/novel_lint.py:913) の格助詞・読点以降は任意の文字列を許すため、「という嘘」も通ります。  
   **修正案：** 引用より前を含む節の範囲を渡し、語り手自身の主張か確認できない場合は WARN。読点・助詞以降を無条件に断定形として受理せず、解析できない残りは WARN にしてください。否定語の追加だけでは同じ問題が続きます。

2. **C01：FAIL を許す文字集合と、実際に数える文字集合が一致していない。**  
   新規表8〜11が再現です。[PLAIN_WORD](scripts/novel_lint.py:914) は感嘆符・中黒・波線・空白を許しますが、[count_chars_of](scripts/novel_lint.py:232) はそれらを計数から落とします。その規約を本文に強制して「五文字」を「四文字」へ直させます。  
   **修正案：** 計数時に文字が落ちる引用は、明示的な計数規約がない限り WARN。特定の記号を一つずつ除外するより、計数対象と元の文字列との差を判定する方が設計に合います。

3. **N 群：引用保護が直後の語と最外層の括弧に依存している。**  
   新規表15〜21が再現です。[mask_mentions](scripts/novel_lint.py:451) は、文末の引用や「と入力した」を保護できず、台詞内の書名・文字列は入れ子の処理で飛ばします。  
   **修正案：** 入れ子も含む引用ごとに、前後の文脈から発話・名称・文字列を分類してください。非発話は保護し、分類できない引用内の表記違反は WARN。通常の `「帰るよ。」` を FAIL にする対照は維持します。

4. **前章末状態：空の構造を「内容あり」と数える。**  
   正常な第4章プロジェクトで、第3章末状態を次のどちらかにすると、`--allow-missing` なしで生成に成功し、欠落表示もありません。

   ```text
   # 状態
   -
   ```

   ```text
   | 所在 | 持ち物 |
   | --- | --- |
   | | |
   ```

   [filled_items](scripts/build_context.py:93) は箇条書き記号を除いた後の空文字を数え、表の見出し・区切り行も値として数えます。空の `-` が3行あれば、文体シートの項目数も3になります。  
   **修正案：** 記号を除去した後に空判定を行い、表は見出し・区切り行を除いたデータセルで判断してください。付属雛形だけでなく、空箇条書き・未記入表も回帰例に追加する必要があります。

新規表22〜23の N05 も、宣言した「英数字始まりは対象外」と一致しません。[行頭判定](scripts/novel_lint.py:518) が ASCII 限定なので、全角英数字を含める修正が必要です。

無報告の音数3例は、誤 FAIL とは別の検出範囲の問題です。対象語を確定できなくても、未処理の「数＋音／拍／モーラ」を検算案内として拾えば、少なくとも黙って通る経路を減らせます。また、部分指定は実測では **C07 INFO ではなく無報告**でした。ここは設計説明と実装を一致させてください。
