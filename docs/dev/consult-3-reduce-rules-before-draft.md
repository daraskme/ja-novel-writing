**次は文言を足すより、初稿前に読む規則を減らす比較を勧めます。軸は（b）共通操作の縮小＋（d）初稿への介入の縮小です。**（a）はその読み分けを実現する仕組み、（c）は不足を見つける補助として使うのがよいと思います。

指定範囲だけを読みました。ファイルは変更していません。以下、本文上の観察と、指示が原因だという仮説は分けます。生成時の参照履歴を確認していないため、特定の節が実際に作用したとは断定しません。

**1．本文で起きていること――不足しているのは、感情語の数より「出来事を受け取る過程」です。**

**屋上の告白：告白へのきっかけはあるが、それを決意に変える時間が短い。返事にも応答を突き放す調子が混じる。**  
対象：[new2](eval-round11/r12-after-reading/gen/romance-rooftop-mutual/t1/new2.md)、[base](eval-round11/r11-new-vs-base/gen/romance-rooftop-mutual/t1/base.md)。

- **17〜19行：「四年間、この人影の意味を訊いたことは一度もなかった。」→「総一が好き」**  
  図面の人物が自分だったという発見から、直ちに告白へ移ります。発見はきっかけとして成立します。ただ、深雪がそれを好意と受け取ったのか、期待するのが怖いのか、今なら言えると思ったのかが書かれない。指先と絆創膏の知覚はあるものの、告白に踏み切る認識の動きを担い切っていません。読者が待ち始めると、すぐ答えが出ます。

- **31行：「そのつもり。ほかに言い方があるなら教えてくれ」**  
  承諾はしていますが、確認した深雪に言い方の問題を返す台詞です。不器用な照れとも読める一方、深雪の切実さを受け止める返事にはなりにくい。その直後に総一側の喜びが十分見えないため、突き放す読みを打ち消せていません。

- **37行：「奢られたら経費で申請できないんじゃないか」**  
  恋人として何かしたいという申し出が、経費処理の話へ移ります。二人らしい軽口になり得ますが、この位置では喜びを膨らませる前に話題を冷ます働きが強い。深雪の「私物だから平気」も、感情への応答ではなく説明で受けています。

ただし、**new2に成就後の反応がない、結びが短いだけ、とは言えません。** 捨てる物が惜しくなる、半歩の距離が埋まる、一緒に箱を運ぶという反応があり、最終段落も複数文です。足された余韻の大部分を、物の象徴と共同作業が担っています。

baseは、告白前に「特別だと気づいていた」「手の震えを隠したい」、返事の後に聞き間違いを疑う反応を置きます。相手も、何が大切だったか、言ってくれてどう思ったかを返す。表現には既製品らしさがあっても、**不安→確認→受容→安心を読み手が辿れる**。この差が大きいです。

**給湯室：対策は空振りしているが、人物が空回りする喜劇としては弱い。**  
対象：[new2](eval-round11/r12-after-reading/gen/office-kitchenette-comedy/t1/new2.md)、[base](eval-round11/r11-new-vs-base/gen/office-kitchenette-comedy/t1/base.md)。

- **13行：「皆川は判子をやめ、洗ったらグループチャットにポットの写真を送るルールに変えた。」**  
  次の対策を考え、売り込み、相手に受け流される場面が一文で済みます。続く写真の使い回しも発見の報告です。仕組みは一段進んでも、皆川の期待や張り切り方、相手との温度差は大きくなりません。

- **16行：「かわりに毎朝七時半に出社し、自分でポットを洗うのが日課になった。」**  
  対策の失敗から自己負担の受容へ直行します。さらに「輪染みを見ながらコーヒーを飲むよりは、よほどましだった」と合理化するため、本人にも妥当な解決になっている。空回りの可笑しさより、損な役回りへの諦めが前に出ます。

- **21行：「ペンを取り、一段目に他の課員の名前を書き足していく。あの日と同じ手つきだった。」**  
  最初に戻る構造上のオチはあります。しかし、新しい思い込みや過剰な意欲が見えないので、「また同じ目に遭う」という苦さで閉じやすい。空回りを笑う着地より、徒労を眺める着地です。

本文は空白を除いて833字で、800〜1,000字の指定内です。したがって「短い」は、まず**展開を体験する時間が短い**という指摘として扱うべきです。

baseにも要約は多い。そこで効いているのは、可愛い判子を自腹で買う、押したくなれば掃除するはずだと期待する、という**本人の張り切り方と見当違い**です。最後には褒めた課長が汚し、主人公が募金箱を移す応酬がある。「要約をなくす」だけでは、この差は埋まりません。

**宿屋：食材の具体は増えたが、会話が相手への関心に育つ前に閉じる。**  
対象：[new2](eval-round11/r12-after-reading/gen/fantasy-inn-dinner/t1/new2.md)、[base](eval-round11/r11-new-vs-base/gen/fantasy-inn-dinner/t1/base.md)。

- **7〜13行：「茸はどこの」／「雨の加減だよ。多すぎても少なすぎても、笠が薄くなる」**  
  産地と生育条件の問答になっています。知識としては具体的ですが、それを聞いた人物の好み、故郷への思い、相手への親しさにはまだ繋がらない。会話の対象が食材であることと、食事の場を楽しめることは別です。

- **23〜25行：「さあ、そこまでは知らないね。うちは味で決める」／「ノエルは黙って匙を動かした。」**  
  ノエルの考察を実務的な返事で閉じ、その後の応答を食べる動作へ移します。二口目が早くなるので、料理を気に入ったことは推測できます。ただ、話しかけた相手との関係は広がりません。簡潔な人物造形として成立しても、温かな掛け合いを待つ読みには物足りない。

- **43行：「明日の分の茸を戻す水を替える。三人が発つのは、その水が冷める前だろう。」**  
  結びの注意が、食卓から翌朝の作業と出立へ移ります。今ここで一緒に食べている充足より、宿の営みが続く静けさが残る。悪い結びではありませんが、選ばれた余韻の種類が違います。

new2にも、水差しを押しやる、チーズを寄せる、パンを分け返す気配りがあります。したがって「所作を足す」処方は既にあるものを増やしかねません。チーズを寄せられた相手の受け取り方など、**配慮が届く側まで書くか**が論点です。

baseの「辛いのは平気かい？」は、情報を教える前に客の身体と好みを尋ねています。さらに手伝い、からかい、味への驚きが返る。材料の話も多いのですが、それが人への関心と往復しています。終盤の人生訓まで採用する必要はありません。

**2．原因候補――抑制を禁じる例外は増えたが、実行しやすい既定と例文は抑制側に残っています。**

特に疑うのは、次の指示です。

prose-core §3の「発生・知覚・反応」を同じ段落に編む指示も、山場の時間を圧縮する方向には働き得ます。ただし、反応自体を削れとは言っていないので、上の項目より原因としての確度は低いです。

**§6の感情の既定は、現在の本文ではかなり中立化されています。ここへ「感情を書いてよい」をさらに足す優先度は低い。** 問題は周囲の削除規則と、具体的な見本です。退職の直言の見本さえ、当番表から名前を消して引き継ぎへ移る。直言は許されても、感情を長く受け止める手つきは見本になっていません。

さらに、参照先に古い強制が残っています。

- [scene-cards「会話」](../../references/scene-cards.md:73)は見出しが「本題を言わせない会話」で、「大事な場面ほど本題は口に出ず、物と用事の話になる」。一般会話の既定にするには作風が強すぎます。
- 同ファイルの「恋愛」「内面」には、directでも名指しの直後に具体を接ぐ指示が残っています。prose-coreで任意に弱めた操作が別経路で復活します。
- [short-pipeline §4.4](../../references/short-pipeline.md:224)には「結びの予算は最初から短く置く」「長さは出来事から出す」、足さない例に「呼び出し音のあいだの内省」があります。今回ほしい緊張の溜めを、工程側が排除しかねません。
- 同§6では最終段落を消して「もう一度試す」。新しい充足の基準を加えても、削り続ける手順は残っています。

**共通から残すのは、声と視点の整合、条件照合、検算、改稿後の連続性確認。削り方・間の作り方・結び方は分岐させる**のが妥当です。

**3．構造の変更――（b）＋（d）を先に試し、新しい技法集の追加は後に回す。**

追加指示がまったく効かなかったわけではありません。宿屋は鍋から始まり、屋上の結びは複数文になっています。**操作への追従は起きたが、読者の体験の改善には届かなかった**。ここを分けて考える必要があります。

| 案 | 見込み | 落とし穴と実装箇所 |
|---|---|---|
| **（a）読む参照を分ける** | 高い。競合する規則を最初から読ませずに済む | `web`は配信形態でもあり、感情の温度とは一致しない。プロファイルは初期候補とし、依頼の約束・声で上書きする。`SKILL.md`約束2、flash手順2、参照表、prose-core冒頭、scene-cardsの常時参照をまとめて変更 |
| **（b）共通操作を少数にする** | 最優先。SKILL本体に残る強い指示を外せる | referencesへ移すだけで結局すべて読むなら効果がない。「書くときの操作」を共通部分と選択参照に分け、毎回のprose-core全文読込をやめる |
| **（c）読者として一度読み返す** | 欠落発見には有望。初稿の傾きを直す主手段としては弱い | 同じモデルが自分の省略を補って読んだり、後付けで合格にしたりする。flash手順とshort-pipeline §3に一度だけの確認を置き、合格宣言や周回を求めない |
| **（d）素直な初稿＋限定修正** | 最初に試す価値が高い。baseの娯楽性を残せる可能性がある | 「素人っぽさを直す」は修正範囲が広すぎる。具体的な支障のある箇所だけ直す。短さも既定字数との比較ではなく、依頼された出来事・反応の欠落で判断する |

（c）は二種類を区別すれば、約束5と両立できます。

- **同じコンテキストでの確認**：依頼と本文を照合し、「告白へ踏み切る箇所」「返事を受け取る箇所」などを指す。見当たらない部分を挙げる。これは編集上の確認で、読者の反応を得たとは扱わない。
- **別コンテキストの読者役**：本文と必要最小限の依頼を渡し、物足りなかった箇所と引用を返す。点数も修正文も求めない。「依頼を満たすか」を尋ねるなら、本文だけの初読反応とは別の検査として明記する。

実装時は、`SKILL.md`約束5にこの区別を置き、short-pipelineの「flashはレビューなし」と整合させます。毎回別役を起動する重さを避けるなら、通常は前者、試験時や問題が続くときだけ後者で十分です。

（d）の限定修正では、たとえば次のように扱います。

- 会話が単調：口調を機械的に散らさず、告白前後で相手への働きかけが変わっているかを見る。
- 内面が少ない：内面の量を増やさず、行動が変わる理由を読めない箇所だけ補う。
- 素人っぽい：この語では修正を発動しない。重複説明、指示対象の混乱などに具体化できたものを扱う。
- 表記・数：検知後に誤りを確認して直す。lintに文学的な合否を決めさせない。

**もう一つ必要なのは、初稿用と推敲用の参照を分けることです。** 現在は、書く前から削除テストを持たせています。（a）の作風別分岐に加えて、§9の重複診断などは書いた後へ移す。これなら新しい娯楽文体へ均す危険も減らせます。

新設するなら `references/flash-experience.md`程度の短い参照にし、内容は「依頼された場面を要約で済ませていないか」「人物が出来事をどう受け取ったか」「どこに読む時間を使うか」に絞ります。**温かさ・反応・余韻を毎回一定量入れる規則にはしません。** また、既に抑制の参照を全文読んだ会話へこれを追加しても、読み分けの実験にはなりません。試験は新しいコンテキストで行う必要があります。

**4．一人への過適合――局所的な不具合の発見には十分ですが、一般読者の好みの推定には足りません。**

10組は10個の独立した依頼ではありません。依頼は7種で、第2回は負けた3種を選び、同じbaseと同じ読者で比較しています。修正対象の選抜、baseへの既知感、各生成のばらつきが混じります。「3回追加しても効かなかった」ことも、個々の指示の無効性を切り分けた実験ではありません。

一方、**明示的な依頼とのずれは、一人の指摘でも修正対象にできます。**

| 既定にしてよいもの | 依頼・契約で選ぶもの |
|---|---|
| 指定された告白・返事・空回りなどが本文に存在する | 甘さ、温かさ、苦さの程度 |
| 重要な行動に、読めるきっかけや動機がある | 告白前の溜めの長さ |
| 求められた読後感を結びで不用意に壊さない | 余韻の長さ、明言か含みか |
| 山場の省略を、字数適合だけで見逃さない | 真顔の喜劇、賑やかな喜劇、苦い風刺 |

温かさ、緊張の溜め、長めの余韻は、**今回の依頼に対する筋の通った好み**です。ただし、許可された資料から「娯楽の掌編読者一般の多数派」とは言えません。特にコメディへ長い温かな余韻を一般化すると、オチを弱めます。

また、この読者は抑えた再会と失恋も選んでいます。夏祭りのnewには温度を下げ得る台詞があっても、全体では選ばれた。したがって、好みを「常に温かく、長く、直球」に要約するのも危険です。**個々の表現の禁止より、場面全体での働きを扱うべきです。**

`genres.md`では、§1の契約と§2の調整項目にこの区別を反映し、個人の好みは明示された場合の利用者向け既定に留めるのがよいです。flashで毎回質問を増やす必要はありません。

**5．次の検証――Claude Codeはまず3件。最初の2件を、未使用依頼の現行版対縮小版に使います。**

検証する仮説は一つに絞ります。

> 初稿前の汎用的な文体指導を減らすと、依頼された感情や掛け合いが厚くなり、条件遵守と文章の整合は保てるか。

最初の試験では、新しい読者レビューや技法参照を同時投入しません。変えるのは、初稿前に渡す指示の範囲です。

| 段階 | 件数 | 内容 |
|---|---:|---|
| Codexで予備確認 | 4依頼×2条件＝8本文 | 屋上・給湯室・宿屋と、既存の成功例から失恋を選び、現行版／縮小版を比較。規則の競合と、長所を壊す修正がないかを見る |
| Claude Codeで本試験 | 2本文 | 未使用の「幸せな告白」依頼を一つ固定し、現行版／縮小版をそれぞれ新規コンテキストで生成。屋上とは設定もきっかけも変える |
| Claude Codeで追加確認 | 1本文 | 給湯室の元依頼を縮小版で生成し、既存new2・baseと比較。こちらは既知課題への改善確認と位置づける |

Codexの結果でClaudeへの有効性を結論づけません。予備確認後に縮小版を固定し、Claudeの未使用依頼を見ながら再調整しないことが大切です。

3件なら提示された単価で**0.9〜2.1ドル**です。4件目は、3件の実費を確認して残高が0.7ドル以上ある場合だけ。使うなら給湯室の現行版を新規生成し、追加確認も同時期の比較にします。

読み比べでは、従来の「条件」「読後感」「読みたい」に加え、次だけ短く記録します。

- 期待・緊張・可笑しさが生じた行。
- 先を急がれた、または冷めた行。
