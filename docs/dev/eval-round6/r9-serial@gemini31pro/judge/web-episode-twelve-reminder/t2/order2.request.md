設定：主人公の真帆は、祖父から継いだ貸衣装店の店主。客の瀬田とは、祭りの衣装の契約を進めている。
前話：瀬田は契約書を持ち帰り、共同出資者である母に見せると言った。返事は保留のまま。作中では昨日の出来事。
今回：瀬田が母を連れて来店する。母は衣装の注文数を減らしたい。真帆はすでに生地を取り寄せていて、契約条件を話し合う。

## 応答 A
瀬田さんが契約書を持ち帰ってから、一週間が経っていた。

「すみません、遅くなって」

店の引き戸を開けて入ってきた瀬田の後ろに、もう一人、見覚えのない女性が立っている。年の頃は五十代後半だろうか、瀬田とよく似た目元をしていた。

「母です。祭りの衣装の件、うちの出資分もあるので、一度お店を見ておきたいと言って」

真帆はカウンターの奥から出て、頭を下げた。

「真帆です。ようこそいらっしゃいました」

瀬田の母は店内をぐるりと見回してから、真帆に向き直った。値踏みするような視線ではなかったが、遠慮のない目だった。

「契約書、拝見しました。数を少し減らせないかと思って」

前置きなしの本題に、真帆は一瞬言葉に詰まった。

「減らす、というのは」

「二十着で見積もっていただいてますけど、十五で十分じゃないかと。祭りの規模を考えると、そこまで要らない気がして」

真帆の頭の中で、すでに手配した反物の束が浮かんだ。先週のうちに、二十着分の生地は問屋に発注をかけている。減らせば、その分は在庫として抱えることになる。

「実は、生地はもう取り寄せてしまっていまして」

瀬田が驚いた顔をした。

「もう発注されてたんですか」

「契約前でしたけど、お祭りの日程から逆算すると、今動かないと間に合わない時期だったので。……ただ、数を調整するご相談自体は、もちろん伺います」

瀬田の母は少し考えるように腕を組んだ。

「取り寄せた分は、こちらが引き取る形になりますか」

「そこは条件次第です。たとえば十五着でご契約いただいて、残りの生地は来年以降の分として店で預からせていただく、という形もできますし、逆に今回まとめて二十着で契約いただければ、単価をもう少し抑えられます」

母娘――いや、母と息子は顔を見合わせた。瀬田が先に口を開く。

「単価が下がるなら、二十のままでもいいんじゃない」

「でも在庫を抱えるのはお店側でしょう。うちが減らしたいって言ったのに、それを丸ごと押し付けるのは筋が違う気がして」

真帆は思わず、少し表情を緩めた。義理堅い人らしい。

「でしたら、折衷案を出させてください。十八着でご契約いただいて、余る生地の分は加工賃だけ次回に繰り越す、という形はいかがでしょう。無駄にはなりませんし、来年また祭りがあるなら、そのときの仕込みにもなります」

瀬田の母はしばらく真帆の顔を見ていたが、やがて小さくうなずいた。

「悪くないですね。息子はどう?」

「僕はそれでいいです。真帆さんに任せます」

真帆はカウンターの契約書を引き寄せ、条件を書き加えるためにペンを取った。窓の外では、来月の祭りに向けて、町がもう少しずつ支度を始めている音がしていた。

## 応答 B
引き戸の鈴が鳴ったとき、真帆は帳場の上に昨日の契約書の控えをまだ置いたままだった。判はどちらの欄にも入っていない。

「こんにちは」

　瀬田だった。ただし、きのうは一人で来て、紙を鞄に仕舞って帰った。今日は隣に、瀬田より頭ひとつ小さい女の人が立っている。デパートの紙袋を提げていて、袋の口から祭りの実行委員会のチラシがのぞいていた。

「母です。契約の件で、直接お話ししたいと」

　瀬田がそう言うと、女の人は軽く会釈をして帳場の前まで進み、真帆も控えを脇へどけて椅子を勧めた。

「瀬田の母です。息子から聞きました、半纏三十着の件」

「はい。浜一組さんの分で、藍の雲取り柄でお預かりしています」

「その三十を、二十にできませんか」

　前置きはなかった。真帆は帳場の抽斗から布見本を出しかけていた手を止めた。

「予算のことでしたら、去年の分から見積もりは変えていないつもりですが」

「予算というより、担ぐ人です。今年は若い衆が五、六人、仕事で祭りに出られない。三十揃えても、着る人がいない年もあるかもしれない。それで無駄になるくらいなら、確実に着る分だけでいい」

　瀬田は隣で、母親の湯呑みに茶を注ぎ足す真帆の手元を見ていたが、何か言いかけて、結局黙った。

　真帆は抽斗の見本を出した。藍に染めた反物の切れ端で、雲の形に白く抜いてある。

「これ、うちで扱っている紺屋に、この柄で三十反、もう染めを頼んであります。あそこは同じ型で染めるとき、三十反に満たないと引き受けてくれません。窯を一回分立てる手間が、二十反でも三十反でも同じだからです」

「じゃあ、二十でも値段は変わらないと」

「反物の代金は変わりません。仕立ての手間賃は、二十着分に減ります。ただ、余る十反は、この柄で染めた反物として、こちらで抱えることになります」

　瀬田の母は湯呑みを持ち上げかけて、口をつけないまま置き直した。

「その分は、こちらの損になるということ」

「損にはしません。ただ、今の契約のままだと、三十着分の生地代は先にいただいて、仕立ては二十着分だけになる。それだと、瀬田さんの側が余分に払うことになってしまいます」

　三人のあいだで、しばらく数字だけが行き来した。三十から二十を引いた十が、誰の懐から出るかという話。

「提案があります」

　真帆は反物の切れ端を、母の手の届く位置まで滑らせた。

「三十反のまま染めてもらって、仕立ては二十着だけ先に作ります。残りの十反は、うちで預かって、来年か再来年、同じ柄が要るときに仕立てます。柄を新しく起こす手間も、染めの発注も、そのときは要りません。生地代は、今年と来年で分けて払っていただく形にできます」

「今年払う分が減るということ」

「減ります。来年、着る人が戻れば、そのときの手間賃だけで済みます」

　瀬田の母は反物を指でつまみ、光にかざした。染めむらのない、深い藍をしている。

「戻らなかったら」

「そのときは、うちで別の柄に染め替えるか、他の地区に融通するか、こちらで引き取ります。瀬田さんに損はさせません」

　瀬田がようやく口を開いた。

「母さん、それなら」

「まだ何も決めてません」

　母はそう言ったが、反物を光にかざしたまま、しばらく下ろさなかった。真帆は帳場の帳面を引き寄せ、鉛筆を持った。

「今日決めていただかなくても構いません。ただ、紺屋への正式な発注は、来週の頭には返事をいただきたくて」

「一週間」

「はい。三十反で進めるか、二十反に減らして仕立ての分だけにするか。減らす場合は、余った柄が使えなくなります」

　母が反物を帳場に置くと、染めむらのない藍が、控えの契約書の上に乗った。

「息子と相談して、また来ます」

　立ち上がるとき、母は反物の切れ端を、指先でもう一度撫でた。真帆はそれを見て、帳面に「保留・来週」とだけ書いた。
