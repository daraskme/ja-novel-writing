しおり

 返却ポストに本を入れたのは、いつも同じ栞だった。押し花でも栞紐でもない、バスの回数券の使用済み片――「〇〇団地前」の文字が薄く印刷されている。三ヶ月で七冊、すべて別人の利用者証で借りられた本にそれが挟まっていた。

 司書の芽衣は最初、誰かの忘れ物だと思っていた。だが同じ路線の回数券が続けて出てくるのは妙だった。しかも挟まっている位置がいつも同じ、全体の三分の二あたり。物語の佳境に差し掛かる直前のページだ。

 借りた人物を調べると、共通点はなかった。年齢も性別もばらばら。ただ一つ、全員がこの一年以内に、この図書館のカウンターで「読み終わったら感想を教えてください」と芽衣自身が声をかけた利用者だった。芽衣は新人の頃からそう声をかける癖があって、続ける人は少ない。だが回数券の主だけは、律儀にその本を読み切っていたことになる。

 七冊のタイトルを並べてみる。恋愛小説、育児エッセイ、闘病記、転職体験記――ジャンルはばらばらだが、共通するのは「三分の二あたりに、主人公が誰かに助けられる場面がある」ことだった。挫けかけた人物が、思いがけない他人の言葉や行動で立ち直る。そこに栞が挟まっている。

 芽衣は回数券の団地名を頼りに、その路線のバス停まで足を運んだ。停留所のベンチに、七十過ぎくらいの女性が文庫本を読んでいた。表紙カバーには図書館のフィルムコーティング。声をかけると、女性は少し驚いた顔をしてから、ばつが悪そうに笑った。

「バレちゃいましたか」

 女性は毎週この図書館で本を借りていた。だが利用者証は持っていない。借りているのは彼女ではなく、待合室で顔を合わせる近所の人たちだった。

「みんな、しんどい時に借りに来るんですよ。旦那さんを亡くした方とか、お子さんが不登校の方とか。カウンターのあなたが『感想教えてください』って言うでしょう。あれ聞くたびに、この人ちゃんと最後まで読むかしらって、こっちが気になっちゃって」

 彼女は利用者証を作らない代わりに、頼まれてもいないのに先回りして本を読んでいた。そして、物語の中で登場人物が誰かに支えられる場面――そこに、自分が使い終えたバスの回数券を栞代わりに挟んで、そっと返す前に元の持ち主に手渡していたのだという。

「ここだよ、って言葉で言うと重たいでしょう。だから栞だけ。気づく人は気づくし、気づかなくても、そのページで指が止まればいいなって」

 団地から図書館までのバス代を、彼女は毎回、他人の物語に栞として置いていっていた。回数券が短くなるたびに、誰かの人生の三分の二が、少しだけ軽くなるように。

 芽衣は礼を言いかけて、言葉に詰まった。声をかけたのは自分なのに、支えていたのはずっと、この人だった。

 翌週、芽衣は新しく入荷した一冊をカウンターの内側にそっと置いた。挟んであるページはまだ決めていない。だが今度は、自分の回数券を使うつもりだった。
