**栞**

　返却された本は棚に戻す前に必ず一度開く。頁を端から送り、折れや線引き、挟まったままの紙を確かめる。糸魚川図書館の返却カウンター、宮田の仕事で、もう八年になる。

　その日戻った『昭和の家庭料理』の真ん中に、また例の紙が挟まっていた。角を斜めに切った厚紙で、隅にコーヒーの輪染みが一つ。貸出票がまだ紙だった年、電算化で余った用紙を数枚だけ抽斗に残し、そのうち一枚だけ角を切って頁の仮止めに仕立てた。それきり奥へしまい込んだはずの一枚だった。

　誰かのレシートや押し花なら気にも留めない。挟まりものは毎日出てくる。だが先週も、部活帰りの高校生が返した文庫の間から同じ紙が出てきた。角の切り方まで同じで、輪染みの位置も変わらない。今週これで三度目だった。恋愛小説の間にも、登山の本の間にも。借りた人はばらばらで、返す曜日も違う。

　カウンターの向かいで新刊にラベルを貼っていた同僚の広瀬に見せると、目を輝かせた。「常連さんの誰かが、好きな栞を勝手に配ってるんじゃないですか」。宮田は角の切り方を見せた。刃物で切ったにしては歪んでいる。爪でむしったような切り口だった。広瀬はラベルを貼る手を止めて紙を眺め、指で厚さを確かめてから、それきり別の説を出さなかった。

　抜いた紙は、返却台の脇にある付箋の空き缶へ落とし、次の本を開く。

　午後四時、カウンターの鈴が鳴った。沢田が新聞の縮小コピーを手に立っている。今日の詰め将棋が解けたかどうかを、必ずこの時間に報告に来る常連だった。雨の日も休まない。西日が返却台に長く伸びるこの時間、宮田は本を開いたまま話を聞くことが多い。開いていた本を閉じかけ、右手が先に缶へ動いた。さっき落とした紙をつまみ、開いた頁に挟んで、本をそのまま「完了」の山へ置く。沢田の話は詰め将棋から隣の猫の話まで続き、話が長引くほど相槌の間隔も開いていく。相槌を打つあいだに、置いた本のことは頭から消えた。

　半月後、貸し出されて戻ってきたその一冊を開いた手が止まった。角を切った厚紙。コーヒーの輪染み。缶に落としたはずの、あの紙だった。返却したのは白髪の老婦人で、玄関先で立ち止まって世間話をしていく人だった。宮田とも沢田とも接点はない。それでも紙はここに戻ってくる。抜いて、また缶へ落とす。次の本を開く。今度はどの本に紛れるのか、考えないようにした。

　翌日の午後四時、また鈴が鳴った。沢田が縮小コピーを掲げて立っている。開いていた本を閉じかけ、右手が缶へ動く。動きながら、自分の手を初めて見た。

　紙は棚から消えたことがない。借りた人が誰であろうと関係なかった。この紙が挟まっているのは、いつも午後四時に手が開いていた、たまたまその一冊だったからだ。沢田が鈴を鳴らすたび、缶の紙は近くの本へ移り、借りられ、戻ってくる。半月に一度、自分の手に拾われるために。高校生の文庫も、登山の本も、料理の本も、たまたまその日その時刻に開いていただけの一冊だった。犯人と呼ぶような相手は、最初からいなかった。

　沢田はまだ将棋の駒の話をしている。紙を挟む手を止め、頁から抜いた。缶へは戻さず、カーディガンの内ポケットへしまう。

「宮田さん、なんかご機嫌だね」

「そうですか」

　答えながら、次の本を開いた。広瀬に見せたら、また目を輝かせるだろう。今度は言わないでおくことにした。ポケットの中の紙は、次に鈴が鳴るまで、そこにある。
