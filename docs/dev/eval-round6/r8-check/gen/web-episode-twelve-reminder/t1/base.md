第十二話

　開店の札を裏返したところで、ガラス戸の向こうに瀬田の姿が見えた。隣には、瀬田より頭ひとつ小さい女性が立っている。母親だろう。真帆は昨日渡した契約書のことを思い出しながら、鍵を開けた。

「すみません、朝早くに」瀬田が頭を下げる。「母を連れてきました」

「瀬田の母です」女性はそう名乗ると、店の中をぐるりと見回した。値踏みするような目つきではなく、単純に興味があるという顔つきだった。

　真帆は二人を作業台の前に案内し、椅子を勧めた。台の上には、数日前に取り寄せたばかりの反物が積んである。祭りの衣装用に選んだ、深い藍色の生地だった。

「契約書、拝見しました」母親が切り出す。「注文数なんですけど、少し減らせないかと思って」

　真帆は手を止めた。想定していなかった話ではない。だが、生地はすでに手元にある。

「今回は何着からいくつに、というお話でしょうか」

「十五着の予定でしたけど、十着くらいで」

　真帆は台の上の反物にちらりと目をやった。十五着分として発注し、割引を受けている生地だ。数を減らせば、単価も割引率も変わってくる。

「実は、生地はすでに十五着分を仕入れています」真帆は言葉を選びながら続けた。「数を減らすこと自体は可能ですが、その分、一着あたりの単価が上がることになります」

　瀬田が母親と顔を見合わせる。母親は少し考えてから、真帆に向き直った。

「単価が上がるのは困りますね……なぜ最初から十五着分を?」

「契約書をお渡しした時点で、口頭では十五着でとお話をいただいていましたので」

　母親は瀬田の方を見た。瀬田は気まずそうに視線を逸らす。どうやら、母親には数字がきちんと伝わっていなかったらしい。

「瀬田さん、そのあたり、私からもう少し詳しくご説明した方がよかったですね」

「いえ……こちらの確認不足です」瀬田が小さく言った。

　真帆は反物を一反、二人の前に広げてみせた。藍色が窓からの光を受けて、少し紫がかって見える。

「余った生地は他の用途にも回せますので、無駄にはなりません。ただ、契約条件として、数量と単価をどう調整するか、今日決めていただけると助かります」

　母親は生地に手を伸ばし、指先で軽く触れた。しばらく黙ったまま、生地の質感を確かめている。

「……悪い生地じゃないですね」

「はい。祭りの日差しでも色が飛びにくい染めを選んでいます」

　母親は小さく頷くと、瀬田の方に体を向けた。

「もう一度、うちの人数分をちゃんと数えましょう。十着じゃ足りないかもしれない」

　瀬田が驚いた顔をする。真帆も内心、話の向きが変わったことに少し驚きながら、静かに二人のやり取りを見守った。
