反物の山を積み直していた真帆の手が、瀬田の名を書いた木札のところで止まった。「保留」の付箋は、貼った日のまま黄ばんでいる。
契約書を預けたきり、瀬田は一度も店に顔を出していない。生地屋にはもう発注をかけてしまった。紺木綿、三十着分。棚に積まれた反物は、まだ晒しの匂いがしている。祖父の代からの取引先で、頼めば急ぎも利くが、断りとなれば話は別だった。
店先の金木犀が匂いはじめている。祭りまで、あと一月半。染めに二週間、仕立てに三週間。ここで数がひっくり返れば、間に合わせられる範囲を最初から引き直すことになる。
真帆は伝票の束をめくり、瀬田の欄に指を止めた。数字はまだ三十のまま、朱で丸をつけてある。判の欄は空のままだった。判を待つあいだも、生地屋への支払いの期日は動かない。祖父の帳面にはそう書いてあった気がしたが、確かめる前に自分で決めて発注した。
帳場の柱時計が十時を打つ。開店してすぐの、まだ誰も来ない時間だった。棚の隅に置いた瀬田の見積もり控えを、真帆はもう一度目でなぞった。柄は三種の藍染め、帯は共布。金額の欄に、瀬田自身の字で丸がしてある。あの日、瀬田は迷いのない声で母に見せると言い、判を持ち帰って店を出ていった。
来店ベルが鳴った。振り向くと、瀬田の後ろに、瀬田より頭ひとつ小さい女が立っていた。単衣の衿の合わせ方に無駄がなく、帯の結び目も崩れていない。普段からきちんと着る人だと分かった。
「母です。祭りの件で、一緒に来てもらいました」
真帆は伝票を置き、頭を下げた。母は会釈だけを返し、店の中を眺め回した。壁にかけた法被の柄、天井近くまで積まれた反物、木札に振った番号。値踏みする目の動きだった。あの日の勢いのよさは、母の隣に立つ瀬田の顔からもう消えている。
「お座りください」
真帆が椅子を勧めても、母は立ったまま壁の法被に手を伸ばした。袖口の布を親指と人差し指でつまみ、糸の詰まり具合を確かめてから離す。値段を確かめる手つきというより、仕立ての良し悪しを見る手つきだった。
「単刀直入に申し上げます」母が言った。「三十着は多すぎます。二十で結構です」
瀬田が横で口を挟もうとして、やめた。
「事情を伺ってもよろしいですか」
「今年は担ぎ手が集まらなかったんです。去年は三十六人いたのが、今年は二十人ちょっと。若い人は祭りより仕事を選びます。空の法被を十着も並べて、みっともない思いをするくらいなら、最初から作らないほうがいい」
言葉に迷いがなかった。数字で物を決める人だと、真帆は思った。値切るための数ではなく、実際に人が足りていない数字だ。
「生地はもう届いています」
真帆は棚から反物を一本抜き、帳場に置いた。畳んだ布の重みが、机を鈍く鳴らした。
「三十着分、染めまで発注済みです。生地屋への支払いは、もう動いています」
「契約書には判を押していません」
「そうですね」真帆は認めた。「でも見積もりを出したのはこちらで、その数で走り始めたのもこちらです。判の有無とは別に、動いた分の埋め合わせはお願いすることになります」
「それは、あなたの都合でしょう」
「はい」
はいとしか言いようがなかった。見込みで先に生地を押さえるのは、この商売のやり方であって、瀬田の母の落ち度ではない。祖父はよく、注文の数より半歩先に反物を押さえておけと言っていた。半歩先が今回は仇になっただけだ。
瀬田が初めて口を開いた。
「母さん、それは」
「あなたは黙ってなさい。契約するのは私」
瀬田は膝の上で手を組み、それきり黙った。共同出資者というのは、名前だけの肩書きではないらしい。
真帆は反物の端を指でなぞった。三十から二十を引けば十。差し引けばそれだけの布が、行き場をなくす。誰かの祭りのために動いた布を、ただの損として棚に戻すのは避けたかった。祖父の代からの布を、担ぎ手のいない法被に仕立てて店の隅に積むところを、一度想像した。
十着分を店の在庫に回すなら、柄は要らない。無地の紺なら、来年別の連から声がかかっても使い回しがきく。二年前、隣町の祭りで急に貸し出しを頼まれたとき、色柄が合わずに断った覚えがあった。あのときの穴を、いま埋められる。
「二十着で承知します」
母がわずかに眉を上げた。あっさり折れたことに、逆に警戒したような目だった。
「ただし、残りの十着分は、今年の連の色ではなく紺の無地で仕立てさせてください。柄を染める前の段階で止めれば、うちの貸し出し用の在庫になります。次の祭りでも、よそさまの祭りでも使えますから」
「その分の損は」
「こちらで持ちます。埋め合わせは、二十着分の仕立て代に色を付けさせていただく形で」
母はしばらく反物を見ていた。木綿の目を確かめるように、端を軽くつまんで光にかざす。壁の法被を触ったときと同じ、仕立てを見る手だった。
「値上げということですね」
「そうです。ただし来年、同じ数でご発注いただければ、今年の分は据え置きます」
瀬田がまた何か言いたそうにしたが、母の横顔を見て口をつぐんだ。
「なぜ、そこまでなさるんです。二十で切って、十着分はうちに買い取らせればいいでしょう」
「買い取っていただいてもいいんです」真帆は反物を撫でた。「でも、それだと来年もこの数でとは言えなくなる。祖父はいつも、今年損をしても来年の注文を潰すな、と言っていました。この店は、瀬田さんの代のお客様だけでやっているわけじゃないので」
「来年の話まで、いまここで決められません」
「決めていただかなくて結構です。今年の分だけ、お返事をいただければ」
母は伝票の数字にもう一度目を落とし、それから反物の畳み目に触れた。指の先が、布の織り目に沿って一度だけ動いた。品定めというより、確かめる手つきに変わっていた。
「十着、紺の無地。染めはうちが決めます」
「柄はお任せいただければ、こちらで見立てます」
「いいえ」母は伝票を真帆のほうへ押し戻した。「色は、私が選びます。次に来たとき、見本を三種類、出してください」
瀬田が驚いた顔で母を見た。真帆は伝票を受け取り、隅に「紺無地・見本三種」と書き添えた。
「承知しました」
母は初めて、値踏みではない目で店の中を見た。壁の法被と、積まれた反物と、真帆の手元の伝票を、順に。
「瀬田、行きますよ」
母は先に暖簾をくぐった。瀬田は戸口で一度だけ振り返った。
「悪かった。うちの母、ああいう人で」
「いいえ」
「実行委員、代わってもらおうかと思ってたんです、正直。数のことで散々言われて」瀬田は苦笑いを浮かべたが、目は笑っていなかった。「でも、母が反物を触った顔、初めて見ました。また来ます。母が、見本を選びに」
戸が閉まる音のあとも、真帆はしばらく伝票を見ていた。棚の反物は三十本のまま、朱の丸はまだ消えていない。
伝票の「紺無地・見本三種」の下に、もう一行、書き足す。
「十着、来年分も仮押さえ」
朱筆を置き、真帆は棚の反物を一本、他の色から離して置き直した。二年前、色柄が合わずに断った隣町の連の名も、ついでに帳面の隅へ書き添えておく。見本を三種持ってくるまでに、今度は先回りできるかもしれない。
