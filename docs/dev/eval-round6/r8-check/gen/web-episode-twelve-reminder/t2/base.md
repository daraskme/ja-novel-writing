開店の準備をしていると、ガラス戸の向こうに瀬田の姿が見えた。真帆は手を止める。隣にもう一人、瀬田より少し背の低い女性がいる。昨日、契約書を鞄にしまいながら「母に見せます」と言っていた、あの母親だろう。

「おはようございます。急にすみません、母を連れてきました」

瀬田が戸を開けながら言う。母親は会釈をして、店内をぐるりと見回した。値踏みするような視線ではなく、単純に興味深そうな目だった。

「瀬田の母です。息子から契約のお話、伺いました」

真帆はカウンターの奥から出て、二人を衣装が並んだ棚の前へ案内した。すでに数着、祭り用に仕立て直した衣装が吊るしてある。

「こちらが、瀬田さんとご相談していた分です」

母親はそのうちの一着に手を伸ばし、袖を軽く持ち上げた。

「立派なものですね。ただ……正直に言ってしまうと、注文の数を少し減らせないかと思っているんです」

「母さん」

瀬田が小さく声をあげたが、母親は構わず続けた。

「共同で出すお金のことなので、私も口を出させてもらわないと。予定の枚数だと、正直うちの負担が大きくて」

真帆は少し間を置いてから答えた。

「実は、いただいたご相談を踏まえて、すでに生地の一部を発注してしまっているんです」

母親の表情がわずかに曇る。

「もう、ですか」

「はい。契約前のご相談段階ではあったんですが、祭りまでの日程を考えると、生地の手配だけは先に進めておかないと間に合わない事情があって」

瀬田が申し訳なさそうに口を開く。

「そこまで進めてくださっていたとは……」

「もちろん、まだ正式な契約は結んでいませんので、枚数の見直しについてはご相談させてください」

真帆はカウンターから発注書を取り出し、広げた。

「取り寄せ済みの分と、これから調整できる分を分けてお話しできます。減らす枚数によっては、生地の方で調整が難しいものと、まだ余裕があるものがあるので」

母親は発注書に目を落とし、ふむ、と小さく声を漏らした。

「思っていたより、きちんと進めてくださっているんですね」

「衣装の質に関わる部分なので、慎重に扱いたくて」

母親はしばらく発注書を眺めていたが、やがて顔を上げた。

「では、その分けていただいたお話を、具体的に聞かせてもらえますか」

真帆は頷き、椅子を勧めた。瀬田がほっとしたように肩の力を抜くのが見えた。話し合いは、ここからが本番だった。
