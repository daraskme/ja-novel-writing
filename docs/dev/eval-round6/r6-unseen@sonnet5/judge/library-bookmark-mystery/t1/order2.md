## 2. 問いへの答え（引用つき）

謎解きの手がかりは両作とも解決前に本文中に出ており、解決は手がかりから導ける。

- A：「全部、土曜日の閉館間際だった」という手がかりが、仕分け担当者＝富田さんという解決に自然に繋がり、「妻の名前――多恵子の頭文字」で読後に「ああ」と落ちる。
- B：「同じ人物が続けて借りた跡はない」という手がかりの積み重ねから、「みんなが同じだけ思ってきただけだ」という解決に至り、柚木自身も同じことをしていたと気づく構成で「ああ」がある。

両者とも謎解きとしては腑に落ちるが、Aは「一人の人物の動機」という明確な着地で分かりやすく、Bは「誰も特別な意図がない」という抽象的な着地でやや余韻寄り。ここは条件充足というより好みの差に近い。
