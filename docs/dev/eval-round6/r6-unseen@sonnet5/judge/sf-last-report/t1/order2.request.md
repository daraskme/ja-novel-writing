## ユーザーの依頼
SFの掌編を書いて。火星の基地に一人残った整備士が、地球への最後の定時連絡を送る場面。専門用語で煙に巻かないで、人の話として読ませてほしい。1200字前後。

## 応答 A
灯を落とす前に

　最後に電源を落とすのは通信室だと、宮下は決めていた。
　温室のポンプは正午に止めた。水耕棚の根が空気にさらされて、しばらくのあいだは湿っているだろう。厨房の冷蔵庫は昨日のうちに空にして、扉を開けたままにしてある。三年住んだ基地は、ひとつずつ黙っていく部屋の連なりになっていた。
　食堂を抜けるとき、壁の写真だけはまだ剥がしていないことに気づいた。着任した日に五人で撮ったもので、誰の顔も日に焼けていない。剥がして持ち帰るつもりで指を伸ばしたが、画鋲を外すところで手が止まった。持ち帰らなくても、覚えている顔だ。
　もとは五人いた。二人はもう地球に戻り、二人は先週の船で発っている。宮下だけがひと月長く残ることになったのは、最後の点検には手が要ると、誰かが決めたからだった。誰かがやらなければならない仕事で、たまたま自分の番が最後に回ってきただけのことだ。順番が違っていれば、いま地球にいたのは自分だったかもしれない。
　通信室の椅子は、まだ座面に温かみを残している。定時連絡の時刻は、人がいてもいなくても変わらない。地球はその時間になれば耳を澄ませる。
　宮下はいつもの書式で今日の分を打った。太陽電池、正常。気密、異常なし。物資、輸送船に積載完了。最後の一行には、明日からこの基地は無人になる、と書き足した。無人、という字を打ってから、しばらく画面を見ていた。
　私信の欄は、いつもは空にしてある。今日は違った。
　〈美咲へ。花壇のチューリップ、今年は自分で植えてみろ。母さんに聞けばちゃんと教えてくれる。前に電話で話したとき、種の袋をまだ開けていないと言っていたな。芽が出るまで一月かかると本に書いてあった。気長にやれ。〉
　打ってから読み返し、「植えろ」を「植えてみろ」に直す。娘は九つで、命令されるのを嫌う年ごろだ。
　送信ボタンを押すと、進捗を示す線が画面の端をゆっくり動く。届くまで十九分、返事が来るとしても、さらに十九分。合わせて四十分近く、ここに座って待つ余裕は、輸送船の出発時刻を考えればまだある。
　だが、待たなかった。
　いつも待たなかった。定時連絡は送れば終わりで、返事を聞く前に次の仕事へ移るのが、この三年の癖だった。今日もそうしていいはずだった。今日だけは違う気がしても、その違いをどう扱えばいいのか、宮下には分からない。
　立ち上がり、椅子を机の下に戻して、壁のスイッチに指をかける。通信室の明かりが落ちると、窓の外の赤い地面と、まだ届いていない自分の声だけが基地に残った。
　ヘルメットを抱えて廊下に出ると、エアロックの向こうで輸送船が白い光を放っていた。振り返らずに歩いた。返事は、地球に着いてから読めばいい。

## 応答 B
定時連絡、火星時間で十九時。いつもと同じ時刻に、いつもと同じボタンを押す。

「こちら、シャムロック基地。整備担当、佐伯です。本日の報告をします」

声に出して言う必要はない。テキストで済む連絡だ。でも三年前からずっと、声で送っている。地球にいる誰かが、これを音声で聞くとは限らないけれど、文字の羅列よりは、人の声のほうが、まだ何か伝わる気がしていた。

「発電パネル、異常なし。水の再生装置、昨日ちょっと詰まりましたが、直しました。作物室のトマトが、三つ赤くなりました。今日食べます」

そこまで言って、少し黙る。マイクの前で黙っていても、向こうには「間」として届くだけだ。十四分後に。

他のみんなが最終便で帰ってから、もう二百日近く経つ。基地を完全に畳むには、まだ機材の解体と梱包が残っていて、それを一人でやる係に、佐伯は自分で手を挙げた。得意なのは機械を直すことで、機械を壊すことじゃないのに、と自分でも思うけれど、誰かがやらなければならなかった。

「解体作業、第三居住モジュールまで終わりました。予定より少し遅れています。すみません」

謝る必要はないと、いつも地球側の返信には書いてある。急がなくていい、無理はしないでくれ、と。それでも謝ってしまうのは、たぶん、遅れることで、ここにいる時間が延びるのを、自分がどこかで喜んでいるからだ。

窓の外は、いつもの赤い地面と、薄い空と、動かない岩。最初の一年は毎日この景色に感動していたのに、今はもう、ただの外の景色になっている。人は慣れる。どんな場所にでも。それが救いなのか、寂しいことなのか、佐伯にはまだよく分からない。

「明日は、貯蔵庫の棚を解体する予定です。あと、」

言葉が止まる。今日、伝えようと決めていたことがある。

「あと、母に伝えてください。誕生日、祝えなくてすみません。来年は、たぶん、一緒に食べられます。地球で」

来年の今頃には、自分はもう地球にいる。最後の便で。それは分かっているのに、「たぶん」とつけてしまう。火星に来てから、確実なことなんて何もないと、骨身にしみて分かってしまったから。

通信パネルの向こうに、地球が浮かんでいる。青くて小さくて、いつも同じ位置にある。あの光の中のどこかに、母がいて、かつての同僚たちがいて、佐伯のことを覚えている人たちがいる。十四分前の自分の声が、今まさにあそこに届こうとしている。

「以上で、本日の定時連絡を終わります。次は明日、同じ時刻に。シャムロック基地、佐伯」

送信ボタンを押す。いつもと同じ、小さな電子音。

椅子に座ったまま、しばらく窓の外を見る。声はもう、光の速さで地球に向かっている。自分より先に、自分の言葉が着く。それだけで、少しだけ、遠くないような気がした。

作業着のポケットから、赤くなったトマトを一つ取り出す。冷えていて、少し硬い。かじると、酸っぱさの奥に、確かな甘さがあった。

「うまいな」

誰もいない部屋で、佐伯はそうつぶやいた。明日も、同じ時刻に、同じ場所から、同じ声を送るために。
