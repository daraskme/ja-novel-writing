2. 問いへの答え
Aは「天井のあたりから。こつん。」（13字）と、音の発生源が移動し日常が侵食される場面で怖さが立ち上がる。しかし終盤、「外側からではなく――内側から」（14字）など視覚的なホラー演出や比喩による説明を足しすぎており、じわっとした怖さの余韻を損ねている。

Bは、自分と同じ行動をとる気配に対し「頬の形に沿うように、何かが」（13字）と、壁越しの不気味な同調の感触のみで幕を引き、説明を削ぎ落として読後に怖さを残すことに成功している。ただし、怪異の性質に気づきながらも「ふざけて咳をひとつしてみる」（14字）など、語り手の行動の危機感のなさが少し不自然である。

総合して、説明を抑え、依頼の「じわっと怖い」余韻を見事に作り出しているBを評価する。
