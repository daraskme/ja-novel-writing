店の引き戸が開いたのは、開店の掃除も終わったばかりの午前だった。

「おはようございます、真帆さん」

瀬田の声に続いて、もう一人分の足音が入ってくる。真帆は帳場から顔を上げた。契約書はまだ保留のままだったから、来るとしても電話が先だと思っていた。

「昨日の今日ですみません。母を連れてきました」

瀬田の後ろに立っていたのは、瀬田より少し背の低い女性だった。品定めするように店内を見渡してから、真帆に軽く会釈する。

「瀬田の母です。息子から契約の話は聞きました」

「ようこそいらっしゃいました。真帆と申します」

真帆は帳場を回り込み、二人を衣装が並ぶ棚の近くへ案内した。瀬田の母の視線が、すでに衣桁にかけられた祭り用の反物に止まる。真帆が数日前に取り寄せたばかりのものだ。

「単刀直入に言いますね」瀬田の母が口を開いた。「注文数、少し減らせませんか」

瀬田が横で気まずそうに目を伏せる。

「共同出資という形にした以上、私にも采配する権利があります。見積もりの数、正直多すぎると思うんです」

真帆は一瞬言葉に詰まったが、すぐに気を取り直した。動揺を顔に出すわけにはいかない。

「理由を伺ってもよろしいですか」

「祭りの規模から言って、去年より参加人数は減っています。同じ数を仕立てても、余るだけじゃないかと」

「実は」真帆は棚の反物に手を触れながら言った。「ご相談いただいた数量に合わせて、すでに生地を仕入れております」

瀬田の母の表情がわずかに硬くなった。

「まだ契約は結んでいなかったはずですが」

「見込みでの手配です。祭りまでの日程を考えると、生地の到着を待ってからでは仕立てが間に合いませんので」

沈黙が落ちる。瀬田が二人の顔を交互に見た。

「母さん、それは真帆さんが早めに動いてくれたってことだよ」

「それは分かってる。でも仕入れた分をこちらが全部背負う話になるなら、最初の交渉と条件が変わってくるでしょう」

真帆は頷いた。ここで意地を張っても仕方がない。

「でしたら、こういうのはいかがでしょう。数量は当初の八割まで減らす形でご契約いただいて、残りの二割分の生地は、色違いの小物や予備の衣装として店の在庫に回します。無駄にはしません」

瀬田の母がわずかに目を細めた。値踏みするような沈黙が数秒続く。

「……悪くない提案ですね」

「その分、単価は当初の見積もりから据え置きでお願いできればと思います。生地はもう手元にありますので」

瀬田の母は腕を組み、少し考えてから息子の方を見た。

「あなたはどう思うの」

「僕は、真帆さんの店の仕事を信頼して契約を持ちかけたんだ。数字だけの話じゃないと思う」

母親はふっと肩の力を抜いた。

「分かりました。八割の数量、単価据え置きで。書面は作り直してもらえますか」

「もちろんです」真帆は棚から新しい用紙を取り出しながら、内心で小さく息をついた。「今日中にご用意します」

瀬田がようやく安堵した表情を見せる。窓の外では、祭りの準備を知らせる幟がもう一本、通りに立てられていた。
