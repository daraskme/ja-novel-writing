1. 条件の充足
A：題材、形式を満たしています。「あらすじを並べず進める」という語り口の条件に対しては、過去の経緯を回想する描写がやや長く停滞気味です（好み）。また、「作中では昨日の出来事」という設定条件に違反しています。
B：題材、長さ、語り口、感情の出し方、形式のすべての条件を満たしています。あらすじを説明せず、自然な流れで今回の話を進められています。

2. 問いへの答え（引用つき）
【A】
良い点：交渉を通じて母が「この十反分の話、書面に」（11字）と歩み寄り、関係性の変化が追えます。また、母の「頼んでおいてください」（10字）という言葉から、来年に向けた関わりがどうなるのか知りたいことが残ります。
悪い点：前話の提示として「契約書を持ち帰ったのは」（11字）と回想から入るため、そのまま話を進める勢いが削がれています。

【B】
良い点：「昨日の今日ですみません」（11字）というセリフのみで、前話の関係と時間を簡潔に提示できています。母の「悪くない提案ですね」（9字）という言葉から、不信から納得への感情の変化も十分に追えます。
悪い点：交渉がまとまり「今日中にご用意します」（10字）と綺麗に完結しているため、次の話で知りたいこと（引き）がやや弱く感じられます。
