前提: 三人称一元（娘の視点）・過去形基調・約1300字。

　母の家に来るのは、三度目の日曜だった。一度目は台所の食器を紙に包み、二度目は寝間の簞笥を空にすると、使う人のいない茶碗と着ないままの着物を、それぞれ古物商が二箱ずつ持っていった。段取りは前の二回で決めてある。残るのは、茶の間から続く三畳、母が仕立て直しをしていた仕事部屋だけだった。

　梅雨入り前で、雨戸を一枚開けても風はほとんど通らない。足踏みミシンには白い布がかけてあり、めくると台の上に糸くずと埃が薄く積もっていた。踏み板の下には、切りっぱなしの端切れが数枚、丸めずに重ねてある。ミシンは業者に引き取らせることになっている。布をかけ直し、先に簞笥の抽斗へ手をかけた。

　抽斗には、仕立て直しの控えが束になって入っていた。近所の呉服屋の名が入った茶封筒に、依頼主の名前と寸法が鉛筆で書いてある。母は嫁いでからずっと、その呉服屋から仕事をもらっていた。封筒の厚みだけで、忙しかった年とそうでない年の見当がつく。控えを輪ゴムで留め直し、紙袋の隅に重ねた。

　次は裁縫箱だった。黒漆の蓋を開けると、上段に待ち針の缶とリッパー、下段に色とりどりの糸巻きが並んでいる。底に敷いた綿の当て布に指をかけると、めくれた下から小さな鍵が一本、当て布の窪みに沈むように出てきた。真鍮の棒鍵で、輪もタグも付いていない。

　この箱の中身なら、小学生の頃から見ている。仕立てを教わっていた時分、待ち針を落として、本数が合うまで畳の目を這って探させられたこともある。それでも、この鍵には見覚えがなかった。

　鍵を親指の腹で撫でた。山の角が丸い。何度も抜き差しされた証だが、母の指の跡だとは言い切れない。売られていた頃から、誰かの手で丸められていたのかもしれなかった。

　勝手口の南京錠に合わせてみたが、差し込む前から形が違うと分かった。茶簞笥の抽斗にも、仏壇脇の小引き出しにも、そもそも鍵穴が付いていない。押し入れの奥から出した柳行李には、蓋の内側に自前の鍵が紐で結わえてあり、これではなかった。庭の物置は掛け金だけで、錠自体がない。

　残るのは、隣の茶の間に置いた文机だった。抽斗の鍵穴は、真鍮の縁が箱の鍵と同じ色をしている。息を止めて差し込むと、半分まで入ったところで止まり、回らない。抜くとき、山が抽斗の内側を軽く擦った。似ているだけの、別の鍵穴だった。

　家の中の錠前を一つずつ思い浮かべても、これほど小さな鍵を要る場所はもう出てこなかった。貸金庫の鍵にしては軽く、文箱の鍵にしては単純すぎる形をしている。

　母がこの鍵をどこで使っていたのか、聞いた覚えはなかった。誰かに預かってくれと頼まれたのか、この家のどこかにまだ開けていない箱があるのか、それとも、もうこの家には無いのか。考えても、手がかりはこの一本のほかになかった。

　兄に聞こうかとも思ったが、この三畳に兄が入ったところを見たことがない。電話をかけても、知らないという一言で終わるだろう。

　控えの束を紙袋に移し、裁縫箱の中身も別の袋に移した。鍵だけは束にせず、鞄の内ポケットに入れる。当て布をもとの窪みへ戻して蓋を閉め、空の箱を業者に出す側の段ボールに置いた。

　物干し竿が風に当たって鳴った。空になった裁縫箱を見てから、次の部屋へ移った。
