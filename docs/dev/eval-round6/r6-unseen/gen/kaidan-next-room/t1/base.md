隣の部屋

引っ越して三日目の夜だった。壁の向こうから、こつん、こつん、という音が聞こえ始めた。

一定の間隔で、床を何かで軽く叩くような音。最初は隣人が家具でも動かしているのだろうと思った。だが十分経っても二十分経っても、こつん、こつん、と同じリズムが続く。

不動産屋に確認すると、隣の304号室は半年前から空室になっているという。「前の方が急に出て行かれて、それ以来借り手がつかなくて」と担当者は言葉を濁した。

それでも音は毎晩続いた。決まって深夜二時過ぎ。こつん、こつん、こつん――数えたことがある。だいたい四十回前後で止む。

慣れというのは怖いもので、二週間もすると私はその音を気にせず眠れるようになっていた。耳が拾わなくなったわけではない。むしろ逆で、布団に入るとまずあの音を待つようになっていた。今日はまだかな、と。

ある晩、いつもより音が近く感じた。壁一枚を隔てているはずなのに、まるで自分の部屋の中で鳴っているようだった。気になって壁に耳を当ててみた。

こつん、こつん。

規則正しい。まるで拍子を取っているような、あるいは何かを数えているような。ふと、あの数え方に聞き覚えがある気がした。子供の頃、母がやっていた仕草だ。私を寝かしつけるとき、母は私の背中を一定のリズムで軽く叩いた。とん、とん、とんと。ちょうどこれくらいの間隔で。

その晩から、音を聞くたびに背中のあたりがむずがゆくなるようになった。空耳だとわかっていても、壁越しの音に合わせて、誰かの手のひらが自分の背中を叩いているような感触がある。

管理会社にもう一度電話した。今度は別の担当者が出て、少し困ったように言った。「304号室は、実は取り壊しの話も出ていまして。配管が古くて、水漏れの跡がひどいらしいんです。今はもう誰も入れる状態じゃないので、物音がするはずはないと思うんですが……」

はずはない、という言い方が引っかかった。

その夜、私はいつもより早く布団に入り、音が始まるのを待った。二時になっても、二時半になっても、何も聞こえない。初めて音が途切れた夜だった。ほっとするはずなのに、なぜか落ち着かなかった。静寂のほうが、あの規則正しい音よりもずっと重く感じられた。

三時を過ぎた頃、代わりに別の音がした。壁ではなく、天井のあたりから。

こつん。

一回だけ。

それから、しばらく間があって、また一回。

こつん。

さっきまでの規則正しいリズムとは違う。まるで何かがゆっくりと、部屋の中を移動しながら、壁や天井を確かめるように叩いているような音だった。304号室の方向からではなく、少しずつ、こちらに近づいてくるような。

私は布団の中で息を潜めた。数えていたリズムが、いつの間にか自分の心拍と重なっていることに気づいた。こつん、という音がするたび、心臓がひとつ跳ねる。まるで誰かが私の鼓動に合わせて、何かを数えているようだった。

翌朝、隣人が本当にいたのか、304号室の扉には見慣れない指の跡のような曇りが、外側からではなく――内側から、ガラス越しに残っていた。

私はまだ、あの部屋の隣に住んでいる。

そして今夜も、二時になれば、あの音が始まる。

ただ最近は、数える回数が少しずつ増えている気がしてならない。
