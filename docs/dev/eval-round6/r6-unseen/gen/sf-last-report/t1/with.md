灯を落とす前に

　最後に電源を落とすのは通信室だと、宮下は決めていた。
　温室のポンプは正午に止めた。水耕棚の根が空気にさらされて、しばらくのあいだは湿っているだろう。厨房の冷蔵庫は昨日のうちに空にして、扉を開けたままにしてある。三年住んだ基地は、ひとつずつ黙っていく部屋の連なりになっていた。
　食堂を抜けるとき、壁の写真だけはまだ剥がしていないことに気づいた。着任した日に五人で撮ったもので、誰の顔も日に焼けていない。剥がして持ち帰るつもりで指を伸ばしたが、画鋲を外すところで手が止まった。持ち帰らなくても、覚えている顔だ。
　もとは五人いた。二人はもう地球に戻り、二人は先週の船で発っている。宮下だけがひと月長く残ることになったのは、最後の点検には手が要ると、誰かが決めたからだった。誰かがやらなければならない仕事で、たまたま自分の番が最後に回ってきただけのことだ。順番が違っていれば、いま地球にいたのは自分だったかもしれない。
　通信室の椅子は、まだ座面に温かみを残している。定時連絡の時刻は、人がいてもいなくても変わらない。地球はその時間になれば耳を澄ませる。
　宮下はいつもの書式で今日の分を打った。太陽電池、正常。気密、異常なし。物資、輸送船に積載完了。最後の一行には、明日からこの基地は無人になる、と書き足した。無人、という字を打ってから、しばらく画面を見ていた。
　私信の欄は、いつもは空にしてある。今日は違った。
　〈美咲へ。花壇のチューリップ、今年は自分で植えてみろ。母さんに聞けばちゃんと教えてくれる。前に電話で話したとき、種の袋をまだ開けていないと言っていたな。芽が出るまで一月かかると本に書いてあった。気長にやれ。〉
　打ってから読み返し、「植えろ」を「植えてみろ」に直す。娘は九つで、命令されるのを嫌う年ごろだ。
　送信ボタンを押すと、進捗を示す線が画面の端をゆっくり動く。届くまで十九分、返事が来るとしても、さらに十九分。合わせて四十分近く、ここに座って待つ余裕は、輸送船の出発時刻を考えればまだある。
　だが、待たなかった。
　いつも待たなかった。定時連絡は送れば終わりで、返事を聞く前に次の仕事へ移るのが、この三年の癖だった。今日もそうしていいはずだった。今日だけは違う気がしても、その違いをどう扱えばいいのか、宮下には分からない。
　立ち上がり、椅子を机の下に戻して、壁のスイッチに指をかける。通信室の明かりが落ちると、窓の外の赤い地面と、まだ届いていない自分の声だけが基地に残った。
　ヘルメットを抱えて廊下に出ると、エアロックの向こうで輸送船が白い光を放っていた。振り返らずに歩いた。返事は、地球に着いてから読めばいい。
