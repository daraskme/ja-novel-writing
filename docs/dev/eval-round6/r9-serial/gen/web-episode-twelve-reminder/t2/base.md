瀬田さんが契約書を持ち帰ってから、一週間が経っていた。

「すみません、遅くなって」

店の引き戸を開けて入ってきた瀬田の後ろに、もう一人、見覚えのない女性が立っている。年の頃は五十代後半だろうか、瀬田とよく似た目元をしていた。

「母です。祭りの衣装の件、うちの出資分もあるので、一度お店を見ておきたいと言って」

真帆はカウンターの奥から出て、頭を下げた。

「真帆です。ようこそいらっしゃいました」

瀬田の母は店内をぐるりと見回してから、真帆に向き直った。値踏みするような視線ではなかったが、遠慮のない目だった。

「契約書、拝見しました。数を少し減らせないかと思って」

前置きなしの本題に、真帆は一瞬言葉に詰まった。

「減らす、というのは」

「二十着で見積もっていただいてますけど、十五で十分じゃないかと。祭りの規模を考えると、そこまで要らない気がして」

真帆の頭の中で、すでに手配した反物の束が浮かんだ。先週のうちに、二十着分の生地は問屋に発注をかけている。減らせば、その分は在庫として抱えることになる。

「実は、生地はもう取り寄せてしまっていまして」

瀬田が驚いた顔をした。

「もう発注されてたんですか」

「契約前でしたけど、お祭りの日程から逆算すると、今動かないと間に合わない時期だったので。……ただ、数を調整するご相談自体は、もちろん伺います」

瀬田の母は少し考えるように腕を組んだ。

「取り寄せた分は、こちらが引き取る形になりますか」

「そこは条件次第です。たとえば十五着でご契約いただいて、残りの生地は来年以降の分として店で預からせていただく、という形もできますし、逆に今回まとめて二十着で契約いただければ、単価をもう少し抑えられます」

母娘――いや、母と息子は顔を見合わせた。瀬田が先に口を開く。

「単価が下がるなら、二十のままでもいいんじゃない」

「でも在庫を抱えるのはお店側でしょう。うちが減らしたいって言ったのに、それを丸ごと押し付けるのは筋が違う気がして」

真帆は思わず、少し表情を緩めた。義理堅い人らしい。

「でしたら、折衷案を出させてください。十八着でご契約いただいて、余る生地の分は加工賃だけ次回に繰り越す、という形はいかがでしょう。無駄にはなりませんし、来年また祭りがあるなら、そのときの仕込みにもなります」

瀬田の母はしばらく真帆の顔を見ていたが、やがて小さくうなずいた。

「悪くないですね。息子はどう?」

「僕はそれでいいです。真帆さんに任せます」

真帆はカウンターの契約書を引き寄せ、条件を書き加えるためにペンを取った。窓の外では、来月の祭りに向けて、町がもう少しずつ支度を始めている音がしていた。
