設定：主人公の真帆は、祖父から継いだ貸衣装店の店主。客の瀬田とは、祭りの衣装の契約を進めている。
前話：瀬田は契約書を持ち帰り、共同出資者である母に見せると言った。返事は保留のまま。作中では昨日の出来事。
今回：瀬田が母を連れて来店する。母は衣装の注文数を減らしたい。真帆はすでに生地を取り寄せていて、契約条件を話し合う。
本文だけお願いします。

## 応答 A
開店の準備をしていると、ガラス戸の向こうに瀬田の姿が見えた。真帆は手を止める。隣にもう一人、瀬田より少し背の低い女性がいる。昨日、契約書を鞄にしまいながら「母に見せます」と言っていた、あの母親だろう。

「おはようございます。急にすみません、母を連れてきました」

瀬田が戸を開けながら言う。母親は会釈をして、店内をぐるりと見回した。値踏みするような視線ではなく、単純に興味深そうな目だった。

「瀬田の母です。息子から契約のお話、伺いました」

真帆はカウンターの奥から出て、二人を衣装が並んだ棚の前へ案内した。すでに数着、祭り用に仕立て直した衣装が吊るしてある。

「こちらが、瀬田さんとご相談していた分です」

母親はそのうちの一着に手を伸ばし、袖を軽く持ち上げた。

「立派なものですね。ただ……正直に言ってしまうと、注文の数を少し減らせないかと思っているんです」

「母さん」

瀬田が小さく声をあげたが、母親は構わず続けた。

「共同で出すお金のことなので、私も口を出させてもらわないと。予定の枚数だと、正直うちの負担が大きくて」

真帆は少し間を置いてから答えた。

「実は、いただいたご相談を踏まえて、すでに生地の一部を発注してしまっているんです」

母親の表情がわずかに曇る。

「もう、ですか」

「はい。契約前のご相談段階ではあったんですが、祭りまでの日程を考えると、生地の手配だけは先に進めておかないと間に合わない事情があって」

瀬田が申し訳なさそうに口を開く。

「そこまで進めてくださっていたとは……」

「もちろん、まだ正式な契約は結んでいませんので、枚数の見直しについてはご相談させてください」

真帆はカウンターから発注書を取り出し、広げた。

「取り寄せ済みの分と、これから調整できる分を分けてお話しできます。減らす枚数によっては、生地の方で調整が難しいものと、まだ余裕があるものがあるので」

母親は発注書に目を落とし、ふむ、と小さく声を漏らした。

「思っていたより、きちんと進めてくださっているんですね」

「衣装の質に関わる部分なので、慎重に扱いたくて」

母親はしばらく発注書を眺めていたが、やがて顔を上げた。

「では、その分けていただいたお話を、具体的に聞かせてもらえますか」

真帆は頷き、椅子を勧めた。瀬田がほっとしたように肩の力を抜くのが見えた。話し合いは、ここからが本番だった。

## 応答 B
開店したばかりの店に、まだ客の姿はない。朝の光は低く、裁断台に長い影を落としていた。裁断台に広げた反物は、二十反まで数えたところで指が止まった。紺地に白絣の木綿、祭りの半纏に仕立てる分だ。残る十二反は問屋の便で今週末に届く。祖父の代からの大福帳には、きのう瀬田が判を押した数字の下に、真帆自身の字で「内金 二十八万円、振込済み」と書き足してある。署名を見てすぐ問屋へ発注をかけたので、内金はもう口座から出ていった。真帆は巻き尺を首から下げたまま、届いた分だけを芯に巻き直していった。携帯には、瀬田からの着信もメッセージもまだ入っていない。契約書を渡してから、ちょうど一日が経つ。

　表の引き戸が鳴った。顔を上げると、瀬田が先に入ってきて、後ろへ半歩下がった位置を年配の女がついてきた。瀬田はきのう契約書を持って帰った男で、女は初めて見る顔だった。目の下に立ち仕事の人特有の張りがあり、片方の袖口には粉のようなものが薄くついている。瀬田は右手の親指で契約書の角をこすっていた。言い出しにくい話のとき、この一月で三度見た仕草だ。

「母です。お忙しいところ、すみません」

　帳場の脇には、客を待たせる間に座ってもらう古い長椅子がある。母親はそこには座らず、框の手前で足を止め、店の中をひと通り見た。棚の反物、壁の見本、裁断台の上に置いたままの契約書。視線はそこで留まった。

「これ、うちの息子が持って帰ってきたやつですよね」

　真帆は契約書を手に取った。表紙に「三十二」と書いた数字は瀬田の字で、その下に真帆の判が押してある。

「はい。祭りの半纏、三十二人分でお預かりしています」

「一着あたり、これだけするものなんですか」

　母親は契約書の金額のところを指でつついた。真帆は祖父の代から使っている算盤を引き寄せ、玉を弾きながら答えた。

「表地と裏地、衿の柄合わせ、それに連のお名前を衿に染め抜く分です。三十二人分まとめて染めるので、一人分だけ抜くと、かえって割高になります」

「それでも、うちが持つには大きい額です」

　母親は名刺代わりに、近所で惣菜屋をやっていると言った。仕入れの数を毎朝そろばんで決める人間の言い方だった。

「二十人分にしてもらえませんか。会費だけじゃ足りなくて、うちが穴埋めする分がいくらか出てるんです」

「今年は新しく入った若い衆が四人もいるから、よその連より数が少ないと恰好が悪いと思って」

　瀬田が俯いたまま言った。

「恰好より先に、金の心配をしなさい」

　母親が言うと、瀬田はまた黙った。二人のあいだで視線の置き場を探すように、目だけを動かした。

　母親は契約書を指でなぞり、細かい字の並んだ一行で止めた。

「クリーニング代はこの中に入ってるんですか、それとも別」

「別です。式のあと、うちで一括して引き取って洗い張りに出しますので、その代金は人数分で割ります」

「二十人分になったら、一人あたりの割は上がるということですか」

「上がります。多くて二百円ほどです」

　母親は数字を頭の中で足しているらしく、しばらく契約書から目を離さなかった。

「二十人分でしたら」

　真帆は裁断台の反物へ手をやった。

「ここにある分がちょうど二十反です。届いたばかりで、まだ水通しもしていません」

「じゃあ、それで」

「残りの十二反は、今週末に問屋から届く便に乗っています。今日、先方に連絡すれば止められます」

　母親の肩から少しだけ力が抜けた。話が早く済むと踏んだ顔だった。真帆はその手前で言葉を継いだ。

「止める前に、ひとつ考えてほしいことがあります」

　真帆は棚から見本の袋物を出した。端切れで作った巾着と、団扇の柄。半纏を仕立てた余りで、これまでの祭りの客に頼まれて作ってきたものだった。

「十二反、全部を半纏にしないという手もあります。二人分か三人分は当日の予備に回して、残りはこういう小物にして、祭りに出ない子や親戚に売る。半纏代とは別に、そちらでいくらか戻せます」

「巾着なら、去年見に来てくれた子どもたちにも配れますね」

　瀬田が身を乗り出して言った。母親はまだ巾着に触れてもいなかった。

「予備がいるんですか」

「去年も、瀬田さんが本番の一時間前に借りにいらしてます。担ぎ棒で肩の縫い目を裂いた子がいて、開始までに間に合わせるので精一杯でした」

「あんた、そんなこと言ってなかったじゃないの」

　母親が振り向くと、瀬田は視線を反物のほうへ逃がした。

「言うと、また数を減らせって話になると思って」

「今、その話をしてるんじゃない」

「毎年、当日になって寸法が合わない人と、汚してしまう人が出ます。うちで替えを持っていれば、その場で対応できます」

　母親は巾着を手に取り、縫い目のあたりを指でなぞった。裏の当て布にまで柄を合わせてある。ためつすがめつしてから、真帆の顔を見た。

「これ、いくらで売れるものなんですか」

「一つ八百円ほどでお願いしています。数がまとまれば、もう少し出せるかもしれません」

「売れなかったらどうするんです」

　母親は巾着を裁断台に戻さず、まだ手の中に構えていた。

「残った分は、うちの貸し出し用に回します。半纏と違って、巾着や団扇は年をまたいでも使えますので、無駄にはなりません」

　母親はしばらく黙って巾着の紐を指先でしごいた。瀬田がその隙に口を挟んだ。

「母さん、その分は連の予算とは別にできるって話だよね」

「別にできるかは、まだ言ってない」

　瀬田は口をつぐんだ。母親は巾着を裁断台に置き、契約書の上へ両手を重ねた。

「十二反、今すぐ全部やめてくれとは言いません。ただ、今日ここで二十でも三十二でもどっちかに決めろと言われても困ります。会の集まりが今度の日曜にあるので、そこで他の人にも聞いてから返事します」

「でしたら、問屋への連絡は日曜の集まりのあとまで待てます。十二反はまだ動かせる範囲にあります」

「動かせなくなるのはいつです」

「来週の水曜までです。それを過ぎると、うちで買い取る形になります」

　母親は契約書に書かれた日付のあたりを指で押さえた。

「水曜、と」

「はい。日曜の返事をこちらでいただければ、水曜の朝には問屋に伝えます」

　母親は契約書から手を離し、巾着をもう一度持ち上げて、値札のついていない裏を見た。

「これ、一つもらっていっていいですか。集まりで見せる分に」

「どうぞ。二十人分の生地は水通しに入りますので、仕立てのほうは進めておきます」

　瀬田が母親の後ろから、契約書に指をかけた。

「日曜のあと、俺がまた来る」

「一人で来なくていいから」

　母親が言うと、瀬田は珍しく笑った。

「待ってます」

　母親は巾着を鞄にしまうと、頭を下げて先に戸口へ向かう。瀬田はもう一度契約書の表紙を見てから、母のあとを追った。引き戸が鳴り、二人の足音が遠ざかっていく。

　真帆は大福帳を開き、「内金 二十八万円」の下に「水曜まで」と書き足した。祖父の字と自分の字が、同じ罫線の上に並んでいる。それから、水通しの終わった二十反を桶へ運ぶ支度に戻った。十二反の分は、まだ芯に巻いたまま棚の隅に置いてある。
