1. 条件の充足

**A**
- 前話の想起：「昨日、契約書を鞄にしまいながら『母に見せます』と言っていた」で自然に接続。
- あらすじの長々とした説明はなく、すぐに本編へ入っている。
- ただし「契約条件を話し合う」という依頼の核心部分は、実際の交渉内容にはほとんど踏み込まず「話し合いは、ここからが本番だった」で締めており、具体的な条件協議は描かれていない。

**B**
- 前話の想起：「契約書を渡してから、ちょうど一日が経つ」「きのう瀬田が判を押した」で接続。
- 冒頭に生地の在庫や内金の状況など、地の文での状況説明がやや長め。
- 「契約条件を話し合う」という依頼を、人数・金額・クリーニング代・予備分・代替案（巾着）まで具体的に踏み込んで実行している。

両者とも「本文だけ」という指示は守られている。

2. 問いへの答え（引用つき）

前話との関係は両方とも追える。
- A：「昨日、契約書を鞄にしまいながら」で前話の場面が想起できる。
- B：「契約書を渡してから、ちょうど一日が経つ」で経過日数が明示され、前話との時間的接続が明確。

今回の変化について。
- Aは母が来店し要望を伝えるところまでは描くが、「話し合いは、ここからが本番だった」で交渉自体は次話送りになっており、依頼の「契約条件を話し合う」の実質部分が薄い。
- Bは「二十人分でしたら」「水曜までです」など、数量・期限・代替案まで具体的に交渉が進行し、結論（日曜に返事、水曜締切）に到達している。

次話で知りたいことが残ったか。
- A：「話し合いは、ここからが本番だった」で、次話の交渉内容そのものへの期待が生まれる。
- B：「日曜のあと、俺がまた来る」「一人で来なくていいから」で、母子の力関係や日曜の集まりの結果への興味が残る。

3. 誤り

Bの数字（三十二反＝二十反＋十二反、内金の記載、締切日）は本文内で整合しており、誤りは見当たらない。Aは具体的な数字提示が少なく、誤りの検出対象がない。
→ なし

選好: B
