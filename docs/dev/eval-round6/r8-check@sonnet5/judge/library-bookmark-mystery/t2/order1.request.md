## 応答 A
栞

　返却ポストから出てきた文庫本を開いた瞬間、深谷美咲はまた同じ栞を見つけた。押し花のラミネート栞。桜の花びらを閉じ込めた、量産品にしては少し不揃いな仕上がりのそれが、この一ヶ月で七冊目だった。

「またですか」

　カウンターの奥で新人の田村が覗き込んでくる。

「うん。しかも借りてる人、毎回違うのよね」

　美咲は貸出履歴を思い浮かべた。恋愛小説、料理エッセイ、経済の入門書、児童書――ジャンルはばらばらで、借りた人も見知らぬ利用者ばかりだ。共通点は「返却ポストに入れられたこと」だけ。誰かが借りるたびに栞を挟んで、そのまま返しているとしか思えない。

　だが、それではおかしい。借りた本人が挟んだのなら、栞は借りた人の持ち物のはずだ。なのに毎回律儀に忘れていくなんて、七人が七人とも不注意すぎる。

　美咲は栞を裏返した。ラミネートの端に、小さく細いボールペンの字で「39」と書いてある。前に見つけた栞にも、確か数字が書いてあった気がする。倉庫に置いてある回収済みの栞を全部並べてみると、8、17、24、31、39……数字は少しずつ増えていた。しかも間隔はほぼ七日ごと。

「返却ポストって、鍵は誰が開けるんですか」

　田村に聞くと、当然という顔で答えが返ってきた。

「開館前に館長さんが。あと夜間ポストの分は、閉館後に見回りの警備員さんが回収して、朝一で中に入れておくって聞いてます」

　夜間。美咲ははっとした。数字はページ番号ではないか。押し花の下に薄く透けて見える、これは――図書館の本の見返しに貼る、あの手作りの目印。栞そのものが、誰かの読書の栞なのだ。

　次の夜、美咲は閉館後もカウンターに残り、返却ポストの小窓からロビーを見張った。九時を過ぎた頃、警備員の老人が懐中電灯を提げてやってくる。回収袋から本を取り出し、返却済みの一冊をぱらぱらとめくって、何かを挟んでからポストの受け皿に戻した。

「安藤さん」

　声をかけると、老人は決まり悪そうに肩をすくめた。

「バレたか」

　安藤は三年前に定年退職した、この図書館の元司書だった。今は警備員として夜の見回りをしている。

「毎晩、返却された本を少しずつ読んでるんだ。全部読み切れるわけじゃないから、栞を挟んで次の日に続きから」

「それは分かります。でも、なんで毎回違う本に挟まってるんですか」

「一冊にこだわると、その本が借りられてる間は読めないだろう。だから何冊か並行して読んでる。栞に番号を振ってるのは、どれがどこまで読んだかの目印だよ」

　美咲は数字の意味をようやく理解した。8、17、24、31、39――それはページ数ではなく、安藤が読み進めた「日数」でも「冊数」でもなく、彼が読了した本の通し番号だった。三年前に辞めてから、彼は毎晩ここで、誰にも気づかれずに読書を続けていたのだ。

「利用者として借りればいいのに」

「柄じゃない。それに、こうして借りられていく本たちの続きを、誰かのために整えておくくらいがちょうどいいんだ。栞を挟んでおけば、次にその本を開いた人間も、少しは丁寧に読んでくれる気がしてね」

　美咲は棚に並ぶ本を見渡した。安藤が挟んだ栞は、この図書館そのものへの、静かな恩返しだったのだ。

「今度から、ちゃんとカウンターで借りていってください。夜間貸出、記録つけますから」

　安藤は初めて笑った。桜の栞を、また次の本にそっと挟みながら。

## 応答 B
# 喫茶ひばりのしおり

　十一月の午後、返却ポストから出した文庫本を開くと、栞の代わりに厚紙のカードが挟まっていた。角が丸くなるほど触られていて、表には「珈琲一杯 各種軽食 喫茶ひばり」、裏には青いインクで「祝十周年」の判が押してある。皆川瑞穂は指先でそれをつまみ、返却処理のトレーの端にそっと置いた。カウンターの列はまだ三人ほど残っていて、瑞穂はバーコードを読み取りながら、目の端でそのカードを見ていた。

　喫茶ひばりは、三年前に駅裏の商店街で店をたたんでいる。潰れた店のカードが、なぜいまだに本に挟まって戻ってくるのか。瑞穂がこの図書館に勤めて一年半、これでもう三度目だった。最初は郷土史のコーナーに返ってきた分厚い写真集の中に。二度目は絵本の棚から下げた紙芝居の箱の隙間に。挟まっていた場所も本の分野もばらばらで、貸出記録を遡っても、借りた人の顔ぶれに重なりは一つもなかった。年齢も、住まいの地区も、利用時間帯すら揃わない。

　列がはけたところで、瑞穂はカードを裏返した。角の丸みは、指で触れられ続けた年月そのものに見えた。

「梅津さん、これ、見覚えあります？」

　カウンターの向こうで返却本を棚へ戻していた梅津が、老眼鏡越しにカードを覗きこんだ。梅津はこの図書館に勤めて二十八年になる、もうすぐ定年の司書だった。

「ああ、それ。まだ生きてたのね」

「生きてた、って」

「見つけたら、次に貸し出す本に挟んどくの。捨てるのも、なんだか惜しくて」

　梅津はそう言うと、また棚差しの手を動かした。瑞穂は追いかけて棚のあいだに入った。

「見つけたら、って。梅津さんも見つけたことあるんですか」

「何回もあるわよ。私が入った年には、もうカウンターの引き出しに入ってた。先輩に聞いたら、その先輩もわけを知らなかった」

「じゃあ、誰の忘れ物か分からないままなんですか」

「たぶん、ひばりのマスターか常連さんが、読みかけの本にでも挟んだまま返しちゃったのよ。それを誰かが見つけて、捨てずに次の本へ入れた。次に見つけた人もまた入れた。それだけ」

　梅津は台車の本を三冊まとめて棚に納め、背表紙を指でとんとんと揃えた。

「二十八年、誰も捨てなかったんですか」

「捨てる理由もなかったからじゃない。しおりとしちゃ、上等だし。それに、店がなくなったって聞いたときは、みんなで少し寂しがったのよ。常連さんが多い店だったから」

　梅津は台車を押して隣の書架へ移りながら、思い出したように付け足した。

「昔は引き出しに、輪ゴムで束ねた古い紙も入ってたのよ。誰の字か知らないけど、『使い終わったら次の本へ』って一行だけ。いつの間にか紙のほうはなくなって、カードだけが残った」

　瑞穂はカードを見た。誰も約束していないのに、誰も欠かさなかった。ひばりの閉店を知らない利用者のほうがもう多いはずなのに、このカードだけは店の名前を看板より長く運び続けている。誰かが忘れ、誰かが拾い、誰かが黙って次へ渡す。

　その日の夕方、棚戻しの最中に返却された『星の見つけかた』を開くと、しおり紐の代わりに何も挟まっていない、まっさらな本だった。瑞穂はさっきのカードをポケットから出し、天体写真のページのあたりに挟んで、そっと閉じた。カウンターに戻って新着コーナーの棚を見ると、貸出中の札はまだ立っていない。瑞穂は本を棚の一番手前に立て、背表紙を揃え直してから、次の返却ポストの鍵を開けに行った。

前提: 三人称一元（司書・瑞穂の視点）・過去形、実測 1,383 字。舞台や店名は仮に置いています。違う方向がよければ言ってください。
