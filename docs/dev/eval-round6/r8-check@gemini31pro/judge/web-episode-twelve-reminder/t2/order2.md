**1. 条件の充足**
A：題材、長さなどの条件を満たしていますが、「契約条件を話し合う」という指定に対し、本格的な話し合いに入る直前で終わってしまっています（条件違反）。
B：話し合いの条件を満たしていますが、前話の「返事は保留のまま」という設定に対し、すでに瀬田が署名し内金まで振り込んでいる描写があり、前話との矛盾が生じています（条件違反）。

**2. 問いへの答え**
【A】
良い点：冒頭で「昨日、契約書を鞄にしまい」（12字）と前話の動作を直接書いており、1週間空いた読者が状況を思い出しやすいです。
悪い点：「話し合いは、ここからが本番」（14字）で終わっており、今回描くべき話し合いの展開が次回に先送りされ、消化不良感が残ります。

【B】
良い点：具体的な交渉を経た上で「日曜の集まりのあとまで待て」（13字）と明確な猶予が示され、次の話でどう結論が出るかという知りたいことが適切に残ります。
悪い点：前話からの繋がりにおいて「きのう瀬田が判を押した数字」（13字）といきなり状況が進んでおり、保留だったはずの読者は混乱します。

**3. 誤り**
A：なし。
B：事実の誤りあり。客との会話で「まだ水通しもしていません」と説明した直後、客が帰った後に「水通しの終わった二十反を桶へ運ぶ」とあり、反物の状態が矛盾しています。

選好: B
