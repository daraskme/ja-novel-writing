# 33 数値閾値の食い違い裁定 — 論点別ソース対照・実測・プロファイル別「単一権威テーブル」案

種別: conflict_resolution（追加調査）。対象: 21 / 22 / 23 / 24（first principles 4 本）、08 / 11（ANA 翻案）、ANA 原典 `common-rules.md`・`tools/check-prose.py`・`skills/anti-ai.md`（Gate A–G）、`novel2agent-jp/scripts/check_prose.py`、`fp23_regex_test.py`。既存レポート 02 / 03 / 05 / 06 / 07 / 09 / 10 は該当箇所のみ参照。

## 0. 先に結論（裁定の要旨）

1. **食い違いの半分は「数値の種類の混同」**。同じ現象に対して (A) 執筆時の目安、(B) lint の警報線、(C) 作品単位の予算、が別々のソースに書かれているだけで、矛盾していないものが多い（体言止め「1,000字に2〜3回」=A と「4回以上で検出」=B、比喩「1場面1〜2個」=A と「ような系が1,000字に5回」=B、22 の「文末は3回まで」=A と同じ 22 の「4連続検出」=B）。新スキルでは **A は文体仕様書（style-sheet）、B は `scripts/data/thresholds.json`、C はレビュー用チェックリスト**に分離し、B を唯一の数値権威にする。
2. **同一文末「3連続でマーク」は不採用**。3 を主張しているのは ANA の「了」規則を日本語へ移した先行調査員の翻案（08/11/02/03/06 の提案）で、日本語の一次ソース 21・22・24 は実質すべて「4連目から検出」で一致している。青空文庫 33 作品の実測では、同一文末 3 連は地の文 1,000 字あたり中央値 2.3 回、4 連は 1.1 回、6 連は 0.43 回、8 連は 0.15 回出る。3 連・4 連を WARN にすると太宰や漱石でも 1 話 3 件前後鳴り、21 が戒める「機械的な交互配置」を誘発する。**裁定: 4連=INFO、6連=WARN、8連=強WARN ＋ 密度指標（4連以上の run に属する文の割合 35% 超で WARN／50% 超で強WARN）＋ た止め率 80% 超で WARN**。LLM 風サンプルのうち三人称の 2 本は、run の存在ではなく密度（45〜69%）と た止め率（81〜90%）が人間の p90 以上に出た（一人称 Web 調の 1 本は人間分布の内側）。
3. **文長 CV は 2 段にすれば 21 と 23/24 は両立する**。人間 33 作品の全文 CV は最小 0.47・中央値 0.62。**0.50 未満=INFO（人間の 9% が該当）、0.40 未満=WARN（人間 0%）**。ANA の 0.42 は 0.40 に吸収。計測は「地の文のみ・30 文以上の章/場面単位」に固定（20 文ブロックの局所 CV は人間でも 1 割が 0.40 を割るので局所には使わない）。
4. **会話比率は「目標値 ±15 ポイントで INFO」（24 の方式）に一本化**し、プロファイルは目標値の既定だけを持つ（文芸 0.30／純文学寄り 0.20・下限なし／エンタメ・Web 0.45／ホラー・ミステリ −0.10）。これで 21・22・24 の帯はすべて包含される。ANA short の 45〜65% と「1,000字に12〜18発話」は中国の通俗感情短編の値で、人間実測（発話密度 p90=11.2/1,000字）を超えるため不採用。
5. **発話連続は 7 と 8 の差に実質がない**（21 の「タグなし 3〜4 往復」= 6〜8 発話、07 の「4 往復」= 8、ANA 8、24 は 7）。文芸 7／エンタメ・Web 8／宣言済みの密集会話段 12 とする。
6. **ANA 由来で日本語に持ち込んではいけない数値**: Gate A の直喩マーカー即削除（人間は ような系を 1,000 字に中央値 2.9 回使う）、認知動詞「章 2 回」（≒0.5/1,000字。人間中央値 0.81）、一文段落率 15〜35% 帯（人間は 3〜88%）、段落 60 字・250 字（中国語字数。日本語換算で約 100 字・約 400 字となり 03 の 110 字・24 の print 400 字と一致する）、接続詞 7/1,000字（全位置・中国語の計数で単位が別）。
7. **Web の字下げは矛盾していない**。22 は「生成時の既定」、24 N05 は「lint の許容」を述べている。裁定: 正本の既定は字下げあり、lint は「混在」を FAIL、Web プロファイルでは「字下げ無しで統一」を PASS（INFO で一括字下げ機能を案内）、print/公募の書き出しでは字下げ必須。
8. 実測は 1908〜1960 年代の作品に限られ、現代の Web 小説・ラノベは権利上入手できず **未較正**。Web/ラノベ列の数値は「calibrate 前提の初期値」と明記した。

## 1. 概要

### 1.1 この調査の目的
新スキルは `scripts/`（機械検査）と `references/`（文章術）の両方に数値を持つ構成になる。ソース間で閾値が割れたまま取り込むと、スクリプトの既定値と参照文書の記述が二重定義になり、(a) LLM がどちらに従うか不定、(b) 片方だけ更新されて腐る、(c) 「3 連続まで」を目標値として文章を歪める、の三つが起きる。本レポートは全ソースの数値を論点別に棚卸しし、どれをどの条件で採るかを根拠つきで裁定し、プロファイル別（文芸／エンタメ・ラノベ／Web 連載／短編）の単一権威テーブル案を出す。

### 1.2 方法
- 精読: 担当 10 ファイルを全文読了。ANA の Gate 定義は `tmp-ana11/skills/anti-ai.md` の該当節（Gate A–G と 6 量化指標）を追加で読んだ。
- 実測: `fp23_regex_test.py` の正規表現と統計部を拡張した `scratchpad/threshold_measure.py`（Python、標準ライブラリのみ）と、その JS 移植 `scratchpad/calib/measure_port.js` を作成。3 本のテキストで両実装の一致を確認した。
  - **人間側コーパス**: 青空文庫の著作権保護期間満了作品 33 本（新字新仮名）。本文はブラウザ内で計測し、**ローカルには保存していない**（残したのは集計値のみ）。内訳は付録 A。純文学寄り 14 本（太宰・芥川・漱石・梶井・賢治・安吾・中島・南吉）＋大衆・時代・探偵・少年もの 19 本（山本周五郎・江戸川乱歩・海野十三・岡本綺堂・吉川英治・久生十蘭）。計約 86 万字。うち 12 本は敬体（です・ます）主体の語り。
  - **LLM 側**: 本調査員（LLM）が文体指示なしで即興に書いた 3 本（喫茶店の再会／異世界 Web 第 1 話／青春もの、各約 1,000〜1,100 字）。失敗カタログを読んだ後に書いており盲検ではない。n=3 で短い。**傾向の例示であって較正データではない**。
- 単位の正規化: 語彙・構文系は「地の文（かぎ括弧内を除いた本文）1,000 字あたり」、記号系と会話系は「全文 1,000 字あたり」。ANA の「章あたり」は 1 章 2,500 中国語字 ≒ 日本語 3,750〜4,500 字（08/11 の換算 1.5〜1.8 倍）として 1,000 字あたりに直した。

### 1.3 数値の 3 分類（以後この記号を使う）
| 記号 | 種類 | 置き場所 | LLM が読むタイミング |
|---|---|---|---|
| A | 執筆時の目安（既定の書き方） | `style/style-sheet.md` の初期値（プロファイルから流し込む） | 執筆前 |
| B | lint の警報線（INFO / WARN / 強WARN / FAIL） | `scripts/data/thresholds.json` のみ。references には ID で参照させ数値を書かない | 読まない（スクリプトが読む。LLM にはヒット箇所だけ渡す: 23 §10.1） |
| C | 作品・場面単位の予算（1 作 1 回、1 場面 1 個など機械で数えにくいもの） | `references/revision/` のチェック項目 | 推敲・レビュー時 |

段の定義（24 C2/C4 を踏襲し、閾値系には FAIL を置かない）:
- **FAIL**: 機械的に誤りと断定できる表記のみ（三点リーダ奇数、字下げ混在など）。自動修正可。
- **強WARN**: fix / keep の分類必須。keep するなら style-sheet に理由つき例外宣言（例 `R01: {max_run: 8, reason: ...}`）が要る。
- **WARN**: fix / keep の分類必須。keep は 1 行理由でよい。「全部 fix は失敗」（23 §10.2）。
- **INFO**: 場所の列挙のみ。分類不要。編集役の材料。

凡例: 「由来」欄の 21〜24 は first principles レポート、ANA は awesome-novel-agent 原典、08/11/09/10/07 はその翻案レポート、02/03/05/06 は既存スキル調査。

### (1) 同一文末の連続

| ソース | 記述 | 種類 | 実質の検出点 |

**食い違いの正体**: 22 の内部不一致は見かけだけ（「3 回まで可」⇔「4 連続を検出」は同じ線）。21・22・24 は 4 で一致、23 だけ 5。3 連は日本語の一次的根拠を持たない。

**実測（文末を 9 クラスに粗分類、純台詞段落で run を切断、引用直後の「と〜」タグ文は除外、地の文 10,000 字あたり件数）**

| 指標 | 人間 p10 | 中央値 | p75 | p90 | 最大 | LLM 風 A / B / C |

| 3 連以上の run | 13.8 | 23.4 | 28.8 | 35.2 | 39.9 | 70.9 / 43.7 / 82.6 |

| 最長 run | 5 | 11 | 16 | 29 | 54 | 11 / 4 / 6 |

読み取り: (a) 4 連は人間の名作でも地の文 1,000 字に約 1 回出る。存在だけで WARN にするとノイズ。(b) LLM 風サンプルが外れるのは**密度**と**た止め率**。(c) 会話の多い大衆小説は地の文が発話タグに偏り た止め率が上がる（半七捕物帳 0.87、山本周五郎 0.62〜0.74）。タグ文を除外して数えること、80% は WARN 止まりにすることが必要。(d) 敬体の語り（銀河鉄道の夜、桜の森の満開の下、ごん狐など 12 本）は ました の長い run が普通（最長 10〜24、こころ下篇は 54）。常体 21 本だけで取り直しても 4 連以上 run に属する文の割合は中央値 0.22・p75 0.29・p90 0.46・最大 0.64、6 連以上は中央値 4.3 で、全体とほぼ同じ。35% 線を超える常体作品は 3/21（青竹、人体解剖を看るの記、半七捕物帳）、50% 線は 2/21。敬体 12 本の同割合は最大 0.59。

**裁定**
- A（全プロファイル）: 「同じ文末は 3 つまでを目安、4 つ目は意図して選ぶ。変化のためでなく、出来事=タ形／状態・知覚=ル形・テイル形で選ぶ」（22 #13 ＋ 21 §1.2）。
- B: 4 連=INFO、6 連=WARN、8 連=強WARN。密度（4 連以上の run に属する文の割合、地の文 20 文以上で計算）35% 超=WARN、50% 超=強WARN。た止め率（場面または章、タグ文除外）80% 超=WARN。敬体の語りは 5 / 8 / 12、密度 60% 超=WARN（敬体 12 本の最大 0.59 の上。現代の敬体小説では未較正）。
- 23 の「5 連」は 4(INFO) と 6(WARN) の間に吸収。21 の「6 文以上の徹底は意図として可」は 6 連 WARN の keep 理由として扱い、8 連以上は style-sheet の例外宣言を要求。
- lint メッセージに「交互配置で消すな。文の結合・台詞で切る・知覚を現在形に落とす、のどれかで」と処方の方向を添える（21 悪い例 B、23 L2-1）。
- 破ってよい条件: 喪の直後・解離・ハードボイルド・報告体・アクションの短打・回想の淡々処理（21/23/24）。

**裁定**

- 連続 5 文の文長が平均 ±25% 以内 = INFO（21 の中庸文＋ANA D6 を統合、未較正）。
- 平均文長（地の文）: 文芸・エンタメで 22 字未満 = INFO（人間最小 22.6）。Web は 15 字未満 = INFO（未較正）。長文の列挙 INFO: 文芸 120 字超（22）／エンタメ 100 字超（24）／Web 80 字超、Web の A は「1 文 60 字以内」（22）。
- A: 文芸 平均 35〜45 字・10 字以下と 80 字以上を 1 場面に各 1 回（21）。エンタメ 30〜40 字、Web 25〜35 字は推定値で未較正。
- 段落長 CV（B）: 地の文段落 8 以上で INFO <0.55／WARN <0.45（23）。Web は INFO のみ（短段落が様式。23 の境界どおり場面間の密度差で見る）。ANA の「連続 5 段落の文数差 ≤1」は INFO（未較正）。
- 破ってよい条件: 列挙・儀式・呪文の反復、子どもの語り、饒舌体（仕様書に明記）、意識の流れ。

### (3) 体言止め

| ソース | 記述 | 種類 |
|---|---|---|
| 21 §1.2 | 2 連続まで、1 段落に 1 回、1,000 字に 2〜3 回が目安 | A |
| 23 L2-5 | 1,000 字に 4 回以上、または 2 連続で検出。正規表現は近似（「大丈夫。」を誤検出） | B |
| 03 | 長さでなく「声の有無」。語り手の判断が乗っていれば体言止めも一行段落も可 | 判定原理 |
| 09 | 戦闘の短文連打は体言止め・一語文込みで定義 | 例外 |

**実測（地の文 1,000 字あたり。文末が漢字・カタカナの文）**: 人間 中央値 0.57、p75 1.42、p90 2.36、最大 3.78。2 連以上は 10,000 字あたり中央値 0、p75 2.5、最大 7.3。3 連以上は p90 2.6。LLM 風は 0〜1.2。

**裁定**: 対立ではなく層の違い。(i) 正本の既定は字下げあり（22/21）。LLM の自然な出力と一致し、flash/short で会話に直接出す本文がそのまま体裁を満たす。(ii) lint: 字下げ率が 5〜95% の混在=FAIL（自動修正可）、半角空白の字下げ=FAIL、print/公募プロファイルで 95% 未満=FAIL、Web プロファイルで 0% 統一=PASS＋INFO（投稿サイトの一括字下げか export で付与できる旨）。(iii) `novel.yaml` に `indent: source | export` を持ち、編集事故が出た環境（06 の事例）では export に切り替え、`export.py` が付与する。

## 3. ワークフロー/アーキテクチャ上の工夫: 単一権威の置き方

1. **`scripts/data/thresholds.json` を唯一の数値権威にする**（ANA の「閾値は common-rules だけ」＋ 24 の `style/lint.json`）。構造案:
   ```json
   {"version": 1,
    "units": {"narr": "地の文1000字あたり", "total": "全文1000字あたり"},
    "rules": {"R01.same_ending_run": {"scope": "narration", "min_sentences": 20,
        "profiles": {"default": {"info": 4, "warn": 6, "strong": 8},
                     "keitai":  {"info": 5, "warn": 8, "strong": 12}},
        "source": ["21","22","24"], "calibrated": "aozora33-2026-09", "overridable": true}}}
   ```
   解決順は `style/lint.json`（calibrate の出力）＞ style-sheet の例外宣言 ＞ プロファイル ＞ default。
2. **references には数値を書かず ID を書く**（「R01 が鳴ったら」）。A 種の目安だけはプロファイル別 style-sheet テンプレートに書く。`scripts/check_thresholds.py` が references / SKILL.md を走査し、「N 連続」「1,000 字に N」型の数値記述が thresholds.json と食い違えば失敗させる（ANA `check-conflicts.py` の移植）。
3. **計数規約を 1 か所に固定**（ANA 蒸留の計数規約、24 C2 前処理）。本調査で使った定義を付録 B に置いた。特に (a) 地の文と台詞を分離、(b) 純台詞段落は文末 run を切る、(c) 引用直後の「と〜」タグ文は文末統計から除外、(d) 字数は空白除外、(e) ルビ・傍点記法を除去してから計測。
4. **最小標本ガード**: 密度系は全文 600 字未満で計算しない（ANA check-prose）、文長 CV は 12 文未満で計算しない、段落 CV は地の文段落 8 未満で計算しない、run 密度は 20 文未満で計算しない。flash（〜2,000 字）では密度系が不安定なので run と表記だけ見る。
5. **calibrate の規則**（24 C2）: ユーザーが承認した章 3 本以上から各指標の平均 ±2SD を `style/lint.json` に書く。FAIL（表記）は calibrate では動かさない。calibrate 後も強WARN の例外宣言は理由必須。見本が 3 本未満ならプロファイル既定のまま。
6. **出力契約**: 総合スコアを出さない（23 §9）、既定 40 行以内・規則ごと上位 N 件（24 A4）、各ヒットに処方の方向を 1 句添える、INFO は件数だけで WARN 以上を先に出す。
7. **短編は「上書きレイヤ」**にする。短編かどうかは文体軸と直交するので独立プロファイルにせず、ベース（文芸/エンタメ/Web）＋ short の差分（最小標本ガード、改稿ループ回数、ANA short の「感情直書きは主観感情を帯びていれば keep」判定）で表す。

## 4. 特に優れている点 TOP 8（実測で裏が取れたもの。なぜ LLM の小説出力に効くか）

1. **23「AI 臭は語でなく分布の偏り」**。人間の 33 作品は ふと系を 1,000 字に中央値 0.34 回、ぼかし語を 0.16 回、フィルタ動詞を 0.81 回使う。ゼロを目標にすると人間の分布からも外れる。LLM は禁止を機械適用するので、密度制と keep の正規化が不可欠。
2. **24 の calibrate＋理由つき例外宣言＋WARN/INFO の区別**。人間側の分散が極端に大きい（一文段落率 3〜88%、会話比率 1〜55%、三点リーダ 0〜10.7）。万人向け閾値は必ずどこかの名作を誤検出する。作品別較正は安全弁でなく必須部品。
3. **21 の三層（既定／診断／破り方）と「数値は警報値であって目標値ではない」**。今回の食い違いの半分は A と B の混同で、この区別を構造として持てば再発しない。
4. **ANA の単一権威と静的整合検査**。この調査の問いそのものへの解。references が増えるほど数値は増殖するので、CI 的な機械検査が要る。
5. **21 と 23 の独立収束**（彼/彼女 7/1,000字、直喩標識 5/1,000字、のだ文 1/1,000字）。経験則でも二者が別々に同じ値へ達したものは初期値として強い。人間 p90 の上に位置することも確認できた。
6. **24 D01 の「目標 ±15pt」方式**。帯をソース間で争う必要がなくなる。LLM には「この作品の目標」を 1 つ渡すほうが、複数の帯を渡すより従いやすい。
7. **03 の下限側規定（平時は 40 字以上で繋ぐ）と 21 の「80 字以上を 1 回」**。LLM 風サンプルの最大の外れは CV ではなく平均文長 15〜18 字・80 字以上ゼロだった。「短く書け」系の助言は LLM の短文メトロノームを悪化させる。
8. **ANA check-prose の最小標本ガードと「警告は硬ゲートに昇格させない」契約**、ダッシュの「数でなく削除テスト」。数値の限界を仕様で認めている。

## 5. 弱点・欠落・日本語小説に合わない点・過剰な点

### 5.1 ソース側
- **実測で崩れた閾値**: 同一文末 3 連（翻案提案）、21 の文頭接続詞 1 割、ANA の認知動詞 章 2 回、ANA Gate A の直喩即削除、ANA の一文段落率帯、ANA short の発話密度 12〜18、読点 4 個を警告扱いにする読み方、タグ文を除外しない た止め率。
- **緩すぎる閾値**: 23 の 情緒副詞 4、身体反応 3、感じた 3 は人間最大の 3〜16 倍。見逃しが増える方向。INFO 段を足して補う。
- 22 は A と B を同じ表に書いており（規則 #13 と style_stats）、読み手が矛盾と誤読する。新スキルでは書式で分ける。
- ANA は「章あたり」で数えるため章長に暗黙依存し、言語をまたぐと壊れる。全部 1,000 字あたりに直すべき。
- 24 R01 の 4 連 WARN は 1 話あたりの警告数が多くなりすぎる。
- `novel2agent-jp/check_prose.py` は文体統計を持たず（本文存在・全角空白・禁止語・一人称・見出しの 5 項目）、字下げを禁止する点で他ソースと逆。事故対策としての意図は (9) の `indent: export` で吸収する。
- `check-prose.py`（ANA）の語彙表・喩体辞書・名詞化パターンは中国語の評論文寄りで、移植価値があるのは統計部（CV、短段落連続、書き出し反復、喩体混在の窓、密度の可変上限 `max(k, 字数/N)`）だけ。

### 5.2 本調査の実測の限界（正直に）
- 人間コーパスは 1908〜1960 年代。現代の一般文芸・ライト文芸・ラノベ・Web 小説は権利上計測できていない。現代文は文が短く会話が多いと予想され、平均文長・会話比率・三点リーダの分布はずれるはず。**Web/ラノベ列は未較正**。
- LLM 側は調査員自身が書いた 3 本（各約 1,000 字）。盲検でなく、モデル 1 種、指示なし条件のみ。23 §12 が求める「素の生成 50 本」には程遠い。
- 文末分類は末尾の文字列による粗い 9 クラス（形態素解析なし）。体言止め判定は「大丈夫。」型を誤検出する。ような系の正規表現は目的の「ように」を含む。青空文庫の段落・文分割は `<br>` と句点に依存し、入れ子の引用や改行のない長台詞で誤差が出る。
- 5,000 字級の短い作品（羅生門、檸檬、ごん狐など）は密度の誤差が大きい。
- 敬体主体の作品は 12 本あるが、童話・少年もの・書簡体に偏る。

### 6.2 A 種（style-sheet テンプレートに流し込む目安）
- 文末: 3 つまでを目安、4 つ目は意図して選ぶ。出来事=タ形、状態・知覚=ル形/テイル形。
- 文長: 文芸 平均 35〜45 字、1 場面に 10 字以下と 80 字以上を各 1 回。Web は 1 文 60 字以内。
- 体言止め: 1,000 字に 2〜3 回、1 段落 1 回。
- 段落: 文芸 1〜8 文で変動／書籍エンタメ 250 字以下を基調／Web 150 字以下・地の文ブロック 3〜5 行。
- 比喩: 効かせるものは 1 場面 1〜2 個（Web は 1,000 字に 1 個前後）、喩辞は視点人物の生活圏、頂点では使わない。
- 会話: タグなしの応酬は 3〜4 往復まで、動作ビートは台詞 3 つに 1 回、1 発話 40 字以内が基本。

## 付録 B. 計数規約（本調査で使った定義。新スキルの `scripts/` にそのまま写せる形）
- 段落 = 1 行。かな・漢字を 1 字も含まない行（記号だけの場面転換行など）は除外。字数は半角・全角空白を除いた文字数。
- 台詞 = `「[^「」]*」` を内側から繰り返し除去したもの（『』は「」の中でだけ消える）。会話比率 = 台詞内字数 ÷ 全字数。
- 段落の型: 純台詞段落（台詞を除くと空）／台詞始まりで地の文を含む段落／地の文段落。段落長統計と一文段落率は地の文段落のみ。
- 文 = 地の文を `(?<=[。！？!?])` で分割し、2 字未満を除外。
- 文末クラス = 末尾の句読点・記号・閉じ括弧を剥がした後の語尾: ました・でした／です・ます系／た・んだ・いだ／だ・である／ない・ぬ・ず／い／う段かな／漢字・カタカナ（体言止め近似）／その他。
- run = 同一クラスの連続。純台詞段落で切断、段落替えでは切断しない。引用の直後に来て「と」で始まる文（発話タグ）は統計から除外し、run も切らない。
- 発話連続 = 連続する純台詞段落の発話数の合計。地の文を含む段落で切断。
- 密度の正規表現は `fp23_regex_test.py` の P をそのまま使用し、フィルタ動詞・程度副詞・まるで単独を追加（`threshold_measure.py` 冒頭）。
