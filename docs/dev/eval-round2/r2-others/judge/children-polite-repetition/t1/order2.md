1. 条件の充足

A：女の子とカエルがなくした長ぐつを探す童話で、地の文は「です・ます」を基調にしています。言葉もやさしく、呼びかけの反復があり、怖すぎる場面もありません。長ぐつが戻り、ダンゴムシにも家ができる、うれしい結末です。明確な条件違反はありません。

B：題材、語り口、やさしい言葉、反復、安心できる結末の条件を満たしています。長さの指定はなく、両作とも分量自体を優劣の根拠にはしません。明確な条件違反はありません。

2. 問いへの答え

読み聞かせでの参加しやすさを重視し、Bを選びます。

Aは「カエルが、ぴょん。」など、動きと息継ぎが結びついていて、耳で追いやすい文章です。「最後の一ぴき」まで待つ姿にもやさしさがあり、結末の喜びを支えています。一方、途中で呼びかけが「長ぐつさーん、ここですね。」に変わるため、覚えた言葉を一緒に言う子には、少し先読みしにくくなります。変化を楽しめる良さもありますが、参加のしやすさでは惜しい点です。

Bは「長ぐつさん、長ぐつさん、どこですか」を最後まで同じ形で繰り返すので、子どもが入るタイミングをつかみやすいです。結末の「右足でとん。左足でとん。」から「ここです、ここです、ここですよ！」への流れも、声と動きで発見の喜びに参加できます。一方、「戸口から、ここまでずっと坂です」以降の位置関係の説明は、耳だけでは少し整理が必要です。それでも、反復と結末のつながりをより評価します。

3. 誤り

A：明確な誤りはありません。

B：「むこうまで行ってみます」の後、長ぐつの中にいるカエルが、通常は外側にあるつま先の赤い丸を確認しています。確認できる位置への移動が描かれておらず、空間描写に不整合があります。両作とも字数などの数え間違いや、本文以外の混入はありません。

選好: B
