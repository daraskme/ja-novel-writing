「待って、蓮」

　校門を出ようとする背中に声を投げた。蓮が振り返る。胸につけた白い花が、風で少し傾いていた。さっきまで写真を撮ろうと笑っていた友達の声が、急に遠くなる。

「どうした。忘れ物？」

「うん。言い忘れたことがある」

　握りしめた卒業証書の筒が、手の中で滑った。

　昨日の夜、何度も考えた言葉は、一つも出てこなかった。離れても連絡しようとか、向こうでも元気でねとか。そんなふうに始めたら、私はきっと最後まで、いい友達の顔をしてしまう。

「好きです」

　蓮の表情が止まった。

「友達としてじゃなくて。蓮と付き合いたい。手をつなぎたいし、会えない日に、会いたいって言っていい人になりたい」

　声が震えた。恥ずかしくて、今すぐ冗談にしたかった。でも、蓮が黙って私を見ている。その目から逃げたら、三年間の私まで置いていくことになる気がした。

「二年の文化祭で、私が看板の字を間違えたとき、残って直してくれたでしょう。あのとき、好きになった。蓮、自分の仕事は終わってたのに、私が帰れるまで帰らなかった」

「……あれは」

「うん。蓮には、それくらい普通のことだったかもしれない。でも私は、すごくうれしかった」

　喉が詰まった。息を吸うと、涙まで一緒にこぼれそうだった。

「それから毎朝、教室に入る前に蓮の声を探してた。席が近くなっただけで、その日はずっと機嫌がよかった。誰かと楽しそうにしてるのを見て、勝手に寂しくなったこともある。そんな自分が嫌で、好きじゃなくなれたら楽なのにって思った」

　蓮が一歩、近づいた。

　私は首を振った。まだ、最後まで言えていない。

「友達でいられなくなるのが怖かった。告白して、明日から隣に座ってくれなくなったらって、そればっかり考えてた。でも今日、もう明日の教室がないんだって気づいて」

　とうとう涙が落ちた。拭こうとした手に証書の筒がぶつかる。ひどく間抜けで、少し笑ってしまった。

「何も言わなかったら、蓮は知らないまま行っちゃう。それが、嫌だった。私がどれだけ蓮に会うのを楽しみに学校に来てたか、知ってほしかった」

「美緒」

「好き。ずっと好きだった。これからも、一緒にいたい」

　言い終えると、膝から力が抜けそうになった。

　蓮は鞄を地面に置いた。それから私の手にある筒を指して、「持つよ」と言った。こんなときまで、と思ったら、余計に泣けた。

　空いた手で目元を拭く間、蓮は待っていた。

「俺、今日おまえに言うつもりだった」

　顔を上げた。

「でも写真撮って、みんなと話して、そのあと二人になっても、言えなかった。駅まで行けば、改札の前ならって、さっきも先延ばしにしてた」

　蓮の手の中で、二本の証書の筒が小さく鳴った。指が震えていた。

「看板、覚えてるよ。美緒と二人でいたくて残ったんだから」

「……そう、なの？」

「うん。俺も好きだよ。卒業したら会えなくなるの、ずっと嫌だった。用事を考えなくても電話したい。美緒が何してるか知りたいし、俺のことも聞いてほしい」

　聞きたかった言葉なのに、すぐには信じられなくて、蓮の顔を見つめた。蓮も目を赤くして、困ったように笑った。

「四月から遠くなるけど、俺と付き合ってください」

「うん」

　返事が小さすぎた気がして、もう一度、うなずいた。

「付き合いたい。私も」

　蓮が片手に筒をまとめて持ち、もう片方の手を差し出した。私はその手を握った。思っていたより冷たくて、強く握り返すと、蓮が長い息を吐いた。

「よかった。ほんとに」

　その声を聞いて、また涙が出た。

　校門の外で、誰かが私たちの名前を呼んでいる。蓮がそちらを向きかけて、先に私を見た。

「行こうか」

「うん。でも、手はこのままがいい」

「俺も」

　つないだ手が二人の間で揺れた。私はもう、うれしいのを隠さずに笑った。
