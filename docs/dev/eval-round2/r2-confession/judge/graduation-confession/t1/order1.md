2. 問いへの答え

受け取りたいのはBです。字数の適否とは別に、怖くても告白を撤回せず「返事を待った」という真帆の選択が、その後の喜びを支えています。圭介の「だから、帰れなかった」で、去ろうとしているように見えた相手も踏み出せずにいたと分かり、冒頭の出来事の意味が変わるところに胸が熱くなりました。

さらに「まず明日、会いたい」は、気持ちを隠して隣にいる関係から、自分で次の約束を求められる関係への変化を示しています。「明日も、ちゃんと言う」という返答にも、告白の熱が日常へ続いていく余韻があります。ただし、「困ってる」で一度拒絶を思わせてから喜びへ転じる運びには、やや演出の作為を感じます。

Aの良さは、「私を好きになってほしい」と願望までさらけ出す強さです。それを受けた「声、聞きたい」は、連絡する理由を遠慮なく持てる関係への変化になっています。「寂しいと言っていい相手」という着地も、遠距離の不安を消さずに喜びへ変えていて温かいです。一方、「涙が落ちた」「涙がこぼれた」と涙の描写が重なり、私には感情の強さを繰り返し示しすぎる印象がありました。これは条件違反ではなく、表現上の好みです。
