- **直言と説明台詞を区別できている点は維持する。** 依頼3の卵焼きの会話は、共有済みの出来事に「当時どう受け取っていたか」を加えています。双方が知る出来事に触れたという理由だけで削ると、評価された長所を失います。
- **依頼4では修正範囲の遵守が勝因です。** 定型語が残ったことだけを追加規則で締めると、この長所を壊します。なお `with_4.md:1` は「二人が微笑み合う穏やかさは残す」と理由を述べており、READMEの「理由を示さず残した」は、少なくとも微笑みについては言い過ぎです。各ヒットとの対応が不明確、と評価するほうが正確です。
- **評価の再現記録を補う。** 完全な依頼文、生成時のスキル版、実際に読ませた資料、ツール使用、判定プロンプトを保存する。次回は結び修正後の再試行と、coreのみ／全工程の差、未実施の戦闘・児童向け・連載途中を優先すると、改善の効き方を判断できます。

短文・総括・説明台詞への操作自体は残っています。問題は緩めたこと全般ではなく、**例外と要約の不一致、実際の適用漏れ、少数の評価結果から新しい一律規則を作りかけていること**です。

## これで出荷してよいか

**まだ出荷しない判断です。**

少なくとも、誤FAIL、未来の変更項目の漏出、必須設定を落とすパック生成を直す必要があります。これらは文章の好みではなく、正しい本文を修正させたり、誤った前提で次章を書かせたりする問題です。

既存テスト117件の通過だけでは今回の境界条件を保証できません。再現例を回帰テストへ加え、flashの仕様を統一し、結びの修正文言を追加評価した段階で出荷を再判断するのが妥当です。
