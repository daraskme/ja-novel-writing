　卒業証書の筒を握りしめたまま、私は昇降口で立ち止まった。校門へ続く道の向こうに、航の背中が見えた。友達と肩をぶつけ合って笑っている。三年間、教室で何度も見てきた背中だった。

　明日からは、見たくても見られない。

「航！」

　思ったより大きな声が出た。何人も振り返ったのに、航だけしか見えなかった。

「ちょっと、待って」

　航は友達に何か言ってから、私のところへ走ってきた。

「どうした？　忘れ物？」

「うん。ずっと、渡せなかったものがある」

　鞄に手を入れかけて、やめた。昨夜書いた手紙が入っている。何度も書き直して、好きという二文字だけは、結局どの便箋にも書けなかった。

　航が私の手元を見た。

「何？」

　喉が詰まった。ここまで呼び止めておいて、まだ「なんでもない」と笑おうとしている自分がいた。

　私は筒を両手で握り直した。

「好きです」

　航の顔から、笑みが消えた。

「友達としてじゃない。航のことが、好き。ずっと好きだった」

　言ってしまうと、怖さはもっと大きくなった。航の目を見ていられなくて、その制服の襟に視線が落ちる。それでも、ここで終わらせたくなかった。

「二年のとき、私が部活やめた日、覚えてる？　みんなには勉強に集中したいって言ったけど、本当は、試合に出られないのが悔しかった。頑張っても駄目な自分が嫌で、逃げたんだって、ずっと思ってた」

「覚えてるよ」

「航だけ、明日から放課後ひまなら一緒に帰ろうって言ってくれた。理由も聞かないで。それが、すごく嬉しかった」

　声が震えた。こんな声を聞かせるのは恥ずかしかったけれど、もう隠せなかった。

「一緒に帰れる日は、朝から嬉しかった。航が休むと、学校がつまらなかった。誰かに好きな人いるのって聞かれて、いないって答えるたびに、嘘ついてごめんって思ってた」

　航が何か言いかけた。私は首を振った。

「ごめん、最後まで言わせて。途中でやめたら、また言えなくなる」

　息を吸う。涙が頬を伝った。

「卒業したら、そのうち忘れるって思おうとした。でも嫌だった。航のこと、忘れたくない。大学でどんなことがあったとか、今日何食べたとか、そういう話を、これからも聞きたい。会いたいって、自分から言えるようになりたい」

　航の顔を見た。驚いたまま、ちゃんと私を見ていてくれた。

「私と、付き合ってください」

　返事を待つ間、校門のほうから誰かの笑い声がした。航は口元を手で覆って、うつむいた。その沈黙が怖くて、私は唇を噛んだ。

「……俺、今日も言えずに帰るところだった」

　顔を上げた航は、目を赤くしていた。

「一緒に帰ろうって言ったの、心配だったのもあるけど、お前と二人になりたかったからだよ」

「え」

「好きな人いないって聞いて、じゃあ俺にも可能性あるかなって思って。でも、今のままでも楽しいからって、ずっと先延ばしにしてた」

　航が一歩近づいた。

「俺も好きです。付き合ってください」

　何度もうなずいたのに、涙ばかり出て、返事にならなかった。航が笑った。私も笑おうとして、変な声で泣いてしまった。

「うん。付き合いたい。すごく、嬉しい」

「俺も」

　差し出された手に触れると、航の指も少し震えていた。私だけじゃなかったのだと思ったら、もっと泣けた。

　二人で校門へ歩きだした。いつもの帰り道なのに、手のつなぎ方がわからなくて、一度ほどいて、つなぎ直した。

「明日、会える？」

　私が聞くと、航はすぐにうなずいた。

「会いたい」

　その返事を聞いて初めて、私は、明日が来るのを楽しみにできた。
