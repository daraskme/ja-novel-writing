　窓の外で雨が降っていた。美咲はさっきから、街灯の下に見える雨粒を目で追っていた。
「……大丈夫？」
　振り向くと、翔太がこちらを見ていた。美咲は頷こうとして、やめた。
「まだ、ちょっと」
　声に出すと、喉が詰まった。窓に目を戻し、息を吐く。翔太は何も聞かず、隣に座っていた。

　しばらくして、美咲は膝の上で握っていた手をほどいた。
「ありがとう」
「何が？」
「ここにいてくれて」
　翔太は少し困ったように笑った。美咲もつられて笑い、指で目元を拭った。

　雨音はもう聞こえなかった。軒先から落ちる雫が、ときどき窓の向こうを横切った。
「明日、少し歩かない？」
　美咲が言うと、翔太は頷いた。
「いいよ。何時にする？」
　美咲は明日の朝のことを考えた。
