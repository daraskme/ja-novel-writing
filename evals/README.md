# evals

| ファイル | 中身 |
|---|---|
| `evals.json` | スキルの動作確認に使う依頼 9 件と、期待する振る舞いの説明（`expected_output`）。人が読むための資料で、生成役にも判定役にも渡さない |
| `blind_prompts.json` | 由来を伏せた読み比べに使う依頼。番号でなく、名前と本文のハッシュで識別する |
| `run_blind_eval.py` | 読み比べの実行器。generate → judge → report |

## 読み比べの走らせ方

結果の置き場所（`--run`）は、このリポジトリの外にする。生成役が過去の結果を読めないようにするためである。

```bash
python -X utf8 evals/run_blind_eval.py generate --run ../blind-runs/r1 --arm with=skill --arm base=none --only graduation-confession --trials 2
```

```bash
python -X utf8 evals/run_blind_eval.py judge --run ../blind-runs/r1
```

```bash
python -X utf8 evals/run_blind_eval.py report --run ../blind-runs/r1
```

- `--arm` は 2 つ。`名前=skill`（このスキル）、`名前=none`（スキルなし）、`名前=ディレクトリ`（別の版のスキル）。文言を 1 つ抜いた写しを作って `new=skill` と `old=その写し` を比べれば、ほかの差分を固定したまま、その文言の有無だけを比べられる。
- 生成役と判定役は `--generator` と `--judge` で別々に差し替えられる（既定はどちらも `codex exec`）。`{cwd}` は作業ディレクトリ、`{out}` は応答の保存先に置き換わる。`{out}` の無いコマンドは標準出力を応答とみなす。
- 途中で失敗しても、同じ `--run` でもう一度実行すれば、済んだものを飛ばして続きから走る。失敗と再試行は `run.json` に残る。

## 比較の条件として守っていること

- スキルの系統には `SKILL.md`・`references/`・`scripts/`・`assets/` だけを写して渡す。`evals/` と `docs/`（過去の評価、敗因、修正の意図）は渡さない。スキルなしの系統と判定役は空のディレクトリで動かす。作業ディレクトリはリポジトリの外に作り、名前から系統を推測できないようにする。
- 判定役に渡すのは、依頼文・2 つの応答・依頼の型ごとの問いだけ。系統の名前、モデル名、版、過去の勝敗、敗因、修正の意図、lint の結果、スキルの本文、`expected_output` は渡さない。問いは依頼文から作り、スキルが理想とする文体を持ち込まない。
- 同じ対を、A/B を入れ替えて 2 回読ませる。2 回で選好が変われば「順序不安定」と記録する。1 回目の提示順は全体で半々にする。判定の 2 回を、生成の 2 試行とは数えない。
- 長さは選好と分けて記録する。比べるために応答を切り詰めない。判定役には、長さや情報量そのものを優位の根拠にしないよう指示する。
- lint の結果は、判定が終わってから研究用の記録として結合する。診断の数と該当箇所の数を分け、C 群を含めて確定した誤りとは数えない。
- 点数も勝率も作らない。依頼ごとに、選ばれた系統・差なし・順序不安定・判定不能・失敗を並べて書く。

## 残る限界

- 読み取り専用のサンドボックスでも、生成役が絶対パスをたどれば元のリポジトリを読める。作業ディレクトリを外に置き、依頼文でリポジトリの場所を教えないことで避けているが、技術的に遮断してはいない。
- 生成役と判定役が同じモデルなら、そのモデルの好みが両方に効く。別コンテキストにしても、この偏りは消えない。告白の場面など結論に使いたい対は、別のモデルか人間でも読み直す。
- `graduation-confession` は、過去の評価での敗因を受けてスキルを直した依頼なので、未知の課題ではない。

> 本評価は、限定した依頼・モデル・設定による少数試行の探索的比較です。選好は掲載した作品対に対する判定であり、一般的な勝率や品質向上を示しません。生成・判定モデルの偏り、提示順序、長さの影響が残ります。過去の評価を参考に修正した既知の課題を含むため、独立した未知の課題での検証ではありません。lint は確認候補を示すもので、文学的品質や誤りの確定を表しません。
