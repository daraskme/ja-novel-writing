# 場面別の技法カード

- いつ読むか: 場面を書く直前。§1.1 の表で当たったカードだけを開く。1 場面に 2〜4 枚。
- いつ読まないか: 企画・人物設計のとき（structure.md / character.md）と、推敲のとき（revision.md / ai-tells.md）。通読もしない。全カードを薄く当てた原稿は、どの場面も同じ味になる。
- 視点・文末・描写・会話の基礎は prose-core.md にある。ここに置くのは、場面の種類で変わる操作だけ。
- 以下、「場面カード」は 1 場面の設計メモ（章ビートの `[[scenes]]`）、ただの「カード」はこのファイルの技法カードを指す。

## 目次

1. カードの選び方と使い方（1.1 ルーティング表 / 1.2 枚数と選び方 / 1.3 具体化の四手順）
2. 場面種別のカード: [会話] [対決] [戦闘] [環境] [転換] [群像] [日常] [恋愛] [回想]
3. 特殊トリガーのカード: [容姿] [内面] [死別] [開示]
4. 書いたあとの確認

## 1. カードの選び方と使い方

### 1.1 ルーティング表

場面カード（章ビートの `[[scenes]]`）の goal / conflict / change / knowledge を見て引く。種別は場面の形から決まり、特殊トリガーは場面の中で起きる出来事から決まる。種別を選んだあと、もう一度 change と knowledge を見てトリガーを拾う。

| 区分 | 場面の特徴 | カード |
|---|---|---|
| 常時 | どの場面でも | prose-core.md（このファイルには無い） |
| 種別 | 二人のやりとりが中心。隠しごと、頼みごと、探り合い | [会話] |
| 種別 | 欲しいものが両立しない相手と向き合う（口論、尋問、商談、別れ話） | [対決]。台詞が多ければ [会話] も |
| 種別 | 身体が危険にさらされる（格闘、追跡、逃走、事故） | [戦闘] |
| 種別 | 新しい場所に入る。場所そのものが意味を持つ。移動する | [環境] |
| 種別 | 時間・場所・視点が飛ぶ | [転換] |
| 種別 | 3 人以上が同じ場で話す | [群像] |
| 種別 | 事件の起きない回（食事、仕事、待ち時間） | [日常] |
| 種別 | 二人の距離が動く | [恋愛] |
| 種別 | 過去の出来事を場面として見せる | [回想] |
| トリガー | 前の場面までに出ていない人物が出る。外見が変わる。誰かが誰かを品定めする | [容姿] |
| トリガー | 視点人物が大きな出来事・選択・受け入れがたい事実に直面する | [内面] |
| トリガー | 死、別れ、退場。またはその直後の場面 | [死別] |
| トリガー | 隠れていた事実が明らかになる。推理が語られる。読者の解釈が入れ替わる | [開示] |

ジャンル契約（novel.toml の `[contract]`）と genres.md の約束事は、カードの既定より優先する。

### 1.2 枚数と選び方

- 1 場面 2〜4 枚。迷ったら、場面カードの change にいちばん近い 2 枚。
- 章のなかで最も重い場面にカードを集める。つなぎの場面は [転換] 1 枚か、カードなしで短く書く。全場面を同じ密度で作り込むと、山が消える。
- 直前の場面・前章で使った操作と同じものは避ける（託す物、転換の手、人物の出し方）。LLM は一度うまくいった型を次の場面でも繰り返す。
- 場面カードの goal / conflict / change が空の場面には、どのカードも効かない。先に structure.md の場面の最小条件へ戻る。

### 1.3 具体化の四手順

カードの操作は、そのまま適用しない。汎用の指示（「会話の合間に所作を挟む」）はどの場面にも貼れるので、貼った場面が全部同じになる。次の順で、この場面だけの指示 2〜4 行に直してから書く。

1. **人物**: この人はどういう人で、この場面ではどんな状態か。声シートと固有の癖を見る。慎重な人のかわし方と短気な人のかわし方は違う。
2. **情報差**: 誰が何を知り、何を隠し、なぜ言えないか（場面カードの knowledge）。読者だけが知っていることがあるなら、人物には見えず読者には見える一言をどこに置くか。
3. **感情の動き**: 下表のどれか。場面の途中で移るなら、どの出来事で移るか。
4. **一本にまとめる**: 1〜3 を 2〜4 行の指示にする。人物名と、その場にある物の名が入っていなければ、まだ汎用のまま。

| いまの状態 | 応答と間 | 所作 | 発話と文 |
|---|---|---|---|
| 張りつめている | 速い。かぶせる、遮る | 減らす（所作は緊張を逃がす）。要の一つだけ大きく | 短く、言い切らない |
| 抑えている・隠している | 遅い。返事が来ない | 増やす。所作が返事を兼ねる | 言いさし。用件の話に逃げる |
| 緩んでいる | 脱線を許す | 間をおいて | 文が最後まで言われる |

具体化の例。カードは [会話] の操作 2「本題は物か用事に託す」。場面は、千尋が実家に寄る午後。鞄に、母の運転免許の返納申請書を入れてきた。

- 人物: 母・寿美江は元保健師で、人に言われる前に自分で決めてきた人。都合の悪い話になると手を動かしはじめる。千尋は相手の言葉尻を繰り返す癖がある。
- 情報差: 母は先週、車庫の柱に車を擦ったことを隠している。千尋は傷を見つけるが、書類のことは母に知られていない。母がどこまで考えているかは、千尋にも読者にもまだ見えない。
- 感情の動き: 双方が抑えている。
- まとめた指示: 「千尋は『免許』も『返納』も口にしない。傷を見ても指摘せず、洗車を申し出る。母は断って庭の水やりを始め、水音で話を切る。千尋がバスの話を振ると、母は乗り換えの待ち時間まで即答する（もう自分で調べてある、とは誰も言わない）。千尋の癖は一度だけ。錨は鞄の中の書類で、最後まで出さない」

この指示で書いた本文が、[会話] の書き直し例。指示は章ビートの direction 欄に書く。執筆をサブエージェントに任せるときは、この指示とカード名だけを渡す。カードの文面を依頼文に貼ると、書き手は具体化を飛ばして文面のほうに従う。

## 2. 場面種別のカード

### [会話] 本題を言わせない会話（隠す理由がある場面の型）

このカードは、人物に本題を言えない理由がある場面のためのもの。告白、謝罪、宣言のように、まっすぐ言うことが出来事になる場面や、食卓の団らんのように言葉を交わすこと自体が楽しみの場面には当てない。

台詞は情報を運ぶ前に、相手に何かをしている（頼む、かわす、試す、引き止める）。隠す理由がある場面では、本題は口に出ず、物と用事の話になる。LLM の会話は、全員が完全な文で、問いに誠実に答え、同じ長さで交互に話す。情報は正しく渡るが、誰も何も隠していないので読者のすることがない。

1. 用件は一人に一つ、別々に決める。同じ用件の二人が話すと復唱になる。言えない理由は状況から決める（言えば何を失うか）。性格のせいにすると、場面が変わっても同じ沈黙になる。
2. 本題は物か用事に託す。託す先は、その場に実際にある物。
3. 応答をずらす。まっすぐな応答が続いたら、答えない・問い返す・別の話を始める・気持ちだけ受けて中身に触れない、のどれかに替える。直前の相手の感情に対して「受ける／逸らす／煽る／退く」のどれをしているかが決まっていれば、ずれても会話は切れない。
4. 呼称と敬語の段階は呼称表のまま固定し、動かすのは関係が動いたときだけ。くだけるのも出来事、親しい相手への敬語に戻るのも出来事（拒絶として読まれるので、口調を地の文で説明せずに済む）。

弱い: 「お母さん、もう運転はやめてほしいの。心配なのよ」「わかってる。柱に擦ったときは自分でも怖かった。でも車がないと病院にも行けないでしょう」

書き直し（§1.3 の指示から）:
> 　車庫の軽は、左の後ろだけ泥がついていなかった。拭いた跡の真ん中に、柱の塗料と同じ緑が一筋残っている。
> 「洗車しようか。ホース出すよ」
> 「いいよ、雨が降れば落ちる」
> 　母は如雨露に水を張りはじめた。蛇口を全開にするので、底を打つ音で話が途切れる。
> 「病院、バスだと乗り換えあるんだっけ」
> 「一回。市役所前で二十分待つけど」
> 「二十分」
> 「座るとこはあるから」
> 　千尋は鞄の口を押さえたまま、縁側に腰をおろした。書類の角が掌に当たっている。
> 「自転車って、まだ物置にあったっけ」
> 「あるよ。空気は抜けてるけど」
> 　母は如雨露を提げて、紫陽花のほうへ行ってしまった。背中を向けたまま、あんたが乗るなら入れとく、と言った。

落とし穴
- 双方が知っていることを読者のために言い合う。既知の情報は地の文一行で済ませる。
- 全台詞に所作がつく。置くのは転機と、話者を取り違えそうな箇所だけ。置くなら台詞と逆向きの所作を、台詞の前に（言葉が強いとき、手は日常の作業を続ける）。頻度は style-sheet.md の目安。
- 数行の説得で相手が考えを改める。人の考えを変えるのは出来事。
- lint の D03（短い窓の発話数）が鳴ったら、所作を足す前に操作 3 を見直す。短い応酬が詰まるのは、たいてい問いと答えがまっすぐ往復しているから。

破ってよい場合: 通過点の事務的なやりとりは、まっすぐ答えさせて短く済ます。声の違う二人の掛け合いが見せ場なら地の文なしで連ねてよい（場面カードに密集会話と書いておく。D02 純台詞の連続発話数は keep）。聴取や取調べなど台詞が手がかりを運ぶジャンルは genres.md が優先。

### [対決] 対決と交渉

対決で書くのは主導権の移動。どの台詞で誰が上に立ち、何がそれを入れ替えるかを先に決める。入れ替えるのは事実・物・第三者の到着で、人は弁舌では折れない。LLM は対立を同じ場面の中で畳みたがり、言い負かされた側に非を認めさせる。

1. 双方に、退けば失うものを具体で持たせる。両立する落とし所が見えるなら、期限か取り返しのつかなさを足して塞ぐ。敵役にも筋の通った損得を。
2. 長さで力関係を見せる。優位な側は短く、説明しない。劣勢の側ほど言葉が増え、理由を重ねる。形勢が入れ替わる瞬間に、長さも入れ替える。
3. 腹を立てている側ほど口調を平らにする。双方が同時に声を荒げると、主導権がどちらにあるか見えなくなる。
4. その場で和解させない。決着がついても、感情は次の場面へ持ち越す。

弱い: 「これ以上は下げられません。うちにも職人の生活があるんです」「……おっしゃるとおりです。御社の事情も考えるべきでした」

書き直し（町工場の事務所。元請けの購買担当が値下げを告げに来た）:
> 「五パーセントです。来期の初回納入分から」
> 　潮田は見積依頼書を机の向こうへ滑らせた。出した茶には手をつけない。
> 「五って、潮田さん、去年も三パー呑んだじゃないですか。ニッケルがこれだけ上がって、電気代だって、うちは炉を夜じゅう落とせないから、それに先月の特急、二回とも日曜に若いのを出して」
> 「他社さんは、この値で出してきています」
> 　鍋島は立って、検査台の下から段ボール箱を引きずり出し、継手を一つ、依頼書の上に置いた。ねじの谷に、旋盤で浚い直した跡が光っている。うちの刻印ではない。
> 「先月、おたくの資材の人が夜に持ってきました。四百個。嵌まらないから何とかしてくれ、伝票は切れないけど、と」
> 「それは、私のところには上がってきていない話で、資材が、おそらく緊急の対応として、正規の手続きとは別に」
> 「手間賃も、まだ頂いてません」
> 　鍋島は継手を指で半回転させて、刻印を潮田のほうへ向けた。

落とし穴
- 優位な側が自分の優位を解説する。黙って物を置くほうが強い。
- 居合わせた人物が一方を褒めるだけの観客になる。脇の人物にも自分の用件を持たせる。
- 交渉の条件が抽象のまま（「それなりの対価」）。金額、期日、物で言わせる。

破ってよい場合: 断罪の決め台詞が売りの作品（ジャンル契約に明記）では、優位な側が言葉で畳みかけてよい。それでも形勢を変えるのは証拠と規則。喜劇では双方が同時に怒鳴るのが様式になる。

### [戦闘] 戦闘とアクション

強さ・速さ・痛みは、壊れた物、ずれた身体、使えなくなった機能で見せる。一手ごとに狙いがあり、決着は状況の読みでつく。LLM の戦闘は評価語つきの動作を交互に並べた実況になり、誰も疲れず、何も壊れない。

1. 動きを先に決め、動詞はそれに合う和語の複合動詞から選ぶ（叩き割る、薙ぎ払う、打ち据える、捻じ込む／掻い潜る、すり抜ける、いなす、絡め取る、など。方向の見本で、この語を使うことが目的にならないように）。当たった場所を身体の部位で特定し、返ってくるものを音と手応えで書く。
2. 威力は結果から書く。攻撃、相手の身体のずれ、周りの物の壊れ方、あとに残るもの。
3. 一手ごとに狙いを持たせる。隙を突く／隙を見せて誘う／場の条件を使う（足場、光、障害物、相手の癖）。
4. 代償は機能の喪失で書く。握れない、片目が塞がる、踏ん張れない。その不自由は章末の状態スナップショットに残し、次の場面でも引き継ぐ。
5. 関心の錨を視覚以外（手応え、息、足裏）から選ぶと実況になりにくい。睨み合いは長い文で、交錯は短く。短文の連打は数手で切り上げ、因果を一文で繋いだ文を挟む。

弱い: 男の拳は凄まじい速さだった。志摩は素早くかわし、渾身の一撃を叩き込んだ。

書き直し:
> 　志摩の背後には、空のトロ箱が腰の高さまで積まれていた。出口は合羽の男の向こうにある。男が拳を振り上げると、志摩は左へ逃げた。拳が右肩に当たり、男はその勢いで箱の山に腹をぶつけた。重なった箱が奥へ傾き、男は前のめりになって両手を床についた。その横を抜けて、志摩は出口へ走った。
> 　引き戸を右手で開けようとして、肩の痛みで手を離した。左手で開け、外から戸を閉めた。

落とし穴
- 二人の動きだけで場所が消える。床、壁、物を巻き込む。
- 互角の打ち合いが何合も続く。狙いのない手は削る。
- 怪我が次の場面で消えている。
- 追い詰められた敵が急に愚かになる。逆転は、すでに示した能力・情報・関係・選択から生じさせる。

破ってよい場合: 技名や擬音が様式の作品（ジャンル契約）。力量差が大きい相手は過程を書かず、結果と、見ていた者の反応で済ます。負ける側に視点を置くのも手。超常の力がある世界は、力の源・届く範囲・代償を genres.md の階層表で先に決める。bungei では暴力そのものは短く、あとに残る不自由のほうを長く書く。

### [環境] 環境と移動

場所は、視点人物の関心でふるった二つか三つの細部で立つ。うち一つは、予想しにくいが言われれば本当らしいもの。LLM は部屋を左右対称に棚卸しし、匂いと光を几帳面に一文ずつ添える。

1. 細部は関心の錨から選ぶ。この人物は職業と目的といまの気がかりから、何を先に見るか。見ないものは書かない。
2. 物に時間を語らせる。小物一つか二つの摩耗・痕跡・置かれ方で、境遇と経過を示す。同じ種類の細部を重ねない。
3. 静物を並べず、人物の行為が触れた順に出す。知覚は出来事・反応と同じ段落に入れる。
4. 同じ景色は心境で違う相を見せる。ただし天気を感情の鏡にするのは一作に一、二度の切り札。晴れた日の葬式のようなずれのほうが効く。
5. 移動は、出発、途中の錨一つ、到着。何も起きない移動は一文で飛ばす。

弱い: 古びた山宿だった。土間の奥に囲炉裏があり、煤けた梁の下には、どこか寂れた空気が漂っていた。

書き直し（塩の行商が峠下の宿に着く。気がかりは、峠がまだ越せるかどうか）:
> 　土間に荷鞍は二つしかなく、どちらも腹帯まで乾いていた。今日着いた者の鞍ではない。トゥガは塩の俵を下ろす前に厩を覗き、騾馬も二頭なのを確かめてから、自分の騾馬を引き入れた。峠が開いている年なら、この時期は鞍の置き場に困る宿だった。
> 　上がり口の柱には、膝から胸の高さまで横に刻みが並び、ひとつずつに年の名が彫ってある。雪の深さだと、前に聞いた。白木の色が残っている刻みは一本だけで、それがほかのどれよりも拳ふたつは高いところにある。
> 「塩かい。置いていくなら、うちで全部もらうよ」
> 　宿の女は自在鉤から鍋を外しながら言った。トゥガは麓の倍の値を言ってみた。女は鍋を下ろして、それでいい、と言った。

落とし穴
- 評価語（古びた、豪華な、荒れた）で済ませる。評価は物に言わせる。
- 視点人物の知識を超えた名前が並ぶ（植物に疎い人物が樹種を言い当てる）。
- 感覚を種類別に一文ずつ足す。材料がなければ視覚だけで構わない。

破ってよい場合: 場所そのものが主役の場面（迷宮、廃墟、初めて見る都）は量を増やしてよいが、人物が動きながら見る形は守る。ミステリでは細部が物証として読まれるので、雰囲気のための小物を気軽に置かない（genres.md）。

### [転換] 場面転換

読者が省かれた部分を気にしなくなる繋ぎ方をする。前の場面の残りを、次の場面の最初の一、二文に持ち込む。LLM は時間を飛ばした直後、感情も状況も白紙に戻った人物を書きはじめる。次から一つ選ぶ。

1. 感情を持ち越す。前の場面の感情が冷めないうちに、別の場所・別の作業の中でそれを続けさせる。
2. 結果から入る。前の場面の末で開いた問いの、答えが出たあとから始める。時間の説明が要らなくなる。
3. 感覚の段差で切る。音、温度、手触りの対比で断絶を示す（気絶と覚醒、昼と夜）。
4. 物で繋ぐ。同じ物に同じ所作で触れて、二つの時間を繋ぐ。ありふれていない、手触りのある物で。
5. 同じ参照物の変化で経過を示す（窓の外の木、鍋の煮詰まり、伸びた爪）。
6. 視点を渡すなら、視線・音・動作の交点で渡す。視点を替えるのは情報差を作るためで、同じ出来事を両側から書き直さない。

区切り記号（`＊` のみの行）と時間の直書きは使ってよい。使ったら、直後の一、二文に 1〜3 のどれかを入れる。

弱い: 三日後。達彦は会社にいた。いつも通りの朝だった。

書き直し（前の場面の末尾と、次の場面の頭）:
> 　封筒は、鋏を取りに行かずに指で破った。
> ＊
> 　給湯室のポットが沸くまでのあいだに、達彦は不採用という字面を頭の中で十回は組み直した。見送り、ご縁、貴意に添いかね、どれを当てはめても同じ便箋の同じ行に収まる。後ろに並んだ経理の人に「お湯、もういいみたいですよ」と言われて、カップ麺の蓋を半分しか剥がしていなかったことに気づいた。

落とし穴
- 目覚め、移動の実況、別の場所へ移る断り書きで始める。
- 場面の末尾を語りの予告で閉じて次へ渡す。切るのは行為・台詞・像（prose-core.md）。
- 危機で切ったのに、次の場面の頭でそれを受けない。

破ってよい場合: 年代記のように遠い語りでは、時間の直書きだけで進めてよい。web の話またぎは前話の引きを受けることを優先し、感情の持ち越しは二の次でよい。

### [群像] 三人以上の場面

三人以上の場は、全員が均等に話すと議事録になる。場面ごとに軸の二人と、場を動かす一人を決め、残りは一言か所作だけの背景に下げる。視点人物が誰を見ているかの順が、描写の順になる。

1. 役を割る。軸の二人（この場面の対立を担う）／割り込む者（話題を変える、茶化す、物を運んでくる）／黙っている者（その沈黙に意味があるなら、視点人物に一度だけ見させる）。全員に台詞を配らない。
2. 話者は声で分ける（一人称、敬語の段階、発話の長さ）。やりとりが二往復ほど進んだら、呼びかけ・素のタグ・その人にしかできない所作のどれかで話者を一度確定する。同じ人のかぎ括弧を続けて並べない。
3. 人は入ってきた順に一人ずつ立てる。名前を出すのは話に加わった時点で、それまでは「奥の二人」のままでよい。
4. 会話を一本にしない。同じ卓で二つの話が並走し、片方がもう片方を遮る。視点人物に聞き取れるのは、注意を向けている側だけ。
5. 視点人物をカメラにしない。口を挟めない理由と、挟む瞬間を持たせる。

弱い: 「私は反対です」と叔母が言った。「私もそう思うわ」と智美が同意した。「僕は賛成だな」と従兄が言った。

書き直し（法事のあとの座敷。仏壇を誰が引き取るか）:
> 「うちはマンションだ」
> 「マンションだって置いてる家はあるわよ。富田さんとこなんか、リビングにこんな小さいの、家具調っていうの、あれ置いて、毎朝ちゃんとお水あげて」
> 「置けない」
> 　伯父は刺身のつまを箸で寄せていて、顔を上げない。叔母の話は富田さんの家の間取りへ入っていった。
> 「あの、お義父さん。ビール、もう一本お持ちしましょうか」
> 「いらない」
> 「では、お仏壇のほうも、うちでは」
> 　智美さんはそこで言葉を切って、瓶の口を布巾で拭いた。隣の従兄はずっと箸袋を折っていて、私が醤油差しを取るふりをして覗くと、脚の四本ある何かがもう二匹、小皿の陰に並んでいた。

落とし穴
- 意見が順番に一巡する。現実の席では、話す人は話しつづけ、黙る人は黙りつづける。
- 語尾の記号だけで人を分ける。語尾を揃えても誰の台詞か分かるのが合格（声シート）。
- 脇の人物が主役を引き立てる相槌係になる。各自に、この席での自分の用件を。
- 登場 3 人以上の場面では、lint の D02（純台詞の連続発話数）が早めに INFO を出す。取り違えそうな箇所だけに手がかりを足す。

破ってよい場合: 会議や法廷のように発言順が制度で決まっている場。掲示板回・配信コメント回など様式のある回は、ジャンル契約で別扱いにする。

### [日常] 事件の起きない場面

事件がなくても変化は要る。小さくてよい。誰かの機嫌、知っていることが一つ増える、習慣が一箇所ずれる。日常場面の仕事は、人物の「ふだん」を読者に覚えさせることで、あとでそれが破れたときに効く。LLM の日常は、全員が機嫌よく、献立が列挙され、一日の感想でまとめて終わる。

1. 小さな用事を一つ持たせる（探し物、買い忘れ、締切前の雑務）。用事があれば人物は動き、会話は用事の隙間に挟まる。
2. 習慣を一つ、数字・物・反復する動作で具体に置く。これが [死別] や終盤の対比の仕込みになる。
3. 筋に奉仕しない細部を、あるなら一つ残す。その場と視点人物に属するものに限る。思いつかなければ入れない。
4. 仕事や料理の段取りは、人物がそれをしながら別のことを気にしている形で書く。手順の説明を目的にしない。
5. 何かが少しずれたところで切る。

弱い: 朝食は焼き鮭と味噌汁と卵焼きだった。三人で食卓を囲み、他愛のない話をした。穏やかな朝だった。

書き直し:
> 　弁当箱の蓋が、どの引き出しにもなかった。倫子は卵焼きを巻きながら左手で食器棚の下段を探り、去年の運動会で使った重箱の蓋なら出てきたが、それでは大きすぎる。
> 「蓋、知らない？　青いほうの」
> 「知らん」
> 「昨日あんたが洗ったんでしょう」
> 「洗ったけど知らん」
> 　航平は立ったまま味噌汁を飲んで、椀を流しの手前の調理台に置いた。三年間言いつづけて、流しまであと四十センチのところで止まっている。蓋は結局、水切りかごの茶碗の下から出てきた。
> 　玄関の物音が長いので覗くと、航平がしゃがんで靴紐を結んでいた。いつもは踵を踏んだまま出ていく。
> 「今日、なんかあるの」
> 「べつに」
> 　結び終えた紐を、もう一度ほどいて結び直している。

落とし穴
- 全員の物分かりがよい。聞き流し、言い間違い、小さな不機嫌が日常の手触りになる。
- 「人間味のある脱線」を割り当てで入れる。毎場面に一つずつあれば、それも型。
- 場面の終わりに一日の感想を置く。

破ってよい場合: 読後感の保証が契約の作品（ライト文芸の連作など）では、小さな解決まで書いて着地させてよい。着地は行為で。web の日常回は短く、一話に変化を一つ。

### [恋愛] 二人の距離が動く場面

恋愛場面で動かすのは距離。呼び方、敬語の段階、座る位置、物の貸し借り、連絡の間隔。気持ちは行為でも直言でも伝えられる。最初に、この場面がどちらかを決める。

- **探り合いの途中の場面**（連載の途中の回、関係がまだ決まらない短編）: 下の 1〜5。距離は一段だけ動かす。
- **告白が実る山場**（依頼や契約が成就を約束している）: 1〜5 の速度の決まりは当てず、その下の「告白が実る山場」で書く。

1. いまの段階を決める（知り合う／探る／どちらともつかない／確かになる）。その段階で自然な行動だけを書き、一場面で二段飛ばさない。
2. 惹かれる理由は、相手がした一つの具体にする。視点人物がそれに気づく瞬間を書く。属性（優しい、有能）は理由にならない。
3. 距離を測るものを一つ選んで動かす。縮んだら、次は少し引く。名字から名前への呼び替えは、作品に一度の出来事として取っておく。
4. 二人を隔てているもの（内側の理由と外側の理由）に、場面の中で一度触れさせる。
5. 身体の反応は人物固有の癖から。汎用の反応を使うなら、前の場面と部位も書き方も変える。

**告白が実る山場**: 依頼や契約が、告白が実ること（両思いになる、相手も気持ちを答える、成就の場面）を約束しているとき、この場面は積み上げた距離が一気に閉じる場面で、上の 1 と 3（一段だけ動かす、縮んだら引く）は当てはまらない。それは途中の回の速度の決まりである。結末が指定されていない告白（「直球で告白する場面」だけ）では、実るか実らないかは書き手が選んでよい。保留や含みで終える契約の作品には、この節を当てない。

- 告白は言葉で言う。実る山場なら、返事も同じ場面の中で言葉にする。気持ち（好きだ、うれしい）と、関係への答え（付き合う、待っている）の両方を口に出させる。
- 実ると約束した場面で、返事を先送りにしない（「考えさせて」「手紙が書けたら」）。条件つきにしない。会う約束や仕草から読み取らせて済ませない。LLM は含みを残すほうを上等と見なしやすいが、読者がこの場面に来た目当ては、言葉が交わされる瞬間そのものにある。
- 二人を隔てる事情（進学、転勤）は消さなくてよい。「気持ちがあれば平気」で溶かさず、具体の約束（いつ、どちらが、どうやって会うか）で受ける。
- 告白と返事のあとに、二人が何を受け取ったかまで書く（恋人になれた喜び、これからの二人）。台詞、内面、行為のどれで渡すかは、依頼と作品の声から選ぶ。行為を一つ置けば済む、感情の語を一つ置けば済む、とはしない。承諾の直後に物や動作へ移って切り上げると、読者は成功を理解するだけで、喜びを受け取る前に終わる。
- 結びの基準は、約束した充足が最後の一行まで保たれていること。二人が交わした言葉や行為で切るのは、確かな選択肢の一つ。相手を見送ったあとの一人の時間で切ってもよいが、そのときは喜びが残る形にする。冷たい物、意味を読者に解かせる仕草、語り手による先の暗示（「二人ともまだ知らなかった」）は、通じ合った喜びより心細さを残しやすい。

弱い: 彼の優しさに、胸が高鳴った。こんな気持ちは初めてだった。

書き直し:
> 　芦原が左手にペンを持つと、野々宮さんは資料の束を芦原から見て右へ寄せ、左の肘を置く場所を空けてくれた。
> 「三十二ページ、ノンブルが切れてました。こちらのミスです。申し訳ありません」
> 「いえ、うちの指定が甘かったので」
> 「それと、これ」
> 　束のいちばん下から、付箋のついた文庫本が出てきた。先月、待ち時間に芦原が読んでいたのと同じ作家の、別の本だった。
> 「面白かったんで。あ、いや、面白かったので、もしよければ」
> 　言い直したあと、野々宮さんは名刺入れを開けたり閉めたりしている。芦原は本を受け取り、付箋の位置を見た。百四十ページあたり。そこまでは読め、ということなのか、そこが良かった、ということなのか。
> 「お借りします。来週の再校のときに」
> 「再校、出ないかもしれないですけど」
> 「出ます。三十二ページがありますから」

落とし穴
- 話せばすぐ解ける誤解で引き延ばす。隔てるものは状況か、本人の誤った信念に置く。
- 相手役が視点人物を無条件に褒める。相手にも自分の用件と都合がある。
- 相手が報酬としてしか存在しない。相手の側の惹かれる理由も場面で見せる。

破ってよい場合: 契約の emotion_naming が direct の作品（溺愛など）では、ときめきを名指ししてよい。名指しの直後に、その場面にしかない物か動作を接ぐ。相手役の誠実さが契約のジャンルでは、引く動きを裏切りに見える形にしない（genres.md）。

### [回想] 過去を場面で見せる

回想は現在の場面を止める。止めるに値するのは、現在の選択の意味を変える過去だけ。入口と出口を現在の知覚に繋ぎ、中は短い場面として書く。LLM は回想を来歴の説明に使い、証拠を並べ、最後に結論の判を押して戻ってくる。

1. 現在の場面が立ち上がってから入る（誰がどこで何をしようとしているかが読者に渡ったあと）。場面の頭では入らない。
2. 入口は現在の物・音・言葉。最初の一、二文だけ「〜ことがある」「〜ていた」で過去だと示し、中はふつうのタ形で運ぶ。
3. 中身は一つの具体（ある晩の、ある動作）に絞る。当時の自分が知らなかったことは、知らないまま書く。
4. 出口は現在の刺激（相手の台詞、物音）。戻ったあとで意味を解説しない。回想の前後で、現在の人物の行動が変わっていること。
5. 一場面に一度。長い過去は回想にせず、独立した場面にして区切る。

弱い: 父はいつも不器用な人だった。思えば、あの時も、あの時も、父は黙って守ってくれていたのだ。

書き直し:
> 　あと二万は上げさせるつもりで、直人はタイヤを去年替えた話を二度していた。査定の男は聞き流しながら荷台のあおりに掌を滑らせ、左の凹みのところで手を止めた。
> 　高二の夏に、直人がつけた凹みだった。免許もないのに畦道で切り返そうとして、用水路の杭に当てたことがある。その晩は納屋に隠れて、父が帰ってくる音を聞いた。父は軽トラのまわりを一周し、何も言わずに母屋へ入った。二日後、隣の爺さんに「お前んとこ、猪が出たってな」と言われた。
> 「ここ、減点になりますけど。何かぶつけました？」
> 「猪です」
> 　男はバインダーに何か書き込み、直人はタイヤの話をもうしなかった。

落とし穴
- 回想の全文が「〜ていた」で続き、場面にならない。
- 思い出した事実を三つ並べる。一つを、結論なしで置く。
- 回想から戻っても現在が何も変わっていない。変わらないなら、その回想は地の文の一行で足りる。

破ってよい場合: 回想体の一人称（語りの現在が文体シートに宣言されている）では、語る私の注釈が入ってよい。過去と現在を交互に進める構成は、転換として設計する（[転換]）。

## 3. 特殊トリガーのカード

### [容姿] 新しい人物の外見

人物は一点で覚えられる。標識になる特徴を一つ決め、登場の動作の中に溶かし、あとの場面でもその一点に戻る。LLM は人物を立ち止まらせ、髪・目・背丈・服を上から順に述べる。

1. 標識は一つ。来歴のある特徴を選ぶ（仕事でついた癖、古傷、持ち物の使い込み）。
2. 初登場は、行動＋標識＋他人への態度。入ってくる、座る、物を受け取る動作の中で見せる。体格や気配は物と周囲の反応で（椅子の軋み、場の声の大きさが変わる）。
3. 誰の目で見るかを決める。評価（美しい、怖い）は視点人物の声としてなら言ってよく、語りの結論としては置かない。
4. 再登場のたびに標識へ戻る。人物の状態の変化は、標識の変化で見せる。

弱い: 現れたのは、長い黒髪に切れ長の目をした、すらりと背の高い女性だった。

書き直し:
> 　調律師は約束の五分前に来て、靴を脱ぐより先に、奥のピアノのほうへ首を傾けた。誰も弾いていないのに、と真紀が思っていると、「冷蔵庫、ピアノと同じ壁にありますか」と訊かれた。唸りが弦に乗るのだという。
> 　居間に通すと、鞄から出した毛布を床に広げ、ピアノの上の写真立てと花瓶を一つずつ両手で持って移した。右手の人差し指だけ、爪が肉の際まで切ってある。名刺には笛木とあった。

落とし穴
- 鏡や水面で視点人物自身の容姿を述べる。自分の外見は、他人の反応と不便（棚に手が届かない）で。
- 周囲が一斉に見惚れる、と総括する。止まった手、途切れた会話の一つで足りる。
- 一場面に新しい人物を何人も出し、全員に同じ分量の紹介をつける。

破ってよい場合: entertainment / web で髪や瞳の色の明示が期待される作品は、標識一点に加えて色を二つまで、動作の中で。一人称の語り手が相手を値踏みする性格なら、棚卸しそのものが声になる。

### [内面] 激しい内面

強い感情の書き方は作品の声とジャンル契約で選ぶ。思考の途切れ、無関係な用事の割り込み、名指し、自己分析も使える。同じ感情の説明と汎用の身体反応だけが重なっていないかを見る。

1. 思考を断片にする。論理の飛び、無関係な日常の念、途中で止まる文。表面は落ち着いていて、動作のほうが先に乱れる。
2. 受け入れがたい事実には段階を踏ませる。軽く見る、言い訳を捻り出す、保てなくなる。各段を場面の出来事に対応させる。
3. 身体の反応は人物シートの固有の癖を先に使う。汎用の反応なら一つだけ、できれば起きなかった方向で（涙が出ない、手が震えない、それに自分で気づく）。
4. 山場は名指し・行為・内面・比喩から選ぶ。`emotion_naming = restrained` なら名指しも比喩も使わない書き方を既定にできる。通過点は名指しで流してよい。同じ内容の説明の重なりを点検する。

弱い: 信じられなかった。頭が真っ白になり、胸が締めつけられた。

書き直し（コインランドリーで、弟の事故を知らせる母の電話を切った直後）:
> 　電話を切ってから、乾燥機の残り時間を見た。十四分ある。十四分あれば駅まで行けるが、洗濯物を置いていくわけにはいかないし、濡れたまま袋に詰めたら電車の中で臭う。母は「命に別状はない」と言った。別状はない、というのは医者の言い方で、母はそういう言葉を使わないから、たぶん医者がそう言ったのをそのまま繰り返したので、だったら本当なのだろう。本当でなければ母はもっと違う声を出す。私は両替機に千円札を入れ、出てきた百円玉を数え、もう乾燥機は回っているのだから両替する必要はなかったと気づいて、十枚とも財布の小銭入れに一枚ずつ落とした。雅也の保険証はどこにあるんだろう。あの子は財布を二つ持っている。

落とし穴
- 心の中で二つの声に討論させる。迷いは、手が二度同じことをする、で足りる。
- 名指しを消した跡を身体反応で埋める。lint は K08（感情語）と K09（身体反応テンプレ）を合算でも見る。片方だけ減っていたら横滑り。
- 固有の癖を毎場面で使う。癖も連打すれば型になる。

破ってよい場合: 自分の感情を分析する知的な一人称、遠い距離の語りでは、名指しが正しい。emotion_naming が direct の作品は名指しを基調にし、直後に場面固有の具体を接ぐ。

### [死別] 死と別れ

死の瞬間は短く平らでよい。読者に届くのはそのあとで、果たされなかった用事と、相手がいた頃の習慣が空振りする瞬間。LLM の死の場面は、穏やかな死に顔と視点人物の号泣に収束し、その場面の中で悲しみを完結させる。

1. あと一歩で断つ。死の前に、小さく具体的な約束や用事を積んでおく（行くはずの店、返していない本）。それが果たされないまま残る。仕込みは [日常] の 2。
2. 習慣の空振りを書く。いつもの動作を身体が先にやって、相手がいないことに追いつく。悲しみは述べず、空いた場所と、渡せなくなった物を置く。
3. 誤解を抱えたまま退場させるなら、真相が分かるまで時間を置く。直後に明かすと、読者の後悔が育つ前に終わる。
4. 最期の台詞に主題を語らせない。日常の用件のほうが残る。
5. 号泣と絶叫は周囲の人物に置くか、書かない。ふだん軽口を叩く人物も、この場では黙らせる。

弱い: 母は眠るように逝った。涙が止まらなかった。もう二度と、あの声は聞けないのだ。

書き直し:
> 　葬儀の翌朝、実家の軽を動かそうとして、和久は乗りこむなり座席の下のレバーを引いた。小柄な母はシートをいちばん前まで詰めて運転するので、この車ではまずハンドルに膝をぶつけ、それからレバーを引いて後ろへ下げる。二十年そうしてきた。
> 　レバーは引けたが、シートは動かなかった。もう下がりきっている。三日前、病院へ着替えを届けた帰りに自分が下げた、そのままの位置だった。
> 　和久はレバーから手を離した。後部座席には、母が生協に頼んだ米が十キロ、袋の口を縛ったなりで載っている。

落とし穴
- 死の場面の直後に、語りが喪失の意味をまとめる。
- 雨、夕焼け、散る花を悲しみの鏡にする。
- 指定された死を、直前で回避する方向に丸める。ユーザーが決めた苦い結末はそのまま書く。

破ってよい場合: 通俗型の短編など感情直球が契約の作品は、視点人物に泣かせてよい。泣く前に、場面固有の物を一つ置く。戦記や年代記の遠い語りでは、死を一行の事実として通過させるのも正統。

### [開示] 謎解きと開示

開示は新しい情報を足す場面ではなく、読者がすでに見たものの意味を差し替える場面。材料は先に全部出してあり、ここで出すのは繋ぎ方だけ。細部はすべて事実のまま、動機や意味だけが入れ替わるのがいちばん強い。LLM は未出の証拠を持ち出し、当事者に長台詞で動機を解説させる。

1. 書く前に照合する。この開示に必要な手がかりは、どの場面に、どの言葉で出したか（伏線台帳と canon）。未出の証拠、未登場の人物、偶然では解かない。足りなければ前の章に戻って置く。
2. 手がかりは、出したときと同じ語で呼ぶ。言い換えると読者が遡れない。
3. 気づく瞬間を場面にする。物を手に取る、言葉が引っかかる。「実はあのとき」の台詞は短く切り、相手の反応と物で分割する。
4. 推理を語らせるなら、ほかの可能性を消す過程を見せる。聞き手は頷くだけにしない。反論させ、逃げ道を探させる。
5. 短く畳む。開示のあとに解説と感慨を続けず、読者が読み返したくなる一点を指して終える。終わったら場面カードの knowledge（誰がいつ知ったか）を更新する。

弱い: 「実は、この店を早く閉めていたのは、亡くなった妻のためだったんです」店主は静かに語りはじめた。

書き直し（前の場面までに出してある手がかり: 「七時まで」と言う店のシャッターがいつも早く下りる。奥の柱時計だけほかの時計と合っていない。店主は終バスの時刻をそらで言える）:
> 　修理の済んだ腕時計を受け取って、安西は自分のスマホと見比べ、それから奥の柱時計を見た。
> 「あれ、七分進んでますよ」
> 「進んでるね」
> 「時計屋さんなのに」
> 「直すと、間に合わなくなるんでね」
> 　何に、とは訊けなかった。七時まで、と言いながらこの店のシャッターがいつも早く下りるのを、安西は店主の横着だと思っていた。柱時計が七時を打ち、店主は預かり証の控えを屑籠に落として立ち上がった。
> 「昔はあれで帰る人がいてね。進めておかないと、いつまでも店で喋ってるもんだから」
> 　半分下りたシャッターの向こうを、駅行きの終バスが、客を一人も乗せずに下っていった。

落とし穴
- 視点人物が知っていたことを、地の文が偽っていた。省略はよいが虚偽は不可。
- 読者がとうに気づいていることを、人物が追いつくまで引っ張る。それは反転にならず、ただの遅延。
- 開示の直後に全員が納得する。受け入れない者、別の解釈にしがみつく者を残す。

破ってよい場合: 解決編の長台詞が様式のジャンル（本格ミステリ）では、探偵の語りを長く取ってよい。その場合も 1・2・4 は守る。怪談は原因を閉じないのが契約なので、開示は一部に留める（genres.md）。

## 4. 書いたあとの確認

1. 具体化した指示の操作が、本文のどの行に出たかを指せるか。指せなければ当て方が薄い。指せる行がどれも同じ形なら、当て方が機械的。
2. 直前の場面と同じ操作を、同じ形で使っていないか（託す物、転換の手、標識の出し方、空振りの型）。
3. カードの言葉（本題、標識、距離、手がかり、錨 など）が本文に出ていないか。lint の X（漏出）でも拾うが、書いた直後に自分で見る。
4. このファイルの対比例から、人物・物・言い回しを本文に持ち込んでいないか。例は操作の見本で、素材ではない。
