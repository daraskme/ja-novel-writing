# AI 臭カタログと処方（推敲専用）

- 読むとき: 推敲で `novel_lint.py` が WARN 以上を出したあと、0.3 の表で引いた節だけを読む。盲検読者や編集役から「既視感がある」「説明された」「誰の台詞か分からない」といった反応が返ったときは、0.3 の下段を使う。
- 読まないとき: 執筆前と執筆中。ここに並ぶ語と型は、読んだ直後の生成で出やすくなる。flash の一発書きでも読まない。通読もしない。
- ここに警報線の数値はない。線は `scripts/data/thresholds.json` にあり、この文書は lint のルール ID と名称で参照する。執筆の目安は style-sheet.md にある。

## 0. 見方と使い方

### 0.1 見方
AI 臭は特定の語ではなく、分布の偏りとして出る。「ふと」を一度使うのは癖ではない。場面が変わっても同じ頻度で、同じ位置に出てくるのが偏りである。人間の小説も「ような」「ふと」「と思った」を使う。ゼロは目標にしない。

偏りは次の三つの形で点検できる。モデル内部の原因を断定する分類ではない。
- 最頻値への回帰: いちばんありそうな語、名前、舞台、反応、結末を選ぶ。
- 親切さの漏出: 説明する、まとめる、安心させる、教訓を渡す。場面のあとに中立の説明が重なる。
- 局所最適: 一文、一段落ごとにきれいに完結させる。全体からムラ、省略、破調が消える。

各項目の「なぜ」は、観測した文の働きを整理するための説明として読む。ここに載っていない型も、反復する位置と読者への効果から点検する。型は字面ではなく修辞の動作（否定を立てて見得を切る、段落末で小さくオチをつける、三つ並べて整える）で捉える。語を替えて同じ動作を続けていれば、直っていない。

### 0.2 手順
1. lint の出力から 0.3 で節を引く。読むのはその節だけ。
2. ヒットを先に 0.4 に当てる。当たれば keep とし、理由を一句残す。
3. 語より先に段落を見る。ヒットの載っている段落について「別の作品の別の人物に差し替えても、そのまま通るか」を問う。通るなら、語を直しても段落は死んだままなので、場面カードに戻って人物の用事と関心の錨を入れ直し、段落ごと書く。通らない段落（細部がその人物の目を通っている、台詞が何かをしている）は、ヒットした箇所だけを最小限に触る。
4. fix は語の置換ではない。その文が果たそうとした機能を特定し、場面の側（行為、物、台詞）で果たし直すか、削る。最初に試すのは「削って前後がつながるか」。
5. 直した先が別の紋切り型になるなら keep。元のほうがましである。
6. 直しの途中で足した文や、分割して短くした文にも、その場で同じ基準を当て直す。混入はここから起きる。
7. fix・keep に目標比率は無い。各ヒットの根拠と作品への効果で決め、全件 fix も全件 keep もあり得る。人間の良い文章でも警報は鳴る。ゼロにすること自体を目標にせず、読者への効果を確かめる。

同じ会話で次の本文を書く前に、場面カードと prose-core.md を読み直す。
可能なら、契約・必要な本文・採用した改稿指示だけを渡した新しい執筆コンテキストで書く。

触ってよい深さは段落の種類で変わる。

| 段落 | 触ってよい範囲 | 変えないもの |
|---|---|---|
| 叙事 | 大きく書き直してよい | 筋の向き、鍵になる動作 |
| 会話 | タグとリズムだけ | 台詞の文言、数字、誰の発言か |
| 内心 | 文の形 | 判断の向き（反転させない） |
| 回想 | 軽く | 時系列、人名、出来事の細部 |
| 作中文書（手紙、画面、掲示） | 触らない | 一字一句 |

### 0.4 直さないケース（ヒットを最初にここへ当てる）
1. 人物に根のある表現。口癖、言い淀み、方言、役割語、教育や性格に由来する文法の崩れ。声シートや人物シートに根拠があるもの。
2. 台詞の中の感情語（人は会話で「腹が立つ」と言う）と、素のタグ（言った、訊いた、答えた）。
3. 視点人物の認識の限界を示す推量。他人の内面への「〜らしい」「〜ようだ」、未確認の事実、反実仮想。断定に直すと視点が破れる。
4. 文体シート、ジャンル契約、声シートで宣言された癖と様式。語り手の偏愛語、比喩家の語り、饒舌な一人称の内心語り、時代物の文語調、ラノベの記号、Web の短段落と連載の引き、通俗短編の感情直球。宣言がなければ漏出として扱う。宣言はないが意図だと判断したら keep にし、宣言の追加をユーザーに提案する。
5. 意味が変わる反復（モチーフ）。台帳の記録は keep の根拠になるが、lint から機械的には除外しない。
6. 具体物の列挙（買い物、積み荷、献立）。疑うのは抽象概念の列挙（勇気、希望、未来）だけ。
7. 作中文書。手紙、チャット画面、ステータス窓、掲示は逐語で保つ。
8. 感情の極点での異常な反応（怒りの極みで笑う、不安で饒舌になる）で、その人物の来歴から出ているもの。
9. 拍のために置かれた接続や反復。冗長は字数ではなく、その文が情報・感情の変化・拍のどれかを足しているかで測る。

判断がつかなければ原文を残し、処置記録に `[疑]` を付けてユーザーに回す。

### 0.5 対になる失敗
片側だけ締めると、もう片側が増える。fix のあとは相方を確かめる。

| 締めたもの | 増えるもの | 確かめ方 |
|---|---|---|
| 感情の名指し（K08） | 身体反応テンプレ（K09） | lint の合算値 |
| 癖語（K10〜K13） | 近縁語（ふと→不意に、静かに→ひっそりと） | 同カテゴリの総数。文の形が同じなら直っていない |
| 「……」「――」（K01〜K03） | 「沈黙が落ちた」型（1.8）、電報体（3.2） | 1.8 の件数、P04 |
| 場面末の総括（6.1） | 語り手の予告（6.4）、体言止めの余韻 | 章末の二文、O 群 |
| 装飾タグ | 全台詞への動作ビート（4.5） | タグとビートを一緒に数える |
| 視覚偏重 | 感覚の直列、後付けの匂い（3.4） | 感覚文の位置 |
| た止めの連続（R01） | 機械的な交互配置（2.1） | 出来事の文が現在形になっていないか |
| 冗長、曖昧表現 | 電報体と白描（2.2）、視点の破れ（2.8） | L02、P04、他人の内面の断定 |
| 無国籍（7.3） | 飾りの精密さ（7.3） | その具体が後で使われるか |
| 模範的な反応（5.2）、隙のない因果（3.5） | 割り当てで入れた「ずらし」と脇筆 | 位置と型が揃っていないか |

## 1. 語彙

### 1.1 情緒副詞で弱い動詞を飾る・動機を「ふと」で省く [K10 K11 K12]
- 症状: 「静かに」「そっと」「ゆっくりと」「小さく」「軽く」「かすかに」「優しく」が動詞ごとに付く（小さく頷く、軽く息を吐く）。「ふと」「思わず」「不意に」「いつの間にか」「気づけば」で、行為のきっかけが書かれない。
- 点検: 動詞やきっかけが曖昧なまま、副詞だけで情緒を指定していないか。
- 処方: まず副詞を外して読む。文が痩せなければそのまま。痩せるなら、動詞か、動作の相手になる物を選び直す。「ふと」は、何がその人を振り向かせたのか（物音、目の端で動いたもの、匂い）を書く。書くほどのきっかけでないなら、語を外して行為だけにする。
  - 悪: 彼女は封筒をそっと仏壇に供え、静かに手を合わせた。
  - 良: 郁代は封筒を仏壇の経机に置いた。角が線香立てに触れて、灰がひとすじ崩れた。
- 残す: 童話・絵本調の語り。いつも音を立てない人、のように人物造形として反復するもの（声シートに書いてあること）。
- 横滑り: 「ひっそりと」「音もなく」「おもむろに」への言い換え。

### 1.2 決めていないことを霧で隠す [K13]
- 症状: 「どこか懐かしい」「何かが変わった」「なんとなく」「言いようのない」「ある種の」「〜ような気がした」「〜のかもしれない」の連用。
- 点検: 何に似ているか、何が変わったかを具体的に指せるか。
- 処方: 何に似ているのか、何が変わったのかを、書く側が決めてから書く。決まらないなら、その文は場面に何も足していないので削る。
  - 悪: 玄関には、なんとなく懐かしいような匂いが漂っていた。
  - 良: 玄関に、灯油と日に当てた布団の匂いがこもっている。小学生の冬、父の泊まり勤務に着替えを届けにいった消防署の仮眠室が、これと同じだった。
- 残す: 人物が本当に特定できない、または特定を避けている（否認）とき。台詞内。0.4 の 3。
- 横滑り: 推量を一律に断定へ変えて、視点人物が他人の心を言い当てはじめる（2.8）。

### 1.3 知覚に「感じた」「気づいた」「見えた」をかぶせる [K07]
- 症状: 知覚と読者のあいだに動詞が一枚挟まり、体験が報告になる。主体のない受動（「〜が感じられた」「〜が明らかになった」）も同じ。一人称では「私の胸が」「私は〜と感じた」「自分の手が震えているのが見えた」と、読者を体の外へ押し戻す形でも出る。
- 処方: かぶせを外し、知覚の対象か行為を主語にする。
  - 悪: 彼は背後に人の気配を感じた。
  - 良: 背後で砂利が一度だけ鳴り、それきり続かなかった。
- 残す: 気づくこと自体が出来事である瞬間。語り手の判断と人物の判断を分けたい箇所。内心語りが売りの一人称（文体シートで宣言）。台詞の直後で発話の様子を受ける一文。
- 横滑り: 外した先が身体反応テンプレになる（5.1）。「思った」まで狩って、判断の書けない白描になる。

### 1.4 直喩マーカーと既製の喩え [S01 S02 S03]
- 症状: 「まるで〜かのように」が段落ごとに出る。喩えの出どころが汎用（時間が止まる、糸が切れる、波が引く、霧が晴れる、世界から音が消える）。同じ喩えを章をまたいで再発明する。
- 点検: マーカーの数より、喩えがその場面に合うかと、対応が具体的に通るかを見る。
- 見分け: その喩えは、視点人物の職業・年齢・土地を知らなくても書けるか。書けるなら既製品。喩えの指す内容を平叙文で言い直せるか。言い直せないなら雰囲気だけで中身がない。
- 処方: 喩えを消して、喩えが言おうとした事実を観察で書く。残すなら語り手の声と作品世界に合う素材を採る。感情の頂点で使うかも契約に従う。喩えの直後に解説を足さない。
  - 悪: 工場は、まるで世界から音が消えたかのように静まり返っていた。
  - 良（観察に戻す）: 昼のサイレンが鳴り終わっても、プレス機の音が戻ってこなかった。
  - 良（生活圏から採る。視点人物は左官）: 義父は返事をしなかった。練って一時間たったモルタルと同じで、もう水を足しても戻らない。
- 残す: 比喩家の語り手、ユーモア小説、童話、幻想。その場合は数ではなく、喩えの出どころの一貫性と混喩だけを見る。意図したモチーフなら keep の根拠になる。S03 から機械的な除外はしない。
- 横滑り: 「まるで」だけ外して「〜のような」を残す。比喩ゼロの乾いた報告文にする。

### 1.5 否定対比で見得を切る [K16]
- 症状: 「A ではなかった。B だった。」誰も A だと思っていないのに A を立てて倒し、B に深みを借りる。点検: 否定した A が文脈に必要か、B が新しい認識を足すかを見る。
- 変形（語を替えても同じ動作）: 「A というより B」「A じゃない、B だ」「A だと思っていた。だが本当は B」「一見 A、その実 B」「A は問題ではない。問題は B だ」「単なる A ではない。B でもあった」。
- 処方: その文が下したかった判断を特定し、否定を経由せずに B だけを一度書く。B が感情のラベルなら、それも場面の行為に戻す。
  - 悪: 悲しいのではなかった。ただ、空っぽだった。
  - 良: 納骨が済んだ翌週、澄夫は母の携帯を解約しに行った。番号を呼ばれるまでのあいだに、ためしに父の誕生日を入れてみるとロックが開いた。写真はどれも台所の鍋の中で、人は一枚も写っていなかった。帰りにうどん屋で大盛りを頼み、残さず食べた。
- 残す: 読者が実際に A を予想している場面。推理の消去。筋として誤解から訂正へ歩んだ箇所の自己訂正（一度）。通俗短編の断罪の決め台詞（契約）。

### 1.6 付帯状況の飾り句・表情テンプレ [K20、表情は K09]
- 症状: 「〜を滲ませて」「〜を帯びた声で」「〜の色を浮かべながら」「一抹の〜を含んだ」「〜を湛えた瞳」。「口角を上げた」「瞳が揺れた」「目に〜の色が宿った」。
- 処方: 飾り句を落として素の動作にする（少し笑った、目をそらした）。感情を運ぶ必要があるなら 5.1 の四択へ。
- 横滑り: 別の飾り句との交換。視点人物に見えない自分の表情を書く（視点の破れ）。

### 1.7 翻訳調 [lint なし。目視]
- 症状: 無生物主語の使役（「その写真が彼に故郷を思い出させた」「不安が彼女を支配した」）。所有代名詞（「彼は彼の鞄を」）。「〜することができた」「〜という事実」。英語圏の身振り（肩をすくめる、眉を上げる、目を回す）。英語では死んでいる比喩の直訳（「疲れが彼をつかまえた」「その一言が彼の中に居場所を見つけた」）。書き手に比喩のつもりがないまま混ざる。
- 見分け（二段）: その述語を、字義どおりの動作として想像できてしまうか。できるなら、主体と対象を具体語で言い直せるか。言い直せるならそれを書く。言い直せないなら、その文は中身が決まっていない。
- 処方: 主語を人か出来事に戻す（「写真を見て、実家の裏の用水路を思い出した」）。可能表現は「〜できた」か単純過去へ。身振りは場面の小道具を使う動作へ。
- 残す: 海外舞台、翻訳ミステリの様式を意図して採る作品。意図して選んだ擬人法。
- 横滑り: 身振りを「首をかしげる」「目が泳ぐ」に替える。日本語の定型に移っただけ（4.5）。

### 1.8 抽象名詞に演技をさせる [K18]
- 症状: 「沈黙が落ちた」「静寂が部屋を包んだ」「時間だけが流れた」「闇が横たわっていた」。
- 処方: その間に聞こえた音、見えた物を書く。
  - 悪: 重い沈黙が落ちた。
  - 良: 誰も箸を動かさない。台所で、炊飯器が保温に切り替わった。
- 残す: 怪談・幻想で抽象が本当に主体になる場合。

### 1.9 呼び名を持ち回る
- 症状: 同じ人物が「少女」「彼女」「その娘」「銀髪の剣士」と段落ごとに呼び替えられる。物や場所でも起きる。
- 処方: 視点人物がその相手を普段呼ぶ呼び方ひとつに揃える。呼称が変わるのは関係が変わったときだけ。正本は呼称表（glossary.toml）。
- 横滑り: 揃えた結果「彼は」「彼女は」の連打になる（2.4）。

### 1.10 語り手が驚きと評価を先に言う [K21]
- 症状: 「なんと」「まさかの」「信じられないことに」「明らかに」「間違いなく」。「美しい」「不思議な」「圧倒的な」「言葉にできない」で対象を済ませる。
- 処方: 驚きは出来事の順序で作る（読者に予想を持たせてから外す）。評価語は、そう評価させた事物に置き換える。
  - 悪: 母の字は驚くほど美しかった。
  - 良: 宛名の楷書は一画も崩れていない。郵便番号の枠の数字まで、同じ高さに揃えてあった。
- 残す: 語り手の人格から出る評価と軽口（誰が言っているかが分かるもの）。台詞内。

### 1.11 報告書と評論の語彙が地の文に混ざる [K22]
- 症状: 「状況を把握する」「感情を整理する」「関係性」「距離感」「〜という事実」「〜を示していた」「〜を意味していた」。出来事を抽象ラベルで済ませる（「二人の関係は一歩前進した」）。
- 処方: ラベルの下で実際に起きたことを書く。視点人物の語彙の層（声シート）にない語は、その人物が口にする言い方へ戻す。
- 残す: 理屈っぽい語り手、職業柄その語を使う人物、報告書体の作品。

## 2. 文

### 2.1 同じ文末が続く・た止めに偏る [R01 R02 R03]
- 症状: 「〜た。〜た。〜た。」短い連続は人間の小説にも普通に出る。偏りとして効くのは、連続に属する文の割合（R02）とた止め率（R03）。
- 処方: 音で散らさない。出来事の種類、語りの時点、知覚への近さ、前後との関係で選び直す。ル形で出来事を進める歴史的現在もある。あわせて文を結合する、台詞で切る。
  - 悪: 店に入った。客はいなかった。店主が顔を上げた。私は会釈した。
  - 良: 引き戸を開けると、客のいない店で店主が夕刊を読んでいた。顔は上げたが何も言わない。品書きは壁の短冊だけで、値段のところに上から紙が貼ってある。私は会釈して、いちばん奥の席に座った。
- 残す: 報告体、ハードボイルド、喪の直後や解離の平板さ、アクションの短打、回想の淡々とした処理。続けるなら徹底する。強 WARN を keep するなら文体シートに例外宣言を書く。敬体の語りは lint が自動で緩い線（R01 の敬体用）を使う。
- 横滑り: た・る・た・る の機械的な交互配置。意図のない切り替えで語りの時点が濁る。体言止めへ逃げる（2.3）。

### 2.2 短文メトロノーム [L01 L02 L04]
- 症状: 同じ長さの短文が等間隔に続き、注意や動作の切れ目も決め所も読めない。短文そのものや長文の不在だけでは判断しない。
- 処方: 注意・動作・間の単位と場面の速度から切り方を選び直す。観察だけの短文も使える。長短を均等に混ぜることは目標にしない。
  - 悪: 雨が降ってきた。真柴は傘を持っていなかった。コンビニに入った。
  - 良: 降り出した雨をよけてコンビニに入ったものの、ビニール傘の七百円が惜しくて、真柴は雑誌の棚の前で立ち読みのふりをしながら、向かいの信用金庫のひさしまで何歩で行けるかを数えていた。
- 残す: 短文基調を文体シートで宣言した作品、子どもの語り、列挙・儀式・呪文の反復。L03（長文の列挙）は INFO で、長いこと自体は欠点ではない。
- 横滑り: 長文を入れるノルマにして、読点で繋いだだけの文を作る。長い文は因果か観察の連なりがあるときだけ。

### 2.3 体言止めのカメラカット [T01 T02]
- 見分け: 「これは誰が言っているか」。語り手の判断・評価・軽口が乗っている体言止めは声である。観察の列挙も、注意の移動や間として働くなら残す。同じ調子が続いて決め所を消すなら繋ぎ方を見直す。
- 処方: 並んだ名詞を、視点人物が見た順と理由を持つ一文に編み直す。
  - 悪: 改札の前。濡れた傘。見覚えのある横顔。
  - 良: 改札の前で傘の水を切っている人がいて、柄を持ちかえる手つきで、顔を見るより先に兄だと分かった。
- 残す: パニック時の断片知覚、フラッシュバック、モンタージュ、詩的散文、ラノベの様式。
- 横滑り: 文末に変化をつける目的で体言止めを使う（2.1 から流れてくる）。

### 2.4 主語を毎文補う・「彼は」「彼女は」の連打 [K14 K26]
- 点検: 文頭の主語が繰り返され、話者や動作主が明らかな箇所でも同じ形になっていないかを見る。
- 処方: 視点人物の動作には主語を立てない。立てるのは動作主が入れ替わる文だけ。立てるときは「彼」より名前か、視点人物から見た続柄・役職（姉、店長）。「〜てくれる」「〜てもらう」と敬語は、主語なしで誰の動作かを示せる。
  - 悪: 彼は助手席のドアを開けた。彼女は荷物をどけた。彼は彼女に礼を言った。
  - 良: 多恵は笑って、助手席の荷物をどけてくれた。用意してきた言い訳は、乗りこむまでに半分忘れた。
- 残す: 名を与えない人物を「彼」で通す設計。翻訳調を意図して採る文体。
- 横滑り: 省きすぎて動作主が分からなくなる。三人以上の場面では省略より名前。

### 2.5 接続詞で全部つなぐ [K04 K05 K06]
- 症状: 文頭・段落頭の「しかし」「そして」「だが」「その後」。全段落の継ぎ目が滑らかで、飛躍が一つもない。「その瞬間」「次の瞬間」「〜したとき、」で動作を繋ぐ、「一方その頃」で場面を渡す、も同じ群。
- 処方: 接続詞を外して前後を読み、通じれば外したままにする。食い違いは「しかし」に言わせず、前の文と噛み合わない事実を次の文に置いて示す。
- 残す: 推理の論証、理屈っぽい語り手、拍のために置いた接続（削ると息が詰まるもの）。横滑り: 全部削って文が孤立する。

### 2.6 「……」「――」に間を任せる [K01 K02 K03]
奇数個・単独などの表記の誤りは N 群で、notation.md の管轄。ここは頻度と用法を扱う。
- 見分け（削除テスト）: 記号ごと、そこに挟まれた語句や続く言いさしを抜いて読む。文意が欠けなければ抜いたままにする。数ではなく用法で一つずつ判定する。
- 残す: 台詞の遮断、言いさし、声の引き伸ばし、内心の言いよどみ、因果や状態を補う間。声シートで宣言した口癖。作中のチャット文面。
- 削る: 単独で文になる同格説明の挿入（「彼――かつて〜と呼ばれた男――は」）。沈黙の代用としての「……」だけの台詞。
- 処方: 沈黙はまず、台詞のあいだの即物的な一文で作る。
  - 悪: 「……わかった」
  - 良: 義兄は爪楊枝の袋を四つに畳んだ。「わかった」
- 横滑り: 記号だけを句点に置換して電報体になる。「沈黙が落ちた」へ逃げる（1.8）。K01〜K03 が減って 1.8 が増えていたら直っていない。

### 2.7 理由を解説する文末・読点の均一 [K15 K17]
- K15: 「〜のだった」「〜のである」「〜からだ」「〜ためだ」で、行為の直後に語り手が理由を補う。理由の文を削って通じるなら削る。昔話調と回顧的な語り手は残す。
- K17 は位置の列挙だけで、読点の多い文は人間も普通に書く。見るのは均一さ、つまりどの文も読点二つで三分割という拍。音読して、読点のない短い文と、読点で息を継ぐ長い文が内容に応じて混ざっているかを確かめる。読点だけを足し引きせず、文の切り方から直す。

### 2.8 視点の破れと推量の両極 [lint なし。目視と編集役の指摘]
- 症状: 三人称一元なのに視点人物以外の内面を断定する（「戸川は内心あきれていた」）。逆に「〜ようだった」「〜らしい」が毎文に付く。
- 点検: 語りが保証する事実と人物の認識を分ける。偏見・願望・誤認は、その人物の認識なら断定形でもよい。
- 処方: 他人の内面は、視点人物に観察できる行動に置き換える。推量は、視点人物が実際に推し量っている箇所にだけ残す。
- 残す: 神視点・多元視点を文体シートで宣言した作品（切替は場面単位）。

## 3. 段落

### 3.1 段落の長さが揃う [P01 P02 P03]
- 点検: 各段落が「導入・展開・小さな締め」の同じ形に揃っていないか。
- 処方: 段落は情報かショットが変わったから切る。山場は、細かく割るか、改行なしで押し切るか、どちらかに振る。文を足して長さを変えるのではなく、切れ目を内容に合わせ直す。
- 残す: Web の短段落と空行は様式。その場合は場面間の密度差で見る。長段落が文体の作品。

### 3.2 段落末の小オチ・一行段落の決め台詞 [P04、T 群]
- 症状: 段落の最後が短い余韻文（「ただ、それだけだった。」「それで十分だった。」「返事はない。」）。「甘かった。」の類が独立段落で立つ。自問自答（「なぜか。決まっている。」）。山場でもないのに数文字の段落が続く（電報体）。
- 点検: 短くした末文が毎段落の締めになり、場面の強弱を消していないか。
- 見分け（削除テスト）: 段落末の一文をすべて消して読む。意味が通るなら、その文は物語世界を何も更新していない。歯切れのよさは残す理由にならない。拍の良し悪しを見るのは、その文が出来事・知覚・判断のどれかを足していると確かめたあと。
- 処方: 削る。段落を動作の途中で切る。一行段落は本当に止まりたい所だけにし、ほかは前後の段落に戻して因果で繋ぐ。
- 残す: コラム的な語り、落語調、ユーモア小説の語り手。情緒の頂点。声の乗った一行。
- 横滑り: 余韻文を削った跡に、予告文（6.4）や体言止め（2.3）を置き直す。

### 3.3 発生・知覚・反応を別段落に三段積みする
- 悪: 「電話が鳴った。」／「千賀は画面を見た。非通知だった。」／「胸がざわついた。」（／は改行）
- 良: 非通知の着信は三度目で、千賀は今度は布巾で手を拭いてから出た。
- 同類: 描写→内省→台詞の順が毎回同じ。編集役に段落を「描写／内省／台詞／行動」でラベルさせると見える。
- 処方: 知覚は出来事と反応と同じ段落に織り込む。場面ごとに配合を変える（ほぼ台詞だけの場面、内省が一行もない場面）。考えてから動く順を崩し、先に動かす。考えは動いたあとに置くか、書かない。

### 3.4 解像度が均一・感覚を順番に並べる
- 症状: すべての出来事を同じ詳しさで書く。視覚→聴覚→嗅覚を一文ずつ並べる。感情＋動作＋環境の三点セットが段落ごとに出る。連体修飾が三層四層に重なる。
- 見分け: この描写を削って、人物について何か失われるか。
- 処方: 効かせる感覚は関心の錨から選ぶ。借金を頼みに来た人は、相手の腕時計と車を見る。恋人の実家に初めて上がった人は、玄関の靴を数える。細部は時間の経過や背景の説明にではなく、動作、人と人の摩擦、関係にぶら下げる。半年を一段落で飛ばし、改札での二分に二ページ使う、という配分を場面ごとに決める。
- 横滑り: 「視覚のみ」の指摘に匂いを一、二行後付けする。足すなら錨と行為に結びつけて段落ごと書き直す。足さないのも正規の判断（keep）。

### 3.5 全段落が筋を進める・因果に隙がない
- 症状: どの文も前の文の直接の結果で、脱線も、死んだ手がかりも、無関係な観察もない。
- 処方: その場面と視点人物に属する脇筆だけを置く。確かめ方: その一文を抜いて読み、場面から情報か、空気か、人物どうしの関係のどれかが欠けるかを見る。何も欠けなければ飾りなので置かない。
- 横滑り: 一定間隔で脇筆を入れる、毎章一度「ずらした反応」を入れる。割り当てで入れたものは位置と型が揃い、新しい指紋になる。「湯呑みの湯気が細くなっていた」式の、時間の経過を物に語らせる脇筆は、とくに揃いやすい。

### 3.6 場面の入りと出が毎回同じ [O 群]
- 症状: 到着、目覚め、天気、「翌朝、〜は静まり返っていた」で入り、退出、就寝、感慨で出る。
- 見分け: 各場面の冒頭文と末尾文だけを抜き出して並べる（長編は canon/endings.log）。
- 処方: 揉めごとがもう始まっている時点から入る。決着がついたら、人物が噛みしめる前に切る。

## 4. 会話

### 4.1 聞き手が知っていることを読者のために言わせる [K24]
- 見分け: この情報を聞き手は既に知っているか。
- 処方: 事情を共有している二人は、指示語と省略で話す。読者に要る情報は、別の用事をしている会話からこぼれる形で出す。こぼれないなら地の文に回すか、出さずに済ませる。
  - 悪: 「お前も知っての通り、うちの別館は去年の台風で使えなくなっただろう」
  - 良: 「別館の鍵、まだ持ってる？」「持ってるけど。入るの」「保険屋が写真いるって」「床、抜けるよ。去年のままだから」
- 残す: 依頼人への説明、法廷、新人研修など、説明が場面の行為そのものである場合。

### 4.2 全員が同じ話し方をする
- 見分け: 台詞だけを抜き、話者名を伏せて別コンテキストに当てさせる（review-protocol.md の声の識別テスト）。語尾を均しても当たるか。
- 処方: 差は語尾より、語彙の層、文の長さ、質問への応じ方、言わないことでつける。声シートに戻る。
- 逆方向の失敗: 役割語の盛りすぎ（現代劇の「〜だわ」「〜のよ」「〜じゃ」）。口癖を毎台詞に入れる。
- 残す: 時代物、契約で許した役割語の人物、方言。

### 4.3 一問一答のピンポン・答えが論理的すぎる [D02 D03]
- 症状: 質問と直接回答が完全に対応する。誰も遮らない、聞き返さない。「元気だった？」「うん、元気」式の、何も運ばない挨拶の往復。
- 処方: 相手に何をさせたいかから応答を選び直す。隠す理由があれば迂回し、直言や直接の回答が事態を変えるなら残す。動作を挟むだけで済ませない。
  - 悪: 「会社、辞めたって本当？」「うん、先月辞めたんだ」
  - 良: 「会社、辞めたって本当？」「ばあちゃんの柿、今年は誰が採るの」「話そらさないで」「そらしてない。採る人がいないなら、俺が採る」
- 残す: 尋問、面接、几帳面な人物。声の違う二人の掛け合い。場面カードの宣言は D02 の keep の根拠にできるが、警報線を変えるには overrides を使う。
- 横滑り: 全台詞の前に動作を置く（4.5）。毎回ずらして会話が一歩も進まない。

### 4.4 台詞が書き言葉・相槌がない・名前を呼びすぎる
- 症状: 全台詞が主語述語の揃った完全文。短い相槌がほとんどない。長台詞が相手の反応なしに続く。二人きりなのに台詞のたび相手の名を呼ぶ（呼びかけが注意喚起・叱責・甘えなどの働きを持つかを見る）。
- 処方: 言いさし、倒置、助詞落ち、繰り返し。長台詞は相手の反応と行為で割る。ひとつの「」はひとつの発話。
- 残す: 学者や几帳面な人物の完全文（設定）。告白・演説の山場。三人以上の場面の宛先指定。呼び方の変化が関係の変化を示す箇所。

### 4.5 タグとビートの定型 [K25 K19]
- 症状: 台詞ごとに「と微笑んだ」「と頷いた」「ため息をついた」「首を傾げた」「目を細めた」。副詞つきタグ（「と静かに告げた」）。全台詞にビートが付く。
- 処方の順: 省略（口調と文脈で分かる）＞素のタグ（言った、訊いた）＞場面固有の物を使うビート（検品の端末、剪定ばさみ、回覧板）＞装飾タグ。「と言った」は読者に透明なので直さない。
- 横滑り: 装飾タグを消した分が、全台詞への動作ビートになる。話者の手がかりを足すのは、読者役が実際に取り違えた箇所だけ。

### 4.6 心情と主題を台詞で言ってしまう
- 処方: 相手への働きかけとして読む。告白・要求・拒絶・宣言が出来事なら直言させる。隠す理由がある人物には迂回を選べる。主題を代弁するだけの台詞と分ける。
  - 直言する例（本人が伝えると決めた場面）: 「本当はね、お母さんに一度でいいから褒めてほしかったんだと思う」
  - 迂回する例（まだ伝える決心がつかない場面）: 「お母さん、県展のときの絵、まだある？」「どの絵」「いい。なんでもない」
- 残す: 抑えに抑えた末の決壊。通俗短編の直球（契約）。台詞内の感情語そのものは直さない（0.4 の 2）。

## 5. 感情

### 5.1 感情の名指しと身体反応テンプレ [K08 K09、合算値で見る]
- 症状（名指し）: 地の文の「悲しみが込み上げた」「不安を覚えた」「安堵した」。
- 症状（テンプレ）: 息を呑む、胸が締め付けられる、涙が頬を伝う、拳を握る、唇を噛む、声が震える、視線を落とす、目を見開く、喉の奥が熱い、心臓が跳ねる、背筋が凍る。
- 点検: 名指しを減らした箇所で身体反応の定型が増えていないか。逆の置換も見る。
- 共通の規則:
  1. 片方の警報だけを見て直さない。
  2. 通過点は名指しで流してもよい。山場は名指し・行為・内面・比喩から声とジャンル契約に合うものを選ぶ。
  3. 二度書きしない。名指しの前後の文が新しい行動・知覚・判断を足していれば二度書きではない。言い換えなら片方を削る。残す手段はジャンル名だけで決めず、`emotion_naming` と作品への効果に従う。
  4. 同じ内容の説明を重ねない。新しい認識や感情の変化は続けてよい。
  5. 置換先が別の紋切り型なら keep。
- `restrained` で名指しも比喩も使わない場合: 行為／知覚の選択／時間感覚の歪み／言い間違いと沈黙などから選ぶ。手作業だけを繰り返さない。
  - 悪: 悲しみが込み上げ、胸が締め付けられた。涙が頬を伝った。
  - 良: 通夜から戻って、三好は父の長靴を洗った。泥はとうに乾いていて、たわしでこすっても溝に残った。洗い終えても干す場所が思いつかず、玄関のたたきに、履く人がいるときの向きで揃えて置いた。
- テンプレは「起きなかった」方向なら使える: 泣くだろうと思っていたのに、焼香の列で考えていたのは駐車券のことだった。
- 通俗短編（`emotion_naming = direct`）の一問: その文は主人公の今の主観感情を帯びているか。帯びていれば名指しでも残す。削るのは、具体が続かない感情の総括と、誰の感情でもない中立の解説。
- 残す: 自己分析的な一人称、名指しが後で裏切られる場合、児童向け、恋愛・ホラーの読者が期待する一定量の身体反応（契約）。
- 横滑り: 固有の癖を毎場面で連打する。テンプレの部位だけ替える（胸→喉→指先）。

### 5.2 模範的な反応・感情を対にして均す
- 症状: 人物が常に最も妥当な反応をする。「期待と不安が入り混じった」「嬉しさと寂しさが同時に」と対に並べる。複雑な感情を一覧にする。
- 処方: 対は強い側だけ残す。反応はその人物の性格か場面の圧力から出す。安全な表現より偏った表現。
- 横滑り: 「泣く場面で笑う」を割り当てで入れる。来歴のないずらしは模範解答と同じく型。

### 5.3 内心の分析レポート
- 症状: 地の文で自己分析が何文も続く。「一方では…他方では…」。二つの声が討論する。
- 処方: 結論だけ残す。残りは行為に回すか削る。
- 残す: 内面の言語化そのものが価値の一人称文芸、饒舌な一人称ラノベ（文体シートで宣言）。直すのは中身のない感情の総括だけ。

### 5.4 すぐ和解する・全員が善人・情調が単色
- 症状: 対立が提示された同じ場面で「ごめん」「ありがとう」に着く。敵対者に言い分がない。主人公が一度も間違えない。しんみり一色、温かさ一色。
- 見分け: 敵対者の言い分を、本人が納得する形で一文に書けるか。主人公は作中で一度でも判断を誤るか。
- 処方（構成に戻る。structure.md、character.md）: 対立は場面をまたがせる。和解には代償を払わせ、未解決の糸を一本残す。主人公に取り返しのつかない小さな失敗。感情に不純物を混ぜる（見舞いの帰りに特売の時間を気にしている、別れ話のあいだ足がしびれている）。
- 残す: 掌編。和解が主題ではなく前提の話。文の推敲では直らず筋に触れるので、revise モードのユーザー原稿では提案に留める。

## 6. 構造

### 6.1 場面のあとで意味を言い直す [K23、段落末なら P04]
- 症状: 「こうして、姉妹の夏は終わった。」「それが、彼女なりの返事だった。」「彼はやっと分かった。〜ということが。」出来事のあとに「いくつもの思いが胸を去来した」とラベルで要約する。
- 見分け: 出来事・知覚・判断を足すか、語り手の声・時間の整理・読者との関係を作るか。誰の声でもない中立の言い直しを削る候補にする。
- 処方（三段）: 削って前後を読む。つながれば終わり。つながらないなら、その文が指そうとした内容を出来事の側の文に書き換える。書き換えても声や時間の整理を含め何も足さないなら、文ごと削って繋ぎを直す。短く整形しただけのものは直っていない。
- 残す: 人格のある語り手の介入、枠物語の枠の開閉、手記・書簡体、回想の時点を示す標識。いずれも文体シートで先に決めてある場合。

### 6.2 きれいにまとめる結末 [O02]
- 症状: 顔を上げる、空を見上げる、朝日、一歩を踏み出す、「きっと大丈夫」。最終文が抽象名詞で終わる。冒頭の像に戻る円環を毎作やる。
- 見分け: 最後の段落を消して、一つ前で終われないか。
- 処方: 結末を三通り考える（片がつく／片はつくが別の何かを手放す／片がつかないまま、ひとつの像で止める）。冒頭で立てた問いにいちばん嘘のないものを採る。最後の一文は物か行為にする。筋の上の問いには答え、人物の気持ちの行方は決めずに置く。
  - 悪: 朝日が差し込んでいた。新しい一日が始まる。私は一歩を踏み出した。
  - 良: 合鍵は郵便受けに入れた。入れてから、自転車の鍵も同じ輪に付けていたことを思い出したが、郵便受けの口には指が二本しか入らなかった。駅まで歩くことにした。
- 残す: ジャンル契約（ロマンスの成就、児童書、お仕事小説）。成功そのものが報酬になる結末には、新しい不利益を足さなくてよい。
- 横滑り: 材料を渡さずに黙って「余白」と称する。省略した箇所ごとに、埋める手がかりが本文のどこにあるかを指せること。

### 6.3 主題・教訓を口に出す
- 症状: 「大切なのは〜」「本当の〜とは」。依頼文の主題語（許し、絆、居場所、再生）が本文に出る。「テーマは喪失と再生」と頼まれて「再生」と書く。
- 処方: 依頼文のキーワードで本文を検索し、当たった文を削る。主題語は題名にも台詞にも使わない。
- 残す: 寓話。説教をしたがる語り手（ただし読者がその説教を鵜呑みにできない書き方で）。

### 6.4 語り手が先回りして予告する [O02]
- 症状: 「このときはまだ知らなかった」「〜とは知る由もなかった」「これは始まりに過ぎなかった」「運命の歯車が」。
- 処方: 章は行為・台詞・像で切る。引きが要るなら出来事で引く（着信、扉が開く、来るはずの人が来ない）。
- 残す: `chapter_hook = required` の連載でも、引くのは出来事で。余韻で切る回は正規の型。語りの設計として先説法を宣言した作品。通俗短編の予告（契約）。
- 横滑り: 偽の危機で切って、次話の頭で偶然に解く。全文を末文の証拠集めにする。

### 6.5 助手の仕事ぶりが筋に漏れる（報告体・小さな完結）
- 症状: 人物が用件を受け、順にこなし、全部済んだことを確かめて場面が終わる。数百字ごとに小さな問題が起きては、その場で解決する。ひとつの場面で了承・合意・確定が何度も取れる。出かける前の段取り（連絡、下調べ、役割分担、移動）を全部書き、時間どおりに着く。教わった人が一度失敗し、直され、場面の終わりには上達している。同じ金額や日数を、地の文と脇役の台詞で二度確かめる。
- 点検: 行動のあとに確認と報告が毎回付き、すでに伝わった内容を重ねていないか。
- 見分け: その段落は「〜を済ませ、〜を確かめ、〜を手配した」と業務日報の一行に要約できてしまうか。まだ決まっていないことを、決まったこととして書いていないか。
- 処方: 人物にやらせるのは、いま手の届く一手だけ。その一手も半分しかうまくいかない。相手の返事は期待とずれる。裏づけは揃いきらない。そして、この場面では片づけずに次へ持ち越す事柄をひとつ決める。
  - 悪: 柿沼は資料を確認し、先方に電話をかけ、了承を得て日程を確定させた。これで準備は整った。
  - 良: 先方の電話は三回鳴って留守電に切り替わった。柿沼は用件を半分まで吹き込んだところで日付を一日間違えていることに気づき、そのまま切った。
- 同類（思い出を並べて結論を出す）: 回想で品物や場面をいくつも並べ、最後に「父は、ずっと見ていてくれたのだ」と結論を出す。きれいに繋がる思い出は一本あれば足りる。ほかは、記憶が食い違う、腹の立つ記憶が混ざる、思い出す途中で邪魔が入る、のどれかにする。結論の文は削る（6.1）。
- 残す: 快楽の回収が契約の場面（逆転、ざまぁ）。その場合も明確な受領は一場面にひとつ。

### 6.6 三つ並べて整える・対称にする [lint なし。個数宣言は C06]
- 症状: 名詞の三点列挙、「〜かもしれない」の三連、否定の三連、「A でも B でもなく C」。章末の「灯りが消えた。声が途絶えた。夜だけが残った。」
- 見分け: 一本削ると情報が減るか。三本が同じことを言っているなら、最も強い一本にする。
- 処方: 二つか四つにする。一つに絞って詳しく書く。最後の一つを異質にする。
  - 悪: 祖母の部屋には、樟脳と線香と古い畳の匂いがした。
  - 良: 祖母の部屋は樟脳がきつい。箪笥を開けると、その奥から、去年のバザーで買ったというラベンダーの匂い袋が二つ出てきた。
- 残す: 具体物の列挙。演説・弁論をする人物の排比。

### 6.7 偶然と後出しで解決する
- 見分け: 「偶然」「たまたま」「ちょうどそのとき」。手紙・日記・遺書・写真・録音が終盤で初めて出る。事故、難病、双子、遺言。
- 規則: 偶然が人物を困らせるのは通る。偶然が人物を助けるのは通らない。転機は人物の過去の行動と、既に示した世界の決まりから出す。処方は構成側（structure.md の事前登場）。
- 残す: 偶然そのものが主題の話、コメディ。

### 6.8 冒頭の設定説明・山場直前の答え合わせ [O 群、P05]
- 症状: 冒頭に年齢・職業・来歴の列挙。天気、目覚め、アラーム。風景や容姿を形容詞で塗り重ねる書き出し。山場の直前の地の文が、これから明かす事実や数字を先に要約する。盛り上がった直後に説明や弁明を挟んで熱を冷ます。
- 処方: 人物が何かをしている最中から書き出す。年齢や職業は、場面がそれを必要とした時点でひとつずつ出す。山場で使う事実・数字・固有名は、直前の地の文で漏らさない。

## 7. 設定

### 7.1 名前が最頻値
- 症状: その世代の命名ランキング最上位の名。月・星・桜・水のつく美称姓か、最多数の姓。主要人物の頭文字や拍数が揃う。
- 処方: 一度本文に出た名前は canon で、推敲で勝手に替えない。未出の人物だけ character.md の命名手順（生年・土地・家の命名の癖から決め、候補を複数出してユーザーに選ばせる）に戻る。決めた名は決定ログに残し、再生成で揺らさない。
- 残す: どこにでもいる人であることが意味を持つ人物の、ありふれた名。ラノベの華やかな名は様式。

### 7.2 舞台・職業・小道具・モチーフが最頻値
- 症状: 喫茶店、古書店、図書館、海辺の町、雨の日、夕暮れ、屋上、祖母の家。写真家、画家、ピアニスト、司書。古い手紙、懐中時計、オルゴール、色褪せた写真。喪失はいつも祖母の死。モチーフは月、星、光、影、雨、桜、海、時計、鍵、扉。題名に「最後の」「永遠」「約束」「記憶」。
- 処方: 設計段階なら初案を捨てる（short-pipeline.md）。書いたあとなら、舞台は替えずにその中で固有化する。喫茶店なら、ランチのあとに豆を挽き直す時刻、灰皿を出す席と出さない席、レジ横に輪ゴムで束ねた回数券。モチーフは舞台と職業の実物から採り直す。クリーニング店なら、蒸気の音、針金ハンガー、預かり札の通し番号。
- 残す: ユーザーが指定した舞台（その中で固有化する）。

### 7.3 無国籍と、その裏返しの飾りの精密さ
- 症状 A（無国籍・安全化）: いつ・どこの話か分からない。値段、機種、方言、病名、金額、手続きが出てこない。
- 症状 B（飾りの精密さ）: 「午前二時十七分」「走行距離八万四千キロ」のような、あとで一度も使われない精密な数字。二度と出ない脇役のフルネーム。
- 点検: A の舞台や人物に固有の事情があるか。B の数字や固有名に、場面での役割と確認先があるか。
- 見分け: その具体は、人物の暮らし・選択・力関係のどれかを教えているか。
  - 良: 時給は県の最低賃金ちょうどで、毎年十月、最賃が上がった分だけ明細の数字も上がる。店長はそれを昇給と呼んだ。
- 処方: A は、年・月・場所・収入・移動手段を決め、場面で必要になった一つだけを出す。B は削る。確かめていない事実（制度、相場、路線、専門の手順）は滑らかに書かず、`[要確認]` としてユーザーに申告する。

### 7.4 繊細な文章と初歩的な誤りの同居
- 症状: 凝った描写の中に、物理的に通らない像（逆光の相手の瞳の色が見える、灯りのない真夜中に表情を読む）、季節と植物の不一致、手順の飛び。
- 処方: 像を一つずつ、視点人物の位置から実際に見えるか、その時季にあるかで確かめる。心象は現実に起こりうるものに限る。

### 7.5 世界にない語が混ざる [G 群]
- 症状: 時代物・異世界に、現代の技術語、ネットスラング、心理学用語（トラウマ、メンタル、ストレス）、現代の制度と職業、メートル・分・パーセント。その人物が知らないはずの物で喩える。
- 処方: 世界の中の機能等価な表現に翻訳する。翻訳が立たないなら概念ごと削り、感覚と行動で伝える。対応は glossary.toml に足す。

## 8. メタ

### 8.1 前置き・後書き・解説が本文に入る [M 群]
「以下は」「いかがでしたか」「（続く）」、字数の注記、あらすじ、執筆メモ、Markdown の装飾。本文ファイルには本文だけを置く。前提や申告はチャット側に短く。M 群は保存事故（本文が空、極端に短い）も拾う。

### 8.2 装置の名前が本文に漏れる [X 群]
- 症状: 「緊張を作れ」と指示されて「空気が張りつめた」と書く。「伏線のように」「この沈黙にはサブテキストがあった」「五感のすべてで感じ取った」。場面カードや指示の語彙（関心の錨、フック、山場）が地の文に出る。
- 処方: 語を削り、その装置を内容の側で実現し直す。装置が働いていれば読者は装置に気づかない。
- 残す: 創作や演劇を題材にした作品で、人物がその語を使う場合。

### 8.3 後半が要約になる・尻すぼみ
- 見分け: 作品を四分割し、会話の割合、平均文長、「数日が過ぎた」型の時間飛ばしを比べる（`novel_lint.py --stats`）。終盤で台詞が減り、飛ばしが集中していれば要約に落ちている。場面数が設計より減っていないか。
- 処方: 後半の場面を場面カードから書き直す。字数は `count_chars.py` の実測だけを信じる。不足は出来事と台詞で埋める。水増しは三つの形で出る。同じ内省を言い換えて繰り返す、形容を重ねる、読者がもう知っていることを説明し直す。

### 8.4 直すたびに無難になる
- 症状: 改稿で良い破調が均される。指摘外の箇所まで書き換わる。口癖、方言、数字、台詞が潰れる。AI 臭対策そのものが型になる（3.5、5.2 の横滑り）。
- 処方: revision.md の手順（保護する長所を先に決める、差分改稿、前版との盲検比較、負けたら戻す）。同じ種類の直し（語の入替、物の入替、順序の入替）を繰り返して改善がなければ、同種をやめて構造に戻るか巻き戻す。

### 8.5 長編の口調ドリフトと再紹介・暗い場面の丸め
- 長編で口調が流れる、人物を毎章紹介し直す: 処方は longform.md（コンテキストパック、呼称表、状態スナップショット）。推敲では、各章の人物初出の一文を並べ、今回の判断に役立たない説明の重複を削る。更新間隔を挟んだ読者に関係や未解決の用件を思い出させ、新しい判断の材料にする再提示は残す（genres.md の Web 連載）。
- 暴力や悪意の場面で暗転する、婉曲にする、語り手が道徳的な注釈を挟む、悪役が自分の非を説明する: 必要な暗さの水準をユーザーと合意して決定ログに残す。語り手の評価は声とジャンル契約に照らし、中立の道徳的な言い直しを足さない。

## 9. 数え上げの誤り [C01〜C08]

LLM の字数・音数の申告は誤ることがある。「ありがとう」を四文字と書けば、実数の五文字と食い違う。本文で数を言う箇所は外部計算で確かめる。

C01・C03 が FAIL にするのは、断定と読める二つの形だけ: 同格形（「X」の／という N 文字）と、コピュラで言い切る主題形（「X」は N 文字だ）。伝聞・思い込み・仮定・疑問・比較・否定・訂正、人物の台詞や引用の中の言及、引用の前に出どころの語がある文、記号や空白を含む語は、lint がそれと検知できた場合は WARN（要確認）に回る。ただし文脈の検知には取りこぼしがあり、FAIL の中に誤検出が混じることも、WARN の中に本当の誤りがあることもある。FAIL も WARN も、前後の本文を読んで数を確かめてから処置する。「N 音」は拍で数え、子音・母音・音節の話は対象外。C08 は年月日と曜日の食い違いと、年があれば曜日なしでも存在しない日付を知らせる。C05〜C07・C09 は案内のみ。C02・C04 や年齢・経過日数・画数・文字遊びは別途検算し、C 群が静かでも正しさの根拠にしない。

- 対象: 字数・音数・画数・個数を明示する表現。「〜の二文字」「たった三文字の言葉」「五七五」「頭文字を繋ぐと」「N 番目の文字」「回文」「しりとり」「アナグラム」「三つの理由（と言って列挙数が違う）」。年齢、日付、曜日、経過日数の計算。
- 規則: 書いたら必ず検算する。手段は lint の C 群か、Python での明示的な計算。検算できない、または面倒なら、数を言わない表現に書き換える（「その短い言葉」「たった一言」）。「一言」「ひとこと」は数え上げではないので使ってよい。
  - 悪: 「ごめんなさい」の五文字が、どうしても言えなかった。（実数は六）
  - 良: 「ごめんなさい」の六文字が、どうしても言えなかった。
  - 良（数を言わない）: その一言が、どうしても言えなかった。

| ID | 見るもの | 重大度 | すること |
|---|---|---|---|
| C01 | 「X」の N 文字／N 文字の言葉「X」 | FAIL | 前後の本文を読み、何を数えているか確かめる（語の一部を消す・書く話、人物の数え間違いではないか）。本文の誤りと確認できた場合だけ、数を実数に直すか、数を言わない形にする。誤検出・意図した表現は理由つき keep、判断不能は本文を変えず要確認 |
| C02 | 括弧なしの語＋ N 文字 | WARN（ひらがな語は INFO） | 目で数える |
| C03 | N 音、N 拍 | FAIL（漢字を含めば WARN） | かなに開いて拍で数える |
| C04 | 俳句・川柳・短歌らしき引用 | WARN | 同上 |
| C05 | 頭文字、縦読み、アナグラム、回文、しりとり、N 番目の文字、画数 | INFO | Python で検算する |
| C06 | 「三つの理由」型の個数宣言 | INFO | 列挙を数える |
| C07 | 上のどれにも当たらない「N 文字」の言及（ひらがな語など） | INFO | 対象の語を決めて `count_chars.py --text "語"` で数える |
| C08 | 「年月日＋曜日」の食い違い、存在しない日付 | WARN | 暦と照合する。年齢・経過日数は別途検算 |

- 字数は「」の中の表記どおりに数える（約物、空白、ルビ記法は除く）。表記が変われば数も変わる。「絆」は一文字、「きずな」は三文字。推敲で漢字をかなに開いたら数え直す。
- 拍: 小書きの「ゃゅょ」などは前の字と合わせて一拍。促音「っ」、撥音「ん」、長音「ー」は各一拍。「きょうと」は三拍、「がっこう」は四拍。漢字を含む句は読みを決めてから数える。
- 検算の例（Windows でも文字化けしないよう UTF-8 モードで）:

```
python -X utf8 -c "print(len('ごめんなさい'))"
python -X utf8 -c "import datetime as d; print('月火水木金土日'[d.date(2019,5,1).weekday()])"
python -X utf8 -c "s='たけやぶやけた'; print(s==s[::-1])"
```

- 残す: 人物が数え間違えること自体が演出の場合。地の文か別の人物に訂正させ、誤りが作者のものに見えない形にする。lint の FAIL が残る場合があるので、keep の理由を処置記録に残す（処置済みの FAIL は残ってよい）。
- 横滑り: 数を直したら前後（「六つ数えるあいだ」など）と食い違う。縦読みや頭文字のように数と位置に依存する仕掛けは、本文を一字でも直したら検算をやり直す。
