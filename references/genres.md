# ジャンル契約

いつ読むか: 企画・設計でジャンルが決まったとき。`novel.toml` の `[contract]` と世界制約を書くとき。「もっと怖く」「テンプレ通りに」のようにジャンルの効き方を調整するとき。読むのは §1〜§3 と該当ジャンルの節（複合ジャンルは主 1 つ＋副 1 つまで）。flash は該当ジャンルの節だけでよい。
いつ読まないか: 場面の執筆中（契約は文体シートとコンテキストパック経由で届く）。文の直し方は revision.md、lint ヒットの処方は ai-tells.md。

- §5 ジャンル読者への問い

## 1. ジャンル契約の書き方

### 1.1 なぜ書くか

読者はジャンルが約束した快楽を受け取りに来る。LLM は放っておくと、どのジャンルも「破綻のない一般小説」へ均す。怪談の結末で原因を説明し、見返しものの悪役を改心させ、ミステリの手がかりを地の文で指差し、児童向けを教訓で締める。推敲でも同じ事故が起きる。汎用規則を一律に当てると、怪談の規則文の反復、物証の同じ呼び名の反復、通俗短編の感情の直書きといった、そのジャンルで機能している様式が「癖」として削られる。契約は、書く側と直す側の両方にこの作品の約束を見せるためにあり、レビュー役と書き手はこれを読み、lint は対応する設定だけを使う。

### 1.2 四つの欄

| 欄 | 置き場 | 書くこと |
|---|---|---|
| 約束する快楽 | `novel.toml` `[contract] promise` | 読者が毎章（毎話）受け取る体験を 1 文 |
| 様式として残すもの | `[contract] keep` | 汎用規則なら直す対象だが、この作品では機能している反復・直書き・型 |
| 切り替え値 | `chapter_hook`（required / optional / off）、`emotion_naming`（restrained / balanced / direct） | 章末の引きが契約か、感情の名指しをどこまで売りにするか |
| lint の例外 | 文体シートの例外宣言欄 | ルール ID と理由 1 行（書式は style-sheet.md） |

世界制約（§3）は `style/glossary.toml` に置く。short は `notes.md` の契約欄に同じ内容を 2〜3 行で書き、flash はファイルを作らず promise と keep を頭の中で決めてから書く。§4 の各節にある「既定値」は、プロファイルの既定を上書きする初期値で、`novel.toml` に書いた時点からそちらが正本になる。

記入例（はんこ屋の連作。ライト文芸と日常の謎の複合）:

```toml
[contract]
promise = "毎話、注文された印鑑一本から、依頼人が名前を変える事情が見えてくる。店主は最後まで理由を訊かない"
keep = [
  "書体と印材は正式名で呼び、初出の呼び名を変えない（手がかりを遡れるように）",
  "代金は端数まで書く",
  "結びで店主が事情を言い当てない。分かるのは読者だけ",
]
chapter_hook = "optional"
emotion_naming = "balanced"
```

### 1.3 promise

読者の体験で書く。ジャンル名・舞台・雰囲気を並べた「はんこ屋を舞台に人の絆を描く心温まる物語」は何も約束していない。上の記入例は、毎話なにが起き、なにが起きないかまで決めている。起きないこと（店主は訊かない、誰も裁かれない、原因は明かされない）を入れると、LLM が親切心で足してしまう場面を先に止められる。

promise の使い道は四つある。章ビートの `reader_should` と照合する。Web 連載では序盤の早い回で一度実演する。推敲で汎用規則と売りが衝突したら売りを残す。レビューではジャンル読者に「約束のものを受け取ったか」を訊く（§5）。

### 1.4 keep（「消すな」リスト）

「何を・なぜ残すか」を 1 行ずつ。推敲と lint の fix / keep 判定で、keep の理由としてそのまま引ける形にする。§4 の各節に候補があるが、全部を写さない。この作品で実際に使う様式だけを選ぶ。使わない様式まで宣言すると、その分だけ検査が素通しになる。

keep に入れてよいかは一問で判定できる。**その反復や直書きを消したら、このジャンルの読者は何かを失うか。** 失うなら様式、失わないなら手癖。怪談で禁忌の文言を毎回同じ形で繰り返すのは、破られる瞬間のための仕込みなので様式。全場面の結びに余韻めいた一文が付くのは、どのジャンルでも手癖。§4 の keep 候補に「契約があっても直す」ものを併記したのは、この区別のため。

### 1.5 lint の緩め方

- `emotion_naming` は lint も読む。`chapter_hook` はレビュー役と書き手が読む設定で、lint は読まない。O 群は定型的な冒頭・結びの表現を INFO で示すだけで、結びの開閉を判定しない。それで足りない分は、ルール ID と理由を文体シートの例外宣言に書く。承認済みの章が 3 本たまったら `calibrate.py` に任せる。
- 較正で動かすのは統計・密度の警報。lint の FAIL は表記の機械的な誤り（N）、数え上げの不一致（C）、本文が空（M01）。作者の表記の流儀は overrides で止められる（style-sheet.md）。数の事実誤りは直し、投稿先の規定にも従う。
- 片側を緩めたら対の指標を見る。名指し（K08）を緩めた作品では、身体反応テンプレ（K09）と「名指しの直後が言い換えになっている文」が増えやすい。名指しを締めた作品では K09 が膨らむ。
- 緩めるのは密度で、同一表現の再出は緩めない。ときめきの描写が多くてよい恋愛でも、同じ部位の同じ反応が続けば直す。

### 1.6 外し方、複合、丸めないこと

- **テンプレを外すときは 1〜2 点だけ**（舞台・職業・能力の制約・関係性のどれか）。全部外すと、そのジャンルを読みに来た人に渡すものがなくなる。約束そのものを破るなら、破ること自体を売りとして冒頭から見せる。
- **複合ジャンルは主契約を 1 つ決める。** 結末の形を決めるほうが主（恋愛ミステリで、謎が解けなくても二人が結ばれれば成立するなら主は恋愛）。副ジャンルの様式は keep に 1〜2 行入れる。
- **契約を安全側に丸めない。** LLM は怪談を怖くない方へ、苦い結末を和解へ、悪役を物分かりのよい人へ寄せる。ユーザーが指定した結末と強度はそのまま書く。避ける線は具体に限る（実在の個人・団体・事件の中傷、差別の肯定、未成年の性的描写など）。ジャンルの強度そのものは抑制の対象にしない。
- **爽快さを加害の過激さで稼がない。** 見返しや復讐の快楽は、報いが加害と対応していることから来る。描くのは不公平の具体で、加害の強度を競わない。脇役を、主人公を持ち上げるためだけに置かない。

## 2. 調整ノブ

「もっと怖く」「もっと甘く」は、どの軸を動かすかが決まらないと、形容と感嘆符が増えるだけになる。ジャンルごとに軸を 3〜4 本持ち、依頼をどれかの軸の移動として受け取る。決めかねるときは軸を 2 つ示してユーザーに選んでもらう。

| ジャンル | 軸 |
|---|---|
| ホラー・怪談 | 恐怖の質（驚き／不気味／哀切）、怪異の説明度、救いの有無、語りの距離（本人／伝聞） |
| ミステリ | 読者への公平さ（本格／サスペンス寄り）、後味、探偵役の内面をどこまで見せるか |
| 恋愛 | 障害の所在（内的／外的）、甘さと辛さの配分、成就をどこまで明示するか |
| SF | 嘘の大きさ、説明の密度、生活描写と思弁の比 |
| ファンタジー・異世界 | 力の上限、語彙の徹底度（§3）、世界説明の密度 |
| Web 系テンプレ | ストレス展開の許容量、報いの強さ、テンプレからずらす 1〜2 点 |
| 純文学寄り | 語りの距離、筋の濃さ、結びの開き具合 |

強度は設計で上げる。怪談なら説明度を下げ、語りを平熱にし、違和感を日常の細部へ近づける。恋愛なら障害を硬くする。

## 3. 世界制約リスト（3 区分）

LLM は現代日本語の高頻度語へ戻る。「大正時代です」という肯定形の設定より、「この世界にはこれが無い」という具体の一覧のほうが守られ、機械照合もできる。これは世界設定であって癖語の一覧とは性質が違う（その文脈でもともと出にくい語なので、見せても引き寄せにくい）。だから執筆時に渡してよく、コンテキストパックに入る。世界観が固まった時点で `style/glossary.toml` に書く。

| 区分 | 中身 | 例 | 置き場と照合 |
|---|---|---|---|
| 1 存在しない語彙 | その時代・世界に無い言葉 | 時代物の外来語や近代の訳語、異世界のメートルや曜日 | `[constraints] forbidden_words`。lint の G 群が部分一致で拾う |
| 2 存在しない概念 | 言葉を替えても持ち込めない制度・物・発想 | 電気の無い世界の「スイッチが入る」、身分制社会の「プライバシー」 | `absent_concepts`。語では拾えないので、校閲役と編集役が読む |
| 3 その人物が知らない | 世界には在るが、この人物の生活圏に無い | 山育ちの少女の医学用語、下働きの少年が語る宮廷の序列 | `[[constraints.unknown_to]]`。章ビートの knowledge 欄と併せて、台詞と内心の前提を確かめる |

- 区分 1 は「現代語 → 作中語」の対応で持つ。`[[terms]]` の canonical に作中語、variants に現代語を書くと、現代語の混入を表記ゆれ検査が拾い、パックには作中語だけが載る。置き換え先が決まっていれば書く側は迷わず、呼び名も揺れない。
- `forbidden_words` は部分一致なので、短い語は別の語の一部に当たる。時間の単位を禁じたいなら「分」ではなく「分後」「分ほど」「数分」のように、当たってほしい形で登録する。
- **比喩の素材も対象。** 語彙検査をすり抜ける時代錯誤は喩えに出る（映像の巻き戻し、電流、画面の切り替わり）。喩えは視点人物の手仕事と暮らしから取る。
- 度量衡・通貨・時刻・暦は最初に決める。異世界は「読者の言葉に訳されているものとして割り切る」か「徹底する」かを冒頭で選び、一貫させる。割り切る場合も、ことわざと宗教由来の慣用句は区分 2 に入れておく。
- 区分 3 は声シートと連動する。三人称一元や一人称なら、地の文の語彙もその人物の知識の範囲に収める。
- 現代ものにも使える。区分 3 を「この語り手が使わない語彙」と読み替えると、十四歳の語り手に大人の抽象語が混じるのを防げる。

## 4. ジャンル別

各節の「lint」はルール ID と名称だけを示す。警報線の数値は `thresholds.json`、執筆の目安は style-sheet.md にある。

### ミステリ

- **既定値** chapter_hook = optional / emotion_naming = restrained〜balanced
- **約束** 解決に要る手がかりは、解決の前にすべて読者の目の前を通っている。語り手は隠してよいが、偽らない。偶然は事件の発生には使えるが、解決には使えない。

**LLM が外しやすい点**
- 手がかりを地の文が指差す（視点人物に理由のない引っかかりを覚えさせ、後で「あのとき気づいていた」と言わせる）。その一文のせいで、読者は初読で通り過ぎられなくなる。
- 物証の呼び名を場面ごとに言い換える。同語の反復を避ける癖が、読者の遡りを不可能にする。
- 雰囲気のために具体物を撒く。ミステリでは数や状態の書かれた物はすべて手がかりの候補になるので、灰皿の吸殻の本数ひとつが偽の約束になる。
- 関係者が事件を順序立てて長々と語る。犯人が自白で全部を説明する。解決編に未登場の証拠が出る。

**こう書く**
- 手がかりには別の仕事をさせる。人物描写、笑い、視点人物の些細な不便として読める文に入れ、直後に別の話題で注意を流す。列挙なら真ん中に置く。
- 物証は初出の呼び名を `glossary.toml` に登録し、最後まで変えない。
- 台詞は情報戦。どの台詞も、手がかり・誤導・探りのどれかを運ぶ。人物が真実を言わない理由は事件の構造に置く（隠している内容そのものが手がかりになる。性格のせいにしない）。訊く側は短く、黙って待つ。訊かれる側は訊き返し、話を逸らす。
- 環境は物証の器。書き終えたら具体物を「手がかり／誤導／純粋な雰囲気」に仕分け、どれでもない数字と状態は消すか、機能を与える。
- 推理は消去で見せる。伏線台帳の note 欄に「この手がかりが誰を除外するか」を書いておくと、消去の順番が解決編の骨になる。
- 解決編は一人の長台詞にせず、聞き手の反論と確認で区切る。開示は、既出の物の意味が変わる形で行う。

対比例。悪い例:「柱時計の硝子蓋が開いていた。なぜか、それが気になった」。良い例:

　通夜振る舞いの座敷で、喪主の次男は客のあいだを回って酒を注ぎ、注ぎ終えるたびに銚子の口を布巾で拭っていた。
「昔からああなの。朝は仏壇の水を替えて、九時に帳場の柱時計を巻いて、それから暖簾を出す。先代が倒れてからこっち、一日だって抜かしたことがないんだから」
　叔母は多恵の猪口に勝手に注ぎ足し、あれで嫁の来手さえあればねえ、と声を落とした。多恵は終バスが気になって、襖の向こうの帳場を見た。柱時計の硝子蓋が半端に開いていて、蛍光灯が映りこみ、座ったままでは針が読めない。鞄から携帯を出すと八時を回っていた。腰を浮かせかけたところへ、叔母が煮しめの鉢を押しつけてくる。里芋はあの子が剥いたのよ、と言う。

几帳面さは銚子の口と叔母の愚痴で二度見せ、時計を巻く日課は三つ並べた真ん中に置いた。その男が毎朝触る硝子蓋が開いたままだという食い違いは、「針が読めない」という多恵の不便として通り過ぎ、すぐ煮しめが来る。地の文も多恵も、蓋については何も考えない。以後この物は必ず「硝子蓋」と呼び、扉やガラス戸に言い換えない。

- **keep 候補** 物証の同一呼称の反復／消去の推理に出る否定の連鎖と接続詞／解決編の長い台詞／取り調べの短い問いの連打。契約があっても直す: 視点人物の気づきを予告する文、場面末で謎の深まりをまとめる文。
- **lint** K04〜K06（文頭・段落頭の接続詞）と K16（否定対比）は推理場面で例外宣言。D01（会話比率）は場面の役割に合う条件を宣言（style-sheet.md）。表記ゆれ検査（G 群）は物証の呼称固定の味方として使う。
- **破ってよい場合** 倒叙・サスペンス・特殊設定ものは、その作品のルールを早い段階で明文化すれば公平さは保てる。日常の謎は事件が小さいだけで、公平さの約束は同じ。叙述の仕掛けは設計として宣言し、再読して地の文に偽りが一つもないことを確かめる。

### ホラー・怪談

- **既定値** chapter_hook = optional（掌編の怪談は off）/ emotion_naming = restrained。「短編の怪談」は一般の掌編の長さを指すことが多いので、字数で確認する。
- **約束** 読み終えたあとに不安が残る。説明されなかった部分が、読者の部屋までついてくる。

**LLM が外しやすい点**
- 結末で原因と正体を説明し、因果を閉じる。全部判明した話は謎解きとして読まれ、怖さは残らない。
- 恐怖を名指しし、名指しを避けると今度は汎用の身体反応を重ねる。どちらも語り手が読者の代わりに怖がってしまっている。
- 形容・擬音・感嘆符・約物で煽る。怪異を場面ごとに増やす。教訓や供養で締めて安心させる。怖くない方へ丸める（§1.6）。

**こう書く**
- 書く前に「この話の恐怖の核」を 1 行で言う。言えない怪談は怖くならない。核は日常の一点のずれに置き、最初の違和感は序盤のうちに、生活の細部として出す。
- 怪異は一つの規則の周りに集める。禁忌型なら、規則を示す → 誰かが破る → すぐ的中する、の順。規則の文言は毎回同じ形で繰り返す。
- 恐怖の場面ほど文は平熱にし、比喩を減らして事実の記述に寄せる。人物の反応は出来事より一段低くする（仕事を続ける、報告書に書く、鍵を返す）。
- 怪異の正体と原因は、明かすとしても半分まで。邪なものほど口調は家庭的で丁寧にする。
- 最終行は像か事実一つで切り、解釈を足さない。

例（実話怪談調）:

　設備点検の仕事をしている知人から聞いた話で、場所は県営団地としか教えてもらっていない。
　その団地の三階に、郵便受けをガムテープで塞いだ部屋が一つある。自治会費は毎月振り込まれているから空き部屋ではないはずだが、管理人は住人の顔を一度も見たことがないという。
　去年の秋、真下の二階から水漏れの連絡が入り、彼は管理人と合鍵で三階に入った。玄関に靴は一足もなく、台所の流しも風呂場も乾いている。濡れていたのは和室の畳だけで、それも部屋の真ん中が、座布団一枚ぶんほどの四角に色を変えていた。見上げた天井には染みひとつない。
　彼は畳を上げて床板を確かめ、報告書には配管に異常なしと書いた。翌月、同じ二階からまた連絡が来た。四角は前より窓のほうへ寄っていたそうだ。

怪異は「濡れた四角」一つだけで、恐怖の名指しも身体反応もない。彼は仕事をしただけで、四角が何なのかは誰も言わない。

| 下位類型 | 契約の違い |
|---|---|
| 実話怪談調 | 誰から・いつ頃聞いたか、何を伏せているかを冒頭 2〜3 文で確定する。因果を閉じない。体験者のその後は一行で足りる |
| 禁忌・因習型 | 規則の反復と的中が快楽。共同体の側の理屈を、丁寧な口調で語らせる |
| 意味が分かると怖い話 | 説明しない。読者が自力で到達する。最終行のあとに解説を足さない |
| 哀切型 | 正体は分かってよい。読後に残すのは、果たされなかったこと |

- **keep 候補** 規則文の反復／伝聞の枠（〜という、〜そうだ）の反復／平坦な報告体の文末の連続／閉じない結末。契約があっても直す: 恐怖の名指しの直後の言い換え、同じ身体反応の再出、擬音の単独行。
- **lint** R01（同一文末の連続）は報告体として例外宣言。D01 は目標を下げて宣言。O 群（冒頭と結び）は定型表現の INFO を読み、契約に照らして判断する。K09 はエンタメ寄りのホラー長編なら一段緩めてよい（怪談調では緩めない）。K01・K02（ダッシュ・三点リーダー）はどちらでも緩めず、間は文の切り方で作る。
- **破ってよい場合** モダンホラーの長編は原因の究明が筋になる。その場合も、解けるのは仕組みまでにして、なぜこの家だったのか、なぜこの人だったのかは残す。

### 恋愛

- **既定値** chapter_hook = optional（Web 連載は required）/ emotion_naming = balanced〜direct
- **約束** 二人の距離が動くこと。そして、そのジャンルが約束した結末（成就か、成就しなかったことの痛みか）。女性向け Web の溺愛・婚約破棄系では、相手役の誠実さそのものが契約になる。

**LLM が外しやすい点**
- 惹かれる理由が属性の列挙になる（優しい、顔がいい、仕事ができる）。
- 結ばれない理由が無い、または「話せば三分で解ける誤解」しか無い。逆に、誤解も対立も一度の会話で物分かりよく解いてしまう。
- 段階を飛ばす（知り合う → 探る → 曖昧 → 確定）。告白のあとに、同じ内容の感情の説明を繰り返す（受け止めや決断を書くのは繰り返しではない）。成就を約束した山場で、返事や喜びを言葉にする前に切り上げる。ときめきが毎回同じ部位の同じ反応になる。

**こう書く**
- 惹かれる理由は、その人にしかない具体の行為一つで見せる。
- 障害は内的なもの（本人の誤った信念）と外的なものを各 1 つ。探り合いの途中の回では、距離は、縮む → 引く → 縮む、で管理する（成就の山場には当てない。`scene-cards.md` の恋愛のカード）。
- ときめきは部位と書き方を毎回替える。相手の持ち物、癖、言い間違いへの視線は、身体反応より長持ちする。
- 溺愛系は辛い区間を短くし、誤解は早く解く。すれ違いを売りにする作品では逆に、障害を客観的な事情か善意の秘匿で硬くする。

　貸した傘は、曲がっていた骨が一本、まっすぐになって返ってきた。礼を言うと三好さんは、曲がってるのを見ると気になるだけ、と言い、私の鞄の肩紐のねじれまで直してから席に戻った。

- **keep 候補** 一人称の饒舌な内心／感情の名指し／相手役の決まった呼びかけや癖の反復。契約があっても直す: 同一の身体反応の再出、名指しの直後の言い換え、相手役が欲も欠点も持たないこと。
- **lint** K08・K09 を一段緩める。K07（フィルタ・認知動詞）は内心語りが売りの一人称なら例外宣言。
- **破ってよい場合** 失恋・片恋を書く文芸寄りの恋愛は成就を約束しない。promise にそう書く。

### SF

- **既定値** chapter_hook = optional / emotion_naming = balanced
- **約束（選ぶ）** 仮定の帰結を追う／異なる世界像を体験する／技術と社会の衝突を描く。仮定の数は制限せず、相互の関係と成り立つ条件を整理する。

**LLM が外しやすい点**

**こう書く**

- 実在の科学に触れる箇所は、確かめるか、ぼかす。確かめられなかった箇所は提出時にユーザーへ伝える。

- **keep 候補** 造語の反復／報告書・ログ・規約など作中文書の文体。
- **lint** G 群に造語を登録する。作中文書へのヒットは様式を理由に keep。
- **選択肢** 奇想・不条理寄りでは像の強さを主にできる。複数の仮定を置く場合も、互いの働きと作品内の一貫性を確かめる。

### ファンタジー・異世界

- **既定値** chapter_hook = Web なら required、書籍なら optional / emotion_naming = balanced（Web は direct 寄り）
- **約束** この世界のルールの中で問題が解かれる。魔法にはコストと限界があり、限界が物語を作る。

**LLM が外しやすい点**
- 強さが場面の都合で伸び縮みする。コストを忘れる。窮地で新能力が出る。
- 世界説明を冒頭に積む。固有名詞を一度に大量に出す。

### 時代小説

- **既定値** chapter_hook = optional / emotion_naming = balanced
- **約束** その時代の暮らしの手触りと、身分や掟が生む、現代には無い不自由。

**LLM が外しやすい点**
- 考証を自信ありげに捏造する（年号、役職、物価、地名）。
- 台詞は時代がかっているのに、地の文と喩えが現代のまま。近代の訳語（社会、自由、時間を守る、の近代的な用法）が混入する。
- 現代の価値観を持つ主人公が、周囲を啓蒙する。

**こう書く**
- 台詞は「それらしい現代語」を基本にする。完全な当時語は読めない。避けるのは、明らかな近代語とカタカナ語。
- 時刻・暦・貨幣・身分と呼称は §3 の対応で最初に固める。喩えは人物の生業から取る。
- 確かめられない史実は書かないか、ぼかす。史実に関わる記述は、本文には印を入れず、提出時の報告か決定ログに「要確認」として一覧で返す。

　暮れ六つの鐘が鳴り終わっても、おりくは店先の行灯に火を入れなかった。向かいの質屋の番頭が、暖簾の陰からこちらの戸口を見ている。客の懐を量るときと同じ、鼻の先を少し上げた見方だった。

- **lint** K15（のだった／のである）は語りの様式として例外宣言。G 群の禁止語彙を厚くする。神視点は文体シートに宣言する。視点の混在が事故か様式かは、冒頭から一貫しているかで決まる。
- **破ってよい場合** 伝奇や、意図して現代語で語る時代ものは、その方針を文体シートに書けば成立する。

### 青春

- **既定値** chapter_hook = optional / emotion_naming = balanced
- **約束** 小さな世界の大きな問題。期限（卒業、大会、引っ越し、夏の終わり）があり、取り返しがつかない。

**LLM が外しやすい点**
- 喧嘩が同じ場面のうちに相互理解に着く。結末で成長を言葉にして総括する。
- 大人が愚か者か、何でも分かっている賢者になる。
- 舞台と小道具が、青春ものと聞いて最初に浮かぶ場所と季節の景物に寄る。流行語や実在サービス名は数年で腐る。

**こう書く**
- 対立は最低でも次の場面まで持ち越す。和解は出来事か物のやり取りで起こし、言葉で説得させない。
- 変化は、できなかったことを一つ、黙ってやることで見せる。変わらなかった、悪くなった、も結末として正規。
- 大人には大人の事情を 1 行与える。舞台は実在の土地の具体（バスの本数、部室の備品、方言の濃さ）から組む。

- **keep 候補** 一人称の自意識の饒舌／仲間内の呼び名と内輪の言い回しの反復。
- **lint** K07 は一人称の内心語りなら例外宣言。O 群で結びが希望・前進の型と出たら、最終段落を削って成立するか試す。
- **破ってよい場合** 期限の無い日常ものは、promise を「毎話の小さな体験」で定義し直す。

### ライト文芸

- **既定値** chapter_hook = optional（各話完結＋全体の縦軸）/ emotion_naming = balanced
- **約束** 各話で小さな謎と感情が片づき、読後感が保証される。お仕事・あやかし・料理などの知識の楽しみが 1 話に 1 つ。全体を縦軸が貫く。

**LLM が外しやすい点**
- 蘊蓄が説明台詞になる。店主や探偵役が何でも見抜く賢者になり、ゲストは一度の会話で諭されて救われる。説得に応じる利害や価値観が示されていないと、変化が唐突になる。
- 毎話が同じ骨組み（来店 → 悩みの告白 → 一品 → 涙 → 解決）で、3 話目には展開が読める。縦軸を忘れる。

**こう書く**
- 知識は、人物がそれを使って何かをする動作の中で出す。
- ゲストを動かす出来事・物・言葉を、その人の利害や価値観に結びつける。レギュラーにも小さな卑しさと見当違いを与える。
- 各話で入口（誰の視点から入るか）、謎の種類、結びの型を変え、`canon/endings.log` に記録する。縦軸は毎話 1 行ぶんだけ進める。

- **keep 候補** 店の決まり文句／料理や道具の正式名の反復／各話の結びの定位置（閉店、暖簾、帰り道）。契約があっても直す: 定位置の結びに感慨のまとめを添えること。定位置は像で足りる。
- **lint** D01 は会話寄りで可。役割語は 2 人まで。
- **破ってよい場合** 長編一本立てのライト文芸は、構成を structure.md の長編の型に従わせる。

### 純文学寄り

- **初期候補** chapter_hook = off / emotion_naming = restrained。選んだ約束に応じて balanced・direct も使う。
- **約束（選ぶ）** 抑制と余白／饒舌な内面／語りによる批評／言葉や構成の実験。語りの声と読者に渡す体験を決める。

**LLM が外しやすい点**
- 余白のつもりで材料を渡さずに黙る。材料の無い沈黙は欠落として読まれる。
- 詩的な抽象語で飾る。最後に主題を言う。何も起きないことに不安になって事件を足す。「転」を対立の激化として書く。
- 全段落が同じ密度と温度で整い、語り手の偏りが消える。

**こう書く**
- 結びの開閉は約束に合わせる。省略するなら、読者が埋める手がかりを渡す。明言や総括も、語り手の声や批評として働けば選べる。
- 語り手に偏りを与える（何を見ないか、何を言い換えるか、どこで話を逸らすか）。声は判断と選択に出る。
- 「転」は別の要素が入って、それまでの意味が変わること。対立が無くても成立する。
- 結末は 3 案出して選び、最終段落を削って成立するなら削る。

- **keep 候補** 長い段落と長い文（饒舌体の宣言）／意図した単調な文末（喪、解離）／語り手の偏愛語（文体シートに記載）／開いた結び。
- **lint** P01（段落長）と L03（長文）は文体として例外宣言。R01 は意図した単調に限って例外宣言。D01 は下限を見ない。O 群は定型的な冒頭・結びの表現を INFO で示すだけで、結びの開閉は判定しない。
- **選択肢** 筋の強い文芸エンタメは entertainment の既定も参照し、結びは語りの声に合う手段で着地させる。

### Web 系テンプレと通俗短編

- **既定値** chapter_hook = required（引きの型に「余韻」を含む。型は structure.md）/ emotion_naming = direct
- **約束** タイトルとあらすじが約束した快楽を、早く、繰り返し渡す。テンプレは読者との契約書として働く。

**LLM が外しやすい点**
- テンプレを恥じて文芸調へ寄せ、約束の快楽を薄める。
- 悪役を改心させ、和解させ、結びで説教する。主人公が謙虚すぎて見返しが不発に終わる。
- 導入が長い。報いが加害と釣り合わない（過剰か、不発）。名指しのあとに汎用の身体反応を重ねる。

**こう書く**
- **思い出させる。** 更新間隔を挟んだ読者のために、再登場時は今回の行動に必要な関係と未解決の用件だけを短く戻す。既出でも新しい判断の材料なら削らない。例:「昨日、契約書を持ち帰った客が、今度は母親を連れて来た」。ai-tells.md §8.5 が削るのは、判断に役立たない再紹介。
- 導入は圧縮する（転生・追放の経緯は第 1 話のうちに）。序盤の早い回で、約束の快楽を一度実演する。ストレス展開は早めに解消し、長く続けるなら予告する。
- 見返しの快楽の正体は、人間関係の変化。設計の問いは「この一撃で、誰の主人公への態度が変わったか」。
- 悪は小さく具体的に書く（金額、物、ひと言）。悪人の台詞には「あなたのため」「しきたり」「家族」の糖衣をかぶせる。清算は証拠と規則で行い（罵倒させない）、報いは加害と対応させて短く描く。前半の加害を控えておき、同じ場所、同じ台詞、攻守が逆、で返す。
- 感情の名指しは売りになる。残すか削るかは一問で決まる。**その文は主人公の今の主観を帯びているか。** 名指しの直後には場面固有の物か動作を接ぎ、一つの感情は一度だけ書く。
- 甘さの積み増しや因果応報が売りの型は、無理に反転を入れない（反転なし、も設計の選択肢）。ステータス表示は 1 話に一度、短く。作品に無い要素のタグは付けない。
- 掲示板回・配信コメント回は反応に層を作る（通りすがりの驚き → 詳しい者の分析 → 立場のある者の反応）。同じ温度の書き込みを並べない。
- 公募に出すなら、Web テンプレそのままは既視感で落ちやすい。突出点を 1 文で言えるようにしてから出す。

　悔しかった。三年間、毎晩この帳簿をつけてきたのは私だ。遠征のたびに干し肉の数を合わせ、団長が酔って割った宿の窓の弁償まで、銅貨一枚の単位で記してある。その帳簿を、団長は中も見ずに暖炉へ放った。
「計算係なんて誰でもできる」
　表紙が反り返って燃えていく。来月の頭には、北の商会へ払う手形の期日が三本重なっている。それを知っているのは、この部屋で私だけだった。

名指しのあとに新しい事実が続き、結びは主人公の手札で開いている（語り手の予告で閉じていない）。

- **keep 候補** 感情の直書き／主人公の主観を帯びた断罪と決め台詞／長文タイトルに対応する約束の反復／一文段落の多い画面設計／擬音の単独行（1 話に一度）／掲示板回・配信コメント回の様式。契約があっても直す: 具体を伴わない感情の総括、人物の主観と無関係な中立の解説、哲理めいた結び、同型の引きの連続。
- **lint** K08 のヒットは、上の一問を通れば keep。K09 と「名指しの直後に具体が続かない文」は見る。P03・P04（一文段落）は web プロファイルの線で見る。O 群の予告型の結びは、通俗短編では主人公の主観を帯びていれば keep。様式回は D02（純台詞の連続発話数）を例外宣言する。
- **破ってよい場合** 文芸寄りの読者層を狙う Web 作品は、profile は web のまま emotion_naming だけ balanced に下げる。

### 児童向け

- **既定値** chapter_hook = optional / emotion_naming = direct（名指しは読解の助けになる）
- **約束** 子どもの目の高さで世界が見え、安心して読み終えられる。

**LLM が外しやすい点**
- 教訓で締める。違いを認め合う式の総括を大人か語り手に言わせる。成長を言葉にする。
- 子どもが大人の理屈と語彙で話す。抽象語が混じる。説明が多い。
- 「安心」を「全部解決」と取り違える。

**こう書く**
- 出来事は具体物と動作で運ぶ。一文は短くてよいが、因果は切らない。繰り返しとオノマトペは、この読者にとって読む快楽そのもの。
- 教訓は言わない。結末の安心は、帰る場所があることで足りる。
- 対象学年、漢字の範囲、分かち書き、敬体か常体か、会話の閉じ括弧前の句点の流儀は、版元・応募先の規定かユーザーに確認する。

　げんたは、きゅうしょくぶくろをふりまわしながら帰った。ふくろの中で、はしばこがかたかた鳴る。きょう、はしばこにはダンゴムシが三びき入っている。おかあさんには、まだ言っていない。

- **keep 候補** 繰り返しの構造と決まり文句／感情の名指し／オノマトペ／敬体の語り。
- **lint** K08、K10（情緒副詞）、S01（直喩）は童話調として例外宣言可。L02（平均文長の下限）は短文基調を宣言する。R01 は敬体と判定された語りに自動で緩い線を使う。閉じ括弧前の句点を規定や作者の流儀として残すなら、`style/lint.json` の overrides に `{"N04": {"off": true, "reason": "閉じ括弧前の句点を用いる流儀"}}` と書き、作品内で統一する。
- **破ってよい場合** 高学年以上の読み物は一般の青春・ファンタジーの契約に寄せ、語彙と漢字だけ規定に合わせる。

### コメディ

- **既定値** chapter_hook = optional / emotion_naming = balanced
- **約束（選ぶ）** 真顔の語り／饒舌な語りと自分へのツッコミ／人物間の温度差など、笑いの仕組みを決める。
- **LLM が外しやすい点** 語り手が笑いを解説する。感嘆符で押す。全員がボケとツッコミを等分に受け持つ。オチのあとに温かいまとめを置く。抑えた観察の文体で淡々と運んでしまい、依頼の核の動き（空回りする、食い違う、どんどん大ごとになる）が大きくならない。
- **こう書く** 選んだ笑いの仕組みを、語りの調子と人物の応答で働かせる。空回りや食い違いは、一度で終わらせず、手を打つたびに事態が一段ずれていくように重ねる（対策 → 裏目 → もっと大げさな対策 → もっと裏目）。語り手自身が笑い、脱線し、自分にツッコむ形も使える。生死や喪失で軽口を使うかは、人物の関係と作品が約束する笑いの質から決める。
- **keep 候補と lint** 記号的な口癖、決まった応酬の反復、一人称の軽口。声シートに登録した口癖へのヒットは keep。地の文の感嘆符は、一人称コメディなら文体シートに宣言する。

## 5. ジャンル読者への問い

レビューでジャンル読者役を立てるとき（運用は review-protocol.md）、その役に渡す問いはここから 1〜2 個選ぶ。渡すのは本文とジャンル名だけで、契約の文面は見せない。約束が本文だけから伝わったかを測るため。答えは引用つきで返してもらい、点数は訊かない。通俗短編やテンプレ作品を、文芸の読者の基準で裁かせない。

| ジャンル | 問い |
|---|---|
| ミステリ | 解決の前に自分でも当てられたと思うか。後出しだと感じた証拠はどれか |
| ホラー・怪談 | 読後に残った像は何か。説明されて怖さが引いた行はどこか |
| 恋愛 | この二人が惹かれ合う理由を、場面を挙げて言えるか。いつまでも結ばれないことに苛立った箇所はどこか |
| SF | この世界の嘘は何だったか。説明を読まされたと感じた段落はどこか |
| ファンタジー・異世界 | 主人公に出来ないことは何か。都合よく強くなったと感じた箇所はどこか |
| 時代小説 | 現代の言葉や考え方に引き戻された行はどこか |
| 青春 | 期限は何だったか。和解や成長が早すぎると感じた箇所はどこか |
| ライト文芸 | この話で覚えた知識は何か。次の話の展開が読めたか |
| 純文学寄り | 何の話だったかを 200 字で再話する。語り手はどんな人だと感じたか |
| Web 系テンプレ・通俗短編 | タイトルが約束したものを受け取ったか。次の話を読むか。やめるならどの行でやめるか |
| 児童向け | 大人が喋っていると感じた行はどこか。読み終えて安心できたか |
| コメディ | 笑った行はどこか。笑えと言われた気がした行はどこか |
